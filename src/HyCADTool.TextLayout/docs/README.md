# HyCADTool.TextLayout 文档

HyCADTool.TextLayout 是什么：HyCAD（本仓库 AutoCAD 插件）里的文字排版程序集，作用是把 Markdown（轻量标记原文）算成分页分栏结果，并生成 MText（AutoCAD 多行文字格式码）字符串。本文档只服务该程序集。

## 使用方法

- 说「**更新日志 / 更新文档**」→ AI 更新 03（及有变化的 01/02/04/05）；**不**改 06；对话结束不自动写
- 说「**记经验 / 踩坑记录**」→ AI 追加写入 05（先过判定门槛，不新建平行文件）
- 说「**生成帮助 / 更新帮助**」→ 写/改 06（不随更新日志自动改）
- 说「**初始化文档**」→ 只建 5 目录 + 6 文件一句话占位（不含 06；06 首次「生成帮助」时再建）
- 说「**压缩文档 / 精简文档**」→ 清理 Learning/Research/Plan/Evaluations 中已脱离核心文档的旧文件（不删活跃 00）
- 为了懂 → 写入 `Learning/`
- 为了选 → 写入 `Research/`
- 说「**总体计划 / 00 计划 / 全局视野**」→ 写/改 `Plan/00-….md`（≤200 行，细节下沉）
- 阶段设计 / 执行计划 → 写入 `Plan/` 编号文件
- 评估结案 → 写入 `Evaluations/`
