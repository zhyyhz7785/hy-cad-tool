# 启动与测试

本程序集无独立可执行文件、无浏览器界面；日常只编库，联调随 `HyCADTool` 插件走，发行随主工程 Production 出包。**已验证**（csproj 为 class library）。

| 项 | 版本/要求 |
|---|---|
| .NET SDK | 能编译 netstandard2.0（仓库其它文档写 ≥ 8.0） |
| 工作目录 | `E:\Code\hy-cad-tool` |
| 联调宿主 | AutoCAD 2025 + 主工程 `src\HyCADTool\HyCADTool.csproj`（net48） |
| 本库单测 | 无测试工程 |

## 首次启动

在仓库根还原并只编本库：

```powershell
cd E:\Code\hy-cad-tool
dotnet restore src\HyCADTool.TextLayout\HyCADTool.TextLayout.csproj
dotnet build src\HyCADTool.TextLayout\HyCADTool.TextLayout.csproj -c Debug
```

成功标志：退出码 0，出现 `HyCADTool.TextLayout ->` 输出路径。首次还原视网络浮动，保守 **1–5 分钟**（**待验证**，本轮未实测）。

## 日常测试

开发态编译本库；没有 `dotnet test` 目标。改排版后若要进 CAD，再编主工程。

```powershell
cd E:\Code\hy-cad-tool
dotnet build src\HyCADTool.TextLayout\HyCADTool.TextLayout.csproj -c Debug
dotnet build src\HyCADTool\HyCADTool.csproj -c Debug
```

成功标志：两步均为 0。仅编本库通常 **不到 1 分钟**（**待验证**）。主工程可能因 AutoCAD 引用或文件锁更久。

本库无单元测试命令。无此环节的替代：编译通过只能说明语法与引用正确，不能证明估高/分栏。**已验证**（检索无 TextLayout 测试 csproj）。

## 完整打包

本库不单独打安装包。客户包路径是主工程 Production，会带上 `HyCADTool.TextLayout.dll` 与 `Markdig.dll`。旧文档曾写 `HyCADTool.Refactored`；现工程名为 `HyCADTool`。**已验证**（`HyCADTool.csproj` 的 Production 说明与 ProjectReference）。

```powershell
cd E:\Code\hy-cad-tool
dotnet build src\HyCADTool\HyCADTool.csproj -c Production
```

成功标志：退出码 0；输出目录含 `HyCADTool.dll` 与 `HyCADTool.TextLayout.dll`。全量编主工程保守 **5–20 分钟**，视机器与还原浮动（**待验证**）。

## 验收步骤

1. `dotnet build` 本库 csproj，退出码 0。
2. （可选）编 `HyCADTool` Debug，确认输出目录出现 `HyCADTool.TextLayout.dll`。
3. 图面验收不属本库单测：AutoCAD 中 `hymd` 绑定 HyMd 后「贴到图纸」，核对说明是否按纸面坐标落 MText。该步验证的是宿主贴图，不是 `LayoutEngine`。**已验证**（读 `InsertFromHyMdDump`）。
4. 若要验收本库分页：需走仍调用 `LayoutEngine.Distribute` 的路径（当前为 `EditorLoader` 回退，命令已不调用）。**已验证**。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 改了本库 CAD 无变化 | 未编主工程或未重载插件 | 先编 `HyCADTool`，再按宿主热重载流程加载 |
| 贴图分页与本库估高不一致 | `hymd` 用 HyMd 导出坐标 | 改 HyMd 几何或旧 `Insert`+`LayoutResult` 路径，不要只改 `LayoutEngine` 指望贴图变 |
| 找不到测试 | 无测试工程 | 不要执行 `dotnet test` 本目录 |
| dll 被锁 | AutoCAD 已加载 | 关 CAD 或按主工程文件锁处理后再编 |
