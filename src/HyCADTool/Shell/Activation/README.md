## 定位（对照总纲 §三）

**许可/激活** 的独立 WPF 窗口宿主：与业务命令分离，由许可流程打开。

## 职责边界

| 属于本目录 | 不属于本目录 |
|------------|----------------|
| `ActivationWindow`（XAML + code-behind） | 具体 Feature 的付费逻辑 → `Licensing` 或 `Features` |
| 仅 UI 层展示与事件 | 持久化机密密钥的落地策略 → 单独安全审查 |

## 目录结构

- `ActivationWindow.xaml` / `.xaml.cs`：激活/许可相关对话框。

## 命令与入口

本目录**无**独立 `commands.json` 键；由许可相关命令或启动流程在运行时打开窗口（以实际调用点为准）。

## 依赖与协作

- **许可模型**：`../Licensing/` 门闸、档位与命令映射配合使用。
- **主题**：与全局 WPF 初始化一致，局部资源合并（见 `../Resources/`、总纲 WPF 约定）。
