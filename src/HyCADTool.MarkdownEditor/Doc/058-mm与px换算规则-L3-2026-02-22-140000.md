# mm 与 px 换算规则 — L3 详解

> 图纸面板以毫米（mm）为逻辑单位，屏幕渲染以像素（px）为单位。本文档说明换算公式、执行位置及参数映射。

---

## 一、核心公式

```
px = mm × PreviewScale
mm = px / max(0.01, PreviewScale)
```

- **PreviewScale**：预览缩放，范围 0.1～5.0，默认 1.0
- **方向**：C# → HTML/JS 时用 mm×scale；JS 回传 C# 时用 px/scale

---

## 二、换算执行位置

| 位置 | 文件 | 方法/作用 | 方向 |
|------|------|-----------|------|
| C# 注入 CSS | `PreviewHtmlRenderer.cs` | `ToFlowExperienceHtml`、`BuildDynamicCss` | mm → px |
| C# 注入 JS | `PreviewHtmlRenderer.cs` | `ToFlowExperienceHtml`、`BuildDynamicJs` | mm → px |
| JS 回传 | `PreviewHtmlRenderer.cs`（flowJsTemplate） | `getPaperState()`、拖拽 `mousemove` | px → mm |
| 缩放控制 | `PreviewManager.cs` | `ApplyPreviewScaleStep`、`FitPaperToPreviewArea` | 更新 PreviewScale |

## 三、参数映射表（mm → px）

### 3.1 纸张与边距（ToFlowExperienceHtml / BuildDynamicCss）

| 配置项（mm） | 输出 token / 变量 | 公式 | 默认 mm | 最小值 |
|--------------|------------------|------|---------|--------|
| `PageWidthMm` | `FLOW_PAPER_WIDTH` / `PAPER_WIDTH` | `Round(mm × scale)` | 594 | 180px |
| `PageHeightMm` | `FLOW_PAPER_HEIGHT` / `PAPER_HEIGHT` | `Round(mm × scale)` | 420 | 180px |
| `MarginLeftMm` | `FLOW_PAD_LEFT` / `PAD_LEFT` | `Round(mm × scale)` | 25 | 0 |
| `MarginRightMm` | `FLOW_PAD_RIGHT` / `PAD_RIGHT` | `Round(mm × scale)` | 10 | 0 |
| `MarginTopMm` | `FLOW_PAD_TOP` / `PAD_TOP` | `Round(mm × scale)` | 10 | 0 |
| `MarginBottomMm` | `FLOW_PAD_BOTTOM` / `PAD_BOTTOM` | `Round(mm × scale)` | 10 | 0 |
| `ColumnGutter` | `FLOW_GAP_PX` / `COLUMN_GAP` | `max(6, Round(mm × scale))` | 5 | 6px |
| `ColumnInnerPaddingMm` | `FLOW_CONTENT_PAD_PX` / `CONTENT_PAD_X` | `Round(mm × scale)` | 5 | 0 |

### 3.2 边框与手柄（仅 Flow）

| 配置项 | 输出 token | 公式 | 说明 |
|--------|------------|------|------|
| `BorderWidth` | `FLOW_BORDER_WIDTH` | `clamp(0.5, 5)`，不乘 scale | 边距引导线宽 |
| `HandleWidth` | `FLOW_HANDLE_WIDTH` | `clamp(1, 10)`，不乘 scale | 栏顶/底手柄高度 |
| `HandleActiveWidth` | `FLOW_HANDLE_ACTIVE_WIDTH` | `clamp(handleWidth, 14)` | 悬停时手柄高度 |

### 3.3 字体与排版

| 配置项 | 输出 token | 公式 | 说明 |
|--------|------------|------|------|
| `TextSize` | `FLOW_BASE_FONT_SIZE` / `BASE_FONT_SIZE` | `textSizeMm × scale` | 正文字号 px |
| `ListIndent` | `LIST_INDENT` | `max(8, ListIndent × DrawScale × scale)` | 列表缩进 px |
| `QuoteIndent` | `QUOTE_INDENT` | `max(8, QuoteIndent × DrawScale × scale)` | 引用缩进 px |

### 3.4 表格样式（mm 常量 → px）

| 逻辑值（mm） | 输出 token | 公式 | 说明 |
|--------------|------------|------|------|
| 0.25 | `FLOW_TABLE_BORDER_PX` / `TABLE_BORDER_PX` | `max(0.5, 0.25 × scale)` | 表格线宽，极细 |
| 0.5 | `FLOW_TABLE_PAD_Y` / `TABLE_PAD_Y` | `max(1, Round(0.5 × scale))` | 单元格上下内边距 |
| 1.0 | `FLOW_TABLE_PAD_X` / `TABLE_PAD_X` | `max(1, Round(1.0 × scale))` | 单元格左右内边距 |

## 四、JS 侧 px → mm 回传

`getPaperState()` 返回给 C# 的 mm 值：

```javascript
pageWidthMm   = PAPER_WIDTH   / Math.max(0.01, PREVIEW_SCALE)
pageHeightMm  = PAPER_HEIGHT  / Math.max(0.01, PREVIEW_SCALE)
marginLeftMm  = MARGIN_LEFT   / Math.max(0.01, PREVIEW_SCALE)
marginRightMm = MARGIN_RIGHT  / Math.max(0.01, PREVIEW_SCALE)
marginTopMm   = MARGIN_TOP    / Math.max(0.01, PREVIEW_SCALE)
marginBottomMm= MARGIN_BOTTOM / Math.max(0.01, PREVIEW_SCALE)
```

拖拽纸张/边距时，JS 用 `PREVIEW_SCALE` 将当前 px 转回 mm 后通过 `paperState` 消息回传。

## 五、关键方法详解

### 5.1 ToFlowExperienceHtml（PreviewHtmlRenderer.cs）

- **输入**：markdown、columnCount、previewScale、config
- **处理**：
  1. `scale = clamp(previewScale, 0.1, 5.0)`
  2. 纸张/边距/栏距：`Round(mm × scale)`
  3. 表格：`0.25×scale`、`Round(0.5×scale)`、`Round(1.0×scale)`，带 `max` 保底
  4. 通过 `.Replace("/*FLOW_*")` 注入 flowCssTemplate、flowJsTemplate
- **输出**：完整 HTML 字符串
- **调用链**：`PreviewManager.RefreshPreviewAsync` → `ToFlowExperienceHtml`

### 5.2 BuildDynamicCss（PreviewHtmlRenderer.cs）

- **输入**：previewScale、cfg
- **处理**：
  1. 纸张/边距/栏距：`Round(mm × previewScale)`
  2. 列表/引用缩进：`max(8, mm × DrawScale × previewScale)`
  3. 表格：同上 3.4 节
  4. 通过 token 数组替换 `CSS_TEMPLATE`
- **输出**：动态 CSS 字符串
- **调用链**：`ToInteractiveHtml`（或等价入口）→ `BuildDynamicCss`

### 5.3 Round 函数

- **用途**：将浮点 px 四舍五入为整数，避免亚像素渲染差异
- **位置**：`PreviewHtmlRenderer` 内部静态方法
- **注意**：表格线宽使用 `Math.Max(0.5, ...)` 保留小数，支持 0.5px 细线

## 六、PreviewScale 来源与约束

| 来源 | 文件 | 行为 |
|------|------|------|
| 默认值 | `EditorConfigDefaults.PreviewScale` | 1.0 |
| 设置面板 | `SettingsPanelControl.xaml` | 双向绑定 `PreviewScale` |
| Ctrl+滚轮 | `EditorWindow.xaml.cs` | `ApplyPreviewScaleStep(vm, delta/120)` |
| 自适应宽度 | `PreviewManager.FitPaperToPreviewArea` | `0.9 × areaWidth / PageWidthMm`，clamp [0.1, 5.0] |
| 约束 | `ApplyPreviewScaleStep` | `cur × 1.06^step`，clamp [0.1, 5.0] |

---

## 七、换算规则汇总

| 规则 | 描述 |
|------|------|
| 统一乘数 | 所有 mm 进入 HTML/JS 前乘以 `PreviewScale` |
| 回传除算 | JS 回传 mm 时除以 `max(0.01, PREVIEW_SCALE)` |
| 保底像素 | 栏间距 ≥6px；表格 padding ≥1px；border ≥0.5px |
| 缩进保底 | 列表/引用缩进 ≥8px |
| 纸张最小 | 拖拽时 `PAPER_WIDTH/HEIGHT ≥ 180px` |
