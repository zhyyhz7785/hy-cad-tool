# HyCADTool.MarkdownEditor — L1 架构总览

> 生成时间：2026-02-15

---

## 项目定位

独立的 WPF Markdown 所见即所得编辑器，由 AutoCAD 插件主项目**反射调用**，接收 JSON 输入（Markdown 文本 + 排版配置），弹出模态编辑窗口，用户编辑/预览后返回编辑结果的 JSON。核心用途：在 AutoCAD 环境中编辑设计说明文档，预览分栏排版效果。

---

## 技术栈

| 项 | 值 |
|---|---|
| 框架 | .NET 8.0 WPF (`net8.0-windows`) |
| WebView2 | 1.0.3065.39（Vditor 富文本编辑 + 分栏预览） |
| Markdig | 0.37.0（Markdown → HTML 解析） |
| Newtonsoft.Json | 13.0.3（JSON 序列化） |
| 输出 | 类库，输出到 `HyCADTool.Refactored/bin/$(Configuration)/net8/` |
| 调用 | `EditorLauncher.ShowDialog(inputJson, ownerHandle)` |

## 模块关系图

```
EditorLauncher（静态入口，反射调用点）
  → EditorWindow（主窗口，组装所有控件）
      → EditorViewModel（双向数据绑定，参数/状态管理）
      → Views/Controls/
      │   ├─ TitleBarControl（标题栏 + 窗口控制）
      │   ├─ LeftPanelControl（文件树面板）
      │   ├─ PreviewPanelControl（WebView2 分栏预览）
      │   ├─ BottomPanelControl（底部参数调节面板）
      │   └─ RulerControl（标尺控件）
      → Views/Themes/EditorTheme.xaml（全局主题资源）
      → Html/
      │   ├─ VditorHtmlTemplate（生成 Vditor 编辑器 HTML）
      │   ├─ VditorJsHelper（C#↔JS 双向通信）
      │   ├─ VditorCacheManager（Vditor CDN 资源本地缓存）
      │   └─ PreviewHtmlRenderer（Markdig 渲染分栏预览 HTML）
      → Services/
      │   ├─ FileTreeService（文件树读取/排序/过滤）
      │   ├─ ThemeManager（亮/暗主题切换）
      │   ├─ PreviewManager（预览刷新调度 + 统计回收）
      │   └─ LeftPanelStateService（左面板展开/折叠状态持久化）
  → Models/EditorContract（EditorInput / EditorResult / EditorConfig / PreviewStats）
  → Models/FileSortMode（文件排序枚举）
```

---

## 数据流

```
主项目（AutoCAD 插件）
  │ 反射调用
  ▼
EditorLauncher.ShowDialog(inputJson, ownerHandle)
  │ JSON → EditorInput 反序列化
  ▼
EditorWindow(input) → ShowDialog()
  │ EditorInput.Markdown → Vditor 编辑器（WebView2）
  │ EditorInput.Config → BottomPanelControl 参数面板
  │                     → PreviewHtmlRenderer 分栏预览
  │
  │  用户编辑循环:
  │  Vditor ──JS回调──→ EditorViewModel.SetMarkdownFromEditor()
  │  参数变更 ──绑定──→ PreviewManager 刷新预览
  │  预览JS ──统计──→ PreviewStats 回传
  │
  ▼ 用户点击确认/取消
EditorResult { Confirmed, Markdown, Config, CharsPerColumn, PreviewStats }
  │ JSON 序列化
  ▼
返回给主项目
```

## 模块一句话速查表

| 模块 | 一句话职责 |
|------|-----------|
| `EditorLauncher.cs` | 静态入口，JSON 反序列化 → 创建窗口 → JSON 序列化返回 |
| `Models/` | 数据契约：输入(EditorInput)、输出(EditorResult)、配置(EditorConfig)、预览统计(PreviewStats)、文件排序枚举 |
| `ViewModels/` | 唯一 ViewModel（EditorViewModel），管理所有可调参数、Markdown 文本、状态栏、命令绑定 |
| `Views/` | 主窗口 + 5 个子控件 + 主题 XAML，负责布局与用户交互 |
| `Html/` | Vditor 编辑器 HTML 模板生成、C#↔JS 桥接、CDN 缓存、Markdig 分栏预览渲染 |
| `Services/` | 文件树管理、亮暗主题切换、预览刷新调度、左面板状态持久化 |
| `RegressionSamples/` | 10 个 .md 测试样本 + manifest.json，用于预览渲染回归测试 |
