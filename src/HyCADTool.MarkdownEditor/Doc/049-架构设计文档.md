# HyCADTool.MarkdownEditor — 架构设计文档

## 1. 整体架构

### 1.1 架构模式

项目采用 MVVM（Model-View-ViewModel）架构，辅以服务层（Services）和 HTML 渲染层（Html），形成五层结构：

```
┌─────────────────────────────────────────────────────┐
│                   EditorLauncher                     │  反射入口层
│              (对外唯一 API 入口)                      │
├─────────────────────────────────────────────────────┤
│                                                     │
│   Views/                    Html/                   │  视图 & 渲染层
│   ├─ EditorWindow           ├─ VditorHtmlTemplate   │
│   ├─ TitleBarControl        ├─ PreviewHtmlRenderer  │
│   ├─ LeftPanelControl       ├─ VditorJsHelper       │
│   ├─ PreviewPanelControl    └─ VditorCacheManager   │
│   ├─ SettingsPanelControl                           │
│   └─ RulerControl                                   │
│                                                     │
├─────────────────────────────────────────────────────┤
│                   ViewModels/                        │  状态管理层
│   ├─ EditorViewModel (主 ViewModel)                  │
│   ├─ EditorContentViewModel                         │
│   ├─ PreviewConfigViewModel                         │
│   └─ UIStateViewModel                               │
├─────────────────────────────────────────────────────┤
│                   Services/                          │  业务逻辑层
│   ├─ PreviewManager (预览调度核心)                    │
│   ├─ ThemeManager                                   │
│   ├─ FileTreeService                                │
│   └─ LeftPanelStateService                          │
├─────────────────────────────────────────────────────┤
│                   Models/                            │  数据契约层
│   ├─ EditorContract (Input/Result/Config/Stats)     │
│   └─ FileSortMode                                   │
└─────────────────────────────────────────────────────┘
```

### 1.2 双 WebView 架构

编辑器采用双 WebView2 实例的设计：

```
┌──────────────────────────────────────────────────────────┐
│                     EditorWindow                          │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐  │
│  │  LeftPanel    │  │ EditorWebView│  │ PreviewWebView │  │
│  │  ─────────   │  │  ──────────  │  │  ────────────  │  │
│  │  文件树       │  │  Vditor      │  │  分栏图纸预览   │  │
│  │  大纲         │  │  (IR 模式)   │  │  (HTML/CSS/JS) │  │
│  │  设置         │  │              │  │                │  │
│  └──────────────┘  └──────────────┘  └────────────────┘  │
└──────────────────────────────────────────────────────────┘
```

- **EditorWebView**：承载 Vditor 即时渲染编辑器，负责 Markdown 编辑
- **PreviewWebView**：承载分栏图纸预览 HTML，负责排版预览与交互

两个 WebView 通过 `EditorViewModel.MarkdownText` 作为中间状态进行同步，由 `EditorWindow` 协调防止回环。

## 2. 模块详解

### 2.1 入口层 — EditorLauncher

```
主项目 (HyCADTool.Refactored)
    │
    │  反射调用
    ▼
EditorLauncher.ShowDialog(inputJson, ownerHandle)
    │
    │  反序列化 EditorInput
    │  创建 EditorWindow
    │  设置父窗口 (HWND)
    │  ShowDialog()
    │
    ▼
EditorResult (JSON) ──→ 返回主项目
```

职责：
- 提供 `ShowDialog`（模态）和 `ShowNonModal`（非模态）两种调用方式
- 管理非模态窗口的生命周期（线程安全，lock 保护）
- 维护同步回调（`manualSyncCallback` / `liveSyncCallback`）
- JSON 序列化/反序列化桥接

### 2.2 视图层 — Views

#### EditorWindow（主编排层）

EditorWindow 是整个编辑器的核心编排节点，职责包括：

1. **WebView2 生命周期管理**：初始化双 WebView、加载 HTML 模板
2. **双向同步协调**：编辑器 → 预览、预览 → 编辑器，防回环
3. **面板布局管理**：大纲/预览/底部面板/标尺的显隐切换
4. **防抖调度**：预览刷新 220ms、AutoCAD 同步 900ms
5. **工作区模式**：写作模式 / 排版模式 / 校对模式

```
EditorWindow 事件流：

Loaded ──→ InitWebView2 ──→ LoadVditorHtml ──→ VditorReady ──→ RefreshPreview
                                                                      │
用户编辑 ──→ Vditor input ──→ postMessage ──→ C# 接收 ──→ 更新 ViewModel
                                                              │
                                                    220ms 防抖 ──→ RefreshPreview
                                                              │
                                              900ms 防抖 ──→ LiveSync to AutoCAD
```

#### 控件层级关系

```
EditorWindow
├── TitleBarControl          菜单栏 + 工具栏 + 窗口控制
│   ├── 文件/编辑/段落/格式/主题/视图 菜单
│   ├── 状态文本
│   └── 标尺/大纲/预览 切换按钮
├── LeftPanelControl         左侧面板（可折叠）
│   ├── 文件选项卡           TreeView 文件树
│   ├── 大纲选项卡           ListBox 标题列表
│   └── 设置选项卡           SettingsPanelControl
├── EditorWebView            Vditor 编辑器
├── PreviewPanelControl      预览面板（可折叠）
│   ├── 工具栏               页面预设/方向/栏数/分页
│   ├── RulerControl (H)     水平标尺
│   ├── RulerControl (V)     垂直标尺
│   └── PreviewWebView       图纸预览
└── BottomPanelControl       底部面板（占位）
```

### 2.3 ViewModel 层

#### EditorViewModel（主 ViewModel）

作为整个编辑器的状态中心，管理 40+ 个可绑定属性：

```
EditorViewModel
├── 内容状态
│   ├── MarkdownText          当前 Markdown 文本
│   ├── CurrentFilePath       当前文件路径
│   └── DialogConfirmed       对话框确认标志
│
├── 排版参数（双向绑定到 UI）
│   ├── DrawScale / PreviewScale
│   ├── TextSize / TextXScale
│   ├── ColumnCount / ColumnGutter / CharsPerColumn
│   ├── PagePreset / PageWidthMm / PageHeightMm / IsLandscape
│   ├── MarginLeftMm / MarginRightMm / MarginTopMm / MarginBottomMm
│   ├── H1/H2/H3 SpaceBefore / SpaceAfter
│   ├── PSpaceAfter / LiSpaceAfter / QuoteSpaceBefore / QuoteSpaceAfter
│   └── BorderWidth / HandleWidth / HandleActiveWidth
│
├── 命令
│   ├── LoadFileCommand       打开文件
│   ├── SaveFileCommand       保存文件
│   └── EditorActionCommand   编辑器操作（撤销/加粗/插入表格等）
│
└── 方法
    ├── BuildConfig()         序列化当前状态为 EditorConfig
    ├── ResetLayoutDefaults() 恢复默认排版参数
    └── SetMarkdownFromEditor() 从编辑器更新文本（不触发回环）
```

#### ViewModel 拆分策略

| ViewModel | 职责 | 说明 |
|-----------|------|------|
| EditorViewModel | 主状态 + 命令 | 聚合所有子 ViewModel |
| EditorContentViewModel | 内容管理 | MarkdownText + CurrentFilePath + 变更事件 |
| PreviewConfigViewModel | 预览参数 | 纯数据持有，无逻辑 |
| UIStateViewModel | UI 状态 | StatusText + DialogConfirmed |

### 2.4 服务层 — Services

#### PreviewManager（预览调度核心）

PreviewManager 是预览系统的大脑，负责：

```
PreviewManager 职责：

1. 预览刷新
   MarkdownText 变更 ──→ 计算脏区块 ──→ 增量/全量刷新 ──→ 注入 HTML

2. 消息处理（来自 PreviewWebView JS）
   paperScale    ──→ 更新标尺缩放
   wheelZoom     ──→ 更新预览缩放
   pageState     ──→ 更新分页状态
   contentChanged──→ 回写 MarkdownText（去重）

3. 分页导航
   GoToPageAsync()   ──→ 跳转指定页
   ShiftPageAsync()  ──→ 前/后翻页

4. 自适应
   FitPaperToPreviewArea() ──→ 自动适配预览缩放
```

状态追踪机制：

```
_markdownVersion / _previewVersion    版本计数器，防止重复刷新
_dirtyBlockStart / _dirtyBlockEnd     脏区块范围，支持增量更新
_lastBlockSources                     上次区块快照，用于 diff 检测
_latestLayoutResult                   当前布局结果
_latestPreviewStats                   最新预览统计
```

#### 其他服务

| 服务 | 职责 |
|------|------|
| ThemeManager | 管理暗色/亮色主题，更新 ResourceDictionary 中的 20+ 个颜色画刷 |
| FileTreeService | 文件树 CRUD 操作：构建树节点、排序、创建/重命名/复制/删除 |
| LeftPanelStateService | 持久化左侧面板状态到 JSON（排序模式、最近目录列表，上限 12 条） |

### 2.5 HTML 渲染层 — Html

#### 渲染管线

```

```

## 3. 核心数据流

### 3.1 编辑 → 预览 数据流

```
用户在 Vditor 中编辑
    │
    ▼
Vditor input 事件 ──→ window.chrome.webview.postMessage()
    │
    ▼
EditorWindow.CoreWebView2_WebMessageReceived()
    │
    ▼
EditorViewModel.MarkdownText = newText
    │
    ▼
PropertyChanged 事件 ──→ 220ms DispatcherTimer 防抖
    │
    ▼
PreviewManager.RefreshPreviewAsync()
    │
    ├── 计算脏区块（diff _lastBlockSources）
    ├── 调用 PreviewHtmlRenderer 生成 HTML
    └── 注入 PreviewWebView
```

### 3.2 预览 → 编辑器 回写流

```
用户在图纸预览中编辑（Flow 体验模式）
    │
    ▼
JS contentChanged 消息 ──→ postMessage({ type: "contentChanged", markdown, version, hash })
    │
    ▼
PreviewManager.TryHandlePreviewWebMessage()
    │
    ├── 校验 hash 去重（防止回环）
    ├── 校验 version 递增
    └── 更新 ViewModel.MarkdownText
         │
         ▼
    EditorWindow 检测 _isUpdatingFromPreview 标志
         │
         └── VditorJsHelper.SetContentAsync() ──→ 同步到 Vditor
```

### 3.3 AutoCAD 同步流

```
方式一：手动同步（点击 "Sync CAD" 按钮）
    │
    ▼
EditorWindow ──→ BuildEditorResult()
    │
    ▼
EditorLauncher.RaiseLiveSync(resultJson)
    │
    ▼
manualSyncCallback(resultJson) ──→ 主项目处理

方式二：实时同步（900ms 防抖）
    │
    ▼
MarkdownText 变更 ──→ 900ms DispatcherTimer
    │
    ▼
EditorLauncher.RaiseLiveSync(resultJson)
    │
    ▼
liveSyncCallback(resultJson) ──→ 主项目处理
```

## 4. 设计模式与关键机制

### 4.1 使用的设计模式

| 模式 | 应用位置 | 说明 |
|------|----------|------|
| MVVM | ViewModel ↔ Views | 数据绑定驱动 UI 更新 |
| 观察者 | INotifyPropertyChanged / 自定义事件 | 跨组件通信 |
| 命令 | RelayCmd / AsyncRelayCmd | 工具栏与菜单命令绑定 |
| 外观 | EditorLauncher | 对外隐藏内部复杂性 |
| 策略 | Flow 模式 / 传统模式 | 可切换的预览渲染策略 |
| 附加行为 | TextBoxHelper | 非侵入式增强 TextBox |

### 4.2 防回环机制

双 WebView 架构中，编辑器和预览之间的双向同步容易产生无限循环。项目采用多层防护：

1. **版本计数器**：`_markdownVersion` / `_previewVersion`，仅当版本递增时才处理
2. **文本哈希**：`contentChanged` 消息携带 hash，与当前文本比对去重
3. **标志位**：`_isUpdatingFromPreview` 标志，阻止回写时触发正向刷新
4. **防抖定时器**：220ms 延迟合并高频变更

### 4.3 增量更新机制

PreviewManager 通过区块级 diff 实现增量预览更新：

1. 将 Markdown 按空行分割为区块（blocks）
2. 与 `_lastBlockSources` 快照逐块比对
3. 记录 `_dirtyBlockStart` / `_dirtyBlockEnd` 脏区范围
4. 仅重新渲染脏区块，减少 DOM 操作

### 4.4 主题系统

ThemeManager 通过修改 WPF ResourceDictionary 中的 SolidColorBrush 实现主题切换：

```
ThemeManager.ApplyTheme("dark" | "light")
    │
    ▼
更新 20+ 个颜色资源键：
├── ThemeBgRootBrush / ThemeBgPanelBrush / ThemeBgSurfaceBrush
├── ThemeBorderBrush / ThemeBorderStrongBrush
├── ThemeTextPrimaryBrush / ThemeTextSecondaryBrush / ThemeTextMutedBrush
├── ThemeAccentBrush / ThemeAccentHoverBrush / ThemeOnAccentBrush
├── ThemeHoverBrush / ThemeSelectionBrush / ThemeFocusBorderBrush
└── ThemeMenuPopup* 系列
    │
    ▼
所有绑定 DynamicResource 的控件自动刷新
```

## 5. 性能优化策略

| 策略 | 实现 | 效果 |
|------|------|------|
| 防抖刷新 | 220ms DispatcherTimer | 避免高频编辑时预览抖动 |
| 增量布局 | 脏区块 diff + 局部渲染 | 减少全量 DOM 重建 |
| 版本追踪 | 版本号 + 哈希双重校验 | 跳过重复更新 |
| 文本缓存 | RulerControl 缓存 FormattedText | 标尺重绘性能 |
| 懒加载 | WebView2 / Vditor 按需初始化 | 加快窗口打开速度 |
| 信号量 | VditorCacheManager 下载锁 | 防止并发重复下载 |
| 本地缓存 | Vditor dist 本地持久化 | 避免重复网络请求 |

## 6. 线程模型

- **UI 线程**：WPF Dispatcher 线程，所有 UI 操作和 WebView2 交互
- **防抖定时器**：DispatcherTimer，在 UI 线程上触发
- **异步操作**：WebView2 JS 调用（`ExecuteScriptAsync`）、文件 I/O
- **线程安全**：EditorLauncher 使用 `lock` 保护非模态窗口引用；VditorCacheManager 使用 `SemaphoreSlim` 保护下载操作
