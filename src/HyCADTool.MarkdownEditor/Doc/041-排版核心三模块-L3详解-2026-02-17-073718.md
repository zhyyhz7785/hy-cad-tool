# 排版核心三模块 L3 详解

## 文档范围

本文件聚焦以下 3 个核心点（L3 深度）：

1. `MarkdownBlockParser.ParseTopLevelBlocks()`：块级解析  
2. `LayoutEngine.Distribute()`：分页分栏分配  
3. `PreviewHtmlRenderer`：预览渲染与交互层  

关联主链路：

`EditorWindow` -> `PreviewManager.RefreshPreviewAsync()` -> `ParseTopLevelBlocks()` -> `Distribute()` -> `ToInteractiveHtml()` -> WebView2 预览。

---

## 1) `MarkdownBlockParser.ParseTopLevelBlocks()`

文件：`HyCADTool.TextLayout/MarkdownBlockParser.cs`

## 1.1 类概述

- 类：`MarkdownBlockParser`（静态类）
- 职责：将 Markdown 文本转换为布局引擎可消费的 `DocumentBlock[]`（顶层块级语义结构）
- 设计要点：
  - 先按“顶层块边界”切片，再结合 Markdig AST 判定块类型
  - 计算布局所需的关键元数据：`DisplayUnits`、`ParagraphCount`、`HeadingLevel`、`IsBreakable`

## 1.2 字段

| 名称 | 类型 | 用途 |
|---|---|---|
| `Pipeline` | `MarkdownPipeline` | Markdig 解析管线（`UseAdvancedExtensions`） |

## 1.3 方法清单

| 方法 | 参数 | 返回 | 职责 |
|---|---|---|---|
| `ParseTopLevelBlocks` | `string markdown` | `IReadOnlyList<DocumentBlock>` | 主入口，输出块列表 |
| `ToType` | `Block block` | `DocumentBlockType` | AST 节点类型 -> 业务块类型 |
| `CountParagraphLikeLines` | `DocumentBlock block` | `int` | 估算段落/列表/代码行计数 |
| `IsOrderedLine` | `string line` | `bool` | 判断有序列表行 |
| `ToPlainText` | `Block block, string fallback` | `string` | 提取块纯文本 |
| `AppendInlineText` | `ContainerInline inline, StringBuilder sb` | `void` | 递归抽取 Inline 文本 |

## 1.4 关键方法详解

## `ParseTopLevelBlocks(markdown)`

输入：Markdown 原文  
输出：带布局元信息的 `DocumentBlock[]`

处理步骤：

1. 空文本快速返回空数组；
2. 调用 `MarkdownColumnSplitter.ExtractTopLevelBlocks(markdown)` 提取顶层文本块；
3. 用 Markdig 解析整文 AST；
4. 对每个顶层块构建 `DocumentBlock`：
   - `Index`：块序号
   - `SourceText`：原块文本
   - `PlainText`：纯文本（供宽度估算）
   - `Type`：块类型（标题/段落/列表/表格等）
   - `HeadingLevel`：标题级别
5. 计算并补齐布局关键字段：
   - `DisplayUnits`：字符显示宽度（中英文统一口径）
   - `ParagraphCount`：用于列表/代码块高度估算
   - `IsBreakable`：表格和代码块不可断开
6. 返回结果列表给布局引擎。

## 1.5 状态管理

- 无实例状态（静态工具类）
- 仅有静态 `Pipeline`，线程内只读使用
- 每次调用完全由输入决定输出，函数式特征明显

## 2) `LayoutEngine.Distribute()`

文件：`HyCADTool.TextLayout/LayoutEngine.cs`

## 2.1 类概述

- 类：`LayoutEngine`（密封类）
- 职责：把 `DocumentBlock[]` 按配置分配到“页 -> 栏”
- 关键目标：与 CAD 导出口径一致，确保“预览布局 ≈ 导出布局”

## 2.2 内部数据结构

| 名称 | 类型 | 用途 |
|---|---|---|
| `MutablePage.ColumnBlockIndices` | `List<int>[]` | 每栏块索引 |
| `MutablePage.ColumnBlockHeights` | `List<double>[]` | 每栏块高度明细 |
| `MutablePage.ColumnUsedHeights` | `double[]` | 每栏已占用高度 |
| `MutablePage.CharsPerColumn` | `int[]` | 每栏估算字/行 |

## 2.3 方法清单

| 方法 | 参数 | 返回 | 职责 |
|---|---|---|---|
| `Distribute` | `IReadOnlyList<DocumentBlock> blocks, DesignSpecConfig config` | `LayoutResult` | 主入口：分页分栏 |
| `EstimateBlockHeightMm` | `DocumentBlock block, DesignSpecConfig cfg, double colWidthMm` | `double` | 估算块在当前栏宽下的高度 |
| `CreatePage` | `int cols, double[] colWidths, DesignSpecConfig cfg` | `MutablePage` | 初始化新页 |
| `MutablePage.ToImmutable` | `int pageIndex` | `LayoutPage` | 内部页转输出页 |

## 2.4 关键方法详解

## `Distribute(blocks, config)`

输入：块数组 + 页面/边距/字体/缩放配置  
输出：`LayoutResult`（包含每页每栏块索引与统计）

核心流程：

1. `Normalize + Validate` 配置；
2. 用 `TextAreaCalculator.Calculate(config)` 计算可用栏宽；
3. 初始化第一页，游标从 `pageIndex=0, colIndex=0` 开始；
4. 逐块放置：
   - 先 `EstimateBlockHeightMm(...)` 估算块高；
   - 判断 `fits`：
     - 若 `当前栏已用 + 块高 <= 页可用高度`，放入当前栏；
     - 或当前栏为空时允许放入（保证超大块也有落点）；
   - 不满足则换下一栏，末栏后换新页；
5. 汇总为 `LayoutResult`：
   - `ColumnWidthsMm`
   - `Pages[]`（每页每栏块索引、高度、字/行）

关键细节：

- 含 guard 循环，避免异常配置导致死循环；
- `pageContentHeight` 按页高和上下边距计算；
- 高度估算按块类型分支：
  - Heading：考虑级别字号与上下间距
  - List/Quote：考虑列表/引用附加间距
  - Table：按行数估算
  - CodeBlock：按代码行数估算
  - 其他：按 `displayUnits / charsPerLine` 估算

## 2.5 状态管理

- 算法是“局部可变、结果不可变”：
  - 计算时操作 `MutablePage`
  - 输出前统一 `ToImmutable`
- 便于调试与序列化，同时保证外部消费稳定

## 3) `PreviewHtmlRenderer`（渲染与交互层）

文件：`HyCADTool.MarkdownEditor/Html/PreviewHtmlRenderer.cs`

## 3.1 类概述

- 类：`PreviewHtmlRenderer`（静态类）
- 职责：生成完整可交互预览 HTML（CSS + JS + 内容）并在 WebView2 中执行
- 特点：
  - C# 负责拼模板、注入参数、输出页面
  - JS 负责页面内布局分发、交互（拖拽、翻页、编辑、重排、统计）

## 3.2 C# 层字段与方法

### 字段

| 名称 | 类型 | 用途 |
|---|---|---|
| `Pipeline` | `MarkdownPipeline` | Markdown -> HTML |
| `CSS_TEMPLATE` | `string` | 预览样式模板 |
| `JS_TEMPLATE` | `string` | 交互脚本模板 |

### 方法清单

| 方法 | 参数 | 返回 | 职责 |
|---|---|---|---|
| `ToInteractiveHtml` | `markdown, columnCount, previewScale, config, layoutResult` | `string` | 主入口：拼接完整 HTML |
| `BuildDynamicCss` | `previewScale, cfg` | `string` | 按配置替换 CSS token |
| `BuildDynamicJs` | `previewScale, cfg, columnCount, layoutResult` | `string` | 注入 JS 运行参数 |
| `BuildCustomColumnWidthsJson` | `layoutResult, previewScale` | `string` | 注入栏宽数组 |
| `ResolvePreviewFontFamily` | `cfg` | `string` | 预览字体回退链 |
| `Round` | `double` | `double` | 统一取整 |
| `BuildFooterHtml` | `int count` | `string` | 页脚栏统计视图 |

## 3.3 JS 运行时状态（核心）

| 变量 | 含义 |
|---|---|
| `COLUMN_COUNT` | 栏数 |
| `PREVIEW_SCALE` | 预览缩放 |
| `LAYOUT_RESULT` | C# 布局结果（优先使用） |
| `customPaperWidth/customPaperHeight` | 页面自定义尺寸 |
| `customColumnWidths/customColumnHeights` | 栏宽/栏高调整结果 |
| `window.previewStats` | 当前页统计与全页统计 |
| `currentPageIndex` | 当前页游标 |
| `isDistributing` | 防止分发重入 |
| `middlePanActive` 等 | 中键平移状态 |

## 3.4 JS 函数分组

## A. 统计与宿主通信

- `getPreviewStats/getColChars/getColParas/getPaperSize`
- `postPaperScaleToHost/postWheelZoomToHost/postPageStateToHost`

## B. 布局分发主流程

- `createPage`：创建页和栏 DOM
- `distributeByLayout`：按 `LAYOUT_RESULT` 精确分发（主路径）
- `distribute`：fallback（DOM 测量溢出分发）
- `setCurrentPage`：页状态 + 页脚统计刷新

## C. 可编辑与增量重排

- `bindEditableColumnEvents`：绑定 input/paste
- `cascadeReflow`：溢出顺延/空缺回拉
- `moveOverflowForward/pullFromNext`：块级级联移动
- `rebuildPreviewStatsFromDom`：重建统计
- `notifyContentChanged`：把编辑后的 markdown 回传宿主

## D. Markdown 回写与公式

- `inlineToMarkdown/blockToMarkdown/extractAllMarkdown`
- `extractKatexTex/renderMathInColumns`

## E. 交互控制

- `startH/startV/startPaperResize`：拖拽栏宽栏高页尺寸
- `startMiddlePan`：中键平移
- `jumpToPage/handleViewportScroll`：翻页/滚动同步
- `init`：初始化入口

## 3.5 关键流程详解

## `ToInteractiveHtml(...)`

1. `Markdown.ToHtml(...)` 生成 `source`（隐藏 DOM 源）；
2. 构建动态 CSS/JS（注入缩放、栏数、边距、布局结果）；
3. 输出页面骨架：
   - `#source`（原始块）
   - `#viewport/#pages`（渲染区）
   - footer（栏统计）
4. 页面 `init()` 后执行 `distribute()`。

## `distributeByLayout(src, els)`

- 读取 `LAYOUT_RESULT.pages[].columnBlockIndices`；
- 按块索引克隆并放入目标栏；
- 计算并更新 `previewStats`；
- 调 `setCurrentPage(0, true)` 同步宿主页状态。

## `distribute()`

- 优先走 `distributeByLayout`；
- 无布局结果时，按 `scrollHeight > clientHeight` 逐块试放并换栏/换页；
- 最后构建各栏字/行与段落统计。

## `cascadeReflow(startPage, startCol, lockedBlock)`

- 编辑后增量重排：
  - 当前栏溢出：把末尾块推到下一栏首位；
  - 当前栏有余量：从下一栏首块回拉；
  - 跨页级联，必要时创建新页；
  - 清理末尾空页，重建统计并保持当前页索引。

## 3.6 状态管理

- “模板静态 + 运行时 JS 状态机”模式；
- 通过 `isDistributing` 避免编辑事件和重排互相触发导致重入；
- 与宿主（C#）通过 `postMessage` 双向同步：
  - 页面状态
  - 缩放状态
  - 内容变化（`contentChanged`）

---

## 4) 三模块协作调用链（按一次预览刷新）

1. `EditorWindow.RefreshPreviewAsync()`
2. `PreviewManager.RefreshPreviewAsync()`
3. `MarkdownBlockParser.ParseTopLevelBlocks(markdown)`
4. `LayoutEngine.Distribute(blocks, layoutConfig)`
5. `PreviewHtmlRenderer.ToInteractiveHtml(markdown, ..., layoutResult)`
6. WebView2 `NavigateToString(html)`
7. 页面 `init()` -> `distributeByLayout()/distribute()`
8. `previewStats` 回传 C#，更新 `EditorViewModel` 的栏统计和段索引

---

## 5) 你在维护时最该盯的点

1. **块语义稳定性**（Parser 输出是否稳定）  
2. **高度估算一致性**（LayoutEngine 估算与实际渲染偏差）  
3. **DOM 分发重入保护**（isDistributing / 事件抖动）  
4. **回写可逆性**（contenteditable -> markdown 的损耗）  
5. **统计一致性**（previewStats 与真实页面同步）

以上 5 点决定了“编辑体验是否稳定 + 预览与导出是否一致”。
