# MarkdownEditor 排版核心逻辑（L1）

## 项目定位

`HyCADTool.MarkdownEditor` 的排版核心职责是：将 Markdown 文本按 CAD 一致口径拆分为块，执行分页分栏布局，渲染为预览 HTML，并回传排版统计给编辑器与导出链路。

## 技术栈（排版相关）

- 平台：`.NET 8 WPF`
- 核心依赖：`Markdig 0.37.0`、`WebView2 1.0.3065.39`、`Newtonsoft.Json 13.0.3`
- 布局引擎：`HyCADTool.TextLayout`（由 `HyCADTool.MarkdownEditor` 引用）

## 模块关系（排版链路）

- `EditorWindow`（触发刷新）
  - -> `PreviewManager.RefreshPreviewAsync`
    - -> `MarkdownBlockParser.ParseTopLevelBlocks`（Markdown -> 块）
    - -> `LayoutEngine.Distribute`（块 -> 页/栏分配）
    - -> `PreviewHtmlRenderer.ToInteractiveHtml`（生成预览 HTML）
      - -> JS `distributeByLayout` / `distribute`（DOM 分栏分页）
      - -> JS `setCurrentPage` + `previewStats`（页码/统计）
  - <- `PreviewManager.SyncFromPreviewAsync`（回收统计，更新 ViewModel）

## 数据流

`MarkdownText`  
-> `DocumentBlock[]`  
-> `LayoutResult`  
-> `InteractiveHtml`（WebView2）  
-> `previewStats`  
-> `EditorViewModel`

## 核心代码定位

1) 总调度（解析 -> 分配 -> 渲染）  
文件：`HyCADTool.MarkdownEditor/Services/PreviewManager.cs`  
关键入口：`RefreshPreviewAsync()`、`BuildLayoutConfig()`

2) Markdown 块解析  
文件：`HyCADTool.TextLayout/MarkdownBlockParser.cs`  
关键入口：`ParseTopLevelBlocks()`（输出 `DocumentBlock` 列表）

3) 分页分栏布局引擎  
文件：`HyCADTool.TextLayout/LayoutEngine.cs`  
关键入口：`Distribute()`（核心放置策略）  
关键逻辑：`EstimateBlockHeightMm()`（按块类型估高）

4) 预览渲染与前端分配  
文件：`HyCADTool.MarkdownEditor/Html/PreviewHtmlRenderer.cs`  
关键入口：`ToInteractiveHtml()`（拼接 CSS/JS/HTML）  
前端核心：`createPage()`、`distributeByLayout()`、`distribute()`、`setCurrentPage()`

## 模块速查表

| 模块 | 一句话职责 |
|---|---|
| `Services/PreviewManager` | 排版总调度：配置映射、调用解析/布局/渲染、维护页状态 |
| `HyCADTool.TextLayout/MarkdownBlockParser` | Markdown 顶层块解析与语义类型归一化 |
| `HyCADTool.TextLayout/LayoutEngine` | 统一度量口径下的分页分栏分配算法 |
| `Html/PreviewHtmlRenderer` | 生成预览 HTML/CSS/JS，并在 WebView2 中执行分栏分页与统计 |
| `Views/EditorWindow` | 触发刷新、接收预览消息、同步排版统计到 ViewModel |
