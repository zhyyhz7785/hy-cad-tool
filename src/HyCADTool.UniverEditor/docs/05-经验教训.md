## 经验条目

### 口径 B 与真相源

- **日期**：2026-09-01（经验定稿于主题文档 2026-07-15，对照现码收录）
- **症状 / 背景**：编辑器屏幕、布局栏数字、CAD 量测三种「毫米」对不上；结构改完下次打开或拾取丢失。
- **走过的弯路**：
  1. 把 Univer 行列像素或 export 样式当成可写回 Domain 的真相。
  2. 拾取时做 mm 反算，或把 Scale 写进表对象，关窗后再打开比例错乱。
  3. 用 Univer 自带插删改网格，不走 TableOpLog。
- **最终正确做法**：Domain / 布局 / 拾取读回一律纸面 mm；仅落图把几何与字高 ×Scale；Scale 打开时取面板值，不持久化到表；结构变更：布局按钮 → C# OpLog → `GridChanged` 回灌快照。**已验证**（现码 `HandleHyCadLayout`、`UniverEditorHostContext.SetScale` 注释与 `mm-display.ts` 口径一致）。
- **关键文件**：
  - `src/HyCAD.Tables/Layout/TableLayout.cs` — 落图尺寸 ×Scale
  - `src/HyCADTool/Features/Tables/Services/UniverTableEditorHostBridge.cs` — 布局消息 / 快照
  - `src/HyCADTool.UniverEditor/Web/src/univer-bridge.ts` — 快照协议
  - `src/HyCADTool.UniverEditor/Services/UniverSessionLifecycle.cs` — `setScale` 不改 grid
- **禁止再犯**：从 Univer export 反推样式当真相；给 Scale 做表级持久化；只改屏幕网格不记账。
- **相关**：仓库 `docs/table/06-技术实现细节.md`

### 布局几何编排

- **日期**：2026-09-01
- **症状 / 背景**：布局模式下网格相对纸面「时好时坏」溢出；`LAYOUT_FIX_PLAN.md` 写明两边从不互校。
- **走过的弯路**：
  1. `layout-grid-fit.ts` 按纸面均分列宽并自己订 zoom=1 基线。
  2. `page-viewport.ts` 用另一套 ppm 算 zoom，不读真实 colSum。
  3. resize / 再入布局只刷新其中一边，同步帧也会 449px vs 466px 对不齐。
- **最终正确做法**：`applyGridFitStep` 只设格子并返回真实 colSum/rowSum，不订 zoom；`page-viewport.ts` 在同一 tick 内 `zoom = 纸张内区 px / colSum`。`installLayoutGridFit` 只提供离开布局时的 baseline teardown。**已验证**（现码函数职责与计划一致）；纸面与 CAD 目视仍 **待验证**。
- **关键文件**：
  - `src/HyCADTool.UniverEditor/Web/src/page-viewport.ts` — 唯一编排者
  - `src/HyCADTool.UniverEditor/Web/src/layout-grid-fit.ts` — `applyGridFitStep`
  - `src/HyCADTool.UniverEditor/Web/LAYOUT_FIX_PLAN.md` — 根因与顺序
- **禁止再犯**：再给 grid-fit 单独订 zoom 或让两套订阅抢布局。
- **相关**：无本目录 Plan 文件

### 开发地址必须用 127.0.0.1

- **日期**：2026-09-01（来自 `Web/README-dev.md` 已写明的踩坑）
- **症状 / 背景**：`npm run dev` 已启动，浏览器开 `localhost:5174` 仍空白。
- **走过的弯路**：
  1. 以为端口没起来，反复重启 Vite。
  2. 用系统 `localhost`（Windows 上可能解析到 IPv6）。
- **最终正确做法**：`vite.config.ts` `host: '127.0.0.1'`、`strictPort: true`、`open` 指向 `http://127.0.0.1:5174/`。**已验证**（配置文件）；本轮未再复现浏览器失败。
- **关键文件**：
  - `src/HyCADTool.UniverEditor/Web/vite.config.ts` — 绑定与自动打开
  - `src/HyCADTool.UniverEditor/Web/README-dev.md` — 开发说明
- **禁止再犯**：文档或脚本把开发 URL 写成 localhost。
- **相关**：无
