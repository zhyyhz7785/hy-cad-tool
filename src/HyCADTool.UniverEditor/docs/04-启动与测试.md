# 启动与测试

工作目录仓库：`E:\Code\hy-cad-tool`。本工程无独立安装包，侧车 DLL 与 `Web\dist` 跟 HyCADTool 一起编。

## 环境要求

| 项 | 版本/要求 |
|---|---|
| .NET SDK | 能编 net48 主工程 + net8.0-windows 侧车 |
| Node.js | 能跑 Vite 5.4（官方要求 Node 18+）**推断** |
| npm | 与 Node 配套 |
| AutoCAD | 开发机已装；热重载命令 C2 可用 |
| WebView2 Runtime | Microsoft Edge WebView2；`GetAvailableBrowserVersionString` 为空则无法开窗 |
| 工作目录 | `E:\Code\hy-cad-tool` |

## 首次启动

```powershell
cd E:\Code\hy-cad-tool\src\HyCADTool.UniverEditor\Web
npm install
npm run build
cd E:\Code\hy-cad-tool
dotnet build src\HyCADTool\HyCADTool.csproj -c Debug
```

成功标志：`Web\dist\index.html` 存在；`src\HyCADTool\bin\Debug\net8\HyCADTool.UniverEditor.dll` 与 `src\HyCADTool\bin\Debug\net8\Web\dist\index.html` 被复制出来。`npm install` / 首次 build 用时视机器与网络浮动，常见数分钟到十几分钟，**待验证**（本轮未实测）。

## 日常测试

开发态：改 C# 后编主工程；改网页后可先走「网页测试」，定稿再 `npm run build`（主工程编译也会跑侧车 `BuildWebAssets`）。本侧车工程内无独立测试项目；快照映射单测在主测试工程。

```powershell
cd E:\Code\hy-cad-tool
dotnet test src\HyCAD.Tables.Tests\HyCAD.Tables.Tests.csproj -c Debug
dotnet test src\HyCADTool.Tests\HyCADTool.Tests.csproj -c Debug --filter "FullyQualifiedName~TableGridUniverAdapterTests"
```

成功标志：xunit 退出码 0。本轮未跑，结果 **待验证**。

AutoCAD 热重载（改完 DLL 之后）：

```text
在 AutoCAD 命令行输入 C2
再输入 N38
```

C2 是 ReCall（热重载壳）把新编的插件字节加载进进程；N38 打开本编辑器。若 TestCommand 仍指向 N38，也可用 C1。

## 网页测试

无 CAD、无 WebView2 时用浏览器改 Ribbon / 布局 / CSS。

```powershell
cd E:\Code\hy-cad-tool\src\HyCADTool.UniverEditor\Web
npm run dev
```

打开 `http://127.0.0.1:5174/`（不要用 `localhost`：Windows 上可能只走 IPv6 导致连不上）。确认：

1. Tab 行能看到文件▾、开始、公式、数据、布局、主题▾。
2. 左下角出现 HyCAD Univer Dev 面板；「人员样表」能加载 fixture。
3. 点「布局」后第二行出现 HyCAD Ribbon；改格子后面板无 error。
4. 拾取/落图类按钮提示仅 CAD 宿主可用（浏览器 mock 预期行为）。

## 完整打包

无此环节的独立安装包：客户包走 HyCADTool 的 Production（生产配置，发出可 NETLOAD 的插件，不含 ReCall 热重载）。侧车应出现在主工程输出下的 `net8` 目录。

```powershell
cd E:\Code\hy-cad-tool
dotnet build src\HyCADTool\HyCADTool.csproj -c Production
```

成功标志：构建成功，且存在 `E:\Code\hy-cad-tool\src\HyCADTool\bin\Production\net8\HyCADTool.UniverEditor.dll` 与同目录 `Web\dist\index.html`。本轮未跑 Production，路径按 csproj `OutputPath` 写出，**待验证**。

开发发行对照（Debug）成品目录同样由 csproj 固定。

### 用时总览

| 步骤 | 参考用时 | 何时必跑 |
|---|---|---|
| npm install | 5–15 分钟（视网络，未实测） | 首次 / 锁文件变更 |
| npm run build | 1–5 分钟（Univer 体积大，未实测） | 改 Web 后进 CAD 前；编侧车时也会跑 |

| 完整打包 Production | 与 Debug 同量级或更长（未实测） | 发行前 |
| C2 热重载 | 通常亚分钟（未在本轮测） | AutoCAD 已开、只换 DLL 时 |

各步骤命令见上方对应代码块。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器打不开页面 | 没起 dev 或用了 localhost | 先跑下方 `npm run dev`，只打开 127.0.0.1:5174 |
| 未找到 Univer Web/dist | 没打包或 C2 复制的 net8 里没有 dist | 在 Web 目录 `npm run build`，再编主工程并 C2 |
| 未检测到 WebView2 Runtime | 机器无运行时 | 安装 Edge WebView2 Runtime 后再开 N38 |
| N38 提示找不到 HyCADTool.UniverEditor.dll | net8 输出未进 ReCall 复制目录 | 编 `HyCADTool.csproj` 后 C2；勿只编侧车却不重载 |

```powershell
cd E:\Code\hy-cad-tool\src\HyCADTool.UniverEditor\Web
npm run dev
```

```powershell
cd E:\Code\hy-cad-tool\src\HyCADTool.UniverEditor\Web
npm run build
cd E:\Code\hy-cad-tool
dotnet build src\HyCADTool\HyCADTool.csproj -c Debug
```
