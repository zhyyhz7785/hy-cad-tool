## 📚 关键算法与技术

### 1. Voronoi 图与 Lloyd 优化 (桩基布置)
- **位置**: `Tools/PileLayout/V1.cs`, `V2.cs`
- **用途**: 优化桩位分布，确保均匀性
- **算法**: 
  1. 初始化种子点
  2. 生成 Voronoi 单元
  3. 计算质心
  4. 迭代优化至收敛

### 2. DCEL (双连边表) 拓扑分析
- **位置**: `HelpClass/DCEL/`
- **用途**: 平面细分、区域检测
- **数据结构**:
  - Vertex (顶点)
  - HalfEdge (半边)
  - Face (面)

### 3. Clipper2 布尔运算
- **位置**: `Converter/Clipper2Converter.cs`
- **用途**: 多边形交、并、差运算
- **应用场景**: 多段线替换、区域裁剪

### 4. 空间聚类算法
- **位置**: `Models/Cluster/`, `Tools/CreatEntity/BaseRein/BR04_bGroupBySpatialProximity4b.cs`
- **用途**: 基于距离的点集分组
- **方法**: K-means 变种、邻近性聚类

### 5. 有限元网格识别
- **位置**: `Tools/CreatEntity/BaseRein/BR03_SelectFiniteElementGrid_Parallel_DIC _del.cs`
- **用途**: 从 YJK/PKPM 导出数据中提取配筋信息
- **技术**: 并行处理、字典缓存

### 6. 最小边界矩形 (MBR)
- **位置**: `Commands/HyMbr/CreateMBR.cs`
- **用途**: 聚类后生成最小包围盒
- **算法**: 旋转卡壳法

### 7. 矩形装箱算法
- **位置**: 使用 `RectanglePacker` 库
- **用途**: 批量布局优化
- **应用**: 多图纸自动排版

## 🎯 设计模式应用

### 1. 工厂模式 (Factory)
- `AreaFactory`: 创建标准区域对象
- `DCELFactory`: 创建 DCEL 拓扑结构
- `AnchorBoltFactory`: 创建地脚螺栓对象

### 2. 单例模式 (Singleton)
- `BaseConfig`: 全局配置单例
- `PaletteSet` 面板: 确保唯一实例

### 3. 策略模式 (Strategy)
- `IEntityFilter`: 图元过滤策略
- `IAreaFactory`: 区域创建策略

### 4. 服务定位器模式
- `Services` 层提供全局服务访问
- 依赖注入管理

### 5. MVVM 模式
- `Views` + `ViewModels`: WPF 界面架构
- 数据绑定与命令绑定

## 🚀 扩展性设计

### 添加新命令
1. 在 `Commands/` 下创建新类
2. 添加 `[CommandMethod]` 特性
3. 实现业务逻辑
4. 注册到主面板（可选）

### 添加新算法
1. 在 `HelpClass/` 下创建新模块
2. 封装核心算法
3. 在 `Tools/` 中提供 CAD 操作接口
4. 在 `Commands/` 中调用

### 添加新配置
1. 修改 `config.json`
2. 更新 `ConfigService`
3. 在相关命令中读取配置
