# HyCADTool 项目功能详细介绍与分类

## 📋 项目概述

HyCADTool 是基于 AutoCAD .NET API 的专业 CAD 辅助设计工具集，面向结构工程（基础、钢筋、桩基、设备基础、标高与剖面、批量出图等）。提供 60+ 功能、80+ 专业命令，覆盖从底图处理到出图的完整流程。

- 开发平台: .NET Framework 4.8
- 适配 CAD: AutoCAD 2024 (AutoCAD.NET 24.3.0)
- 关键依赖: Clipper2, NetTopologySuite, Newtonsoft.Json, RectanglePacker

## 🎯 功能分类与导航

### 一、主控制面板（hy）
- 打开主面板，包含：`ReinPanel`（钢筋）、`FilterPanel`（过滤器）、`BaseReinPanel`（基础钢筋）、`PilePanel`（桩基）、`ClusterPanel`（螺栓聚类与基础标注）。

### 二、钢筋配筋（Reinforcement）
- 基本绘制与编辑：`gj`、`ggj`、`gg`、`gd`、`ge`、`ge1`
- 锚固处理：`g1`（弯钩锚固）、`g2`（直锚）
- 标注工具：`gb`、`gb1`、`gb2`、`hysrt`
- 特点：自动锚固长度、类型识别、批量引线标注

### 三、基础底板配筋（Base Reinforcement）
- 分步流程：`hyb1` 优化底图 → `hyb2` 文本筛选 → `hyb3` 网格识别 → `hyb4` 空间分组 → `hyb5` 生成配筋 → `hyb6` 标注
- 一键流程：`hyb5all`
- 场景：适配 YJK/PKPM 网格，自动生成配筋边界与尺寸标注

### 四、地脚螺栓（Anchor Bolt）
- 数据与布置：`hyab`（圆转螺栓，1-9 号）、`hyabA_Align`（对齐）、`hyabR_RectSection`（矩形布置）
- 计算与显示：`hyabC_Calculat`（受力）、`hyabCD_ChangeDisPlay`（显示切换）、`hyabCT_CreateAnchorBoltTable`（汇总表）
- 数据持久化：扩展字典（JSON）

### 五、标高与剖面（Elevation & Section）
- 平面标高：`bg`、`hybgTCE_TextsCreatElevation`、`bgR_RotateElevation`、`bgu_UpdateElevationText`
- 三维生成：`hy3_Generate`（平面→三维）、`hy3CS_CreateSection`（剖面）

### 六、尺寸标注（Dimension）
- 基本：`dds`、`ddss`
- 高级：`sd`、`hydimA_AddVertexAtIntersections`
- 特点：轴线区域感知、自动对齐与分割

### 七、轴线与轴网（Axis）
- `hyAxis_AlignedAxisText`、`hyef_Axis_Construct`
- 功能：自动识别 X/Y 轴、编号、区域划分、点集归属（详见 `Models/Axis/AxisReadme.md`）

### 八、桩基布置（Pile Layout）
- 命令：`hyz_PlacePileAndVoronoiWithLloydOptimization`、`HYz_GroupCirclesZFinal`
- 算法：Voronoi + Lloyd 优化，边界约束与最小桩距；参数见 `config.json` 的 `PileConfigData`

### 九、设备基础（Equipment Foundation）
- 基础数据/轴线/螺栓：`hyef_Base_ConstructBaseData`、`hyef_Base_HighlightBoltData`、`hyef_Axis_Construct`
- 特点：设备基础优化流程，扩展字典关联

### 十、图形处理（Geometry Tools）
- 线段：`hyov`、`BreakCrues`、`BreakLines`
- 多段线：`hyDcP_Poly`、`hyDcL_Line`、`HYRp_ReplacePolygon`、`HYRps_ReplacePolygonsByIntersection`
- 区域检测：`DetectClosedRegions`、`Dcel`

### 十一、布局与视口（Layout & Viewport）
- `HYMBR`（最小边界矩形/聚类MBR）、`HYMBRC_CreateLayoutViewports`（批量视口）、`HYMBRD_DrawTitleBlock`（图框）
- 批量出图：智能分组、布局排版（RectanglePacker）、一键多图

### 十二、数据导出（Export）
- `ExportEntityPropertiesToCsv`、`hyex_MarkdownTable`、`hydl_DrawLinesOnEachLayer`
- 格式：CSV、Markdown

### 十三、其他工具
- `HyRT_aftThicknessText`（筏板厚度）、`HYc2_block_color`、`HYc2_block2leader`

## 🧭 使用流程示例

- 基础底板配筋：`hyb5all` → `ddss` → `HYMBR`
- 设备基础：`hyab` → `hyabA_Align` → `hyabC_Calculat` → `hyabCT_CreateAnchorBoltTable` → `hy3_Generate`
- 桩基优化：定义边界 → 调整参数（面板或 `config.json`）→ `hyz_PlacePileAndVoronoiWithLloydOptimization`

## 🏗️ 架构与目录

- 分层：Commands → HelpClass → Tools → Services → Models → Views → Config → Converter → GeometryUtils
- 关键说明：
  - `Commands/` 命令入口；`HelpClass/` 核心算法（DCEL、Pile、Elevation3d 等）；
  - `Tools/` CAD 操作与几何工具；`Services/` 全局服务；`Views/` WPF 面板；
  - `Converter/` 第三方库转换；`GeometryUtils/` 几何映射；`Models/` 数据模型。

---

## ⚙️ 配置与样式

- 配置文件：`HyCADtool/config.json`
- `PileConfigData`：桩型、直径/边长、排列方式、最小桩距、边距、输入约束
- `BaseConfigData`：`TextStyle`、`DimStyle`、`MLeaderStyle`（比例可通过 `BaseConfig.Scale` 调整，默认 30）
- 图层命名：`00_Hy_螺栓_{1~9}`、`00_Hy_配筋`、`00_Hy_标注`、`00_Hy_轴线`

## 🔑 核心技术要点

- Voronoi + Lloyd（桩基优化）
- DCEL 拓扑（区域检测/平面细分）
- Clipper2 布尔运算（多段线替换/裁剪）
- 并行与缓存优化（网格识别、批处理）
