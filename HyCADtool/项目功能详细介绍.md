# HyCADTool 项目功能详细介绍与分类

## 📋 项目概述

**HyCADTool** 是一个基于 AutoCAD .NET API 开发的专业 CAD 辅助设计工具集，主要面向结构工程设计领域，特别是混凝土结构、基础设计、钢筋配筋等专业应用。该插件提供了丰富的自动化工具，大幅提升设计效率。

### 技术栈
- **开发平台**: .NET Framework 4.8
- **CAD版本**: AutoCAD 2024 (AutoCAD.NET 24.3.0)
- **核心依赖**:
  - Clipper2 (几何运算)
  - NetTopologySuite (拓扑分析)
  - Newtonsoft.Json (数据序列化)
  - RectanglePacker (布局优化)

5. **配筋生成**: 自动生成优化的配筋边界多段线
6. **智能标注**: 自动生成配筋尺寸标注

5. 使用 `hy3_Generate` 生成三维模型

#### 场景3: 桩基布置优化
1. 定义基础边界
