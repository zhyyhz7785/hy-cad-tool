## 基础底板配筋

| 命令 | 功能 | 说明 |
|------|------|------|
| `hyb1` | 优化底图 | 清理冗余图元，规范图层 |
| `hyb2` | 筛选无用文本 | 自动识别并移除非结构性文本 |
| `hyb3` | 选择有限元网格 | 从YJK/PKPM导出数据中提取配筋信息 |
| `hyb4` | 空间邻近分组 | 基于柱、墩等结构元素聚类 |
| `hyb5` | 生成配筋 | 自动生成配筋边界 |
| `hyb5all` | **一键生成** | **执行全部步骤（推荐）** |
| `hyb6` | 配筋标注 | 自动标注配筋尺寸 |

**推荐工作流**: 直接使用 `hyb5all` 一键完成，或按 `hyb1` → `hyb2` → `hyb3` → `hyb4` → `hyb5` → `hyb6` 顺序执行

## 💡 使用技巧

### 常用命令组合

#### 快速配筋设计
```
1. hyb5all        # 一键生成基础配筋
2. ddss          # 批量标注
3. HYMBR         # 生成布局
```

#### 设备基础完整流程
```
1. hyab          # 创建螺栓（选择圆，输入型号1-9）
2. hyabA_Align   # 对齐螺栓
3. hyabC_Calculat # 计算受力
4. hyabCT_CreateAnchorBoltTable # 生成汇总表
5. hy3_Generate  # 生成三维模型
```

#### 图纸整理
```
1. hyov          # 清理重复线段
2. DetectClosedRegions # 检测区域
3. HYMBR         # 生成布局
```

## ⚙️ 配置文件位置

- **主配置**: `HyCADtool/config.json`
- **样式配置**: 文本样式、标注样式、引线样式
- **桩基参数**: 直径、间距、边距等

### 快速修改比例

在任意命令运行前，修改 `BaseConfig.Scale` 可调整全局比例（默认30）。

## 🆘 常见问题

### Q: 命令输入后无响应？
A: 检查是否已加载插件，尝试重新加载或重启 AutoCAD

### Q: 配筋生成结果不理想？
A: 调整 `config.json` 中的参数，或使用分步命令 `hyb1`-`hyb6` 逐步检查

### Q: 螺栓数据丢失？
A: 螺栓数据存储在扩展字典中，避免使用"分解"命令

### Q: 标注样式不符合要求？
A: 修改 `config.json` 中的 `DimStyle` 配置节点
