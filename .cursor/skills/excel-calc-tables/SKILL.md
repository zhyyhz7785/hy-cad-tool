# Excel 计算表格生成

## 触发词

`Excel计算表`

---

## 1. 输出形式选择

| 用户需求 | 输出形式 |
|----------|----------|
| 单组参数验算、先看步骤与结果 | **算例脚本**：顶部输入、常数字典、纯函数、`main()` 打印完整过程与结论 |
| 要在 Excel 里改参数、拉公式、多截面 | **openpyxl 脚本**：生成 .xlsx，含输入区、公式单元格、可选「计算说明」sheet |
| 概算/工程量清单/造价表 | **联动型概算表**：基本参数 sheet + 分项概算 sheet + 费用汇总 sheet，全公式联动（见第 4 节） |
| 两者都要 | 先给算例脚本便于核对，再给或同时给 openpyxl 脚本生成 .xlsx |

未明确时：仅「帮我验算一例」→ 算例脚本；「做一张计算表 / Excel 表」→ openpyxl 脚本；「概算表 / 工程量清单 / 造价表」→ 联动型概算表。

---

## 2. 算例脚本结构

- **文件头**：`# -*- coding: utf-8 -*-`，docstring 注明算例名称、依据规范条文。
- **输入区**：脚本顶部集中赋值，单位与注释写清。
- **材料与系数**：用字典集中存放，便于维护与对照规范。
- **纯函数**：几何与公式用函数实现，不依赖全局可变状态。
- **main()**：按计算顺序调用上述函数，打印标题、输入回显、中间量、最终承载力或验算结论。
- **入口**：`if __name__ == "__main__": main()`。

不写 Excel 时保持单文件、无 openpyxl 依赖，运行即得可读的完整计算过程。

---

## 3. openpyxl 脚本结构（验算型）

- **依赖**：`openpyxl`，脚本内或说明中注明 `pip install openpyxl`。
- **工作簿**：至少一个「计算」sheet（输入区 + 公式区），可选一个「计算说明」sheet。
- **输入区**：固定行号，便于公式引用；A 列写参数名，B 列写默认值。
- **公式区**：按规范逐步写出 Excel 公式，与算例脚本中的公式一致。
- **样式**：表头加粗、合并标题行、边框/对齐按需。
- **输出**：生成**单一 .xlsx 文件**。

---

## 4. 联动型概算表结构（工程概算/工程量清单/造价表）

当用户需要概算、工程量清单、造价计算表时，采用**三层联动结构**：

### 4.1 整体架构

| Sheet | 内容 | 联动关系 |
|-------|------|----------|
| **基本参数** | 可调输入参数 + 费率参数 + 面积自动计算 | 所有 sheet 的数据源头 |
| **分项概算** | 各分项工程量清单，数量引用基本参数，单价可调 | 引用基本参数，被费用汇总引用 |
| **费用汇总** | 直接费→费率→建安费→总投资→经济指标 | 引用分项概算合计 + 基本参数费率 |

> **第一性原则**：参数 → 面积/工程量 → 单价 → 合价 → 费率 → 建安费 → 总投资。每一步都可追溯。

### 4.2 基本参数 sheet 设计要点

**左右分区布局**（参照海绵城市概算格式）：

```
左侧（A~D列）               右侧（E~H列）
─────────────               ─────────────
一、道路/工程基本参数         二、费率参数
  参数名 | 数值 | 备注          费率名 | 费率 | 计费基础

三、面积/工程量自动计算
  计算项 | 面积 | 公式说明
```

关键规则：
- **蓝色单元格（FILL_INPUT）**：用户可调参数（路线长度、间距、费率等），字体 `FT_INPUT`（深蓝加粗）
- **灰色单元格（FILL_CALC）**：公式自动计算，不可手动改
- **黄色单元格（FILL_RESULT）**：关键结果（建安费合计、总投资等）
- 面积/工程量全部用 Excel 公式引用参数区，修改参数自动刷新全表
- 首行标注图例：`■ 蓝色 = 可调输入    ■ 灰色 = 自动计算    ■ 黄色 = 关键结果`

### 4.3 分项概算 sheet 设计要点

**标准七列结构**：

```
序号 | 工程名称 | 单位 | 数量 | 综合单价(元) | 合价(万元) | 备注
```

关键规则：
- **数量列**：尽量用公式引用基本参数 sheet（如 `=基本参数!C27`），而非硬编码
- **单价列**：蓝色可调输入（`FILL_INPUT`），用户可直接修改
- **合价列**：公式 `=ROUND(D行*E行/10000,2)`，灰色自动计算
- **分类标题行**：浅绿底色（`FILL_SECTION`），`merge_cells` 合并全行
- **小计行**：浅蓝底色（`FILL_SUBTOTAL`），公式 `=SUM(范围)`
- **合计行**：深蓝底色（`FILL_TOTAL`），合价单元格黄色（`FILL_RESULT`）
- 各分类小计行的行号需在代码中动态记录，合计行用 `=F小计1+F小计2+...` 引用

### 4.4 费用汇总 sheet 设计要点

**两段式结构**：

上半段：直接费 → 措施费 → 管理费 → 利润 → 规费 → 税前 → 增值税 → **建安费**

```
序号 | 名称 | 计算公式/基数 | 费率 | 金额(万元) | 备注
  1    直接费    分项概算合计    /     =分项概算!F合计行
  2    措施费    直接费×费率     =基本参数!G6    =ROUND(E4*基本参数!G6,2)
  ...
       建安费    税前+增值税                     =E税前+E税      ← 黄色
```

下半段：建安费 → 其他费 → 预备费 → 征地 → **总投资**

底部：关键经济指标（单位长度/面积造价、与可研对比比例等）

### 4.5 Sheet 数量控制

> **简洁原则**：概算表一般 **3 个 sheet 足够**（基本参数 + 分项概算 + 费用汇总）。除非特殊需要（如海绵专项需要径流计算），不额外增加 sheet。用户能在一张分项概算表中看到所有工程量和单价，在一张费用汇总中看到全部费用计算链。

## 5. 样式与颜色约定

### 5.1 色彩系统（四色标识）

| 用途 | 填充色 | 色号 | 字体 |
|------|--------|------|------|
| 可调输入 | 浅蓝 | `DAEEF3` | 深蓝加粗 `1F4E79` |
| 自动计算 | 浅灰 | `F2F2F2` | 普通黑色 |
| 关键结果 | 浅黄 | `FFF2CC` | 加粗黑色 |
| 表头 | 深蓝 | `4472C4` | 白色加粗 |

### 5.2 字体约定

| 用途 | 字体名 | 大小 | 样式 |
|------|--------|------|------|
| 表标题 | 微软雅黑 | 14 | 加粗 |
| 分区标题 | 微软雅黑 | 11 | 加粗 |
| 表头 | 微软雅黑 | 10 | 白色加粗 |

### 5.3 数字格式

| 类型 | 格式代码 | 示例 |

## 6. 编码与防乱码（必须遵守）

| 项目 | 要求 |
|------|------|
| 文件头 | 脚本第一行必须为 `# -*- coding: utf-8 -*-` |
| 文件编码 | 生成/保存的 .py 文件必须以 **UTF-8** 编码写入 |
| 字符串字面量 | Python 3 中直接使用 `"中文"` 即可（默认 Unicode） |
| openpyxl 写入 | 单元格赋值直接使用 Unicode 字符串，openpyxl 内部以 UTF-8 存储 |
| **print() 防乱码** | **Windows PowerShell 默认 GBK 编码**，`print()` 内容中**禁止使用** `²`（上标2）、`³`、`×`、`÷`、`≥`、`≤`、`φ`、`Φ` 等非 GBK 字符，否则会报 `UnicodeEncodeError`。用 `m2`、`m3`、`x`、`>=` 等 ASCII 替代 |
| 禁止格式 | **禁止**使用 CSV（.csv）、Excel XML（.xml）作为计算表输出 |

> **Excel 单元格 vs print()**：Excel 单元格内可安全使用任何 Unicode 字符（`m²`、`×`、`Φ` 等均可），乱码问题只存在于 `print()` 控制台输出。

## 7. 通用约定

- **输出语言**：**一律使用中文**。包括：脚本 docstring、注释、`print()` 内容、Excel 中的表头/参数名/说明文字、sheet 名称。变量名、函数名可保留英文或规范符号。
- **单位**：在输入与 docstring 中统一注明（如 mm, N, m, 万元）。
- **规范依据**：docstring 或「计算说明」中写清规范编号与条文。
- **命名**：算例脚本用 `calc_<主题>.py`；生成 xlsx 的脚本用 `generate_tables.py` 或 `gen_<主题>.py`。
- **路径**：脚本内路径用 `os.path`，避免反斜杠字符串。
- **输出路径**：`OUT_DIR = os.path.dirname(os.path.abspath(__file__))`，xlsx 生成到脚本同目录。
