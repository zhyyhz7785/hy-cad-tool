## 💡 手动插入图像的方法

由于自动插入功能还在开发中，可以手动插入图像：

### 方法 1：使用 AutoCAD IMAGEATTACH 命令

1. **插入图像**
   ```
   命令: IMAGEATTACH
   选择: 布局.tif
   ```

2. **定位图像**
   - 使用已绘制的红色边界作为参考
   - 调整图像位置和大小以匹配边界

### 方法 2：使用 AutoCAD XREF 命令

1. **附加外部参照**
   ```
   命令: XATTACH
   选择: 布局.tif
   ```

2. **设置位置**
   - 参考红色边界进行定位

## 🔧 技术细节

### TFW 文件格式

```
Line 1: PixelSizeX      (米/像素，X 方向)
Line 2: RotationX       (旋转参数，通常为 0)
Line 3: RotationY       (旋转参数，通常为 0)
Line 4: PixelSizeY      (米/像素，Y 方向，通常为负)
Line 5: OriginX         (左上角 X 坐标)
Line 6: OriginY         (左上角 Y 坐标)
```

### 坐标转换公式

**像素 → 地理坐标**：
$$X_{geo} = OriginX + PixelX \times PixelSizeX + PixelY \times RotationX$$
$$Y_{geo} = OriginY + PixelX \times RotationY + PixelY \times PixelSizeY$$

## 🐛 已知限制

### 当前限制

1. **图像插入**：自动插入功能暂不可用
2. **旋转图像**：支持计算但需要手动调整显示
3. **大文件**：超大 TIF 文件可能影响性能

### 解决方案

1. **手动插入**：使用 AutoCAD 内置命令
2. **分步处理**：先定位边界，再手动插入图像
3. **文件优化**：使用适中大小的 TIF 文件
