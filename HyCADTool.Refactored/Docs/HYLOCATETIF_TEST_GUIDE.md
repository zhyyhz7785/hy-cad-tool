# HYLOCATETIF 命令测试指南

## 测试环境准备

### 系统要求
- **AutoCAD** 版本: 2024 或更高版本
- **.NET Framework** 4.8 或更高版本
- **操作系统**: Windows 10/11 64-bit

### 编译和部署
1. 使用 Visual Studio 编译项目
2. 将生成的 DLL 复制到 AutoCAD 加载项目录
3. 在 AutoCAD 中加载插件

### 创建测试 TIF 文件

使用任何图像编辑工具（如 Photoshop、GIMP）创建测试 TIF 文件：

| 文件名 | 尺寸 | 说明 |
|------|------|------|
| `test_image_1.tif` | 1000 × 1000 px | 对应 test_image_1.tfw |
| `test_image_2.tif` | 2000 × 2000 px | 对应 test_image_2.tfw |
| `test_image_3.tif` | 500 × 500 px | 对应 test_image_3.tfw |
| `test_image_rotated.tif` | 1000 × 1000 px | 对应 test_image_rotated.tfw |

**快速创建方法** (使用 Python):
```python
from PIL import Image

# 创建 1000x1000 的红色 TIF 图像
img = Image.new('RGB', (1000, 1000), color='red')
img.save('test_image_1.tif')
```

## 功能测试用例

### 测试 1: 基本功能 - 正常加载

**目标**: 验证命令能够正确读取 TFW 文件并定位 TIF 图像

3. 选择 `test_image_1.tfw` 文件

**预期结果**:
- ✓ 命令行显示: "图像定位完成: test_image_1"

- ✓ 在图像中心显示绿色文本标注
- ✓ 显示图像尺寸: 1000 x 1000 像素
- ✓ 显示地理范围: X: 500000.00 - 501000.00, Y: 1999000.00 - 2000000.00

### 测试 5: 错误处理 - 文件不存在

**目标**: 验证命令能够正确处理 TFW 文件不存在的情况

**步骤**:
1. 输入命令: `HYLOCATETIF`
2. 选择一个不存在的 TFW 文件路径（手动输入）

**预期结果**:
- ✓ 命令行显示错误信息: "TFW文件不存在: [路径]"
- ✓ 命令正常退出，不产生异常

### 测试 6: 错误处理 - TFW 格式错误

**目标**: 验证命令能够检测 TFW 文件格式错误

**步骤**:
1. 创建格式错误的 TFW 文件 (少于 6 行):
   ```
   1.0
   0.0
   0.0
   -1.0
   ```
2. 输入命令: `HYLOCATETIF`
3. 选择格式错误的 TFW 文件

**预期结果**:
- ✓ 命令行显示错误信息: "TFW文件格式错误: 需要6行参数，实际4行"
- ✓ 命令正常退出

### 测试 7: 错误处理 - TIF 文件不存在

**目标**: 验证命令能够检测对应的 TIF 文件不存在

**步骤**:
1. 创建 TFW 文件但不创建对应的 TIF 文件
2. 输入命令: `HYLOCATETIF`
3. 选择 TFW 文件

**预期结果**:
- ✓ 命令行显示错误信息: "未找到对应的TIF文件: [路径]"
- ✓ 命令正常退出

### 测试 8: 文件扩展名兼容性

**目标**: 验证命令支持多种 TIF 扩展名

**步骤**:
1. 创建相同内容的 TIF 文件，使用不同扩展名:
   - `test_image.tif`
   - `test_image.tiff`
   - `test_image.TIF`
   - `test_image.TIFF`
2. 为每个文件创建对应的 TFW 文件
3. 分别测试每个文件

**预期结果**:
- ✓ 所有扩展名都能正确识别和加载

### 测试 9: 坐标转换精度

**目标**: 验证像素坐标到地理坐标的转换精度

**步骤**:
1. 使用 `test_image_1.tfw` (1.0 m/pixel)
2. 手动计算四个角点的地理坐标:
   - 左上角 (0, 0): (500000, 2000000)
   - 右上角 (1000, 0): (501000, 2000000)
   - 右下角 (1000, 1000): (501000, 1999000)
   - 左下角 (0, 1000): (500000, 1999000)
3. 对比命令输出的坐标

**预期结果**:
- ✓ 所有坐标计算精确到小数点后 2 位
- ✓ 无浮点数精度问题

## 常见测试问题

### Q: 如何验证坐标转换的正确性？
A: 使用已知的 TFW 参数和图像尺寸，手动计算四个角点的地理坐标，然后对比命令输出的坐标。

### Q: 如何测试旋转影像？
A: 设置 RotationX 和 RotationY 参数为非零值，验证多段线显示的边界是旋转的。

### Q: 如何测试性能？
A: 使用 AutoCAD 的性能监视工具或在代码中添加 Stopwatch 计时。

### Q: 如何测试内存占用？
A: 使用 Windows 任务管理器或 Visual Studio 的内存分析工具。
