## 📋 完整使用流程

### 准备阶段

#### 1. 获取 TFW 文件
- TFW 文件必须包含 6 行参数
- 与 TIF 文件同名

#### 2. 获取 TIF 文件
- 支持的格式: .tif, .tiff, .TIF, .TIFF
- 与 TFW 文件同名

#### 3. 启动 AutoCAD
- 版本: 2024 或更高
- 加载插件: NETLOAD HyCADTool.Refactored.dll

```
HYLOCATETIF
```

- 点击 "打开"

- CAD 中绘制图像边界
- 显示图像信息标注

### 结果验证

- [ ] 文本标注显示图像名称

## ⚠️ 常见问题

### Q1: 命令无法执行

**A**: 检查以下几点：
1. DLL 是否正确加载 (NETLOAD)
2. 是否看到初始化消息
3. 尝试重新加载 DLL

### Q2: 文件选择对话框不出现

**A**: 
1. 检查 AutoCAD 版本是否为 2024+
2. 尝试使用系统对话框
3. 检查 WinForms 是否启用

### Q3: TFW 文件格式错误

**A**: 
1. 检查文件是否有 6 行
2. 每行必须是数字
3. 参考示例文件

### Q4: TIF 文件找不到

**A**:
1. 确保 TIF 文件与 TFW 同名
2. 检查扩展名 (.tif, .tiff 等)
3. 确保文件在同一目录

### Q5: 坐标计算不对

**A**:
1. 验证 TFW 参数
2. 检查 PixelSizeY 是否为负数
3. 手动计算验证

## 📊 TFW 文件格式

### 标准格式

```
Line 1: PixelSizeX      (米/像素，X 方向)
Line 2: RotationX       (旋转参数，通常为 0)
Line 3: RotationY       (旋转参数，通常为 0)
Line 4: PixelSizeY      (米/像素，Y 方向，通常为负)
Line 5: OriginX         (左上角 X 坐标)
Line 6: OriginY         (左上角 Y 坐标)
```

### 示例 1: 标准正射影像

```
1.0
0.0
0.0
-1.0
500000.0
2000000.0
```

说明:
- 像素大小: 1.0 m × 1.0 m
- 无旋转
- 左上角: (500000, 2000000)

### 示例 2: 高分辨率影像

```
0.5
0.0
0.0
-0.5
600000.0
1900000.0
```

说明:
- 像素大小: 0.5 m × 0.5 m (高分辨率)
- 左上角: (600000, 1900000)

### 示例 3: 低分辨率影像

```
5.0
0.0
0.0
-5.0
400000.0
2100000.0
```

说明:
- 像素大小: 5.0 m × 5.0 m (低分辨率)
- 左上角: (400000, 2100000)

## 🎯 最佳实践

### ✅ 推荐做法

1. **使用标准的 TFW 格式**
   - 6 行参数
   - 数字格式正确
   - 参数值合理

2. **保持文件同名**
   - image.tfw 和 image.tif
   - 便于自动查找

3. **使用合理的像素大小**
   - 0.5m - 5.0m 范围
   - 避免极端值

4. **定期备份**
   - 备份 TFW 和 TIF 文件
   - 防止数据丢失

### ❌ 避免做法

1. **不要修改 TFW 文件**
   - 除非确实需要
   - 修改前备份

2. **不要使用特殊字符**
   - 文件名中避免特殊字符
   - 使用英文和数字

3. **不要混淆坐标系统**
   - 确保 TFW 参数与实际坐标系统一致
   - 检查单位 (米/像素)

4. **不要忽视错误信息**
   - 仔细阅读错误提示
   - 按照提示修正
