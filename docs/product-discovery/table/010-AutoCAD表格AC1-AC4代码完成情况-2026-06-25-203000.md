## 3. 三层数据模型（AC3 已落地）

| 层 | 内容 | 实现 |
|---|---|---|
| **L1 Domain** | 完整 `TableGrid` JSON | Carrier 扩展字典键 `HyTable_JSON`（`ExtensionDictionaryService.WriteLongString`） |
| **L2 CAD 标签** | TABLE_ID / KIND / SCHEMA / CELL | RegApp `HY_TABLE`（`HyTableXdata.cs`） |
| **L3 CAD 分组** | 整表可选中 | Group 名 `*HyTable-{TableGrid.Id:N}`（`AcadTableStore.BuildGroupName`） |

**Carrier**：`TableLayout.TableBounds` 外框 Polyline，JSON 与 Carrier XData 只写在此实体。  
**成员**：每个可见格 Polyline（`KIND=Grid`）+ DBText（`KIND=Text`），`CELL` 为 Anchor 坐标 `"r,c"`。

读回唯一入口：`AcadTableStore.TryResolveTableGrid(tr, db, picked, out grid, out error)`。

## 6. 核心 API 速查

```csharp
// 渲染 + 写真相源（单事务）
var handle = new AcadTableRenderer(db).RenderAndAttach(grid, insertionPoint);
// handle: GroupId, CarrierId, TableId, EntityCount

// 读回
AcadTableStore.TryResolveTableGrid(tr, db, pickedEntity, out TableGrid grid, out string error);
```

Attach 流程：`SerializeGrid` → Carrier 扩展字典 → 全员 XData → 创建 `*HyTable-{id}` Group。

TryResolve 流程：Carrier 直读 JSON；Grid/Text 成员经 Group 找 Carrier；Group 对象直扫组内 Carrier。

## 9. 关键决策记录

1. **JSON 只存 Carrier**，成员仅轻量 XData——与 [005 §5](./005-复杂表格Domain统一设计-2026-06-24-232335.md) 唯一真相源一致。  
2. **Group 而非 Block** 作为 MVP 表对象——见 [009 Group vs Block](./009-定稿表对象CAD分组方案对比-Group-vs-Block-2026-06-25-190000.md)。  
3. **WPF / 定稿态始终操作整表 `TableGrid`**；改 Domain 后整表 `RenderAndAttach`，不做逐实体 patch。  
4. **C1 用无交互路径**（`ExecutePersonnelAtOrigin`）；N33 保留 `GetPoint` 供正式插入。
