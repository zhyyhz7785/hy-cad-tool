## 0. 目标与约束

| 项 | 内容 |
|---|---|
| **核心功能** | AutoCAD 插件内独立表格编辑器：Excel 级网格 + Office 级 Ribbon + CAD 落图 |
| **目标用户** | 工程制图员（熟悉 Excel 开始/布局 Tab） |
| **平台** | net48 WPF 独立 `TableEditorWindow`；320px Tab 仍用 `TableFillGridView`，**不在本次替换范围** |
| **约束** | 优先 MIT/Apache-2.0；`HyCAD.Tables` 为唯一真相源；AdWindows/PaletteSet 局部 ResourceDictionary merge |
| **成功标准** | 人员模板：真 merge、选区、对齐/边框可辨；C2→C1 无 Badge/主题回归 |
| **五维权重** | 易用 40% / 功能 30% / 稳定 15% / 可靠 8% / 差异化 7% |

## 2. 五维对比与结论

| 方案 | 功能 | 易用 | 稳定 | 可靠 | 差异化 | 加权 | 主要代价 |
|---|---|---|---|---|---|---|---|
| **A 继续自研 ExcelGrid + Blender Ribbon** | 3 | 2 | 3 | 4 | 4 | **2.7** | 长期 polish 难达 Excel 级 |
| **B ReoGrid + Fluent.Ribbon + Adapter** | 4 | **5** | 4 | 4 | 4 | **4.4** | 适配层；ReoGrid 无 FieldKey 语义 |
| **C WebView2 + Univer OSS** | **5** | **5** | 3 | 3 | 3 | **4.2** | 进程/焦点/主题坑 |
| **D ReoGrid V4 商业 + Fluent.Ribbon** | **5** | **5** | **5** | 4 | 3 | **4.5** | 许可费用 |

**结论：推荐方案 B（开源混合路径）。**

## 3. 推荐产品定义（替换后）

**定位**：Office 级 WPF 表格壳 + HyCAD.Tables 工程语义（CAD 落图、FieldKey、012 结构优先）。

| 优先级 | 内容 |
|---|---|
| **Must** | ReoGrid 显示/编辑人员模板；Fluent.Ribbon 三 Tab；`TableGrid ↔ ReoGrid` 加载 + 编辑回写 OpLog；落图不变 |
| **Should** | FieldKey/Role → `Cell.Tag`；Inspector ↔ Ribbon 双向同步 |
| **Could** | ReoGrid 公式栏、xlsx 导入导出 |
| **Won't(now)** | 替换 HyCAD.Tables；320px Tab 换 ReoGrid；Univer 全量 Designer |

## 4. 技术选型与适配规范

| 组件 | 选型 | NuGet | 许可 |
|---|---|---|---|
| 网格 | ReoGrid WPF V3 | `unvell.ReoGridWPF.dll` 3.3.0 | MIT |
| Ribbon | Fluent.Ribbon | 11.0.2 | MIT |
| 适配 | `TableGridReoGridAdapter` | 自研 | — |
| Domain | `HyCAD.Tables` | 不变 | — |

### 4.1 `TableGridReoGridAdapter` 映射

```
Load:  TableGrid → Worksheet.Reset → 行列尺寸 → anchor 文本 → MergeRange → Style/Borders → Cell.Tag
Edit:  CellDataChanged → 解析 anchor → TableEditorViewModel.CommitCell → OpLog
Select: SelectionRangeChanged → SetSelectedRange(start/end)
Meta:  TableGridReoGridCellTag { Row, Col, FieldKey, Role } 序列化到 Cell.Tag
```

### 4.2 架构风险

| 风险 | 对策 |
|---|---|
| ReoGrid merge 语义不一致 | 人员表 PoC 验收；隐藏格只写 anchor |
| AutoCAD WPF 主题冲突 | ReoGrid/Fluent **局部** merge；不挂 Application.Current 全局主题 |
| NuGet 传递依赖复制旧版 AdWindows | AutoCAD.NET 已 `ExcludeAssets runtime`；新包检查传递引用 |
| 双向同步 bug | ReoGrid 作 View；编辑仅经 OpLog |
