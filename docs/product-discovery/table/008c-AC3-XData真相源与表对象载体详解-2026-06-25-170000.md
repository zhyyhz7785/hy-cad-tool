## 1. 三层数据模型

| 层 | 内容 | 存放 |
|---|---|---|
| **L1 Domain** | 完整 `TableGrid` JSON | **仅 Carrier** 扩展字典 `HyTable_JSON` |
| **L2 CAD 标签** | TABLE_ID / KIND / SCHEMA / CELL | 每个 Polyline、DBText、Carrier 的 **XData**（RegApp `HY_TABLE`） |
| **L3 CAD 分组** | 可选中 Group | `*HyTable-{TableGrid.Id:N}` |

**禁止**在每个单元格 Polyline 上重复存 JSON。

---

## 2. HY_TABLE XData 键表

RegApp：`HY_TABLE`

| Key | Carrier | Grid Polyline | Text DBText |
|---|---|---|---|
| `TABLE_ID` | Guid D 格式 | 同左 | 同左 |
| `KIND` | `Carrier` | `Grid` | `Text` |
| `SCHEMA` | `1` | `1` | `1` |
| `CELL` | （无） | `"r,c"` Anchor | `"r,c"` Anchor |

扩展字典（仅 Carrier）：

| Key | 内容 |
|---|---|
| `HyTable_JSON` | `TableJson.SerializeGrid(grid)` 长文本分片 |

---

## 3. Carrier 与 Group

- **Carrier**：`TableLayout.TableBounds` 闭合 Polyline，图层 `HyTable-Grid`，线宽可略加（与单元格共线）。
- **Group 名**：`*HyTable-{TableGrid.Id:N}`（前导 `*` = AutoCAD 可选中组）。
- **成员**：Carrier + 全部单元格 Polyline + 全部 DBText。

---

## 4. Attach 流程

```
RenderAndAttach(grid, insertionPoint)
  → TableLayout.Create
  → 事务内：图层、Carrier、单元格几何
  → WriteLongString(Carrier, JSON)
  → HyTableXdata.WriteCarrier / WriteMember
  → 创建 Group，Append 全部 ObjectId
  → 返回 TableCadHandle { GroupId, CarrierId, TableId }
```

---

## 5. TryResolveTableGrid 流程

```
点选 Entity
  → HyTableXdata.ReadTableId + ReadKind
  → KIND=Carrier → ReadLongString → DeserializeGrid
  → KIND=Grid|Text → 找含该实体的 Group → 组内 KIND=Carrier → 读 JSON
  → GridInvariants.Validate（报告给命令行）
```

---

## 6. 定稿 vs 编辑（预留）

| 模式 | 选取 | 数据源 |
|---|---|---|
| 定稿 OFF | Group / 任意 HY_TABLE 成员 | Carrier JSON → 整表 `TableGrid` |
| 编辑 ON（AC10） | 单线/单字 | 成员 `CELL` + Infer 写回 Carrier |

WPF（AC11）ViewModel 始终绑定 `TableGrid`；改值后 **整表重 RenderAndAttach**。
