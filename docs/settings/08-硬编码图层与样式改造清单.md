# 08 — 硬编码图层/样式/比例改造清单

供后续增量重构使用。**比例**业务真相源：见 01-配置体系总览（`SettingsPanelViewModel` / `GetScale`）。

## 1. 已落地：用户可编辑图层表

- 默认层表与语义 ID 见 `Domain/ValueObjects/Configuration/User/LayerCatalogFactory.cs`（合并原 `PluginInitializer.GetRequiredLayers()` 与 `HyRoadLayers.GetAll()`）。
- 当前图纸初始化：`ILayerService.EnsureUserLayerItems`（`LayerService` 实现）从设置中的 `UserLayerSettings` 创建/更新图层。
- 按语义名解析（用户可改名）：`UserLayerNameResolver` + `SettingsPanelViewModel.TryResolveLayerName`；`HyRoadLayers` 中图层**名称**已改为**属性**并走解析器，道路模块改名后生效。

## 2. 仍建议跟进的硬编码

| 类型 | 说明 | 建议 |
|------|------|------|
| 非道路图层名 | 如 `"01_hy_1钢筋_线钢筋"` 仍散见于钢筋/聚类命令 | 在 `LayerCatalogFactory` 有语义行后，逐步改为 `UserLayerNameResolver` / 专用 `HyBuiltinLayerNames` 属性 |
| 样式名 | 部分命令写死 `0-hy-说明-S` 等 | 与 `BuildStyleName`/上下文 `ScaleContext` 对齐或从设置取 |
| 图框/标高 | `DrawingSheetTitleSpec` 等含 `05_hy_道路_横断面_*` 字符串 | 改为 `HyRoadLayers` 或解析器，避免与层表重名后不一致 |
| 道路以外 | 交叉口等若仍用字面量 | 同道路：语义 ID + 解析器 |
