# 01 · 比例 · 说明

> 对象：HyCADTool.Refactored Settings 面板「比例 / 单位 / 小数位 / 副比例」五大参数。
> 目标：让出图比例、绘图单位与标注读数三件事解耦，并一次讲清**公式 → UI → 代码 → 验收**。
> 读者：插件使用者（CAD 工程师）+ 后续维护者（开发）。

---

## 0. 一句话心智模型（TL;DR）

> **纸面标记尺寸固定（2.5 mm），标注读数等于真实世界尺寸，几何按需要×/÷ 一个倍数。**

具体拆成三条不变量：

1. **纸面标记恒定**：文字字高、箭头大小、延长线等，打印到纸上永远是同一物理尺寸（默认 `paper_mm = 2.5 mm`）。
2. **标注读数真实**：无论单位是 mm / cm / m，无论是否启用副比例，`DIM` 命令量出来的数字**等于物体真实尺寸**。
3. **几何 1:1 语义**：1 个模型单位 = 1 个绘图单位（例如单位=m 时，5m 长墙存储成 `5.0`，而不是 `5000`）。

所有派生量（DIMSCALE / DIMLFAC / Dimtxt / 文字字高 / 箭头大小 / 样式名）都由这三条不变量**推导**出来，**不存在独立配置项**。

类比：把纸面看成"最终成品外壳"，模型空间看成"图纸骨架"，DIMSCALE / UnitFactor / GeomMul 就是"**三个螺栓**"——你只拧一个就把骨架放大缩小，另外两个会自动补偿让外壳不变形。

---

## 1. 背景：为什么需要这四个参数

### 1.1 只有"出图比例"（MainScale）不够

- 传统做法：按 1:100 出图，就把 `DIMSCALE = 100`；文字纸面 2.5 mm 存 `Dimtxt = 2.5`，AutoCAD 自动放大 100 倍 → 模型字高 250，打印时 ÷100 回到 2.5 mm。够用，直到遇到**单位切换**和**局部详图**。

### 1.2 单位换一下，数字就全错（需要 Unit）

- 同一堵 5 m 墙：
  - 用 mm 画 → 存 `5000`，标注显示 `5000`（符合习惯）
  - 用 m 画 → 存 `5.0`，标注显示 `5.0`（更自然）
- 但**字高**若照搬 mm 的公式，m 单位下字高会变成 `2.5 × 100 = 250 m`——比 16 个足球场还大。所以必须引入 **`UnitFactor`** 把"纸面 mm"换算到"模型单位"。

### 1.3 大图套小详图，需要副比例（SubScale）

- 总图 1:100，但右上角想插一块 1:20 节点详图。
- 节点详图里的墙只有 200 mm，如果按 1:100 画，纸上只剩 2 mm，看不清。
- 做法：**把几何放大 5 倍**（100/20=5），让墙画成 1000 mm；同时**把标注读数再除以 5**，保持 `200` 的真实读数。
- 这个"5 倍"叫 `GeomMul`，"÷5"叫 `DIMLFAC`。两者由 `MainScale` 和 `SubScale` 派生。

### 1.4 小数位不是美学偏好（Precision）

- mm 单位下读数通常整数够用（墙长 5000，不需要 5000.00）
- m 单位下读数天然带小数（5.000 / 5.250）
- cm 介于中间（250 / 250.5）
- 业务上一致希望"切到 m 自动给 3 位、切到 cm 自动 2 位、切到 mm 自动 0 位"，用户仍可手动覆盖。

## 2. 核心公式（唯一真理源 = `ScaleContext`）

### 2.1 符号

| 符号 | 含义 | 代码字段 | 典型值 |
|---|---|---|---|
| `M` | 主比例（整体出图比例）| `MainScale` | 100 |
| `S` | 副比例（局部详图出图比例）| `SubScale` | 20 |
| `UseSub` | 是否启用副比例 | `UseSubScale` | true/false |
| `uf` | 单位因子（paper_mm → model_unit）| `UnitFactor` | mm=1 / cm=0.1 / m=0.001 |
| `p` | 标注小数位（DIMDEC / DIMTDEC）| `Precision` | 0..3 |
| `paper_mm` | 纸面标记大小 | `TextSize` 等 | 2.5 |

### 2.2 派生式（代码里是 `ScaleContext` 的只读属性）

```
DIMSCALE  = M                        // 标注整体放大倍数，恒等于主比例
DIMLFAC   = UseSub ? S / M : 1       // 标注线性比例因子：抵消 GeomMul，让读数=真实
GeomMul   = UseSub ? M / S : 1       // 局部详图几何放大倍数（由使用者×入块/图元坐标）
UnitFactor= { mm:1.0, cm:0.1, m:0.001 }   // 纸面 mm → 模型单位
```

样式里写盘的纸面基值（Dimtxt / Dimasz / Dimexo ...）规则：

```
stored_value = paper_mm × UnitFactor         // 写入样式
display_value_in_model = stored_value × DIMSCALE   // AutoCAD 渲染时自动 × DIMSCALE
                      = paper_mm × UnitFactor × M
```

文字样式（**没**有 DIMSCALE 自动放大）写盘规则：

```
TextStyle.TextHeight = paper_mm × UnitFactor × M    // 已经乘完
```

**验证**（纸面 2.5 mm / 1:100 出图）：

| 单位 | UnitFactor | stored Dimtxt | model 字高 | 打印字高 |
|---|---|---|---|---|
| mm | 1.0    | 2.5    | 2.5 × 100 = 250 mm | 250 mm ÷ 100 = **2.5 mm ✓** |
| cm | 0.1    | 0.25   | 0.25 × 100 = 25 cm | 25 cm ÷ 100 = **0.25 cm = 2.5 mm ✓** |
| m  | 0.001  | 0.0025 | 0.0025 × 100 = 0.25 m | 0.25 m ÷ 100 = **0.0025 m = 2.5 mm ✓** |

结论：三种单位下纸面字高**全部 = 2.5 mm**，这就是"纸面标记恒定"不变量。

### 2.3 DIMLFAC 抵消 GeomMul 的代数

- 在副比例区，模型里几何被×`GeomMul = M/S`
- 标注长度读数 = 模型长度 × `DIMLFAC`
- 读数 = 真实长度 × (M/S) × (S/M) = **真实长度** ✓

## 3. 样式命名规则

所有比例参数变化都**编码进样式名**，这样 AutoCAD 里可以同时存在多套样式互不干扰：

```
Dim      : 0-Hy-{M}-{S}-Dim-{u}-{p}        例：0-Hy-100-20-Dim-m-3
MLeader  : 0-Hy-{M}-{S}-Mleader-{u}-{p}    例：0-Hy-100-20-Mleader-m-3
Table    : 0-Hy-{M}-{S}-Table-{u}          例：0-Hy-100-20-Table-m   （表格无小数位）
```

规则：

- `UseSub = false` 时，`{S}` 段回填为 `{M}`（例：`0-Hy-100-100-Dim-mm-0`）
- 比例是整数就不带小数点（`100` 而非 `100.00`）
- 小数比例最多 2 位（`0.5` / `2.5`）
- 切换任一参数后，样式名立刻变化，后续的"置为当前"会**新建**一个样式而非覆盖旧样式

好处：同一张图里可以同时存在 `0-Hy-100-100-Dim-mm-0` 和 `0-Hy-100-20-Dim-m-3`，节点详图用后者、总图用前者，互不影响。

## 4. UI 与行为

面板顶部横条：

```
[主比例 1 : (输入)] [√] [启用副比例] [1 : (输入)] [单位 ▽] [小数位 ▽]
```

### 4.1 "模式切换" vs "数值微调"

| 操作 | 归类 | 样式名是否变化 | auto-apply（立即写 AutoCAD）|
|---|---|---|---|
| 勾/取消 `启用副比例` | 模式切换 | 是（`{S}` 段切换）| **✅ 立即**|
| 下拉 `单位` | 模式切换 | 是（`{u}` 段）| **✅ 立即**|
| 下拉 `小数位` | 模式切换 | 是（`{p}` 段）| **✅ 立即**|
| 输入 `主比例` 数字 | 数值微调 | 是（`{M}` 段）| ❌ 需手动点「置为当前」|
| 输入 `副比例` 数字 | 数值微调 | 是（`{S}` 段）| ❌ 需手动点「置为当前」|

理由：数值输入框在打字中会出现半成品（如 `0`、`5`），立即 apply 会炸；下拉/勾选都是离散、瞬时完成、不会产生非法中间态。

### 4.2 状态栏显示条语义

显示条文本：`当前标注样式 ▶ {AppliedDimStyleName}`

- `AppliedDimStyleName` **只在 ApplyStyle() 成功落盘后才刷新**
- 模式切换会 auto-apply → 显示条**立即**跟着变
- 数值微调不 auto-apply → 显示条**保持不变**，直到用户点「置为当前」

目的：显示的永远是 AutoCAD 里真正激活的那个样式名，避免"面板上已经显示新样式、但画标注还是旧样式"的误导。

### 4.3 自动联动

- `Unit` 切换时：
  - `_precision` 自动重置为 `GetDefaultPrecision(unit)`（mm=0 / cm=2 / m=3）
  - AutoCAD `INSUNITS` 系统变量同步（mm=4 / cm=5 / m=6）
  - 触发 auto-apply
- `UseSubScale = false` 时：
  - `_subScale` 自动归一为 `MainScale`（样式名 `{S}` 段回填）
  - 输入框显示同步刷新
  - 触发 auto-apply（让标注/引线切回主比例样式）

## 5. 代码接入（开发者视角）

### 5.1 单一真理源：`ScaleContext`

```
HyCADTool.Refactored/Domain/Models/Drawing/ScaleContext.cs
```

不可变值对象（sealed class），构造参数 `(M, S, UseSub, Unit, Precision)`，派生属性 `UnitFactor / DimLfac / GeomMul / EffectiveSubScale / InsUnitsCode / UnitShortName`，静态工厂 `GetAllowedPrecisions / GetDefaultPrecision / ClampPrecision`，样式名工厂 `BuildDimStyleName / BuildMLeaderStyleName / BuildTableStyleName`。

### 5.2 全局广播：`ActiveScaleContextProvider`

```
HyCADTool.Refactored/Presentation/ViewModels/ActiveScaleContextProvider.cs
```

`ApplyStyle()` 成功后 `Set(ctx)`，后续命令（导出、标注、块插入等）可通过 `Current` 拿到当前生效的 context，读取 `GeomMul` / `UnitFactor` 做自己的换算。

### 5.3 样式服务签名

```csharp
// HyCADTool.Refactored/Infrastructure/AutoCAD/Services/StyleService.cs

CreateDimensionStyle(
    string styleName, string textStyleName, double scale,
    double dimtxt, double dimexo, double dimexe,
    double dimdle, double dimgap, double dimasz,
    double dimlfac, int dimdec, double unitFactor);   // 内部做 paper × uf

CreateMLeaderStyle(
    string styleName, string textStyleName, double scale,
    double arrowSize, double landingGap, double textHeight,
    int textColorIndex, double unitFactor);           // 内部做 paper × uf × scale

CreateTextStyle(
    string styleName, string font, string bigFont,
    double textHeight,        // 由调用方预乘：paper × uf × scale
    double widthFactor);
```

设计权衡：

- **Dimension 走 uf，不走 scale**：因为 AutoCAD 的 `DIMSCALE` 会在渲染时再乘一遍 scale，所以写盘不能预乘 scale，否则双倍放大。
- **MLeader / Text 走 uf × scale**：这两类样式**没有** DIMSCALE 自动放大机制，必须预乘。
- 所有单位换算统一收口到 StyleService 内部，调用方只传"纸面 mm 基值 + uf"，不需要关心 Dim 与 MLeader 的差异。

### 5.4 ViewModel 调用骨架

```csharp
// HyCADTool.Refactored/Presentation/ViewModels/SettingsPanelViewModel.cs :: ApplyStyle()

var ctx = BuildScaleContext();
double uf = ctx.UnitFactor;
double scale = ctx.MainScale;

_styleService.CreateTextStyle(StyleSName, StyleSFont, StyleSBigFont,
                              TextSize * uf * scale, StyleSXScale);
_styleService.CreateDimensionStyle(
    ctx.BuildDimStyleName(), TextStyleName, scale,
    Dimtxt, Dimexo, Dimexe, Dimdle, Dimgap, Dimasz,
    ctx.DimLfac, ctx.Precision, uf);
_styleService.CreateMLeaderStyle(
    ctx.BuildMLeaderStyleName(), TextStyleName, scale,
    MLeaderArrowSize, MLeaderLandingGap, TextSize, MLeaderTextColorIndex, uf);

ActiveScaleContextProvider.Set(ctx);
_appliedContext = ctx;
OnPropertyChanged(nameof(AppliedDimStyleName));
```

## 6. 验收用例

以下 4 个用例覆盖所有参数组合，变更任意代码后请逐一回归。

### 用例 A：mm / 1:100 / 不启用副比例

- 操作：单位=mm，小数位=0，主比例=100，副比例关闭
- 期望：
  - 样式名：`0-Hy-100-100-Dim-mm-0`
  - 模型字高 = 250 mm，打印字高 = 2.5 mm
  - 标注读数 = 真实长度（mm）

### 用例 B：m / 1:100 / 不启用副比例

- 操作：单位=m（小数位自动变 3），主比例=100，副比例关闭
- 期望：
  - 样式名：`0-Hy-100-100-Dim-m-3`
  - 模型字高 = 0.25 m（相对用例 A **缩小 1000 倍** ✓）
  - 标注读数 = 真实长度（m，3 位小数）

### 用例 C：cm / 1:100 / 不启用副比例

- 操作：单位=cm（小数位自动变 2），主比例=100
- 期望：
  - 样式名：`0-Hy-100-100-Dim-cm-2`
  - 模型字高 = 25 cm（相对用例 A **缩小 100 倍** ✓）

### 用例 D：m / 1:100 总图 + 1:20 副比例

- 操作：单位=m，主比例=100，勾启用副比例=20
- 期望：
  - 样式名：`0-Hy-100-20-Dim-m-3`
  - `DIMSCALE = 100`
  - `DIMLFAC = 20/100 = 0.2`
  - 节点详图处几何按 `GeomMul = 100/20 = 5` 放大后，标注读数仍 = 真实尺寸
  - 纸面字高 = 2.5 mm（与主比例区一致）

### 用例 E：状态栏显示条稳态

- 先点「置为当前」，显示条显示 `...-Dim-mm-0`
- 改主比例输入框 100 → 50：显示条**不应变**（仍显示 mm-0 且 M=100 那一版）
- 再点「置为当前」：显示条更新为 `...-50-50-Dim-mm-0`
- 下拉单位切到 m：显示条**立即**变为 `...-50-50-Dim-m-3`（auto-apply）

## 7. 常见误区

1. **"m 单位下怎么字高这么小"** → 这是正确的。模型空间存的是**模型单位**数值（m），0.25 m 就是 0.25。打印 1:100 出图会除以 100 回到 0.25 cm = 2.5 mm 纸面。
2. **"切完单位面板上的字高标签没变"** → 检查 `ActualTextHeight` 是否 `OnPropertyChanged`。目前 `Unit` setter 里已经调用 `NotifyScaleContextChanged()`，内部广播 `ActualTextHeight`。
3. **"改了主比例显示条没变，是 BUG 吗"** → 不是，**这是特性**。显示条只在「置为当前」后更新（见 §4.2）。要观察下一个样式名，可在 XAML 里额外绑 `DimStyleName`（实时派生）。
4. **"副比例样式和主比例样式撞车了"** → 样式名含 `{S}` 段，不会撞。若想强制合并，关闭「启用副比例」即可。
5. **"改了小数位但标注只能看到整数"** → 注意区分 `DIMDEC`（主单位小数位）和 `DIMTDEC`（换算单位小数位）。当前实现两者同值写入。
