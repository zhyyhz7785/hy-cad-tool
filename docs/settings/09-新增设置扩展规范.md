# 09 — 新增设置扩展规范（绘图 / 图层 / 样式）

本文件约定：在 HyCADTool 中新增「用户可改、需持久化、与 AutoCAD 落图相关」的参数时，如何接入 **hy-settings.json** 与 **设置面板**，避免再出现多套真相源。

## 1. 分层

| 层 | 存放 | 说明 |
|----|------|------|
| 用户全局 | `%APPDATA%\HyCADTool\hy-settings.json` | 主面板由 `SettingsPanelViewModel` 序列化；图层表为 `UserLayerSettings` 节点 |
| 默认表 | `Infrastructure/AutoCAD/Configuration/LayerCatalogFactory` | 内置默认图层语义 + 默认名/色；与 `UserLayerSettingsMerger` 合并 |
| 道路图层名解析 | `HyRoadLayers.*` 属性 → `UserLayerNameResolver` | 用户改名后命令仍取到当前名；`GetAll()` 仍返回**默认**名供建表 |
| 部署级 | `config.json` | 仅部署/兼容旧 GlobalConfiguration，非日常 UI 主路径 |

## 2. 新增「图层」相关

1. 在 `LayerSemanticIds` 增加**稳定语义 ID**（勿改已有 ID；新增用新键）。
2. 在 `LayerCatalogFactory` 的 `GetNonRoadSeeds` 或 `MapRoadNameToSemanticId` 中增加一行默认项（与默认图层名一致）。
3. 命令中**不要**写死最终图层字符串；道路类用 `HyRoadLayers.XXXLayer`（已走解析器）；其它模块逐步改为 `SettingsPanelViewModel.Current.TryResolveLayerName(semanticId, defaultName)`。
4. 文档资源初始化：`PluginInitializer` 已改为 `ILayerService.EnsureUserLayerItems(vm.LayerCatalogItems)`。

## 3. 新增「样式 / 比例 / 单位」等

1. 在 `SettingsPanelViewModel` / 内嵌 `SettingsData` 增加字段与默认值；`LoadSettings` 做缺省兼容。
2. 在 `HyPreferencesView` / `HySettingsViewModel.BuildSkeleton` 增加分组与 `GroupKey`；对应 `DataTemplate` 接到子 `*SettingsView`。
3. 落图：经 `EnsureStylesApplied` / `IStyleService` 写入当前 DWG；比例仍以 `SettingsPanelViewModel` 为业务真相源（见 01）。

## 4. 禁止项

- 新功能不要在命令里直接写死道路图层名（除非经解析器）；见 [08-硬编码改造清单](./08-硬编码图层与样式改造清单.md)。
- 不要把仅 WPF 用的资源写进 `hy-settings.json`（主题/UI 缩放除外，已存在字段）。
