# 06 — 扩展、排障与约定

## 1. 新增 `hy-settings.json` 字段的推荐步骤

1. 在 `SettingsPanelViewModel` 增加属性（默认值与业务一致）。  
2. 在嵌套类 `SettingsData` 中增加 **同名 JSON 属性** 与 **默认值**。  
3. 在 `SaveSettings` 中把属性写入 `SettingsData` 实例。  
4. 在 `LoadSettings` 中读取并兜底（旧文件无字段时保持兼容）。  
5. 若影响 AutoCAD 样式，将相关字段纳入 `BuildStyleSignature()`，避免无意义的重复 `EnsureStylesApplied()`。  
6. 若有 UI，在对应 Preferences XAML 绑定新属性。

---

## 2. 自动保存与 `StatusMessage`

`SetProperty` 对 `StatusMessage` **不触发**自动保存，避免频繁写盘与循环。

---

## 3. Scale 与配置一致性

- 业务代码取比例：优先 `SettingsPanelViewModel.Current?.Scale`，或使用 `ConfigurationService.GetScale()`（内部已优先 VM）。  
- 若直接改 `GlobalConfigurationService` 中的 Scale 而不同步 VM，可能导致 **短暂不一致**；推荐通过 `ConfigurationService.SetScale` 或只改 VM。

---

## 4. `config.json` 缺失时

- `JsonConfigurationLoader.EnsureConfigLoaded` 在文件不存在时抛 `FileNotFoundException`；上层 `GlobalConfigurationService` / `ModuleConfigurationService` 构造中 **catch** 后回退默认配置，避免 DI 失败。  
- 开发环境若未部署 `config.json`，插件仍应能启动，功能依赖默认对象。

---

## 5. 图层 / 样式常见问题

| 现象 | 可能原因 | 排查 |
|------|----------|------|
| 新 DWG 无某图层 | 该文档未跑过 `EnsureCurrentDocumentResourcesInitialized`；或图层只在 `HyRoadLayers.GetAll()` 而从未被服务创建 | 开图后执行任意会触发初始化的命令；检查 `GetRequiredLayers` 与 `HyRoadLayers` |
| 改代码里图层名后命令仍写旧层 | 某处字符串未替换 | 全局搜索旧图层名 |
| 改 `hy-settings` 后样式未变 | `_stylesDirty` 未置位或命令未调 `EnsureStylesApplied` | 跟 `BuildStyleSignature` 与命令入口 |

---

## 6. WPF 主题与 AutoCAD 宿主

- 主题与 UI 缩放存于 `hy-settings.json`（`Theme`、`UiFontScale` 等）。  
- PaletteSet 宿主下修改全局 `Application.Resources` 可能引发与 AutoCAD 内部控件冲突；项目规则见 `hycad-project-pitfalls` / `wpf-paletteset-resource-pitfalls` skill，**此处不展开**。

---

## 7. 版本控制建议

- **不要**将用户 `%APPDATA%\HyCADTool\*.json` 提交进 Git。  
- 仓库内可保留 **匿名示例**（如 `config.json`）作为结构参考。  

---

## 8. 文档维护

当以下文件行为变化时，应同步更新 `doc/Setting`：

- `SettingsPanelViewModel.SettingsData`  
- `PluginInitializer.GetRequiredLayers`  
- `HyRoadLayers`  
- `ConfigurationService` / `JsonConfigurationLoader`  
- 各面板独立 JSON 的 DTO
