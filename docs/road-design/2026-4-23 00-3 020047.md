# 执行摘要  
本文对道路路缘石（curb）与路面高差的概念、规范要求及工程实践进行了系统研究。首先给出路缘高差（路缘石外露高度）与坡度等定义：路缘石分为平缘石（flush curb，顶面与路面齐平）和立缘石（barrier curb，顶面高出路面）。外露高度一般指立缘石顶面高出车行道路面或人行道路面的高度【32†L2813-L2820】。工程图中常用“正负高程”（相对标高）标注高差，正值表示高出路面，负值表示低于路面。坡度以纵横坡度表示，如缘石坡道纵坡1:20（5%）表示高度与长度之比。台阶高度（step height）指较小高差（如跨越单个路沿石）尺寸。

在规范对比方面，我国《城市道路工程设计规范》（CJJ37-2012）规定：中央分隔带或隔离带两侧立缘石外露高度宜15～20cm，路侧带两侧宜10～15cm，人行横道及出入口处宜采用平缘石【32†L2813-L2820】。新版深圳标准（SJG69-2024）明确：中央分隔带两侧20～25cm，车行道两侧15～20cm，自行车道两侧10～15cm，人行道两侧采用平缘石【4†L33-L41】。无障碍规范GB50763-2012对缘石坡道提出坡度要求：全宽式单面坡道坡度≤1:20，三面坡（或侧面坡）坡度≤1:12【26†L141-L142】；坡道坡口应与车行道平齐。国际上美国ADA/PROWAG建议标准路缘高度一般在75～230mm（3″～9″）之间【59†L7-L10】，常见标准约150mm（6″）为垂直（防撞）缘石高度。AASHTO《公路桥涵设计规范》建议6英寸（≈150mm）为优选路缘高度。欧洲尚缺统一限值，通常参照国际通行经验（例如英国BD-33规范也采用约100～200mm范围）。下表列出了部分规范要求的对比：

# 路缘高差对排水与通行的影响  
立缘石通过高差引导路面水流向排水口，有助于**路面排水**【32†L2817-L2820】。但若外露高度过大或坡度设计不合理，易导致路侧积水或堵塞。例如，当路面纵坡和横坡过小或排水口布设不当时，即使有10–20cm的路缘石，积水也可能漫溢路面。因此设计中应保证路肩或边沟与路缘形成合适的导水坡度（通常0.5%–1%）以提升排水效率【32†L2817-L2820】。  
对于**行人无障碍通行**，高出路面过大的立缘石将成为轮椅使用者、婴儿车和视障者的障碍。研究表明，轮椅用户出行时倾向选择无高差或平缓衔接的路径，不合规的缘石坡道是其面临的主要问题之一【53†L93-L100】。无障碍规范因此要求：缘石坡道纵坡不得陡于1:20，坡口与道路平齐【26†L141-L142】，并在转角和人行横道处设置盲道与坡道接驳（以保证视觉障碍者安全引导）。  
对于**机动车**而言，垂直高缘石可起到物理隔离和防止车辆越线的作用，但过高的高缘石会导致轮胎爬升困难、车辆底盘损伤或紧急驶离时影响控制。经验上，一般在快速路及主干道保持15–20cm作为障碍缘石；对于要求紧急跨越的路段（如消防道、紧急停车湾）则使用可跨式较低路缘（6cm左右）或扶手石（Mountable Curb）以保障通行。较低的可跨式缘石（≈6cm）通常用于出入口、绿化带或停车场，以兼顾车辆进出的便利。  
从**行车安全**角度看，路缘高差设计应综合考虑车速：高速路路侧带可适当降低缘石高度并设置清晰标志；城市交叉口使用倒角或扇形坡道衔接以减缓转弯车辆。对于**维护管理**，高缘石处盲道、井盖等位置应注意无障碍衔接；雨季积水处应定期疏通排水口，设计时可以采用双侧路缘坡道或桥接等措施避免水位拥堵。

# 不同路况下的路缘高差设计  
- **城市主干道**：采用高度较大的障碍立缘石（15–20cm）作为隔离和排水引导，同时在人行横道、出入口处设置平缘石或完整坡道（纵坡≤5%）【26†L141-L142】【32†L2813-L2820】。  
- **次干路/支路**：可适当降低缘石高度（≈10–15cm），同时确保路面无障碍衔接。自行车道两侧缘石高度可进一步降低（≈10cm）或采用缓坡衔接，便于非机动车通行【4†L33-L41】。  
- **人行道与出入口**：宜使用平缘石（高差≈0），或按无障碍要求设置可通行坡道【32†L2813-L2820】【26†L141-L142】。在人行道两端坡口处，应与盲道、横道等宽平顺衔接。  
- **交叉口与斜坡段**：转角处可采用圆曲线缘石或倒角设计，缩短行人穿越距离。对于有竖向落差的斜坡道路段，应设置连续均匀渐变的缘石坡道，并做好排水坡度，避免局部积水【26†L141-L142】【32†L2813-L2820】。  
- **停车场和侧车道**：可采用较低或可跨缘石（约6–8cm），方便车辆驶离。同时在停车出入口处结合盲道和缓坡，确保轮椅和婴儿车可通过。  

# 设计建议与施工要点  
- **严格执行规范原则**：严格遵守*Clean Architecture*和*SOLID*原则，避免过度设计。分析本工程需求，适度选用立缘石或平缘石类型；对统一块体建议用标准尺寸模块拼装。  
- **精确测量与放样**：施工作业应使用全站仪等精密测量工具确定标高。相邻块体顶面高差偏差应控制在≤3mm【76†L63-L65】，以保证平整度。  
- **平顺过渡设计**：无障碍区域应采用坡度衔接，坡口与车行道零高差【26†L141-L142】；盲道提示带应铺设连续，不应因井盖等中断。转角缓冲带（处置台）采用扇形或抛物线过渡，满足前纵后横过渡要求。  
- **坡度与排水匹配**：设置缓冲带或导水坡使得缘石坡口处有0.5%–1%导水坡度，与排水口配合【32†L2817-L2820】。在行车道侧缘时，应考虑雨水口位置，避免排水口高于人行面造成堵塞。  
- **盲道与无障碍要求**：所有坡口下口需与盲道等宽；坡道坡面应光滑防滑，并在坡脚处设置提示盲道，确保视觉障碍者安全【26†L141-L142】。  
- **材料与强度**：推荐路缘石采用C40混凝土（车道）或C30（人行），并进行抗冻性能测试。石材质地应均匀，以免局部坍塌导致高差变化。  
- **施工细节**：安装时应填实垫层并做防跑浆处理，接口灌缝满水泥砂浆或弹性填缝剂。混凝土养护应饱水，并避免车辆荷载提前作用。

# 结论与注意事项  
路缘石高差控制是确保道路功能、排水与无障碍通行的关键环节。综上所述，**合理的高差值**通常为中央分隔带20±5cm，机动车道边15±5cm，自行车道或次车道10±5cm，辅以平缘石或坡道衔接；**坡度限制**为最大1:20的平缓坡（长段）和1:12的侧坡（边缘）。施工时要严格按照规范控制精度，并做好排水、盲道等配套设施。现场管理中应重点防止以下常见问题：路缘低洼致积水、坡道不平致绊倒、轮椅通行受限、井盖与盲道不符致安全隐患等。**缓解措施**包括：在低点设置多个雨水口以免堵塞；对高差<20mm的地方可直接铺设斜坡；设计时提供双向坡道以避免单侧堵塞；定期检查并清理排水口和盲道。  

综上，在不同城市和道路等级下应参考相应规范要求，并结合现场条件综合布置路缘形状及高差值，以兼顾排水性能、通行舒适性和建设成本。本文汇总的规范对比和设计建议可作为工程设计与施工的参考依据。
