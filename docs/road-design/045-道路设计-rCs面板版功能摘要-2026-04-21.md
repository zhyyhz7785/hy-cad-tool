# 045 · 道路设计 · rCs 面板版（v2）功能摘要

> **文档性质**：对 **`hyRoadCs` / `rCs`** 打开的 **横断面绘制面板 v2**（`CrossSectionDrawWindow`，BlenderUI Workbench 风格）已实现能力的**浓缩清单**，便于培训、验收或与鸿业式「标准横断面」对标时快速对齐预期。  
> **关联入口**：[041 · 道路设计 · AI 上下文索引](./041-道路设计-AI上下文索引.md) · [042 · rCs / 标准横断面](./042-道路设计-rCs-AI上下文索引.md) · [052 · 命令与流程](./052-道路设计命令功能-2026-04-19.md) §4 M3。

---

## 1. 定位

| 项 | 说明 |
|----|------|
| **面板版含义** | 相对 v1 `CrossSectionDesignerWindow`（三列 DataGrid），v2 为 **Outliner + 视口预览 + PropertyEditor + StatusBar** 的 Workbench 布局，数据仍走同一套 `CrossSectionDesignerViewModel` 基类 + `CrossSectionDrawViewModel` 扩展。 |
| **命令别名** | `rCs` → `hyRoadCs`；`rCsL` → `hyRoadCsLoad`；`rCsQ` → `hyRoadCsQuick`（见 042 命令表）。 |
| **统一道路面板** | `RoadDesignViewModel` 中「横断面」按钮已绑定 `RoadCrossSectionDrawCommand`，**不再**走已 Obsolete 的 `hyRoadT` 转发壳。 |

---

## 2. 命令入口（已实现）

| 行为 | 命令 | 用户可见结果 |
|------|------|----------------|
| **新建** | `hyRoadCs` / `rCs` | 默认 **CJJ 37 城市主干路** 预设 → 打开 v2 窗口 → 定稿后提示插入点 → **落图 + 写 Registry / JSON**。 |
| **从当前图加载** | `hyRoadCsLoad` / `rCsL` | 从当前 DWG 已存 `RoadDesign.Templates` 选一模板 → 打开同一窗口编辑 → 定稿后落图；解析失败时回退默认预设并提示。 |
| **命令行快出** | `hyRoadCsQuick` / `rCsQ` | **不打开 WPF**：命令行选内置预设 → 插入点 → 直接出图（脚本 / 回归）。 |
| **兼容壳** | `hyRoadT` | Obsolete，内部转发到 `RoadCrossSectionDrawCommand`，与 v2 同实现。 |
| **预设导出 / 列出** | `hyRoadCsPresetSave`、`hyRoadCsPresetLoad` | 从 Registry 选 Template 导出到用户预设目录；或列出内置 + 用户预设（M7.1，与面板顶部预设下拉互补）。 |

## 3. 界面结构（v2 窗口）

- **宿主**：`BlenderWindow`（`HyCAD.BlenderUI`），合并 BlenderDark 主题与道路设计样式字典。
- **顶栏**：标题绑定 `Title`；右侧含 **出图模式切换**（见 §5）、**大纲/属性侧栏显隐**、**预设 ComboBox**。
- **主体（典型五列）**：**Outliner（条带树）** | 分割条 | **Toolbar + Canvas 预览** | 分割条 | **PropertyEditor（属性表）**。
- **底栏**：左路幅（左半 / 右半 / 总宽）、中央 **规范检查通过与否**、右侧 **确定并出图 / 取消**（及复制粘贴等，见 §6）。
- **模态行为**：窗口以 AutoCAD 主窗口为 Owner，避免被主窗口压在后面；极端非 CAD 宿主可回退 `ShowDialog`。

## 4. 建模与编辑能力（面板内）

以下由 **`CrossSectionDesignerViewModel`（基类）** 提供逻辑，**`CrossSectionDrawViewModel`** 仅增加 Outliner、状态栏、侧栏折叠、复制粘贴与 M7.4 出图模式等。

### 4.1 条带与几何

- **左右条带列表**：增删、上下移动、镜像、从预设 **整表替换**（`LoadPresetCommand`）。
- **条带类型（Kind）**：机动车道、非机动车道、人行道、绿化带、路牙、土路肩、中分带等（`AvailableKinds`）。
- **全局参数**：设计速度（规范校核用）、比例尺（1:50 / 1:100 / 1:200）、**中央隔离带宽度**（可与 Outliner 中位节点联动）。
- **路牙 / 横坡 / 路拱**：路牙类型、坡型（单 / 双）、路拱形式（线形 / 抛物线 / 折线）、路面结构枚举等，供几何生成与出图使用。

### 4.2 三层路面结构（M7+，UI/VM）

- **承载结构条带**（机动车道 / 非机动车道 / 人行道）可展开 **面层 / 基层 / 垫层**（及自定义层）：增删、排序、厚度 / 填料 / 填充符号等；非承载类型（绿化、路牙等）侧 **不展开**结构层编辑器。
- **默认方案**：`DefaultStructureSchemes.For(Kind)` 在 Kind 切换且层为空时注入默认分层（**注意**：结构方案 Phase 1 主要为 VM/UI；**完整 JSON 持久化策略以 057 / 领域模型为准**）。

### 4.3 Outliner 与选中路由（v2）

- **三段树**：中央隔离带节点、左侧根、右侧根；条带行含 **启用、类型色条、名称、宽度**。
- **三路互斥选中**：条带行 / 中分带节点 / 左或右侧根 → 右侧 PropertyEditor 切换不同 **Expander** 组（条带详情、中分带、侧级全局/桩号/规范等）。
- **`SyncTreeSelection`**：保证 VM 改选时 `TreeView` 勾选状态一致。

### 4.4 预览与规范

- **Canvas 预览**：`CrossSectionPreviewRenderer` 将 `CrossSectionFigure` 绘到 WPF，与 v1 共用规则。
- **实时重算**：布局变更 → `CrossSectionLayout` → `CrossSectionFigure` + **CJJ 37 相关** `CrossSectionCodeChecker` 报告；未通过项可在确认时 **二次确认**（`NonCompliantConfirm`）。

## 5. 出图模式（M7.4）

窗口顶栏 **单选**：

| 模式 | `CrossSectionDrawMode` | 落图效果（摘要） |
|------|-------------------------|------------------|
| **厚度轮廓**（默认） | `WithStructureThickness` | 与 v1 一致：轮廓、分段填充、尺寸链、标注、图题等（见 `RoadStandardSectionDrawService` 注释）。 |
| **单线** | `SingleLine` | **仅**顶面投影轮廓 + 中心虚线 + 方位箭头等，**跳过**板块填充、尺寸与标题等，供 **平面图单线** 用途。 |

用户点确定后，命令层读取 `CrossSectionDrawViewModel.UseSingleLineMode` 传入 `RoadStandardSectionDrawService.Draw(..., mode)`。

## 6. v2 专属交互

| 功能 | 说明 |
|------|------|
| **状态栏** | 汇总左/右板块数、总宽、规范通过文案（`StatusMessage` / Footer 绑定）。 |
| **大纲 / 属性折叠** | `ToggleOutlinerCommand`、`TogglePropertyPaneCommand`，与 `IsOutlinerVisible` / `IsPropertyPaneVisible` 绑定。 |
| **复制 / 粘贴条带** | 复制当前选中条带到剪贴板；粘贴到 **当前选中条带所在侧**（未选中则默认左侧），并选中新行。 |
| **确定并出图** | `DrawCommand` 与基类 `ConfirmCommand` 同一实例，语义别名。 |

## 7. 数据流与下游（面板定稿之后）

1. **`CrossSectionLayout`** → **`CrossSectionLayoutBuilder`** → **`Template`**（写入 `RoadDesign.Templates`）+ **`CrossSectionFigure`**。  
2. **持久化**：Registry + `.roaddesign.json`（与同目录 DWG 策略一致，详见 057）。  
3. **落图**：`RoadStandardSectionDrawService` 写入 ModelSpace，实体挂 **`HY_ROAD` XData**（`KIND=CrossSectionStandard`，`ID=template.Id`），支持同 Id 幂等 **先 Clear 再画**。  
4. **其它命令依赖**：如 `hyRoadPlan` 扫掠平面走廊会要求先有 Template；提示用户先 **`hyRoadCs`**。
