## 五、调用方式速查

### 5.1 命令行

```
hyRoadTree      或
rTree
```

打开独立 `PaletteSet`，从当前 DWG 的 `RoadProject` 建树。

### 5.2 DI 解析

```csharp
// 项目级注册表（跨 DWG + Data Shortcut）
var reg = componentContext.Resolve<RoadProjectRegistry>();
var project = reg.GetOrCreateForDocument(doc.Name);

// 项目树 VM（会自动注入 AutoCadRoadTreeInteractionHandler）
var vm = componentContext.Resolve<RoadProjectTreeViewModel>();
vm.Project = project;
```

### 5.3 Schema 升级

- 旧 `.roaddesign.json`（Schema 1.0 / 1.1 / 1.2）——继续直读 `Load(path)`；Schema 字段会在 `LoadProject(path)` 包装时升到 `"2.0"`
- 新 `.roadproject.json`（Schema 2.0）—— `LoadProject(path)` 直接反序列化
