# HyCADTool 配置系统完整指南

> **日期**：2026-02-12  
> **版本**：v2.0（重写）

---

## 一、30 秒速览

项目有 **两套独立的配置系统**，互不干扰：

| 系统 | 文件 | 管什么 | 谁用 |
|------|------|--------|------|
| **SettingsPanelViewModel** | `hy-settings.json` | 样式、钢筋参数、Scale | 绝大多数命令 |
| **ConfigurationService** | `config.json` | 容差、路径、桩基参数 | 桩基模块、少数全局查询 |

**Scale 的唯一真相源是 `SettingsPanelViewModel.Current.Scale`**。`ConfigurationService.GetScale()` 内部也是优先读它。

## 二、启动时发生了什么

```
AutoCAD 加载 DLL
  └→ PluginInitializer.Initialize()
       ├→ 1. 构建 Autofac 容器（所有服务单例注册）
       ├→ 2. LoadConfigurations()
       │     └→ ConfigurationService.LoadAll()
       │          ├→ GlobalConfigurationService.LoadConfiguration()
       │          │     └→ 从 config.json 读取 → GlobalConfiguration 对象
       │          └→ ModuleConfigurationService.LoadAllConfigurations()
       │                └→ 从 config.json 读取 PileConfigData 等
       ├→ 3. InitializeStylesAndLayers()
       │     ├→ SettingsPanelViewModel.GetOrCreate(docName, styleService)
       │     │     └→ 构造函数内 LoadSettings()
       │     │           └→ 从 %APPDATA%\HyCADTool\hy-settings.json 读取
       │     ├→ 用 VM 的参数创建 4 种样式（文字/标注/引线/表格）
       │     └→ 创建所有预定义图层
       └→ 4. RegisterDocumentEvents()
```

**关键**：两个 JSON 文件在不同时机加载，互不依赖。

## 三、SettingsPanelViewModel — 主配置系统

### 3.1 它是什么

一个 WPF ViewModel，同时承担了**配置中心**的角色。项目中 95% 的命令都从这里读参数。

**源文件**：`Presentation/ViewModels/SettingsPanelViewModel.cs`

### 3.2 数据在哪

```
%APPDATA%\HyCADTool\hy-settings.json
```

通常是 `C:\Users\<你的用户名>\AppData\Roaming\HyCADTool\hy-settings.json`

### 3.3 多文档机制

```csharp
// 按文档名存储，每个 DWG 文件一个独立实例
private static readonly Dictionary<string, SettingsPanelViewModel> _documentViewModels;

// 访问当前文档的 VM
SettingsPanelViewModel.Current  // 自动匹配当前活动文档
```

**但**：所有文档共享同一个 `hy-settings.json` 文件。切换文档时不会切换配置文件。每个实例构造时从同一文件加载，所以实际值相同。

### 3.4 属性变更 → 自动保存

```
用户在面板改了一个值
  └→ 属性 setter
       └→ SetProperty()
            ├→ 值不同？更新字段
            ├→ 触发 PropertyChanged（UI 刷新）
            └→ if (!_isLoading && propertyName != "StatusMessage")
                  └→ SaveSettings()  ← 立即写入 JSON
```

**每改一个属性就写一次文件**。这保证了即使 AutoCAD 崩溃也不丢设置。

### 3.5 样式脏标记 (`_stylesDirty`)

不是每次改参数都重建 AutoCAD 样式（代价大，8~10 个事务）：

```
Scale/字体/标注参数变更 → _stylesDirty = true
                              ↓
命令执行前 → if (_stylesDirty) EnsureStylesApplied()
                ├→ 创建/更新 TextStyle、DimStyle、MLeaderStyle、TableStyle
                └→ _stylesDirty = false
```

### 3.6 命令如何读参数

**钢筋命令**（gj/gg/ge/gb 等）：

```csharp
var vm = SettingsPanelViewModel.Current;
var parameters = vm != null ? vm.CreateReinParameters() : ReinParameters.CreateDefault();
vm?.EnsureStylesApplied();
// 然后用 parameters 做事
```

**其他命令只需 Scale**：

```csharp
double scale = SettingsPanelViewModel.Current?.Scale ?? 40.0;
```

**底板配筋**（特殊，见第五节）：

```csharp
// BaseReinPanelViewModel.SendCommand() 中：
_config.Scale = settingsVm.Scale;  // 从主面板同步 Scale
settingsVm.EnsureStylesApplied();  // 确保样式同步
```

### 3.7 内部 DTO：SettingsData

`SettingsData` 是 `SettingsPanelViewModel` 内部的 `private class`，纯数据容器，每个字段都有默认值：

```csharp
private class SettingsData
{
    public double Scale { get; set; } = 40.0;
    public string FontFileName { get; set; } = "tssdeng.shx";
    // ... 每个字段都有默认值
}
```

**向前兼容**：旧版 JSON 缺少新字段时，Newtonsoft.Json 反序列化会使用 DTO 中的默认值，不报错。

## 四、ConfigurationService — 辅助配置系统

### 4.1 它是什么

通过 Autofac DI 注册的服务，协调 `GlobalConfigurationService` 和 `ModuleConfigurationService`。

**源文件**：`Infrastructure/Configuration/ConfigurationService.cs`

### 4.2 config.json 在哪

按优先级查找：
1. `Assembly.Location` 同级目录
2. `Environment.CurrentDirectory`
3. `AppDomain.CurrentDomain.BaseDirectory`
4. 开发路径 `..\..\...\bin\Debug`

### 4.3 GlobalConfiguration 包含什么

```
GlobalConfiguration
  ├→ ScaleConfig（Default/Min/Max）  ← 已被 SettingsPanelViewModel 取代
  ├→ ToleranceConfig（Double/Vector/Point 容差）
  ├→ PathConfig（导出/导入/临时文件路径）
  ├→ StylesConfig（旧样式配置）  ← 已被 SettingsPanelViewModel 取代
  └→ ElevationLength（标高符号长度）
```

**注意**：`Scale` 和 `Styles` 在 `GlobalConfiguration` 中已**废弃**（但代码保留），真正用的是 `SettingsPanelViewModel`。`ConfigurationService.GetScale()` 的实现：

```csharp
public double GetScale()
{
    // 优先 SettingsPanelViewModel，回退到全局配置
    return SettingsPanelViewModel.Current?.Scale ?? _globalConfigService.Scale;
}
```

### 4.4 模块配置

| 模块 | 是否从 config.json 加载 | 状态 |
|------|------------------------|------|
| Pile（桩基） | 是 | 活跃使用 |
| Foundation | 否，用默认值 | 未被命令使用 |
| Reinforcement | 否，用默认值 | 未被命令使用 |
| Elevation | 否，用默认值 | 未被命令使用 |

`ModuleConfigurationService.SaveAllConfigurations()` 仍是 **TODO**，模块配置修改后不会持久化。

## 五、BaseReinforcementConfig — 底板配筋专用

### 5.1 它是什么

底板配筋流程（6 个步骤）的专用配置，**不参与** JSON 持久化。

**源文件**：`Domain/Models/Configuration/BaseReinforcementConfig.cs`

### 5.2 生命周期

```
BaseReinforcementService 构造时
  └→ GetCurrentConfig() → 返回 CreateDefault() 的默认值

BaseReinPanel 面板打开时
  └→ BaseReinPanelViewModel 构造
       └→ _config = _reinforcementService.GetCurrentConfig()
            → 面板属性直接读写 _config 的字段

面板按钮点击时
  └→ SendCommand()
       ├→ _config.Scale = settingsVm.Scale  ← 从主面板同步
       ├→ settingsVm.EnsureStylesApplied()
       └→ _reinforcementService.DrawReinforcement(_config, ...)
```

### 5.3 与 SettingsPanelViewModel 的关系

| 参数 | 来源 | 说明 |
|------|------|------|
| `Scale` | 从 SettingsPanelViewModel 同步 | 运行时覆盖 |
| `PlateThickness`、`RebarDiameter` 等 | 面板独立设置 | 与主面板无关 |
| 样式（文字/标注） | 主面板负责 | 底板配筋不管样式 |

```

│                      配置层级（从高到低）                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  层 1: hy-settings.json ← SettingsPanelViewModel            │
│  ──────────────────────────────────────────────             │
│  位置: %APPDATA%\HyCADTool\hy-settings.json                │
│  管辖: Scale, 字体, 标注参数, 钢筋参数                       │
│  触发: 属性变更即保存 / LoadSettings 加载                     │
│  消费者: 95% 的命令直接读 SettingsPanelViewModel.Current     │
│                                                             │
│  层 2: config.json ← ConfigurationService                   │
│  ──────────────────────────────────────────────             │
│  位置: DLL 同级目录或开发目录                                │
│  管辖: 容差, 路径, 桩基参数, ElevationLength                 │

│  消费者: 桩基面板, PluginInitializer 日志                    │
│                                                             │
│  层 3: BaseReinforcementConfig ← 仅内存                     │
│  ──────────────────────────────────────────────             │
│  位置: 无文件，仅在 BaseReinforcementService 内存中           │
│  管辖: 底板配筋专用参数（板厚, 附加筋, 方向等）               │
│  触发: 面板 UI 直接写 _config 字段                           │
│  消费者: BaseReinforcementService 的 6 个步骤                │
│                                                             │
│  层 4: 硬编码默认值                                          │
│  ──────────────────────────────────────────────             │
│  位置: 各 CreateDefault() 方法                               │
│  作用: JSON 缺失/损坏时的兜底                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**Scale 的读取优先级**：

```
SettingsPanelViewModel.Current.Scale          ← 最高优先级（面板值）
  ↓ 为 null 时
GlobalConfigurationService.Scale              ← config.json 中的值
  ↓ config.json 缺失时
GlobalConfiguration.CreateDefault().Scale     ← 硬编码 40.0
```

## 七、如何自己修改配置

### 场景 A：给 SettingsPanel 加一个新参数

**例子**：要加一个 `LineWeight`（线宽）参数。

**第 1 步**：在 `SettingsPanelViewModel` 加属性

```csharp
// 在 SettingsPanelViewModel.cs 的属性区域加：
private double _lineWeight = 0.25;
public double LineWeight 
{ 
    get => _lineWeight; 
    set => SetProperty(ref _lineWeight, value); 
}
```

**第 2 步**：在内部 `SettingsData` DTO 加字段

```csharp
// 在 SettingsData 类中加（注意给默认值！）：
public double LineWeight { get; set; } = 0.25;
```

**第 3 步**：在 `SaveSettings()` 中写入

```csharp
var data = new SettingsData
{
    // ... 已有字段 ...
    LineWeight = LineWeight,  // ← 加这行
};
```

**第 4 步**：在 `LoadSettings()` 中读取

```csharp
// 在 LoadSettings() 的 data 读取区域加：
LineWeight = data.LineWeight;
```

**第 5 步**：在 `ResetToDefaults()` 中重置

```csharp
LineWeight = 0.25;
```

**第 6 步**（可选）：在 XAML 面板中绑定

```xml
<TextBox Text="{Binding LineWeight, UpdateSourceTrigger=PropertyChanged}" />
```

**就这些**。不需要改 `ConfigurationService`、`config.json` 或任何其他文件。旧的 `hy-settings.json` 缺少 `LineWeight` 字段时，`SettingsData` 的默认值 `0.25` 会自动填充。

### 场景 B：给底板配筋加一个新参数

**第 1 步**：在 `BaseReinforcementConfig.cs` 加属性

```csharp
public double NewParam { get; set; }
```

**第 2 步**：在 `CreateDefault()` 中设默认值

```csharp
NewParam = 100.0,
```

**第 3 步**：在 `Clone()` 中拷贝

```csharp
NewParam = NewParam,
```

**第 4 步**：在 `BaseReinPanelViewModel` 加属性（直接代理 `_config`）

```csharp
public double NewParam
{
    get => _config.NewParam;
    set { if (_config.NewParam != value) { _config.NewParam = value; OnPropertyChanged(); } }
}
```

**第 5 步**：在 `BaseReinPanel.xaml` 中绑定。

### 场景 C：给 GlobalConfiguration（config.json）加一个新参数

**第 1 步**：在 `GlobalConfiguration.cs` 或其子配置类（`ToleranceConfig`/`PathConfig` 等）中加属性。

**第 2 步**：在 `GlobalConfiguration.CreateDefault()` 和 `Clone()` 中处理。

**第 3 步**：在 `JsonConfigurationLoader.LoadBaseConfiguration()` 中解析。

**第 4 步**：手动编辑 `config.json` 文件加入新字段。

### 场景 D：修改某个参数的默认值

直接改三个地方（都是同一个值）：
1. `SettingsPanelViewModel` 中的字段初始化值：`private double _xxx = 新值;`
2. `SettingsData` 中的属性默认值：`public double Xxx { get; set; } = 新值;`
3. `ResetToDefaults()` 中的赋值：`Xxx = 新值;`

然后**删除** `%APPDATA%\HyCADTool\hy-settings.json`（否则旧文件中的旧值会覆盖新默认值）。

## 八、命令如何访问参数 — 完整代码路径

### 8.1 面板按钮点击

```
面板按钮 → RelayCommand → SendCommand(action)
  │
  ├→ SaveSettings()                          // 先存盘
  ├→ PendingCommand = () => {                // 包装命令
  │     if (_stylesDirty) EnsureStylesApplied();
  │     action();                            // 实际命令
  │   }
  └→ doc.SendStringToExecute("_HyExec\n")   // 让 AutoCAD 执行 C1
       │
       └→ CommandRegistry 中的 [CommandMethod("_HyExec")]
            └→ ConsumePendingCommand()?.Invoke()
                 └→ 实际命令在 AutoCAD 命令线程执行
```

### 8.2 TestCommand 直接执行

```
C1 → TestCommand.Run()
  └→ new SomeCommand().Execute()
       └→ 命令内部读 SettingsPanelViewModel.Current
```

### 8.3 参数传递路径（以 DrawReinforcementCommand 为例）

```
SettingsPanelViewModel.Current
  └→ .CreateReinParameters()
       └→ 返回 ReinParameters 值对象
            └→ ReinService.Draw(parameters, ...)
                 └→ 用 parameters.Scale, parameters.RebarDiameter 等绘图
```

## 十三、常见问题

### Q：我改了面板参数但重启后丢失了？

检查 `%APPDATA%\HyCADTool\hy-settings.json` 是否存在。如果文件被锁定或目录权限不对，`SaveSettings()` 会静默失败（只写 Debug 输出）。

### Q：我想让不同 DWG 用不同的 Scale？

目前不支持。虽然有按文档存 VM 的字典，但所有 VM 共享同一个 `hy-settings.json`。要实现需要把配置路径改为按文档名区分。

### Q：BaseReinforcementConfig 关闭面板后参数丢了？

设计如此。`BaseReinforcementConfig` 仅内存存储。如需持久化，可仿照 `SettingsPanelViewModel` 的模式添加 JSON 读写。

### Q：我直接编辑 hy-settings.json 会怎样？

下次 ViewModel 构造时（通常是下次打开 AutoCAD 或 C2 热重载时）会读取你的修改。但如果面板已打开，不会自动刷新——需要重启或重新打开面板。

### Q：添加新参数后旧的 hy-settings.json 会报错吗？

不会。`SettingsData` 的每个字段都有默认值，`JsonConvert.DeserializeObject` 对缺失字段自动用默认值填充。
