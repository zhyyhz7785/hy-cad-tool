## 极简版（手机备忘录）

```
【Git 三连】
git add .
git commit -m "描述"
git push

【Cursor】
Ctrl+Shift+G = Git面板
点+ = 暂存
Ctrl+Enter = 提交

【回退已推送的提交】
git log --oneline -5          # 找到要回退到的提交哈希
git reset --hard abc1234      # 回退（abc1234是哈希值前7位）
git push --force              # 强制推送覆盖远程
```

## 回退已推送提交的完整步骤

### 场景：做了没用的修改，已经 push 了，想回到之前的状态

```bash
# 1. 查看提交历史，找到想回退到的那个提交
git log --oneline -10

# 输出示例：
# a1b2c3d (HEAD) 没用的修改3     ← 当前
# e4f5g6h 没用的修改2
# i7j8k9l 没用的修改1
# m0n1o2p 这是好的提交           ← 想回到这里
# ...

# 2. 回退到那个提交（使用哈希值前7位）
git reset --hard m0n1o2p

# 3. 强制推送到远程（覆盖掉那些没用的提交）
git push --force

# 完成！远程仓库也回退了
```

### reset 的三种模式

| 模式 | 命令 | 效果 |
|------|------|------|
| **--soft** | `git reset --soft 哈希` | 回退提交，但保留改动（在暂存区） |
| **--mixed** | `git reset 哈希` | 回退提交，保留改动（在工作目录） |
| **--hard** | `git reset --hard 哈希` | 回退提交，**丢弃所有改动** |

### 在 Cursor Git Graph 中操作

1. 打开 Git Graph（点击左下角分支名）
2. 找到想回退到的提交
3. 右键点击 → **复制提交 ID**
4. 打开终端（`Ctrl+``）执行：
   ```bash
   git reset --hard 粘贴ID
   git push --force
   ```
