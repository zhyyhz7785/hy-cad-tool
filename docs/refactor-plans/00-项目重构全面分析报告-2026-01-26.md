## 一、项目概述

### 1.1 项目目标

HyCADTool 是一个专业的 AutoCAD 二次开发插件，专注于结构工程设计领域。重构项目的核心目标：

1. **架构现代化**: 从传统 CAD 插件架构迁移到 Clean Architecture + DDD
2. **平台无关性**: Domain 层 100% 平台无关，为未来 Blender Python 迁移做准备
3. **代码质量提升**: 可测试、可维护、可扩展
4. **开发效率提升**: 热重启机制，无需重启 AutoCAD 即可测试

### 1.2 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| .NET Framework | 4.8 | 运行时 |
| AutoCAD .NET API | 24.3.0 | CAD 平台接口 |
| Autofac | - | 依赖注入容器 |
| Clipper2 | 1.4.0 | 多边形布尔运算 |
| NetTopologySuite | 2.5.0 | 拓扑分析、几何运算 |
| Newtonsoft.Json | 13.0.3 | JSON 序列化 |

## 九、开发工作流程

### 9.1 标准开发循环

```
1. 修改代码
   ↓
2. Visual Studio 编译 (Ctrl+Shift+B)
   ↓
3. AutoCAD 执行 C2 命令（热重启）
   ↓
4. AutoCAD 执行 C1 命令（测试）
   ↓
5. 检查输出和耗时
   ↓
6. 重复 1-5 直到测试通过
   ↓
7. 提交代码
```

### 9.2 核心命令

| 命令 | 功能 | 说明 |
|------|------|------|
| **C2** | 热重启 | 重新加载 HyCADTool.Refactored.dll |
