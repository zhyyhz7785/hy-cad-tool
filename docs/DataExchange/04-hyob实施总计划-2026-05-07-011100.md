## 0. 总目标与边界

### 0.1 总目标

在 HyCADTool.Refactored 工程内交付一个名为 **HyCAD Object Base (hyob)** 的子系统，它：

1. 与每个 `.dwg` 平行存在一个 `.hyob/` 目录
2. 用 SHA-256 内容寻址 + Tree + Commit 提供版本化历史
3. 用紧凑二进制（schema 隐式 + 字段无名）压缩存储已识别类型
4. 用 OpaqueObject（DXF 字节保留）兜底未识别类型
5. 跟 AutoCAD Database 双向同步，DWG 由 AutoCAD 自己读写
6. 所有 HyCAD 命令一次执行 = 一次 hyob commit
7. CI 上跑 DWG corpus 的 round-trip 防回归

### 0.2 边界

**做**：
- 平面 DWG（HyCAD 日常工作量）
- HyCADTool.Refactored 已建模的对象类型升级 TypedObject
- 命令级双写、启动期 reconcile、自动降级、round-trip 自检

**不做**（首期）：
- 三维 ACIS 实体的 schema 化（一律 OpaqueObject）
- AutoCAD 进程外打开 hyob（不做独立查看器）
- 跨 .dwg 的 cherry-pick / rebase
- 真分布式协同（git push/pull 等价物）—— 留作后续

## 3. 命令清单与注册

跟 HyCAD 既有规则一致：Refactored 写 Execute，commands.json 占位 N1~N50，C2 → C1 联调。

| 命令名 | 类 | 作用 |
|---|---|---|
| `hyobI` | HyobInitCommand | 在当前 DWG 旁边初始化 `.hyob/` |
| `hyobS` | HyobStatusCommand | 显示当前 layer / HEAD / 待提交对象 |
| `hyobC` | HyobCommitCommand | 把当前 Database 同步状态 commit |
| `hyobL` | HyobLogCommand | 命令行打印 commit 历史 |
| `hyobD` | HyobDiffCommand | 比较两个 commit / Database 与 HEAD |
| `hyobB` | HyobBranchCommand | 创建 / 列出 / 切换 layer |
| `hyobCo` | HyobCheckoutCommand | 切换 HEAD 到指定 commit / layer |
| `hyobM` | HyobMergeCommand | 三路合并 |
| `hyobES` | HyobExportHygeomCommand | 导出选区 hygeom JSON（接 01） |
| `hyobR` | HyobRoundTripCommand | 强制跑一次 round-trip 自检 |
| `hyobG` | HyobGcCommand | loose objects 打包 + 删孤儿 |
| `hyobP` | HyobShowHistoryPanelCommand | 弹出历史面板（git log 风格） |

注册：

1. 每个命令在 `commands.json` 占用一个 `N1~N50` 占位符（参考 `06-新命令注册流程.mdc`）
2. 命令实现写在 `HyCADTool.Refactored`，**不打 `[CommandMethod]`**（避免热重载 eDuplicateKey）
3. ReCall C2 装载占位符 + 反射调度

## 5. 关键接口（设计目标，非实现）

```csharp
namespace HyCADTool.Hyob.Domain.Repository;

public readonly struct Hash
{
    public byte[] Bytes { get; }
    public string Hex { get; }
}

public interface IHyobRepository
{
    HyobLayer CurrentLayer { get; }
    HyobCommit Head { get; }

    Hash WriteObject(IHyobObject obj);
    IHyobObject ReadObject(Hash hash);

    Hash WriteTree(HyobTree tree);
    HyobTree ReadTree(Hash hash);

    HyobCommit Commit(Hash tree, string message, IDictionary<string, object> meta);

    void Checkout(string layerName);
    HyobLayer CreateLayer(string name, string baseLayer);

    HyobDiffResult Diff(Hash from, Hash to);
    HyobMergeResult Merge(string source, string target);
    HyobStage Compose(IEnumerable<HyobLayer> layers);
}

public interface IAutoCadMirror
{
    void MirrorDatabaseIntoHyob(Database db);
    void ApplyHyobChangesToDatabase(Database db, Hash from, Hash to);
    RoundTripReport SelfCheck(Database db);
    void DowngradeToOpaque(Hash objectHash, string reason);
}

public interface IHyobCodec
{
    ushort TypeId { get; }
    byte SchemaVersion { get; }
    void Encode(IHyobObject obj, HyobBinaryWriter writer);
    IHyobObject Decode(HyobBinaryReader reader, byte version);
}
```

**目标**：任何 DWG 都能完整 mirror 进 hyob 再写回 Database round-trip 通过，**所有对象走 OpaqueObject**。先证明端到端通路。

任务清单：

|---|---|
| `HyobObjectHeader` + Magic/CRC 编码 | 单测覆盖 |
| `HyobOpaqueObject` 二进制 schema | 单测：编码 → 解码字节相等 |
| `DxfBinarySerializer`：Database Entity ↔ DXF group code binary | 单测：Line / Circle / Hatch 三种序列化稳定 |
| `Hash` (Sha256) + `HyobObjectStore` 文件系统读写 | 单测覆盖 |
| `HyobTree` + `HyobTreeStore` | 单测覆盖 |
| `HyobCommit` + `HyobCommitStore` + `HyobRefStore` (HEAD/refs/heads/main) | 单测覆盖 |
| `AutoCadDatabaseMirror.MirrorDatabaseIntoHyob`：扫描 Database 全部对象 → OpaqueObject → Tree → Commit | 集成测试：corpus 3 个样本通过 |
| `AutoCadDatabaseMirror.ApplyHyobChangesToDatabase`：基于现有 Database 做 patch（不重建） | 集成测试 |
| `RoundTripValidator.SelfCheck`：mirror → 反向写回 → DXF dump 对比 | corpus 3 个样本 round-trip 通过 |
| 命令：`hyobI` / `hyobS` / `hyobC` / `hyobL` 实现 | 在 AutoCAD 中可执行 |

验收标准：

```text
打开 sample.dwg
  hyobI  → .hyob/ 创建
  hyobC  → 一个 commit 写入
  hyobL  → 看到 1 条 commit
  hyobR  → round-trip 通过

  hyobS  → handle 与上次一致，无 dirty
```

依赖：M0。

## 9. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|:---:|---|
| AutoCAD 跨版本 DXF 序列化不稳 | 中 | 用 binary DXF + AcDb open save round-trip 自检；版本相关字段在 codec 内显式分支 |
| Civil 3D / Map 3D 自定义对象解码失败 | 高 | 全部走 OpaqueObject，从不尝试展开 |
| 大图打开 mirror 过慢 | 中 | M7 引入 pack / mmap / 增量 mirror |
| 命令双写性能损耗 | 低 | 异步落盘 + transaction batch |
| Database.ObjectModified 事件风暴 | 中 | 合并去重 / 命令边界提交 |
| hyob 损坏（磁盘故障） | 低 | hash 校验 + 自动从 Database 重建 |
| 用户拷走 .dwg 不拷 .hyob/ | 低 | 启动期把 .dwg 当成 source 重建 hyob |
| 黑盒对象升级白名单时旧历史不兼容 | 中 | append-only：旧 commit 里 OpaqueObject 不动；codec 按 type_id+schema_ver 分支 |
| 与 ReCall 热重载冲突 | 中 | 不打 `[CommandMethod]`；命令注册走 commands.json N1~N50 |
| AutoCAD 锁文件导致 ReCall 构建失败 | 中 | 已有 skill `hycad-project-pitfalls` 覆盖 ReCall 单向引用方案 |
