## 9. 建议的后续整理项

1. **模型目录迁移**：当前 Ollama 模型（≈31.7 GB）存放在 C 盘默认路径，C 盘剩余 414 GB 暂无压力，但若后续拉更多大模型建议设置 `OLLAMA_MODELS` 迁移到 D/G 盘。
2. **WSL 版本**：当前 Ubuntu 22.04 运行稳定，若不需要 24.04 新特性可维持现状；若需升级，应先 `wsl --export` 备份。
3. **qwen3-vl:8b 注册**：已拉取到 Ollama 但未注册到 OpenClaw，如需使用需在 `openclaw.json` 的 `models.providers.ollama.models` 数组中添加。
4. **`.wslconfig` 调优**：当前未配置，WSL 默认取宿主机一半内存（31 Gi）；如 Ollama 全在 Windows 侧跑，可适当降低 WSL 内存分配。
5. **代理干扰**：sing-box 代理导致 WSL 每次启动有 localhost 代理警告，目前不影响功能，但排查网络问题时应首先排除此因素。
6. **root 用户**：OpenClaw 当前以 root 运行，长期建议切换到普通用户以降低安全风险。
7. **旧文档修正**：将 `041` 等早期文档中的 `qwen2.5:14b`、`127.0.0.1:11434`、`Ubuntu-24.04` 等旧值标注为"历史方案"或更新为当前实测值。
