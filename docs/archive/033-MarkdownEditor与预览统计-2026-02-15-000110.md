# MarkdownEditor 与预览统计

## 1. 目标

说明 `HyCADTool.MarkdownEditor` 子项目如何提供编辑体验、预览分栏统计，以及这些统计如何反馈到 Refactored 主流程。

## 2. 关键文件

- `HyCADTool.MarkdownEditor/Views/EditorWindow.xaml.cs`
- `HyCADTool.MarkdownEditor/Html/PreviewHtmlRenderer.cs`
- `HyCADTool.MarkdownEditor/Models/EditorContract.cs`
- `HyCADTool.MarkdownEditor/EditorLauncher.cs`

## 3. 编辑器职责分层

### 3.1 `EditorLauncher`

- 接收主项目传入 JSON。
- 打开 `EditorWindow`。
- 将编辑结果序列化为 JSON 返回。

### 3.2 `EditorWindow`

- 承载 Vditor（编辑）与 WebView2（预览）。
- 负责：
  - 同步编辑器文本
  - 触发预览刷新
  - 从 JS 读取 `PreviewStats`
  - 构造 `EditorResult`

### 3.3 `PreviewHtmlRenderer`

- 将 Markdown 转成交互式 HTML。
- 注入分栏与统计脚本 `distribute()`。
- 维护 `window.previewStats`。

## 4. `PreviewStats` 数据结构

定义于 `EditorContract.cs`：

- `CharsPerColumn`
- `ColumnParagraphIndicesText`
- `ColumnParagraphIndices`
- `Columns`（每栏统计）
- `BlockTypeCounts`

其核心价值：

- 给主项目提供稳定的“按栏段落索引”与“字/行估计”。
- 为回归测试提供结构化对照数据。

## 5. 分栏核心脚本逻辑（JS）

`PreviewHtmlRenderer` 中 `distribute()` 主要步骤：

1. 遍历 source 区块元素；
2. 试放入当前栏；
3. 若超高则回退并放入下一栏；
4. 记录每栏段落索引、字符统计、块类型统计；
5. 回写 `window.previewStats`。

## 6. 从预览到主项目的桥接

1. `EditorWindow.OnConfirmClick` 先同步最新 Markdown；
2. 刷新预览并读取 `getPreviewStats()`；
3. 写入 `ViewModel.CharsPerColumn` 与 `ViewModel.ColumnParagraphIndices`；
4. 输出 `EditorResult`。

主项目 `EditorLoader` 再解析 `EditorResult`，驱动后续拆分与渲染。

## 7. 关键口径一致性

- 预览端与 Domain 层都采用近似“中英宽度单位”口径。
- `ColumnParagraphIndices` 是分栏唯一来源，后端不应自行重排。
- 预览层可空栏；后端应接受空栏而不是强行填充。

## 8. 常见问题

- 预览看似两栏，落图一栏：通常是 `ColumnParagraphIndices` 第二栏为空组。
- 大文档预览抖动：与全量刷新策略有关，建议后续做增量优化。
- 编辑器可用但预览统计为空：需检查 WebView2 初始化与 JS 注入时序。

## 9. 演进建议

- 把 `PreviewStats` 持久化到回归快照，支持自动对比。
- 增加“显示栏索引覆盖”调试层，便于定位分栏争议。
- 对超长文档引入分段渲染策略，降低预览延迟。
