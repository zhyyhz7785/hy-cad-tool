# HyCAD .bundle 安装与离线许可（代理商/销售速查）

## 1. 安装包

- 开发机构建: `tools\PackBundle.ps1` → `dist\HyCAD.bundle` 与 `dist\HyCAD-v1.0.0-bundle.zip`  
- 用户级推荐路径: `%APPDATA%\Autodesk\ApplicationPlugins\HyCAD.bundle\`  
- 或 Inno Setup: `build\HyCAD-Setup.iss`（需本机安装 ISCC，并修正 `#define RepoRoot`）

## 2. 收费档（与插件内门闸）

| 档 | 含意 |
|----|------|
| Freemium | 无 license：仅 `hy`/`HyB`/沉降 `HYJC`/`hySC`、首选项 `HYOV`、诊断 `hyCmdList`、`hyLicense` 等 |
| standard | 配筋/标高/尺寸/地脚/设备基础等（多数命令） |
| professional | standard + 道路 `hyRoad*`、桩基 `HYpile*`、三维 `HY3`、`hySeg3` 等 |
| enterprise | 同 professional（多机/服务条款在商务合同单控） |

## 3. 签发流程

1. 客户 CAD 中执行 `hyLicense`，复制机器码（5 段）。  
2. 你方运行 `HyCADTool.LicenseSigner`（见 `HyCADTool.LicenseSigner/README-签发流程.md`）。  
3. 生成 `license.lic` 发客户；客户用 `hyLicense`「导入」或放到 `%ProgramData%\HyCAD\license.lic`。

## 4. 发错/作废

当前为**纯离线**方案：无中心吊销。处理办法：同机器码**重新签一份**发客户覆盖；台账记录旧文件作废时间。

## 5. 环境变量

- `HYCAD_BYPASS_LICENSE=1`：跳过门闸（仅排障/内部；勿告知终端客户常开）

## 6. 密钥与公钥

- 公钥编译在 `HyCADTool.Licensing/EmbeddedPublicKey.cs`。  
- 私钥仅本地 `PrivateKey.xml` 或 `tools/rsa-priv.xml`；**勿入库**；丢失后需换密钥对并**全体重签**。
