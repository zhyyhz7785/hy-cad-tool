## 四、架构改进

### 4.1 三层分离

```
Domain（平台无关）
  ├── Entities：AnchorBolt, EquipmentFoundation, Pile, Wall3D, Slab3D...
  ├── ValueObjects：Point2D, Line2D, Polygon2D, ReinParameters...
  ├── Services：LineOverKillService, PileLayoutService, VoronoiOptimizationService...
  ├── DataStructures：DCEL（全新实现）
  └── Utilities：ReinforcementUtils

Infrastructure（AutoCAD 封装）
  ├── Extensions：EntityExtensions, PolylineExtensions, MLeaderExtensions
  ├── Services：ReinService, StyleService, LayerService, ElevationService...
  ├── Utilities：LayerHelper
  ├── Selection：SelectionHelper, AdvancedSelectionService
  └── Interactive：ElevationSymbolJig, HookJig

Presentation（命令与 UI）
  ├── Commands：57 个命令类
  ├── ViewModels：SettingsPanelViewModel, BaseReinPanelViewModel
  └── Views：SettingsPanel, BaseReinPanel, FilterPanel
```

### 4.2 旧代码问题 → 新架构解决

| 旧代码问题 | 新架构方案 |
|------------|-----------|
| 全局静态状态 `Reinforcement.*` | 从 `SettingsPanelViewModel` 读取，局部变量传递 |
| `ZTools` 万能工具类 | 按职责拆分为 `EntityExtensions`、`MLeaderExtensions`、`LayerHelper` |
| `[CommandMethod]` 热重载冲突 | 除 HYOV/HYDCEL 外不用 `[CommandMethod]`，通过 TestCommand 调用 |
| `ReinPanel.ActivePanel?.xxx` | `SettingsPanelViewModel.Current?.xxx` |
| 硬编码路径 | 改为 SaveFileDialog / GetPoint 用户选择 |
| 缺少 `LockDocument` | 所有写操作统一 `doc.LockDocument()` |
| 反射调用旧项目 | 禁止，逻辑真正移植到 Refactored |

### 4.3 DI 与服务定位

- **Autofac** 容器注册所有 Infrastructure 服务
- `ServiceLocator.Resolve<T>()` 统一获取服务
- Domain 层 100% 纯净，不依赖任何 AutoCAD API
