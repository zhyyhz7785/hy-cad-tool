# 插入一致性回归验收规范

## 1. 目的

建立“Markdown 预览”和“AutoCAD 实际插入”之间的一致性验收标准，形成发布前可重复执行的回归流程。

## 2. 固定测试入口

- 执行路径：`C2 -> C1`
- `C1` 入口文件：`HyCADTool.Refactored/Test/TestCommand.cs`
- 当前固定命令：`new DesignSpecCommand().Execute();`

## 3. 回归样例集

目录：`HyCADTool.MarkdownEditor/RegressionSamples`

- `01-empty.md`
- `02-all-cn.md`
- `03-mixed-extreme.md`
- `04-code-block.md`
- `05-table-heavy.md`
- `06-long-doc.md`
- `07-font-consistency.md`
- `08-special-symbols.md`
- `09-mixed-code-table.md`

## 4. 核心验收指标

1. 字体一致性
   - 正文、粗体、代码块字体表现与预览策略一致。
   - 修改字体配置后，插入结果即时生效（含已存在样式）。
2. 分栏一致性
   - `CharsPerColumn` 与视觉栏宽变化方向一致。
   - `ColumnParagraphIndices` 与最终落图顺序一致。
3. 换行一致性
   - 预览与插入换行偏差目标：每 1000 字不超过 1 行。
4. 符号兼容性
   - 高风险字符出现时弹出提示；
   - 选择降级后替换结果符合预期。

## 5. 测试步骤模板

1. VS 编译成功。
2. AutoCAD 执行 `C2` 热加载。
3. 执行 `C1` 进入 Markdown 插入流程。
4. 使用样例文档逐个验证：
   - 预览视觉检查（字体、换行、分栏）
   - 插入后模型空间检查（MText/Table）
5. 记录结果并与上次基线比较。

## 6. 结果记录模板

建议每次回归记录以下内容：

- 构建时间：
- 测试人：
- 样例文件：
- 字体策略（TTF/SHX/混合）：

- 插入结果：通过/失败
- 关键偏差描述：

- 结论与后续处理：
