# Rules 与 Skills 速查对照

> 配合 [001-Cursor与Claude-Code-使用总览](./001-Cursor与Claude-Code-使用总览-2026-06-30-120000.md) 使用  
> **日期**：2026-06-30

---

## 一句话

- **Rule** = 交通规则（常走的那几条必须知道）
- **Skill** = 操作手册（做某件具体事时翻开）

---

## 决策树

```
要写入 Agent 配置的指令
        │
        ├─ 是否「每条对话都必须遵守」？
        │     └─ 是 → Project Rule（alwaysApply: true）
        │
        ├─ 是否「仅某类文件」才需要？
        │     └─ 是 → Project Rule（globs: **/*.xaml）
        │
        ├─ 是否「多步骤工作流 / 排障清单 / 模板」？
        │     └─ 是 → Skill
        │
        ├─ 是否「个人偏好、与项目无关」？
        │     └─ 是 → User Rules（Settings）
        │
        └─ 是否「全员强制、跨所有仓库」？
              └─ 是 → Team Rules（Dashboard）
```

---

## 文件模板

### Rule（`.cursor/rules/my-rule.mdc`）

```markdown
---
description: 一句话说明 + 触发关键词
globs: src/**/*.cs
alwaysApply: false
---

# 标题
- 必须 …
- 禁止 …
```

### Skill（`.cursor/skills/my-workflow/SKILL.md`）

```markdown
---
name: my-workflow
description: 第三人称。做什么 + 何时用 + 关键词。
paths:
  - "src/HyCADTool/**"
---

# 工作流标题

## Step 1
## Step 2
```

## 优先级与冲突

| 层级 | 来源 | 冲突时 |
|------|------|--------|
| 1 | Team Rules | 最高，覆盖下方 |
| 2 | Project Rules | 覆盖 User Rules |
| 3 | User Rules | 最低 |
| — | Skills | 不与 Rule「优先级」硬比；**重复内容 Rule 的硬性约束更权威** |

---

## 目录速查

| 放什么 | 路径 | Git |
|--------|------|:---:|
| 项目规则 | `.cursor/rules/*.mdc` | ✅ |
| 项目技能 | `.cursor/skills/<name>/SKILL.md` | ✅ |
| 跨工具说明 | `AGENTS.md` / `CLAUDE.md` | ✅ |
| 个人规则 | Settings → User Rules | ❌ |
| 个人技能 | `~/.cursor/skills/` | ❌ |
| 内置技能 | `~/.cursor/skills-cursor/` | ❌ 勿改 |
| 人类文档 | `docs/**` | ✅ Agent 不自动读 |

---

## 调用方式

| 类型 | 自动 | 手动 |
|------|------|------|
| Rule | alwaysApply / globs / 智能 description | `@规则文件名` |
| Skill | Agent 匹配 description | `/skill-name` 或 `@skill-name` |
