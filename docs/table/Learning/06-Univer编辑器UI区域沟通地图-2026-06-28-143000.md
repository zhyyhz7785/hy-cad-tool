## 3. 分区说明（按屏幕从上到下）

### 3.1 U1 Tab 行

从左到右固定布局（`global.css` 绝对定位 + 居中 Tab 组）：

```text
[文件▾]     开始 | 公式 | 数据 | 布局 | 主题▾              —  □  ✕
  U1a              U1b（居中）                              U1c
```

| 控件 | 点击后 | 5174 行为 |
|---|---|---|
| **U1a 文件▾** | 下拉菜单 9 项（§5） | 新建/样表可用；导入导出/拾取/落图 → Dev 状态栏提示 CAD only |
| **U1b 开始** | 显示 U2 + **U9** | Univer 原生编辑工具 |
| **U1b 公式** | 显示 U2（公式相关） | Univer 原生 |
| **U1b 数据** | 显示 U2（排序筛选等） | Univer 原生 |
| **U1b+ 布局** | **隐藏 U2，显示 U3** | HyCAD 纸张/行列/合并（§4） |
| **U1b+ 主题▾** | 下拉 5 项（§6） | **5174 完全可用**，本地换肤 |
| **U1c — □ ✕** | 窗口控制 | 5174：D1 状态「仅 CAD 宿主」 |

### 3.2 U2 与 U3（第二行 Ribbon，二选一）

| 状态 | 可见 | 沟通说法 |
|---|---|---|
| 当前 Tab = 开始/公式/数据 | **U2** | 「默认 Ribbon 第二行」 |
| 当前 Tab = 布局 | **U3**（`#hycad-layout-ribbon-panel`） | 「布局 Ribbon」；U2 加 class `hycad-layout-toolbar-hidden` 隐藏 |
| 当前 Tab = 布局 | U2 不可见 | 不要说「开始 Tab 的工具条」 |

**U9 落图范围▾** 只在 **开始 Tab + U2 显示时** 出现在 U2 **最左侧**（不是布局 Tab 里）。

### 3.3 U4 公式栏

- Univer 原生：左侧 `fx`，中间单元格地址，右侧内容/公式编辑。
- 5174：改格内容会发 `cellChanged`（dev 宿主静默）；不影响 D1 状态 unless error。

### 3.4 U5 / U6 / U7 网格区

| 代号 | 是什么 |
|---|---|
| **U5** | 左侧行号 1、2、3… |
| **U6** | 顶部列标 A、B、C… |
| **U7** | 中间白格区域，**所有单元格编辑发生在这里** |

5174 交互反馈：

- **框选** → `selectionChanged` → **D1「选区」** 显示如 `B3:D5`；**U3「单元格大小 mm」** 行高/列宽框跟选区刷新（CAD 才写回 Domain，5174 仅 UI 跟随）。
- **改单元格** → Univer 本地生效；导出快照可见。

### 3.5 U8 Footer 底栏

贴页面最底（`sheet-bar-guard` 保证不被挤出视口）：

| 子区 | 作用 |
|---|---|
| Sheet 标签 | 工作表切换（PoC 通常单 Sheet） |
| 统计栏 | 选区计数、求和等 |
| 缩放滑块 | 约 10%–400%；改 zoom 后网格视觉缩放 |
| 菜单 | Footer 扩展菜单 |

**与 D1 位置关系**：D1 浮在 `bottom: 48px`，刻意避开 U8，不遮挡 SheetBar。

### 3.6 D1 Dev 面板（5174 独有）

**外观**：左下角圆角白/蓝头卡片，标题 **HyCAD Univer Dev**，副标题 **5174 · mock 宿主**。

**默认折叠**：只露出 header + **▸**；点 ▸ 展开 body。

| 区块 | 内容 |
|---|---|
| **按钮行** | 人员样表 · 新建空表 · 导出快照 · 回填布局初值 |
| **meta 行** | `选区 —` · `状态 就绪`（随操作更新） |
| **验收清单** | `<details>`「Tab 行 / Ribbon 验收」6 条（与 `dev-panel.ts` `UI_CHECKLIST` 一致） |

| 按钮 | 5174 实际效果 |
|---|---|
| 人员样表 | `fetch /fixtures/personnel-snapshot.json` → `loadSnapshot` |

#### 3.7.2 「WebView2 未连接」是什么意思

```text
5174 浏览器                          CAD N38 WebView2
─────────────────                    ─────────────────
无 window.chrome.webview 真对象  →   C# 注入 WebView2 桥
dev-host 装 mock webview         →   真 postMessage 到 UniverSessionLifecycle
ready 后 D1 显示「未连接」        →   不会出现 D1；状态在 WPF W5
```

- **白话**：页面在告诉你——「现在是浏览器自测模式，后面 AutoCAD 那层还没接上」。
- **不是故障**：`dev-host.ts` 在 `ready` 时**故意**写这句，并紧接着自动 mock `setViewport` + `setScale(40)`。
- **真接上时**：同一套 U1–U9 进 CAD，**D1 整 panel 不会出现**（`installDevHostIfNeeded` 检测到真 WebView2 就走 C# 桥）。

## 4. U3 布局 Ribbon — 十组控件（左→右，与屏幕一致）

点 **布局** Tab 后第二行；每组下方有小字 **caption**。

```text
┌─视图────┬─结构/填值─┬─纸张 L0─ … ─┬─HyCAD──┐
│☑标尺    │☑结构模式  │纸型 方向 …  │落图 …  │
│☑行列头  │           │             │        │
│☑纸张边界│           │             │        │
└─────────┴───────────┴─────────────┴────────┘
```

| 组 caption | 控件 | 5174 mock |
|---|---|---|
| **视图** | 标尺 / 行列头 / 纸张边界 ☑×3 | ✅ 纯前端；默认全开 |
| **结构/填值** | 结构模式 ☑ | ✅ 切换；关则禁用「单元格」「合并」组按钮 |
| **纸张 L0** | 纸型 A4/A3/A2/自定义、方向、总宽 mm、边距 mm、**列宽适配纸宽** | ❌ 提示 CAD only |
| **表格** | 行、列、**新建空表**、模板下拉、**从模板加载** | 新建/空白模板 ✅ demo；人员模板 ✅ fixture；家庭 ❌ 未提供 |
| **内容驱动** | 自动调整行高、自动调整列宽 | ✅ Univer 本地 autoFit；发 `hyCadTrackSizes`（不写 Domain） |
| **单元格大小 mm** | 行高、列宽（跟选区） | ❌ 改值提示 CAD only；**显示**仍跟选区变 |
| **单元格** | +行 -行 +列 -列 | ❌ CAD only（结构模式关时禁用） |
| **合并** | 合并、拆分 | ❌ CAD only |
| **比例** | Scale 数字框 | ✅ 仅回填框 + D1 状态；不落图 |
| **HyCAD** | 落图、拾取、角色 | 落图/拾取 ❌ CAD only；角色 → error「R6 后期开放」 |

与 **U3 → HyCAD 组 → 落图**（全表 `publish`）是不同入口；5174 都会提示 CAD only。

| `hyCadAction` | U9 | D1「仅 CAD 宿主」 |
