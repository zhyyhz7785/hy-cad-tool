# 启动与测试

## 环境要求

| 项 | 版本/要求 |
|---|---|
| .NET | 主工程 net48；侧车 net8.0-windows |
| Node.js / npm | 能跑 Vite（`HyCADTool.UniverEditor/Web`） |
| AutoCAD | 开发机已装；C2 热重载可用 |
| WebView2 | 运行时（Windows 通常已带） |

## 首次启动

```powershell
# 前端依赖
cd src\HyCADTool.UniverEditor\Web
npm install

# 构建前端产物 → Web/dist（侧车会拷贝/解析）
npm run build

# 编译主工程（含侧车引用链）
cd ..\..\..
dotnet build src\HyCADTool\HyCADTool.csproj -c Debug
```

## 日常开发

**浏览器 HMR（改布局 Tab / bridge，不启 CAD）：**

```powershell
cd src\HyCADTool.UniverEditor\Web
npm run dev
# 打开 http://localhost:5174
```

**AutoCAD 联调：**

1. 改代码后 AI/`dotnet build` 主工程
2. AutoCAD 命令行 **C2** 热重载
3. **N38**（或 C1 若 TestCommand 指向打开 Univer 表）打开编辑器

部署链摘要：

```
npm run build → Web/dist
  → build UniverEditor → build HyCADTool
  → C2 复制到 ReCall temp
  → N38 → UniverSessionLifecycle 解析 dist
```

## 验收步骤

1. **C2 → N38** 打开 Univer 表格编辑器
2. 右下角「布局」工具条：比例 ≈ hy 面板 Scale（常为 50）
3. 选中行/列：行高/列宽显示纸面 mm（如 10、25）
4. 改尺寸 → 刷新；落图后 CAD 量测 ≈ **纸面 mm × Scale**
5. **拾取**已落图表 → 编辑器回显相同纸面 mm（非模型 mm 反算）
6. 点「角色」→ 提示后期开放（当前预期）

浏览器 5174 可先看布局联动；最终以 AutoCAD 内 WebView2 为准。

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 白屏 / 无表格 | dist 未 build 或路径解析失败 | `npm run build` 后重建主工程；查 `ResolveDistPath` |
| 改 TS 无效果 | 只改了源、未 build 或未 C2 | 5174 用 HMR；CAD 内需 build + C2 |
| Badge / 主题崩溃 | AdWindows 双载入等 | 对照 hy-cad-tool pitfalls / ReCall 宿主黑名单 |
| 布局数字对、格子看着不对 | 像素换算 vs 纸面 mm | 已知缺口，见 [03](03-当前状态.md) / [04](04-下一步计划.md) |
