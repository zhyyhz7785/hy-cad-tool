## 当前阶段详情

### 布局 Tab + 口径 B 之后 → P2 / 视觉 mm

**目标**：Univer 网格视觉贴近纸面 mm；补齐 WPF 布局 Tab 缺口；推进三 Tab IA。

**步骤**：

1. 调整 `mmToRowPx` / `mmToColPx` 或列宽 API，使格子视觉比例贴近布局 Tab 真值
2. 结构模式、行列数、新建空表、模板加载迁入 Univer
3. 验证 Univer 原生「布局」Tab 可行性，或升级 DOM 条位姿
4. 按产品排期推进 P2 开始/页面 Tab 注入

**完成标准**：布局 Tab 数字、Univer 目视、CAD 落图（×Scale）三者可对上；高频编辑 ≤2 点击可完成。
