## 1. 这是什么 / 适合谁

HyCAD 表格：在 AutoCAD 里用接近 Excel 的网格编辑工程表格，再**落图**到图纸，或从已落图的表**拾取**回来改。适合制图员做人员表、明细表等模板化表格。

> 当前为插件内预览能力（命令入口以现场版本为准）。未在界面确认的入口标为「规划中」，不编造菜单名。

## 2. 五分钟上手（最优默认路径）

1. 在 AutoCAD 中打开 HyCAD 表格编辑器（开发版常见命令 **N38**；正式菜单名以安装版为准）。
2. 用「文件」相关入口加载人员样表或新建空表（若菜单可见）。
3. 在网格中编辑单元格文字。
4. 用右下角「布局」工具条调整行高/列宽（纸面 mm）、插入或合并单元格。
5. 点「落图」把表画到模型空间；需要再改时用「拾取」选回已落图的表。

## 3. 推荐日常工作流

1. 定纸面尺寸与比例（布局条上的比例，通常跟 hy 面板 Scale）。
2. 先调结构（行列、合并、尺寸），再填文字。
3. 落图 → 图面检查 → 拾取微调 → 再落图。

## 4. 功能操作详解

### 打开编辑器

- **目标效果**：进入独立表格编辑窗口
- **推荐流程**：
  1. 在 AutoCAD 命令行执行已注册的表格编辑器命令（开发：**N38**）
- **等价操作**：

| 入口 | 步骤 |
|---|---|
| 命令行 | N38（开发） |
| 菜单 / Ribbon | 暂无（以安装版为准，2026-07-15） |

### 布局：改行高列宽 / 行列 / 合并

- **目标效果**：按纸面毫米调整表格结构
- **推荐流程**：
  1. 在网格中选中目标行/列或区域
  2. 在右下角「布局」工具条改行高/列宽，或点 +行/-行/+列/-列、合并/拆分
- **等价操作**：

| 入口 | 步骤 |
|---|---|
| 布局工具条 | 尺寸框 / 行列按钮 / 合并按钮 |
| WPF 旧编辑器布局 Tab | 若仍开放则可对等操作（逐步收敛到 Univer） |

- **注意**：布局数字是**纸面 mm**；图里实际大小 ≈ 纸面 mm × 比例。

### 落图与拾取

- **目标效果**：把编辑中的表画到 CAD，或把已画的表读回编辑器
- **推荐流程**：
  1. 编辑完成后点布局条「落图」
  2. 需要修改时点「拾取」，选择图中 HyTable，继续编辑后再落图
- **等价操作**：

| 入口 | 步骤 |
|---|---|
| 布局工具条 | 落图 / 拾取 |
| 文件菜单 | 若仍有落图/拾取项，效果相同 |

- **注意**：「角色」按钮当前为占位（后期开放）。

## 5. 常见问题（用户向）

| 现象 | 解决 |
|---|---|
| 格子看起来和数字对不上 | 数字以布局条为准；图面尺寸看落图后量测。视觉对齐仍在改进中 |
| 改完比例关掉再开丢了 | 正常：比例不随表保存，跟打开时的 hy 面板 |
| 点「角色」没反应或提示后期 | 功能尚未开放 |
