### 真相源与口径 B

- **日期**：2026-07-15
- **问题 / 背景**：编辑器、布局数字、CAD 模型尺寸三者易混用「像素 / 纸面 mm / 模型 mm」
- **最终方案**：
  - Domain / 布局 Tab / 拾取读回：**纸面 mm**
  - 仅落图：几何、字高、padding、边框线宽 **×Scale**
  - Scale：打开时默认 hy 面板，布局 Tab 可改，**不持久化到表**
  - 结构变更：布局按钮 → C# OpLog → 回灌快照；禁止只靠 Univer 内置插删当真相
- **关键文件**：
  - `src/HyCAD.Tables/Layout/TableLayout.cs` — 落图尺寸 ×Scale
  - `src/HyCADTool/Features/Tables/Services/UniverTableEditorHostBridge.cs` — 布局消息 / OpLog
  - `src/HyCADTool.UniverEditor/Web/src/layout-tab-inject.ts` — 布局 DOM 条
  - `src/HyCADTool.UniverEditor/Web/src/univer-bridge.ts` — 快照协议
- **易错点 / 反例**：拾取时做 mm 反算；给 Scale 做持久化；从 Univer export 反推样式当真相源
