## 使用方法

- 说「**更新日志**」→ 同步更新 [03-当前状态](03-当前状态.md) + [04-下一步计划](04-下一步计划.md)
- 做调研 → 写入 `Research/`，命名 `编号-标题-YYYY-MM-DD.md`
- 学概念 → 写入 `Learning/`，命名 `编号-主题.md`
- 阶段设计 → 写入 `Plan/`，不堆在根目录
- 评估结案 → 写入 `Evaluations/`
