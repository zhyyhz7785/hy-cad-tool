## §0 执行摘要

| 项 | 内容 |
|---|---|
| 目标 | Shell **同窗**显示梁位移 `U_mag` 色带；**不**依赖 ParaView |
| 技术 | Avalonia `NativeWebView` + 随应用打包的 vtk.js |
| 数据 | `ResultMesh` → `ResultMeshJson` → `window.hyfea.setMesh` |
| 平台前提 | Windows + **WebView2 Runtime**（非 ParaView） |

## §2 数据契约

```json
{
  "points": [x,y,z, ...],
  "lines": [i0,i1, ...],
  "scalars": { "UX": [...], "UY": [...], "U_mag": [...] },
  "activeScalar": "U_mag"
}
```

求解成功 → `BeamResultMeshBuilder` → `ResultMeshJson.ToJson` → WebView `InvokeScript`。

## §3 验收清单

| # | 标准 | 状态 |
|---|---|---|
| 1 | `dotnet test` 全绿（含 JSON） | 通过（**27**） |
| 2 | Shell 求解后视口内见 `U_mag` 色带 | 待目视 |
| 3 | 断网可用（无 CDN） | 资源已 vendor |
| 4 | 无 ParaView 启动路径 | 已移除按钮 |
| 5 | Core 无 UI；Viz 无 UI | 通过 |

启动：

```powershell
dotnet run --project src\HYFEA\HYFEA.Shell\HYFEA.Shell.csproj -c Debug
```

流程：改参数 →「求解」→ 上方视口自动刷新云图；「导出 VTU」仍为可选旁路。

重建 vtk 包（仅改 `viewer-entry.js` 时）：

```powershell
cd src\HYFEA\HYFEA.Shell\Assets\Viewer\build
npm install
npx esbuild viewer-entry.js --bundle --outfile=../vendor/viewer.bundle.js --format=iife --platform=browser --target=es2020
```

## §4 WebView2 前提

若视口空白或状态栏提示失败：安装 [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。
