# 启动与测试

## 环境要求

| 项 | 版本/要求 |
|---|---|
| .NET SDK | >= 8.0（netstandard2.0 + net48 目标） |
| AutoCAD | 2025（宿主联调） |
| ReCall | C2 热重载 + C1 测试命令 |

## 首次启动

```powershell
cd hy-cad-tool
dotnet build src\HYFEA\HYFEA.Core\HYFEA.Core.csproj
dotnet build src\HYFEA\HYFEA.Tests\HYFEA.Tests.csproj
```

## 日常开发

### 内核开发与测试（无需 AutoCAD）

```powershell
# 编译内核 + 宿主抽象
dotnet build src\HYFEA\HYFEA.Core\HYFEA.Core.csproj -c Debug
dotnet build src\HYFEA\HYFEA.Hosting\HYFEA.Hosting.csproj -c Debug

# 运行全部测试（当前 27 项，含 BeamSolveSession + VTU + ResultMeshJson）
dotnet test src\HYFEA\HYFEA.Tests\HYFEA.Tests.csproj -c Debug
```

### Avalonia 独立壳（无需 AutoCAD）

```powershell
dotnet run --project src\HYFEA\HYFEA.Shell\HYFEA.Shell.csproj -c Debug
```

改参数 →「求解」→ 右侧上方 **PyVista/trame 边车**（变形叠加云图）；失败则回落 vtk.js。  
下方为结果表。「导出 VTU」仍为旁路。  

首次需准备边车 venv（详见 [Plan/08](Plan/08-trame边车视口V2-2026-07-12.md)）：

```powershell
cd src\HYFEA\HYFEA.Viewer.Py
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

需本机 **WebView2 Runtime** + **Python 3.12**（边车）。

### 宿主联调（需 AutoCAD 开着）

```powershell
# 1. AI 编译主工程
dotnet build src\HyCADTool\HyCADTool.csproj -c Debug

# 2. AutoCAD 命令行
C2    # 热重载插件
C1    # 执行 TestCommand 配置的命令
```

> C1 默认入口：`src/HyCADTool/App/Test/TestCommand.cs`。测梁元 MVP 时确保指向 `HyFeaBeamMvpCommand`。

### 直接命令（不经 C1）

AutoCAD 命令行输入 **N7** 对应的 `HYFEA 梁元 MVP`（`HyFeaBeamMvpCommand`）。

## 验收步骤

1. `dotnet test` → 25/25 通过
2. （可选）`dotnet run` HYFEA.Shell → 改参数求解，结果表刷新
3. AutoCAD 中 C2 → C1（或 N7）→ 选一条直线
4. 面板设置：材料 E、截面 A/I、均布荷载 q、EndA/EndB 约束
5. 点击求解 → 检查变形折线、M/V 图、支座反力文字回写
6. 切换简支/两端固接，对比解析解趋势是否合理

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `CS2012 dll 被锁定` | MSBuild 节点复用 | `dotnet build-server shutdown` 后加 `-nodeReuse:false` 重试 |
| C2 后命令未更新 | 未编译主工程 | 先 `dotnet build src\HyCADTool\...` 再 C2 |
| 面板恒为悬臂 | EndA/EndB 未绑定（已修复） | 确认 `BeamMvpPanel.xaml` 有 ComboBox 绑定 |
| Badge XamlParseException | ReCall 双载入 AdWindows | 见 05-AdWindows 规则，检查 AssemblyResolve 黑名单 |
| Shell 启动失败 | 缺 .NET 8 SDK / Avalonia 还原失败 | 确认 SDK ≥ 8；`dotnet restore` Shell 工程 |
| 导出 VTU 后无色带 | 主路径为边车；VTU 仅旁路 | 见 [Plan/08](Plan/08-trame边车视口V2-2026-07-12.md) |
| 视口空白 / 推送失败 | 缺 WebView2 / 边车未起 | 安装 Evergreen Runtime；按 Plan/08 §2 建 venv |
| 状态栏「回落 vtk.js」 | 未找到 `.venv` 或依赖 | 在 `HYFEA.Viewer.Py` 执行 README 安装步骤 |
