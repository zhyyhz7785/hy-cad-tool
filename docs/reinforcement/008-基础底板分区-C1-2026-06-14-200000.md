## 1. 目标

在土气分界（阶段 B）之后，对每个设计分组 $G_g$ 的**基础图形** $O^\*_g$ 识别**基础/底板**区域：

- 仅在割线左右土气点 X 区间 $[X^{cut}_{min}, X^{cut}_{max}]$ 内竖切条带（断点含土壤弧端点）
- **底边** = 土壤 CCW 弧（左土气点→右土气点，非竖直段）；列中点落在土壤段上才参与
- **上轮廓** = 最下混凝土带第 2 交点 `TopSeg` 真实 Y（保留斜面/阶梯）
- $H = y_{top1}-y_{soil} \le h_b$ 才出底板；$H>h_b$ 本轮跳过（墙/大体积，后期完善）

---

## 2. 算法（符号见 000 §12–§13、[010](010-Y向割线与基础厚度-2026-06-15-140000.md)）

对每个 $O^\*_g$：

1. X 断点 = 土壤弧端点 ∪ 区域顶点，限制在割线左右土气点区间 → 条带 $\tau_i$，中线 $x_m$
2. **落地门控**：$x_m$ 落在土壤 CCW 弧（非竖直段）上 → S 接触，否则不出底板
3. 竖线求最下混凝土区间，第 2 交点 $y_{top1}$ 所在 `TopSeg` 作上轮廓
4. 候选高 $H = y_{top1}(x_m) - y_{soil}(x_m)$（底 = 土壤弧在 $x_m$ 的真实 Y）
   - $H \le h_b$ → cell 下边 = 土壤弧在 $x_0/x_1$ 真实 Y，上边 = `TopSeg` 真实 Y
   - $H > h_b$ → 本轮跳过（`SkippedTooThick`，墙/大体积）
5. 底板 cell 相邻合并 → 蓝色预览
