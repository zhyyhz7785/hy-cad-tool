## 2. 数据流

1. 选 LWPOLYLINE → `ClassifyBoundaries`
2. `BuildGroupedIndependentRegions`（C1 独立区域，非 N8 的 Union 合并）
3. `RegionBoundaryAnalyzer.AnalyzeAllGroups` → 每组 `CutY = groupMinY + 埋深×1000`
4. `ComponentRecognizer.Recognize(group, params, { SoilCutY=cutY, ClipToRegion=true, UseVerticalEdgeWalls=true })`
5. `RegionPartitioner.Partition(..., soilCutY=cutY, useVerticalEdgeWalls=true)` — 阶段2 竖边成对判墙
6. 每个 `PartitionRegion.Polygon` → `PolygonBoolean.IntersectPolygonWithRegionAll` 裁回有效混凝土域
7. `ComponentPreviewService.DrawSession`（同 N8 预览层）

---

## 3. 超界修复

**根因**（004 §7）：N8 梯形弦线近似 + 无最终裁剪 → Hatch 超出原轮廓。

**N12 做法**：出口裁剪（策略 A），每个分区多边形做 `subject ∩ Outer − Holes`，碎片各自成 `ComponentRegion`。独立小轮廓快路径仍用精确 `Outer`，无需裁剪。

---

## 4. 土气 cutY 注入点

`RegionPartitioner.Partition(..., soilCutY)` 三处（`soilCutY=null` 时与 N8 一致）：

| 位置 | 行为 |
|------|------|
| grounded 门控 | `regionMinY <= soilCutY` |
| 预填底板顶 | `Math.Min(maxTop, soilCutY ?? maxBot+h_b)` |
| 底板 cut | `cut = Math.Min(refTop, soilCutY ?? maxBot+h_b)` |

## 6. 竖边成对识别墙（N12 专用）

**问题**：N8 阶段2 用 `SplitRaisedCellByWidth` 逐 Y 高度带量「穿过列中心的连续混凝土宽度」，570mm 竖肢在上下与大体积连通时量宽 ≫ 墙厚，再叠加 `WallMinHeightMm=500` 矮带门控 → 整根判红。

**N12 做法**（`UseVerticalEdgeWalls=true`，N8 不变）：

1. 从 `segments` 提取竖直面：与竖直夹角 ≤ `ParallelAngleThresholdDeg`（默认 ±15°）；近水平边（≤15°）自然排除
2. 用 `IsValidRebarPoint(x±1mm, yMid)` 定左面/右面（混凝土在内侧）
3. 左面 + 右侧最近右面：间距 `≤ 墙厚`、**两面平行（角度差 ≤ 阈值）**、Y 重叠 ≥ minH、中线 1/4/3/4 采样为混凝土
4. **平行占比闸**：`重叠高 / 混凝土柱全高 ≥ ParallelLineRatioMin`（默认 0.6）→ 滤除宽块边缘浅凹口伪墙
5. Y 夹紧到覆盖 strip 的 `wallCandidate` 范围（不越过 cut 进底板）
6. 对 `wallCandidate` 逐 strip：矩形 Y 区间 → 墙（绿），其余 → 大体积（红）

命令行输出 `竖边墙柱=N` 及每堵 `x / 宽 / 高 / 占比` 便于核对（如 570 竖肢占比≈1.0，伪墙 <0.6 被滤）。

| 对比 | N8 `SplitRaisedCellByWidth` | N12 竖边成对 |
|------|----------------------------|--------------|
| 量宽方式 | 水平割线连续混凝土宽度 | 两条竖直外轮廓边间距 |
| 角度闸 | 硬编码 5°/85° | 面板 `ParallelAngleThresholdDeg` ±15° |
| 平行占比 | 无 | `ParallelLineRatioMin` ≥0.6 |
| 矮带门控 | `<500mm` 不作墙 | 无（整段重叠高度判墙） |
| 上下连通 | 易被拖成大体积 | 竖肢独立成墙 |
