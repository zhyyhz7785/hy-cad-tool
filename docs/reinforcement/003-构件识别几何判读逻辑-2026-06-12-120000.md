# 003 — 构件识别几何判读逻辑

> 版本：**v5.6.3**（cut 下限夹紧 maxBot，修紧贴深坑台阶的单侧残留洋红/孤洞）  
> 日期：2026-06-12  
> 范围：**仅几何判读**。实现：`RegionPartitioner.cs` + `ComponentRecognizer.cs`

---

## 1. 判读动机（受力 → 几何顺序）

| 构件 | 受力特征 | 几何判据 |
|------|----------|----------|
| 基础/底板 | x 向最下层 xmin–xmax 与土壤接触 | 每条带最下区间，厚度 ≤ 底板上限 |
| 墙体 | 竖向，侧向土压力为主 | 某高度处轮廓实测宽度 ≤ 墙厚上限 |
| 楼板/梁 | 承担上部弯剪扭 | 水平层厚 ≤ 板厚上限；下凸窄 → 梁 |
| 大体积 | 三向受压块体 | 上述阶段剩余 |
| 局部混凝土 | 基础顶矮台/小凸起 | 上凸高 < 局部高差阈值 |

**判定顺序**：基础 → 墙 → 板/梁 → 大体积/局部。先判定的构件占有体积；仅墙锚固段允许重叠。

---

## 2. 总流程

```
选择多段线 → ClassifyBoundaries → BuildGroupedRegions（bbox 间隙聚类 → 组内 Union）
  → 每组独立 Recognize（组 bbox 最低点 = 地面基准）
  → 每个 ReinRegion 四阶段流水线（非落地跳过基础切割）
```

```
ReinRegion
  ├─ 独立小轮廓？ → 外包框整判（梁/墙/板/底板）
  └─ 大轮廓 → 四阶段流水线
        阶段0 条带采样
        阶段1 统一基础 cut + protrusionPool（仅 grounded）
        阶段2 墙（高度带 + 轮廓量宽）
        阶段3 板 + 梁（薄厚拆分 + 下凸）
        阶段4 大体积 / 局部收尾
```

### 2.1 多外轮廓合并（v5.1）

- **规则**：与外轮廓区域内有交叉/搭接的图形，均属于同一 `ReinRegion`。
- **实现**：组内 `BuildMergedRegions` — 外轮廓 `UnionAll`，孔洞按点包含归属。
- **效果**：组内相交外轮廓共享最小标高。

### 2.2 区域分组聚类（v5.2，同 hymbr）

- **动机**：多行独立结构一次性识别时，全局最低 Y 取自最底一行 → 上方行浮空基础误判。
- **规则**：外轮廓 bbox 间隙 ≤ `RegionGroupDistanceMm`（默认 1500）→ 同一计算组；同行主轮廓与旁侧矩形间隙≈0 同组，行间距远大于阈值 → 分组。
- **实现**：`ClusteringService.ClusterByBoundsDistance`（BFS + `BoundingBox.DistanceTo`）→ 每组 `BuildMergedRegions` → 每组独立 `Recognize`。
- **地面门控**：`Partition(..., groundY = 组 MinY)`；`regionMinY > groundY + 底板上限` → **非 grounded**，阶段 1 `cut = 区间底`，整列进 protrusionPool，不生成底板。

---

## 3. 阶段 0：条带采样

- X 断点 = 全部顶点 X；割线 `xm` = 相邻断点中点。
- gap 中点 `IsValidRebarPoint` → 竖向区间（j1 最高）。
- **非最下区间** → 暂存为 `upperSlabCells`（板候选）。
- **最下区间** → 暂存为 `StripBottomInfo`（阶段 1 再 cut）。

---

## 4. 阶段 1：基础统一切割

**前提**：区域 **grounded**（`regionMinY ≤ groundY + 底板上限`）；非 grounded 区域 `cut = 区间底`，跳过底板 cell，整列进 protrusionPool。

每条带最下区间（grounded 时）：

1. **预填** `bottomTopAtStrip[i] = min(区间顶, 区间底 + 底板上限)`。
2. **正式 cut**：
   ```
   cut = clamp( min(左邻底板顶, 右邻底板顶, 区间底 + 底板上限, 区间顶),  下限=区间底(maxBot) )
   ```
   **下限夹紧（v5.6.3）**：cut 不得低于本条带自身底面 `maxBot`。否则深坑邻列把 cut 拖到真实底以下 → 既不生成底板 cell，又使 `bumpHeight = 顶 - cut` 虚高跨过 1000 阈值跳过矮凸起合并 → 紧贴深坑的台阶单侧残留洋红/底部孔洞。夹紧后路由高度回归真实板厚。
3. `[区间底, cut]` → **底板 cell**（桥接横带）。
4. `[cut, 区间顶]` → 按高度预分类：**矮凸起**（高 < 局部高差上限且坐在底板上）与 **高凸起**（进 protrusionPool）。

**矮凸起（v5.6.2，`MergeBumpsIntoBottomSlab`「局部凸起并入底板」）**：
- **勾选（默认，=并入）**：
  - 本列已有底板 cell → 顶抬到凸起顶，一体蓝色。
  - **孤立矮凸起**（本列无底板 cell，基底贴邻列底板顶，`cut≈maxBot`）→ 用 `OrigBot` 新建底板 cell `[真实底轮廓, 凸起顶]`，不再进 protrusionPool，消除洋红残留与底部楔形孔洞。
- **未勾选（=拆分）**：仅「本列已有底板 cell」的矮凸起进 shortBumps；按底板 run 求 `runMinTop`；底板顶**逐侧夹紧** `newTop = max(runMinTop, 该侧底面)`，余量输出**局部混凝土**。

**protrusionPool 分流**（仅高凸起）：
- 块高 < `LocalConcreteMaxHeightMm`（默认 1000）→ **局部混凝土**，直接输出。
- 否则 → **wallCandidates**，进阶段 2。

**非落地板系（v5.3）**：`grounded == false` 时整列先进 `floatingCells`，`MergeCells` 预分组：
- 组内存在薄列（`ThicknessMm ≤ SlabMaxThicknessMm`）→ `Kind=Slab` 转入阶段 3（顶板+下挂块组合体）。
- 全厚列组 → 仍进 protrusionPool → 墙/大体积（悬空竖墙矩形不变）。

---

## 5. 阶段 2：墙体

对 `wallCandidates` 每个 cell 做 **高度带 + 原始轮廓水平割线量宽**：

- 量宽：`MeasureContourWidthAt`（轮廓线到轮廓线，非条带累加）；同高返回左右板缘 X。
- 宽 ≤ 墙厚上限 → 墙带；带高 < 500 → 降级大体积。
- 宽超限且**同高板缘距列边 ≤ 锚固长度** → 板带候选（kind 2）；否则 → 大体积带。
- **v5.5 2-run 下邻判型**：板带候选 run 下邻为大体积 → 转大体积（延伸到列顶）+ X 裁剪锚固舌；下邻为墙 → 保持板带（屋面过墙连续）。
- 墙带：向上锚固；下方夹层 < 局部高差阈值 → 延伸到列底；否则锚固长度。

---

## 6. 阶段 3：板 + 梁

合并 `upperSlabCells` + 阶段 2 回流的 `slabPieces`：

| 板组情况 | 处理 |
|----------|------|
| 全列厚 > 板厚上限 | 整组 → massPool |
| 全列薄 | 输出楼板 |
| 薄 + 厚混合 | 薄列下边 = **板基线** |

厚列拆分（v5.4 板/大体积交接锚固）：
- 厚柱 `[底,基线]` 为下段，`[基线,顶]` 暂存，由下段判型决定上段归属。
- 下段判大体积（宽 > 梁宽 或 贴 massPool）：下段 + 上段全归大体积（占满到顶）；空档边缘 **ClipCellX ≤ 锚固长度** 的上段复制为楼板锚固舌（几何重叠，预览大体积在上）。
- 下段判梁：下段 = 梁，上段 = 楼板（板在梁上连续）。
- 无下段厚柱 → 直接 massPool。

---

## 7. 阶段 4：大体积 / 局部

- massPool 合并：高 ≥ 局部高差阈值 → 大体积；否则局部。
- 局部贴大体积 → 迭代升级为大体积。
- 底板 cell 最终输出。

---

## 8. 独立小轮廓（不变）

外包框 `(w,h)` + 全局底边：梁 → 墙 → 板/底板，不满足则进大轮廓流水线。

---

## 9. 几何阈值

| 参数 | 默认 | 用途 |
|------|------|------|
| BottomSlabMaxThicknessMm | 1500 | 底板最大高度 |
| WallMaxThicknessMm | 500 | 墙厚 / 量宽上限 |
| SlabMaxThicknessMm | 300 | 板厚上限 |
| BeamMaxWidthMm | 800 | 下凸梁宽上限 |
| LocalConcreteMaxHeightMm | 1000 | 局部混凝土高差 / 矮凸起上限 |
| MergeBumpsIntoBottomSlab | true | 局部凸起并入底板（勾=并入一体蓝，不勾=拆分洋红局部） |
| RegionGroupDistanceMm | 1500 | 区域分组 bbox 间隙聚类（同 hymbr） |
| AnchorageLengthMm | 500 | 墙锚固延伸 |
| WallMinHeightMm | 500（常量） | 矮墙带降级 |

---

## 10. 重叠与守恒

- 底板 / 板 / 梁 / 大体积 / 局部：**互斥**。
- 墙：锚固段可与底板、大体积、板重叠；预览 Priority 墙最高。

---

## 11. 变更摘要（v4 → v5 → v5.1）

**v5**
1. 基础上凸统一为 **protrusionPool**（修复多区间/单区间路径不一致漏判墙）。
2. 判定顺序明确为 **基础 → 墙 → 板/梁 → 大体积**。
3. 新增 **板下凸 → 梁** 识别（`ProcessSlabGroups`）。
4. 新增参数 **LocalConcreteMaxHeightMm**。
5. 删除厚板邻大体积复判补丁。

**v5.1**
1. **BuildMergedRegions**：相交外轮廓 Union 为同一区域，消除浮空基础。
2. **板锚固舌**：同高板距当前列 > 锚固长度不再判板带，大体积不被板横穿。
3. **下凸先合并再判型**：贴大体积的下凸归 massPool，不再误判梁。

**v5.2**
1. **BuildGroupedRegions**：hymbr 同款 bbox 间隙聚类，多行结构分组独立计算。
2. **地面门控**：`Partition(groundY)`，非落地区域不生成底板。
3. 面板「区域分组」Expander：`CompGroupClusterDistance`（默认 1500）。

**v5.3**
1. **floatingCells 预分组**：非落地多外轮廓组合体（顶板+下挂块）含薄列证据时转阶段 3 板基线拆分，不再整体判大体积。
2. 薄带 → 楼板；下凸宽 ≤ 梁宽 → 梁；否则 → 大体积/局部。
3. 无薄列的全厚悬空组保持 v5.2 墙/大体积路径。

**v5.4**
1. **板/大体积交接锚固**：厚柱上段不再整段判楼板；大体积占满到顶，楼板仅从空档边缘伸入一个锚固长度（重叠、配筋用）。
2. 梁上方楼板保持连续；预览 Priority 大体积 > 楼板不变。

**v5.5**
1. **阶段 2 大体积到顶**：板厚带下邻为大体积时转大体积 run（不再截断红块顶）；下邻为墙保持板带（屋面连续）。
2. **锚固舌 X 裁剪**：`MeasureContourWidthAt` 返回左右板缘；阶段 2/3 锚固舌按 `ClipCellX` 精确 ≤ 锚固长，不再整条条带判板。

**v5.6**
1. **矮凸起开关接线**：矮凸起预分类 + 勾选并入底板 / 未勾选 runMinTop 分台阶局部。
2. 删除已无功能的 `BottomSlabHeightToleranceMm`（150mm）及面板「底板高差 mm」行。

**v5.6.1**
1. **正向语义改名**：`IgnoreBottomSlabHeightDiff`「忽略底板高差」→ `MergeBumpsIntoBottomSlab`「局部凸起并入底板」（勾=并入，不勾=拆分），全链路（参数类/VM/JSON/面板）同步。
2. **斜坡孔洞修复**：拆分路径底板顶逐侧夹紧 `max(runMinTop, 该侧底面)`，局部混凝土余量底面跟随底板新顶；消除坑底斜坡过渡段梯形自交导致的漏填。

**v5.6.2**
1. **勾选并入补孤立**：`merge=true` 时孤立矮凸起（本列无底板 cell）也进 shortBumps；合并路径用 `OrigBot` 新建底板 cell，底面贴真实轮廓，消除勾选状态下残留洋红与底部黑洞。
2. **拆分路径不变**：`merge=false` 时 shortBumps 条件与原 v5.6.1 等价（仅本列已有底板 cell 的矮凸起）。

**v5.6.3**
1. **cut 下限夹紧**：stage-1 grounded 分支 `cut = max(cut, maxBot)`，修复紧贴深坑的台阶被邻列拖低 cut 导致 `bumpHeight` 虚高（≥1000）跳过矮凸起合并的**单侧**残留洋红/孤洞；夹紧后台阶按真实板厚路由进矮凸起，与 v5.6.2 孤立分支一起两侧对称并入底板。
