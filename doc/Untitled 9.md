发现问题

1 预览里面 字宽0.7 并没有针对0.7倍字宽，AutoCAD中是真的0.7倍字宽了，导致每一行文字宽度不同，预览中提前换行了

2 AutoCAD中表格都被放到下面去了，不是真实位置

3 预览中很多信息没有显示，每一栏到了后面会丢失一些信息

4 预览中的缩进和AutoCAD中有很大不同

5 表格宽度，由于字体宽度不同的原因，导致表格高度也差很多





之前的思路：
  Markdown → HTML → distribute() 复杂分配 → 只读预览 → 另开编辑器

现在的思路：
  Markdown → HTML 块列表 → 按高度分配到栏（一次性）
  → 每栏 = 独立 contenteditable div（位置不同，其余相同）
  → 编辑时增量级联（溢出/回流移动末尾块）
  → 保存时提取所有栏内容 → 合回 Markdown

**警惕过度工程化：** Vditor 没有像 Monaco Editor 那样实现极其复杂的行差异算法，而是选择了依靠 WebAssembly (Lute) 的暴力计算速度来弥补逻辑上的“非原子性”。
