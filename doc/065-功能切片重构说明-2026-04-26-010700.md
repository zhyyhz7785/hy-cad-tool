# 功能切片重构说明

> 时间：2026-04-26 01:07  
> 范围：`HyCADTool` 按功能切片迁移，重点是 `Presentation/Commands` 命令向 `Features/*` 收口。  
> 验证：`dotnet build HyCADtoolGpt.sln` 已通过。

## 1. 重构目标

本次重构的核心目标是把原来集中在 `Presentation/Commands`、部分散落在 `Presentation/Views` / `ViewModels` 的业务入口，按功能归入 `HyCADTool/Features/*`。

重构后约定：

- 一个功能优先放在一个 `Features/{FeatureName}` 目录中。
- 命名空间统一为 `HyCADTool.Features.{FeatureName}`。
- `ReCall/commands.json` 中的 `type` 指向新的 Feature 命名空间。
- `Presentation` 保留面板宿主、通用 View / ViewModel、命令分发基础设施，不再作为业务命令主目录。
- `Shared` 只保留跨功能复用的 AutoCAD 基础设施、服务、几何与启动逻辑。

## 5. 关键适配点

### 5.1 面板入口

`ShowPanelCommand` 已迁入 `Features/Shell`。

相关引用已同步：

- `Test/TestCommand.cs` 改为引用 `HyCADTool.Features.Shell`。
- `ReCall/commands.json` 中 `Hy` / `HyB` 指向 `HyCADTool.Features.Shell.ShowPanelCommand`。

### 5.2 底板配筋

底板配筋面板已迁入 `Features/BaseRein`：

- `BaseReinPanel.xaml`
- `BaseReinPanel.xaml.cs`
- `BaseReinPanelViewModel.cs`

同步点：

- `HyCADTool.csproj` 的 Page 路径改为 `Features\BaseRein\BaseReinPanel.xaml`。
- `AutofacModule` 的 DI 注册改为 `HyCADTool.Features.BaseRein.*`。
- `HySettingsViewModel` 通过 `HyCADTool.Features.BaseRein` 使用 `BaseReinPanelViewModel`。

`BaseReinforcementService` 仍保留在 `Shared/AutoCAD/Services`，因为它目前更接近 AutoCAD 绘图服务实现，且可能被面板与后续入口共同复用。

### 5.3 OverKill 设置

`HyovSettings` 已从 `Presentation/Commands` 迁入 `Features/OverKill`。

同步点：

- `OverKillCommand` 直接使用同 Feature 下的 `HyovSettings`。
- `HyovSettingsWindow.xaml.cs` 改为引用 `HyCADTool.Features.OverKill`。

### 5.4 命名冲突处理

迁移后部分 Feature 名与类型名重名，已通过别名解决：


| 冲突                                                                    | 处理                                          |
| --------------------------------------------------------------------- | ------------------------------------------- |
| `Features/Elevation` vs `Domain.ValueObjects.Elevation`               | `Elevation3DCommand` 使用 `ElevationValue` 别名 |
| `Features/AnchorBolt` vs `Domain.Entities.AnchorBolt`                 | 地脚螺栓相关命令使用 `AnchorBoltEntity` 别名            |
| `Features/Dimension` vs `Autodesk.AutoCAD.DatabaseServices.Dimension` | `SplitDimensionCommand` 使用 `AcDimension` 别名 |


## 6. 编译验证

已执行：

```powershell
dotnet build HyCADtoolGpt.sln
```

结果：

- 编译成功。
- 仍有 1 个既有架构警告：`MSB3270`，原因是项目 `MSIL` 与 AutoCAD.NET 包内 `AcSeamless.dll` 的 `AMD64` 架构不匹配。该警告与本次迁移无直接关系，且符合当前 AnyCPU + AutoCAD 运行时策略。

## 8. 后续事项

1. 发版前同步 `dist/HyCAD.bundle/Contents/Win64/commands.json`。
2. 若后续要继续收口，可把 `Presentation/Commands/Base` 迁到更中性的基础设施目录，例如 `Shared/Commands`。
3. `EditorLoader` 当前仍服务于 Markdown 编辑器桥接，短期可保留在 `Presentation/Commands`；若 Markdown 相关功能继续模块化，建议迁入 `Features/Export` 或 Markdown 专属模块。
4. 各新 Feature 目录可逐步补齐 `README.md` 和 `Doc/001-从层级结构迁入-*.md`，目前已有 `Settlement`、`OverKill`、`DimensionForReinforcement`、`Road` 等先例。
