# HyCAD 旧到新图层映射 v1.1

> 版本：v1.1 · 2026-04-24 · **合并版映射表**
> 作用：驱动 `LayerMigrationService` 把现有 DWG 里的旧图层批量更名为 v1.1 规范名，并驱动代码侧 `LayerDefinitionItem.LegacyNames[]` 的填充。
> v1.1 相对 v1.0：全部新层名汉化；部分旧层合并到同一新层（N→1）；新增 XData KIND 字段供代码区分合并源

## 范围

- **旧层名**：涵盖整个 HyCADTool 代码仓所有 `"XXX"` 字面量的图层名，共计 **111 条**
- **新层名**：遵循 [000-HyCAD图层规范-v1.md](000-HyCAD图层规范-v1.md) v1.1，共计 **91 条** + **2 条动态模板**
- **合并映射**：对于旧层合并到同一新层的情况，标注 XData KIND（见 [001-图层完整清单-v1.md §6.3](001-图层完整清单-v1.md#63-合并后-xdata-重构清单)）

## 表格说明

- **旧层名**：代码或 DWG 中的现有字符串
- **新层名**：v1.1 规范名
- **类型**：`1:1` 一对一改名；`N:1` 多对一合并（同一新层承接多个旧层，需写入 XData KIND）；`模板` 动态模板
- **XData KIND**：合并类型下，新实体需写入的 XData 字段值（注册簇名见"合并重构说明"章节）
- **来源**：该旧层出现在哪个 service / command / xdata 文件

## 5. 迁移工具草图

### 5.1 `LayerMigrationService` 接口

```csharp
public sealed class LayerMigrationService
{
    public MigrationReport Analyze(Database db);           // 扫描 DWG 返回待迁移层数 + 实体数
    public MigrationReport Migrate(Database db);           // 执行迁移（只改 LayerTable，不删旧层）
    public MigrationReport MigrateAndCleanup(Database db); // 迁移后删除空的旧层
}

public sealed class MigrationReport
{
    public int LayersRenamed { get; set; }         // 更名的层数
    public int LayersMerged { get; set; }          // 合并到同一层的层数
    public int EntitiesMigrated { get; set; }      // 迁移的实体数
    public int XDataWritten { get; set; }          // 写入 XData KIND 的实体数
    public IReadOnlyList<string> UnknownLayers { get; set; } // 未识别的遗留层
}
```

### 5.2 `hyLayerMigrate` 命令

```csharp
[CommandMethod("hyLayerMigrate")]
public static void MigrateLayers()
{
    var doc = Application.DocumentManager.MdiActiveDocument;
    var ed  = doc.Editor;
    ed.WriteMessage("\n[HyCAD] 开始图层迁移...");
    var service = ServiceLocator.Resolve<LayerMigrationService>();
    using (doc.LockDocument())
    {
        var report = service.Migrate(doc.Database);
        ed.WriteMessage($"\n[HyCAD] 迁移完成：更名 {report.LayersRenamed}，合并 {report.LayersMerged}，实体 {report.EntitiesMigrated}，XData {report.XDataWritten}");
        foreach (var unknown in report.UnknownLayers)
            ed.WriteMessage($"\n[HyCAD] 未识别层：{unknown}");
    }
}
```
