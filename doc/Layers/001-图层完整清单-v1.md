# HyCAD 图层完整清单 v1.1

> 版本：v1.1 · 2026-04-24 · **本文档是 v1.1 合并 + 汉化版清单，与 [000-HyCAD图层规范-v1.md](000-HyCAD图层规范-v1.md) 对齐**
> 全量 **91 条图层 + 2 条动态模板**，按 `大类 → 子组 → 具体层` 组织

## v1.1 主要变化（相对 v1.0）

- 总层数：**106 → 91**（减少 14%）
- `01 结构-钢筋` + `01 结构-筏板` **合并为 `1配筋` 单个子组**
- `01 结构-聚类` 原 15 条合并为 5 条，内部用 XData 区分
- 全部层名**汉化**：`MBR` → `主` / `3D` → `体` / `Voronoi` → `维诺` / `BP/AAP/BAP/ABolt/SteelPlate` → 合并为 `主` 等
- 后缀 `-3D` 改名 `-体`；新增 `-标`

## 字段说明

| 字段 | 说明 |
|---|---|
| 新层名 | 遵循 v1.1 规范的标准层名，**全中文** |
| 语义 ID | `LayerSemanticIds` 常量，代码层定位锚点（保持英文命名） |
| 色 | ACI 颜色索引（1-255） |
| 线型 | `Continuous` / `CENTER` / `DASHED` / `HIDDEN` 等 |
| 线宽 | mm（`-1 = ByLayer`） |
| 锁 | 默认锁定状态（L=锁定，—=不锁） |
| 打 | 可打印（Y/N） |
| 归属 | 主要写入/读取服务或命令 |
