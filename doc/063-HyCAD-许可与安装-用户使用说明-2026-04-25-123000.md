# HyCAD 许可与安装 — 使用说明

本文面向三类人：**用插件的 CAD 用户**、**收单发 license 的销售/内勤**、**打安装包与签发的开发者**。更细的代理商流程见同目录 `062-HyCAD-Bundle与许可-代理商签发-2026-04-25-120000.md`。

---

## 一、最终用户（设计师 / AutoCAD 端）

### 1. 安装插件（.bundle）

1. 拿到发布方提供的 **`HyCAD.bundle` 文件夹**（或 zip 解压后得到该文件夹）。
2. 将整个文件夹复制到（**推荐，无需管理员**）：
   - `%APPDATA%\Autodesk\ApplicationPlugins\HyCAD.bundle`
   - 可在资源管理器地址栏输入：`%APPDATA%\Autodesk\ApplicationPlugins\` 后粘贴 `HyCAD.bundle`。
3. **关闭并重新启动 AutoCAD**。启动后由 Autodesk 自动加载（Autoloader），一般**不需要**再手动 `NETLOAD`。

若使用安装程序（Inno Setup 等），按安装向导选择同一用户级路径即可。

### 2. 不激活时能用什么（免费 / Freemium）

未导入有效 `license.lic` 时，仍可使用部分命令，例如：

- 统一面板：`hy`、`HyB`、面板执行 `_HyExec`
- 基础沉降：`HYJC`、`hySC`
- 绘图单位/首选项相关：`HYOV`、`HYOVSET`
- **许可窗口**：`hyLicense`（查看机器码、二维码、导入授权文件）
- 诊断：`hyCmdList`、`CHECKWPF`（若版本包含）

其余大量命令（钢筋、道路、桩基等）需要购买对应**标准版 / 专业版 / 企业版**后导入 license。

### 3. 购买后如何激活（离线）

1. 在 AutoCAD 命令行输入 **`hyLicense`**，打开「许可与激活」窗口。
2. 将窗口中的 **机器码**（五段 `XXXX-XXXX-…`）复制，或让对方扫 **二维码**。
3. 把机器码、购买的**套餐**和**期限**（1 年 / 3 年 / 终身等）发给销售/代理商。
4. 对方会发回一个 **`license.lic` 文件**（JSON 内容，扩展名多为 `.lic`）。
5. 在 `hyLicense` 窗口点 **「从文件导入」**，选中该文件。  
   - 成功后会复制到本机：  
   **`%ProgramData%\HyCAD\license.lic`**  
   （`ProgramData` 一般为 `C:\ProgramData`，全机共享，**升级插件 bundle 不会覆盖此文件**）。
6. 若提示已激活但仍无法使用高阶命令，**关闭并重新打开一次 AutoCAD** 后再试。

### 4. 环境变量排障（一般用户勿开）

在 Windows「环境变量」中设置 `HYCAD_BYPASS_LICENSE=1` 可**临时跳过**许可检查（仅用于技术支持排查）。**日常使用请删除该变量**，否则等同于无保护。

## 二、销售 / 内勤

1. 向客户索取 **`hyLicense` 窗口中的机器码**（或清晰截图），并确认套餐与期限。
2. 将信息交给有 **LicenseSigner 签发权**同事，由对方生成 `license.lic` 发回客户。
3. **发错内容**：当前为**纯离线**方案，无中心吊销。处理办法是**用正确信息重新签一份**发给客户，让客户再次「导入」覆盖；自己保留台账记录即可。

（签发操作步骤见项目内 `HyCADTool.LicenseSigner/README-签发流程.md` 与 `doc/062-...`。）

## 三、开发者 / 打包与签发

### 1. 一键打 Bundle（安装目录）

在**仓库根目录** PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\PackBundle.ps1
```

可选指定版本号：

```powershell
powershell -File tools\PackBundle.ps1 -Version 1.0.1
```

产物：

- `dist\HyCAD.bundle\`：可直接复制到 `%APPDATA%\Autodesk\ApplicationPlugins\`
- `dist\HyCAD-v1.0.0-bundle.zip`：便于分发

构建使用 **`HyCADTool.Refactored` 的 `Production` 配置**（脚本内已 `dotnet build -c Production`）。

**制作License**

`dotnet run --project HyCADTool.LicenseSigner`

### 2. 签发 `license.lic`（仅授权人员）

1. **首次或轮换密钥**：在仓库根执行 `tools\_gen-rsa-keys.ps1`，得到 `tools/rsa-priv.xml`（**勿提交 git**；公钥需与 `HyCADTool.Licensing` 内嵌公钥一致，轮换时需同步改嵌入公钥并重新出插件）。
2. 编译并运行 `HyCADTool.LicenseSigner`：填写客户机器码、客户名、档（standard / professional / enterprise）、1 年/3 年/终身，生成并保存 `license.lic`。

3. **制作License**

   `dotnet run --project HyCADTool.LicenseSigner`
4. 若存在 `tools\rsa-priv.xml`，发布目录下会自动带 `PrivateKey.xml` 链（见 Signer 项目说明）。

### 3. 私钥与备份

- **私钥丢失** = 旧 license 无法补签，需换一对密钥并在插件中更新公钥，**所有客户需重新发 license**。
- 务必备份：本地加密盘、U 盘、网盘多份，**不要进版本库**。

### 4. 可选：Inno 安装包

`build\HyCAD-Setup.iss` 需本机安装 **Inno Setup**，编译前把脚本里的 **`RepoRoot`** 改成你机器上仓库根路径，用 ISCC 编译为 `dist\HyCAD-Setup-*.exe`，安装目标为用户级 `…\ApplicationPlugins\HyCAD.bundle\`。

## 四、常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 启动 AutoCAD 后没有 Hy 命令 | bundle 路径不对、或 CAD 主版本不在 PackageContents 声明范围内 | 确认 `PackageContents.xml` 与 `…\ApplicationPlugins\HyCAD.bundle\` 结构完整，必要时 `APPLOAD` 看「已加载包」或重启 CAD |
| 提示签名校验失败 | license 被改过、或插件与签发用的**公钥/私钥**不是同一对 | 用同一套密钥重新签；确认客户拿的是为当前大版本出的插件 |
| 提示机器码不符 | 客户把 license 换到另一台电脑 | 按新机器码重新签 |
| 提示时钟异常 / 被锁定 | 系统时间被大幅往回改 | 校准系统时间后联系重签或按文档说明处理 state |
| 道路/桩基仍不能用 | 当前 license 为 **Standard**，专业功能需 **Pro** | 升档并重新签 |
