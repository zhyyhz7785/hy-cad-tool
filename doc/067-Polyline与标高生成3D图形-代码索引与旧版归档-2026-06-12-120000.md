# Polyline + 标高数据 → 3D 图形：代码索引与旧版归档

> **结论**：当前仓库**已有**重构版实现（命令 `HY3`）。旧版 `ElevationModelGenerator` 已于 **2026-04-17** 删除；剖面/断面相关命令**尚未**迁入 Refactored。

---

## 1. 业务含义（「表格」指什么）

本功能链路的输入**不是** AutoCAD `Table` 实体，而是：

| 输入 | 说明 |
|---|---|
| **Polyline** | DCEL 输出的 `dcelOuter`（外轮廓）+ `dcelInner`（各基础分区） |
| **标高「表格」** | `Dictionary<Polyline, 标高>`：每个内部分区 Polyline 对应一个标高值（来自 DBText/MText） |

输出：`Solid3d` 墙体 + 筏板（3D 基础模型）。  
可选后续：从 3D 实体生成剖面图（旧版 `hy3C_CreateSection` / `GenerateCrossSection`，**未重构**）。

## 2. 当前 Refactored 代码（可用）

### 2.1 命令入口

| 项 | 位置 |
|---|---|
| 命令名 | `HY3`（`commands.json` → `Elevation3DCommand.Execute`） |
| 入口类 | `src/HyCADTool/Features/Elevation/Elevation3DCommand.cs` |
| 注册 | `src/ReCall/commands.json` 第 88 行 |

### 2.2 主流程（5 步）

```
DCEL 命令 → dcelOuter / dcelInner Polyline
    ↓
HY3 选 Polyline + 标高 TEXT
    ↓
Polyline ↔ 标高匹配 → GeometryData
    ↓
Elevation3DCalculator → Wall3D / Slab3D
    ↓
Geometry3DBuilder.ExtrudePolygon → Solid3d 落图
```

### 2.3 分层文件清单

| 层 | 文件 | 职责 |
|---|---|---|
| **Presentation** | `Elevation3DCommand.cs` | 选集、编排、落图 |
| **Infrastructure** | `Services/ElevationDataExtractor.cs` | Polyline ↔ 标高文本匹配（面积优先） |
| | `Services/Geometry3DBuilder.cs` | `Polyline` → `CreateExtrudedSolid` |
| | `Services/Solid3DBuilder.cs` | 墙体矩形拉伸 |
| | `Services/WallGenerationService.cs` / `SlabGenerationService.cs` | 批量生成 |
| | `Shared/AutoCAD/Services/PolygonAdapter.cs` | AutoCAD Polyline ↔ Domain Polygon2D |
| **Domain** | `Domain/Services/GeometryAnalyzer.cs` | 边界条件分析 |
| | `Domain/Services/Elevation3DCalculator.cs` | 墙体/筏板 3D 参数（注释标明源自旧 `ElevationModelGenerator`） |
| | `Domain/Services/WallBufferGenerator.cs` | 墙体缓冲多边形 |
| | `Domain/Services/WallConnectionHandler.cs` | 墙体连接（当前部分禁用） |
| | `Domain/ValueObjects/GeometryData.cs` | 单分区几何 + 标高 + 墙段 |
| | `Domain/ValueObjects/WallData.cs` | 墙段内外标高 |
| | `Domain/Entities/Wall3D.cs` / `Slab3D.cs` | 3D 实体模型 |
| **上游** | `Features/Misc/DCELCommand.cs` | 生成 `dcelOuter` / `dcelInner` |
| | `Features/DCEL/Services/DCELRenderer.cs` | DCEL 渲染为多边形 |

### 2.4 关键算法位置

- **Polyline 拉伸为 Solid**：`Geometry3DBuilder.ExtrudePolygon`（注释：`ElevationModelGenerator.ExtrudeWallRegion`）
- **标高解析**：`Domain/ValueObjects/Elevation.cs` → `ElevationValue.TryParse`
- **图层**：筏板体 `LayerSemanticIds.RaftSolid3D` → `01-hy-4基础-筏板-体`

### 2.5 与旧版的差异（联调时注意）

| 项 | 旧版 | 重构版 |
|---|---|---|
| 内多边形图层 | `dcelInter` | `dcelInner` |
| 标高文本图层 | 固定 `00_hy_3公共_标注4_标高` | 用户框选 TEXT，不限图层 |
| 标高单位 | `ParseExtrudeDistance`：文本米 × 1000 → mm | `ElevationValue` 统一值对象 |
| 剖面命令 | `hy3C_CreateSection` / `GenerateCrossSection` | **无** |

## 4. 易混淆：其他「Polyline / Table / 3D」代码

| 功能 | 是否「Polyline+表格→3D」 | 位置 |
|---|---|---|
| **HY3 标高 3D** | ✅ 是（Polyline + 标高文本） | `Features/Elevation/` |
| 道路 PI 表 + Polyline3D | ❌ 2D 线位/表格编辑，非 Solid3d | `Features/Road/Alignment/` |
| 桩基按标高分组 | ❌ 输出统计 **Table**，不生成 3D | `GroupCirclesByElevationCommand.cs` |
| 设备基础螺栓 **Table** | ❌ XY 坐标表，非 3D | `EquipmentFoundationService.cs` |
| Markdown → Table 落图 | ❌ 2D 表格 | `DesignSpecService.cs` |
| 道路横断面 | ❌ 2D 横断面图 | `Features/Road/CrossSection/` |
