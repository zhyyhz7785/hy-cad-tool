# 基于表面的三维建模新方法

> **日期**: 2025-10-26  
> **命令**: C15  
> **状态**: ✅ 已实现（待测试）  
> **原理**: 不识别相邻边，基于表面和扩张生成三维模型

---

## 🎯 核心思路

### 问题背景
原方法需要识别相邻边和重合边，当一条长边被多个短边相邻时逻辑复杂。

### 新方法原理
**不再识别相邻边**，而是基于表面和扩张：

```
1. 上表面 = 多边形 @ 标高
2. 下表面 = 根据标高规则计算
3. 墙体 = 多边形外侧扩张 300mm
4. 底板 = 多边形内部区域，厚度 400mm
5. 0.000 平面 = 土壤分界线
```

---

## 📐 详细原理

### 1. 上表面和下表面

**上表面**：
- 多边形在其标高平面上

**下表面规则**：
- **正值标高**（如 +700mm）：
  - 先延伸到 0.000（地面）
  - 再向下 400mm
  - **底标高 = -400mm**
  
- **负值标高**（如 -5000mm）：
  - 直接向下 400mm
  - **底标高 = -5400mm**

**代码实现**：
```csharp
private Elevation CalculateBottomElevation(Elevation topElevation)
{
    if (topElevation.Value >= 0)
    {
        // 正值：延伸到 0.000，再向下 400mm
        return Elevation.FromMillimeters(-400.0);
    }
    else
    {
        // 负值：直接向下 400mm
        return Elevation.FromMillimeters(topElevation.Value - 400.0);
    }
}
```

### 2. 墙体生成

**墙体 = 外轮廓 - 内轮廓**：
- **外轮廓**：原多边形外侧扩张 300mm
- **内轮廓**：原多边形
- **高度**：从下表面到上表面

**扩张算法**：
```csharp
// 多边形外侧扩张 300mm
var wallRegion = polygon.Offset(300.0, isOutward: true);
```

### 3. 底板生成

**底板**：
- **区域**：原多边形（内部）
- **顶标高**：下表面标高
- **厚度**：400mm

### 4. 土壤接触面识别

**0.000 平面作为土壤分界线**：
- **0.000 以下的外表面** = 与土壤接触
- **底板下表面** = 与土壤接触

**判断逻辑**：
```csharp
bool contactsWithSoil = bottomElevation.Value < 0;
```

## 🏗️ 数据结构

### Surface3D（三维表面）
```csharp
public class Surface3D
{
    public Polygon2D Polygon { get; }    // 表面轮廓
    public Elevation Elevation { get; }  // 表面标高
    public string Name { get; }          // 表面名称
}
```

### WallSolid3D（墙体实体）
```csharp
public class WallSolid3D
{
    public Polygon2D OuterPolygon { get; }      // 外轮廓（扩张后）
    public Polygon2D InnerPolygon { get; }      // 内轮廓（原始）
    public Elevation BottomElevation { get; }   // 底标高
    public Elevation TopElevation { get; }      // 顶标高
    public bool ContactsWithSoil { get; }       // 是否与土壤接触
}
```

### SlabSolid3D（底板实体）
```csharp
public class SlabSolid3D
{
    public Polygon2D Polygon { get; }           // 底板区域
    public Elevation TopElevation { get; }      // 顶标高
    public SlabThickness Thickness { get; }     // 厚度
    public Elevation BottomElevation { get; }   // 底标高（自动计算）
}
```

### SurfaceBasedModel（完整模型）
```csharp
public class SurfaceBasedModel
{
    public Surface3D TopSurface { get; }        // 上表面
    public Surface3D BottomSurface { get; }     // 下表面
    public WallSolid3D WallSolid { get; }       // 墙体
    public SlabSolid3D SlabSolid { get; }       // 底板
    public bool ContactsWithSoil { get; }       // 是否与土壤接触
}
```

## 📊 示例

### 示例1：正值标高（+700mm）

**输入**：
- 多边形：矩形 10000mm × 8000mm
- 标高：+700mm

**计算**：
- **上表面**：+700mm
- **下表面**：-400mm（延伸到 0.000，再向下 400mm）
- **墙体**：
  - 外轮廓：10300mm × 8300mm（外扩 300mm）
  - 内轮廓：10000mm × 8000mm
  - 高度：1100mm（从 -400mm 到 +700mm）
- **底板**：
  - 顶标高：-400mm
  - 底标高：-800mm
  - 厚度：400mm
- **土壤接触**：是（底标高 -800mm < 0）

**生成结果**：
```
墙体: 1100mm 高（-400mm → +700mm）
底板: 400mm 厚（-800mm → -400mm）
土壤接触面: 墙体外表面（0.000 以下）+ 底板下表面
```

### 示例2：负值标高（-5000mm）

**输入**：
- 多边形：矩形 10000mm × 8000mm
- 标高：-5000mm

**计算**：
- **上表面**：-5000mm
- **下表面**：-5400mm（直接向下 400mm）
- **墙体**：
  - 高度：400mm（从 -5400mm 到 -5000mm）
- **底板**：
  - 顶标高：-5400mm
  - 底标高：-5800mm
  - 厚度：400mm
- **土壤接触**：是（全部在 0.000 以下）

**生成结果**：
```
墙体: 400mm 高（-5400mm → -5000mm）
底板: 400mm 厚（-5800mm → -5400mm）
土壤接触面: 墙体外表面全部 + 底板下表面
```

## 🔧 技术细节

### Polygon2D.Offset 实现

**基于法线方向偏移**：
```csharp
public static Polygon2D Offset(this Polygon2D polygon, double distance, bool isOutward)
{
    // 对每个顶点：
    // 1. 计算前后两条边的向量
    // 2. 计算两条边的法线
    // 3. 取平均法线
    // 4. 考虑角度，计算偏移因子
    // 5. 沿平均法线偏移

```

- 简化版本，适用于简单多边形
- 复杂多边形可能需要 Clipper2 库
