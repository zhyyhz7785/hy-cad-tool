# HYOV 开关功能测试指南

> **日期**: 2025-10-25  
> **目的**: 验证三个 FILLET 步骤开关是否正常工作  
> **问题**: 用户反馈开关无效

---

## 🔍 问题诊断

### 可能的原因

1. **未保存设置** - 修改后没有点击"确定"按钮
2. **未重新编译** - 修改代码后没有重新生成 DLL
3. **未热重启** - 编译后没有执行 C2 命令
4. **缓存问题** - AutoCAD 使用了旧的 DLL

---

## 🔧 故障排查

### 情况1：开关状态显示错误

**症状**：
```
========== 开关状态 ==========
打断相交开关: True    ← 明明取消勾选了，但显示 True
```

**原因**：设置没有保存

**解决方案**：
1. 重新打开设置窗口（HYOVSET）
2. 检查开关状态（应该是勾选的，说明上次没保存）
3. 取消勾选
4. **点击"确定"按钮**（不要点"取消"）
5. 重新执行 HYOV

---

### 情况2：仍然执行了打断/延伸步骤

**症状**：
```
========== 开关状态 ==========
打断相交开关: False   ← 显示正确
端点延伸开关: False   ← 显示正确
端点到线开关: False   ← 显示正确
=============================
第0步-预清理：10 → 10 线段
第1步-打断相交：10 → 15 线段    ← 不应该出现！
第2步-端点延伸：15 → 15 线段    ← 不应该出现！
```

**原因**：使用了旧的 DLL（代码修改后没有重新编译/热重启）

**解决方案**：
1. Visual Studio 重新生成项目（Ctrl+Shift+B）
2. AutoCAD 执行 C2 命令（热重启）
3. 重新执行 HYOV（或 C11）

---

### 情况3：命令行没有显示"开关状态"

**症状**：
```
=== HYOV 命令（OVERKILL + FILLET） ===
已选择 XX 条线段
当前单位：毫米(mm)
（没有"开关状态"输出）
第0步-预清理：XX → XX 线段
```

**原因**：使用了旧版本的 DLL（没有调试输出代码）

**解决方案**：
1. 确认代码已更新（OverKillCommand.cs 第 96-103 行应该有调试输出）
2. Visual Studio 重新生成项目
3. AutoCAD 执行 C2 命令
4. 重新执行 HYOV

## 🎯 常见错误

### 错误1：忘记点击"确定"

**现象**：修改开关后，直接关闭窗口或点击"取消"

**结果**：设置不会保存，下次打开仍然是旧设置

**解决**：必须点击"确定"按钮

---

### 错误2：没有重新编译

**现象**：修改代码后，直接执行命令

**结果**：AutoCAD 使用旧的 DLL，代码修改无效

**解决**：
1. Visual Studio 重新生成（Ctrl+Shift+B）
2. AutoCAD 执行 C2 命令

---

### 错误3：没有热重启

**现象**：编译后，直接执行 HYOV

**结果**：AutoCAD 仍然使用旧的 DLL

**解决**：编译后必须执行 C2 命令

---

### 错误4：使用了错误的命令

**现象**：使用了旧项目的命令（HyCADtool/Commands/...）

**结果**：执行的是旧代码，没有开关功能

**解决**：确保使用 `HyCADTool.Refactored` 项目的命令
