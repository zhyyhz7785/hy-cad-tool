### 1. API 不匹配修复

- 提供 `GetNormal()`, `Scale()`, `Negate()`, `Add()`, `RotateBy()`

**Line2D API**：
- `Start/End` → `StartPoint/EndPoint`

**Polygon2D API**：
- `Area` → `GetArea()`

### 2. 构造函数可访问性修复

所有值对象和实体使用静态工厂方法：
- `Elevation.FromMeters()` / `Elevation.FromMillimeters()`
- `WallThickness.Create()`
- `SlabThickness.Create()`
- `Wall3D.CreateNormalWall()` / `Wall3D.CreateRetainingWall()`
- `Slab3D.Create()`
- `GeometryData.Create()`

### 3. Nullable 类型处理

**Line2D 是 struct，不能为 null**：
```csharp
// 修复前
Line2D coincidentEdge = null;  // ❌

// 修复后
Line2D? coincidentEdge = null;  // ✅
```

**BoundaryCondition 构造函数**：
```csharp
private BoundaryCondition(
    Line2D edge,
    bool isSoilBoundary,
    Polygon2D adjacentPolygon,
    Elevation adjacentElevation,
    bool isWall,
    Line2D? coincidentEdge)  // ✅ 使用nullable
{
    CoincidentEdge = coincidentEdge ?? default(Line2D);
}
```

### 4. Using 指令补全

所有文件添加必要的 using：
```csharp
using HyCADTool.Refactored.Domain.ValueObjects;
using HyCADTool.Refactored.Domain.ValueObjects.Geometry;
```

## 🐛 调试指南

### 常见问题

**Q1: C14 命令无响应**
```
原因：DLL 未正确加载
解决：重新执行 C2 命令
```

**Q2: 提示"未选择任何基础多边形"**
```
原因：选择的不是闭合 Polyline
解决：确保 Polyline 已闭合（属性面板检查）
```

**Q3: 提示"未找到标高数据"**
```
原因：标高文本格式不对或未选中
解决：文本格式应为 -2.500 或 ±0.000
```

**Q4: 生成的墙体位置不对**
```
原因：可能是单位问题
解决：检查 ToleranceSettings 和 scale 参数
```

## 📊 技术亮点

### Clean Architecture 实践

```
Presentation (Commands)
    ↓ 依赖
Infrastructure (AutoCAD Adapters)
    ↓ 实现
Domain (100% Platform-Agnostic)
    - Services（算法逻辑）
    - Value Objects（数据封装）
    - Entities（3D实体）
```

### SOLID 原则

1. **单一职责**：每个服务专注一个功能
2. **开闭原则**：可扩展新连接类型、新缓冲区算法
3. **里氏替换**：可无缝切换平台实现
4. **接口隔离**：`IGeometry3DBuilder` 隔离平台差异
5. **依赖倒置**：Domain 层不依赖任何基础设施
