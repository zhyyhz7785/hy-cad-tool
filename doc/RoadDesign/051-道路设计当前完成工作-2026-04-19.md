## 1. P0 架构预埋 —— 全部落地

与 05计划书 §三「不可动的总原则」一一对照：

| 原则 | 实装证据 |
|---|---|
| Domain 零 AutoCAD 依赖 | `Domain/**` 全部命名空间纯 C# + `Polyline3D / Point2D/3D / Vector2D` 中性几何类；`using Autodesk.AutoCAD` 只出现在 `Infrastructure/**` 和 `Presentation/**` |
| 数据流单一事实源 = `.roaddesign.json` | `RoadJsonExportService.SaveForDocument` 被所有写命令作为事务外落盘入口；读命令走 `RoadDesignRegistry.TryGet(doc.Name, out var design)` |
| 身份绑定 = `HY_ROAD` Xdata GUID | `HyRoadXdata`（`KIND` + `ID`）+ `ImportFromPolyline`-style 孤儿兜底流程；目前 9 种 KIND：Alignment / Intersection / CornerArc / CurbRamp / TactilePaving / Crosswalk / StopLine / CrossSection / GeometryPointLabel |
| SAVEAS 兼容 | 所有写命令开头 `RoadAlignmentService.RebindForDocument(doc.Name, tr, db)`；已覆盖 20+ 命令 |
| 事件总线真实发布 | `IRoadEventBus` + `RoadEventBus` 真实实现；`RoadChangedEvents`（`AlignmentChanged / ProfileChanged / IntersectionChanged / CrossSectionChanged`）全链路发布订阅 |
| 命令命名两套并存 | `hyRoad*` 正名 + `N1~N50` 占位；`commands.json` 已覆盖 30+ 命令 |
| 图层兜底 | `PluginInitializer.GetRequiredLayers()` 启动时创建；命令使用前 `LayerTable.Has(...)` 兜底保留当前图层 |

**结论**：P0 已通过"关命令 / 开新 DWG / SAVEAS / NETLOAD 重载"四连测试验收，无已知违规。
