# 047 · 道路设计 · 四步联动实施说明（2026-04-25）

> 对应计划：**道路设计四步联动**（`Alignment` 桩号区段 `CrossSectionAssignment`、项目树顶栏、自动相交检测）。

## 1. 数据

- **值对象** `Domain/ValueObjects/Road/CrossSectionAssignment.cs`：`TemplateId`、`StartStation` / `EndStation`（米）、`Note`。
- **模型** `Alignment.CrossSectionAssignments`：JSON 使用 `ObjectCreationHandling.Replace`，旧图无此字段时反序列化为空列表。

## 2. 命令（ReCall + `commands.json`）

| 命令 | 作用 |
|------|------|
| `hyRoadAName` | 拾取多段线登记路线并输入名称。 |
| `hyRoadAlnAssign` | 拾取路线，选设计内模板，输入桩号区段，写入区段（防重叠）。 |
| `hyRoadAlnPlan` | 有区段则 `CorridorSweepService.SweepWithAssignments`，否则提示并可用首模板兜底。 |
| `hyRoadAutoIntersection` | 当前设计内 ≥2 条路线，两两求交 + 聚类，用户选序号后批量 `IntersectionDesigner` + 落图。 |
| `hyRoadPlan` | 保留入口，**转发**与 `hyRoadAlnPlan` 一致（脚本兼容）。 |

## 3. 领域服务

- **`CorridorSweepService.SweepWithAssignments`**：按桩号排序区段、校验、分段扫掠、硬切拼接；多模板条带数不一致时仅出中心线+左右红线（`UsedBandDividers=false`）。
- **`IntersectionDetector`**：线段求交、按半径聚类；在 **Autofac** 中注册为单例，`RoadAutoIntersectionCommand` 经 `ServiceLocator.Resolve` 使用。

## 4. UI

- **`RoadProjectTreePanel`**：首行 4 按钮（新建路线 / 配置横断面 / 生成平面图 / 检测相交），第二行搜索+刷新。
- **`RoadProjectTreeViewModel`**：`NewAlignment` / `AssignCrossSection` / `GeneratePlanFromTree` / `DetectIntersections` 经 `IRoadTreeInteractionHandler` 到 **`AutoCadRoadTreeInteractionHandler`** 发上述命令。
- **横断面树节点**：优先按 `CrossSectionAssignments` 展示；无区段时回退为全量可引用模板列表。

## 5. 测试

- `CrossSectionAssignmentTests`：区间与 JSON。
- `CorridorSweepServiceAssignmentTests`：单区段全路径扫掠出左右红线。
- `IntersectionDetectorTests`：交点、聚类、边界。
- `RoadProjectTreeViewModelToolbarCommandsTests`：`NullRoadTreeInteractionHandler` 下四按钮可执行无异常。

## 6. 明确未做（与计划一致）

- 区段间过渡不插值（硬切）；无自动配模板；非立交；无拖拽排序。
