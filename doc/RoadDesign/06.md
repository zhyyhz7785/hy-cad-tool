## 1. 全局参数（标题栏 + 设计参数区）

| 鸿业字段（截图） | HyCADTool 字段 | 类型 | 备注 |
|------------------|----------------|------|------|
| 标题 / 图名 | `CrossSectionDesignerViewModel.Title` → `CrossSectionLayout.Title` | string | 落到出图标题栏；空时取"标准横断面图" |
| 设计速度 | `CrossSectionDesignerViewModel.DesignSpeed` → `CrossSectionLayout.DesignSpeed` | int (km/h) | 取值列表 = `AlignmentCodeChecker.SupportedSpeeds`，驱动 `CrossSectionCodeChecker` 查表 |
| 比例尺 (1:N) | `CrossSectionDesignerViewModel.ScaleDenominator` → `CrossSectionLayout.ScaleDenominator` | int | 默认 100；UI 下拉值 `AvailableScales = {50, 100, 200}` |
| 中分带宽 | `CrossSectionDesignerViewModel.CenterMedianWidth` → `CrossSectionLayout.CenterMedianWidth` | double (m) | ≥ 0；为 0 表示不画中分带 |
| 镜像 / 对称 | `CrossSectionDesignerViewModel.IsMirror` (UI 开关) + `CrossSectionLayout.IsSymmetric` (派生) | bool | 开启时左右条带写回相互同步；派生只读字段以 0.01 m 容差判左右半幅是否对称 |
| 起始桩号 K0+xxx | `CrossSectionDesignerViewModel.StationStart` → `CrossSectionLayout.StationStart` | double (m) | 仅用于标题/图签，几何不参与 |
| 终止桩号 K1+xxx | `CrossSectionDesignerViewModel.StationEnd` → `CrossSectionLayout.StationEnd` | double (m) | 与 `StationStart` 配对；`StationLength = max(0, end - start)` |
| 中心线偏移 | `CrossSectionDesignerViewModel.CenterlinePosition` → `CrossSectionLayout.CenterlinePosition` | double (m) | NaN 表示自动取 `LeftHalfWidth + CenterMedianWidth/2` |
| 路面高程偏移 | `CrossSectionDesignerViewModel.ProfileElevationOffset` → `CrossSectionLayout.ProfileElevationOffset` | double (m) | v1 仅作为字段保留，绘图未启用 |
| 空装配 (Empty Assembly) | `CrossSectionDesignerViewModel.IsEmptyAssembly` → `CrossSectionLayout.IsEmptyAssembly` | bool | true 时仅显示中心线参考，不出几何 |
| 派生：左 / 右半幅 / 红线总宽 | `LeftHalfWidth` / `RightHalfWidth` / `TotalWidth` | double (只读) | 由 `Recalculate()` 自动刷新 |

## 2. 条带（Band）字段

> 截图中"中分带 / 绿化带 / 非机动车道 / 机动车道 / 人行道"五大条带 → `TemplateComponentKind` 枚举一一对应。

### 2.1 条带类型映射

| 鸿业条带名 | `TemplateComponentKind` 枚举值 | 默认横坡 | 路牙工厂 |
|-----------|-------------------------------|---------|---------|
| 机动车道 | `Pavement` (=1) | 1.5% | `Lane()` / `LaneWithCurb()`（与人行道相邻者带立缘 15×10×50） |
| 非机动车道 | `NonMotorized` (=7) | 1.5% | `NonMotor()` |
| 人行道 | `Sidewalk` (=2) | 1.5% | `Sidewalk()` |
| 绿化带（分车绿带 / 行道树带） | `GreenStrip` (=8) | 0% | `GreenStrip()` |
| 中央分隔带 | `MedianStrip` (=4) | 0% | `Median()`，侧别强制 `Center` |
| 路肩 | `Shoulder` (=5) | — | 暂未提供工厂；用完整构造函数 |
| 边坡 | `Slope` (=6) | — | 同上，v1.x 仅占位 |
| 单纯缘石（不依附板块） | `Kerb` (=3) | 0% | `Kerb()` |

> `BandRowViewModel.Kind` 下拉枚举 `AvailableKinds` 现仅暴露常用 7 项（去掉 `Slope` 与 `Unknown`）。

### 2.2 单条带字段

每一行条带（左半路幅 `LeftBands` / 右半路幅 `RightBands`，均**从中心向外**排列）的字段：

| 鸿业字段（截图） | `BandRowViewModel` 属性 | 类型 / 单位 | 校核 / 默认 |
|-----------------|------------------------|-----------|------------|
| 名称 | `Name` | string | 空白会被改成 "条带" |
| 类型 | `Kind` | `TemplateComponentKind` | 见 §2.1 |
| 宽度 | `Width` | double (m) | ≤ 0 自动改为 0.01；0 不允许 |
| 横坡 | `CrossSlopePct` | double (%) | clamp 到 [-20, 20]；正值表示"内高外低" |
| 侧别 | `Side` | `BandSide` (`Left = -1` / `Center = 0` / `Right = 1`) | 加入到 `LeftBands/RightBands` 时由 `CrossSectionLayout.Create` 静默修正 |

### 2.3 路牙（外侧 / 内侧分别配置）

> 鸿业把"路牙"分外侧与内侧两组，HyCADTool 同款。

外侧：

| 鸿业字段 | `BandRowViewModel` 属性 | 类型 / 单位 | 备注 |
|---------|------------------------|-----------|------|
| 外侧路牙类型 | `OuterKerbType` | `RoadKerbType` (`None=0` / `Curb=1` / `Plain=2` / `Combined=3`) | 切到非 None 且高度为 0 时自动套预设尺寸 |
| 型号 | `OuterKerbModel` | string | 例如 "15×10×50"，cm，宽×厚×长 |
| 高度 | `OuterKerbHeight` | double (m) | < 0 改为 0 |
| 宽度 | `OuterKerbWidth` | double (m) | < 0 改为 0 |
| 派生：是否生效 | `HasOuterKerb` | bool | type ≠ None 且 height > 1e-6 |

内侧字段一一对应：`InnerKerbType` / `InnerKerbModel` / `InnerKerbHeight` / `InnerKerbWidth` / `HasInnerKerb`。

`KerbSpec` 自带三个预设工厂：

| 工厂 | Type | Model | Height (m) | Width (m) | 用途 |
|------|------|-------|-----------|-----------|------|
| `KerbSpec.None` | `None` | `""` | 0 | 0 | 默认 |
| `KerbSpec.DefaultCurb()` | `Curb` | `"15×10×50"` | 0.18 | 0.15 | CJJ 37 §6.4 推荐立缘石 |
| `KerbSpec.DefaultPlain()` | `Plain` | `"10×10×30"` | 0.02 | 0.10 | 微凸平石（绿带 / 非机动车道边界） |
| `KerbSpec.DefaultCombined()` | `Combined` | `"15×10×50 + 10×10×30"` | 0.18 | 0.25 | 立缘背靠平石 |

### 2.4 坡型 / 路拱 / 路面铺装 / 车道数

| 鸿业字段 | `BandRowViewModel` 属性 | 枚举 | 说明 |
|---------|------------------------|------|------|
| 坡型 | `SlopeType` | `RoadSlopeType` (`Single=0` / `Double=1`) | 单坡（外低）/ 双坡（中央高） |
| 路拱形式 | `CrownProfile` | `RoadCrownProfile` (`Linear=0` / `Parabolic=1` / `Folded=2`) | 默认直线型；抛物线 / 折线供老旧道路 |
| 路面结构 | `SurfaceLayer` | `RoadSurfaceLayer` (`None=0` / `PavementSurface=1` / `SidewalkPaving=2` / `NonMotorPaving=3` / `GreenSoil=4`) | 决定填色与未来分层结构线 |
| 车道数 | `LaneCount` | int (≥ 0) | 仅 `Pavement` / `NonMotorized` 有意义；0 = 不划分车道线 |

## 3. 命令与命令选项映射

| 鸿业操作 | HyCADTool 命令 / 入口 |
|----------|---------------------|
| 新建标准断面 | `hyRoadCs`（见 `RoadCrossSectionDrawCommand.Execute()`，提供"新建 / 加载 / 命令行"三模式） |
| 加载预设 | VM `LoadPresetCommand` 绑定 `CrossSectionPresets.All`（v1：城市主干路 / 次干路 / 支路三种） |
| 添加左 / 右条带 | VM `AddLeftBandCommand` / `AddRightBandCommand`（默认 3.5 m 机动车道，1.5% 横坡） |
| 删除选中条带 | VM `RemoveBandCommand` |
| 上 / 下移 | VM `MoveUpCommand` / `MoveDownCommand` |
| 镜像 | VM `IsMirror = true` 后所有左右修改自动同步 |
| 应用 / 出图 | VM `ConfirmCommand`（`AllChecksPassed=false` 时走 `NonCompliantConfirm` 二次确认） |
| 取消 | VM `CancelCommand` |

## 4. 实现状态盘点（v1 → P2 之间）

### 4.1 已完成 (P0/P1 衍生 + P2 起步)

- ✅ Domain VO 全套：`CrossSectionLayout` / `CrossSectionBand` / `KerbSpec` / 4 个枚举。
- ✅ 5 类条带的简化工厂：`Lane / LaneWithCurb / NonMotor / Sidewalk / Kerb / GreenStrip / Median`。
- ✅ `CrossSectionPresets`：3 种 CJJ 37 预设（主 / 次 / 支）。
- ✅ `CrossSectionLayoutBuilder`：`Layout ↔ Template` 双向转换 + `ToFigure` 出图几何。
- ✅ `CrossSectionCodeChecker`：7 项规范（横坡范围 / 车道宽 / 中分带 / ...）。
- ✅ `CrossSectionDesignerViewModel` + `BandRowViewModel`：全字段绑定 + 镜像 + 重算管线。
- ✅ `hyRoadCs` 命令入口（"新建 / 加载 / 命令行"三模式）。
- ✅ DWG 落图：复用 `HyRoadLayers.CrossSection*` 9 个图层（轮廓 / 中心线 / 车行道 / 人行道 / 路牙 / 绿化带 / 尺寸链 / 文字 / 图题 / 方位）。

### 4.2 待实现（与鸿业的功能差距）

- ❌ 标准断面库扩展：当前仅 3 种预设；鸿业典型出货是 6+ 种（含一块板 / 两块板 / 三块板 / 四块板 / 单向通行 / 高架辅路），对应 `CrossSectionPresets` 还需新增工厂方法。
- ❌ 「按板块加铺装结构层」：`SurfaceLayer` 字段已有，但出图层只画填色，缺分层线（沥青面层 / 基层 / 底基层）。需要在 `CrossSectionLayoutBuilder.ToFigure` 增图元类型 + `HyRoadLayers` 增结构层图层。
- ❌ 「沿桩号变化的渐变断面」：`StationStart/End` 已有，但当前一张 `Layout` 只对应一张恒定断面，不支持沿桩号插值。属于 P5 走廊范畴。
- ❌ 与鸿业 `.htf` / `.scs` 互通（横断面定义 / 设计文件读写）：未启动。属于 P5 出图与交换主线。
- ❌ 「加载工程模板库 + 项目级断面索引」：HyCADTool 当前只在内存预设；缺 JSON 持久化的断面库（`<工程根>/templates/*.cs.json`）+ 浏览面板 (`hyRoadTplLib`)。
- ❌ 「右键属性编辑 + 拖放重排」：当前依赖按钮 + 数据网格，鸿业截图为属性面板式，UX 差距明显，留 P2 后段处理。

## 6. 红线（不可动）

> 任何对横断面字段或 UI 的修改，违反下面任何一条都要回退。

1. `CrossSectionLayout` / `CrossSectionBand` / `KerbSpec` 是不可变 readonly struct / sealed class，**只能新增 With* 重载**，不允许公开 setter。
2. 所有几何走 `CrossSectionLayoutBuilder.ToFigure` 单一入口，不允许 ViewModel 直接生成 `CrossSectionFigure`。
3. 横坡 / 道牙高 / 道牙宽的范围校核必须由构造函数和 `CrossSectionCodeChecker` 共同负责，不允许 UI 层默默改值（除了显式的 `Sanitize`）。
4. 镜像（`IsMirror`）的同步逻辑只在 ViewModel 层；Domain 不感知镜像状态。
5. 任何新增枚举值要同步：（a）`AvailableKinds` 等 UI 下拉、（b）测试用例、（c）`CrossSectionLayoutBuilder` 路由、（d）`HyRoadLayers` 图层（如有新颜色）。
