# 046 · 道路设计 · rCs v3 横断面增强（2026-04-22）

## 1. 本次增强目标

- 左侧大纲升级为可直接编辑：`宽度(m)`、`横坡(%)`、`高差(m)`。
- 大纲顶部新增统一 `＋添加`，按当前选中条带向下插入。
- 支持同侧拖拽重排条带顺序。
- 右侧结构层改为三级分组（面层/基层/垫层），并约束数量上限。
- 新增“从图形拾取”用于给当前条带回填宽度/坡度/厚度。
- 落图新增高差 `MLeader` 标注；比例默认值加入 `1:150`。

## 2. 数据与建模

- `CrossSectionBand` 新增 `ElevationDiff`，并贯穿 `With*`/工厂/比较逻辑。
- `TemplatePoint` 新增 `ExtendedData`，用于兼容性保存 `ElevationDiff`。
- `CrossSectionLayoutBuilder`：
  - `ToTemplate` 写入点扩展键 `ElevationDiff`；
  - `FromTemplate` 回读高差；
  - `ToFigure` 生成几何时将高差累计到下一条带起点。

## 3. 面板交互变更

- `CrossSectionDrawViewModel`
  - 新增 `InsertBandAfterSelectedCommand`；
  - 新增 `PickBandGeometryCommand` 与 `PickGeometryRequested` 事件。
- `BandRowViewModel`
  - 新增 `ElevationDiff`（范围 `[-2, 2]`）；
  - 新增 `SurfaceLayersView/BaseLayersView/SubbaseLayersView`；
  - 新增 `CanAddSurfaceLayer/CanAddBaseLayer/CanAddSubbaseLayer`。
- `CrossSectionDrawWindow`
  - 左大纲 DataTemplate 改为两行紧凑输入；
  - 删除中间竖向工具条；
  - 右侧结构层使用 `BlenderPropertyGroupLevel1/2/3`。

## 4. AutoCAD 侧

- 新增 `RoadCsPickGeometryInteractor`：选取 2D Polyline，反解宽度/坡度/总厚度。
- 扩展 `PolylineToBandExtractor.TryExtractWithThickness`。
- `RoadStandardSectionDrawService` 在完整模式下，根据 `ElevationDiff` 增加 `MLeader`。

## 5. 测试

- `BandRowInsertTests`：验证“当前选中向下插入”与无选中默认插入左侧。
- `ElevationDiffRoundtripTests`：验证高差字段在 Layout↔Template 往返不丢失。
