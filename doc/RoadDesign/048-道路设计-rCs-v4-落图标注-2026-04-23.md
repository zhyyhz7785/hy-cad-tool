# 048 · 道路设计 · rCs v4 落图标注（2026-04-23）

## 1. 本轮目标

把 `CrossSectionDrawWindow` 的“向 CAD 绘制结构线”升级为一键横断面出图：

- 顶面几何（outline）
- 中心线 + 方位箭头
- 尺寸链（改为 `AlignedDimension`）
- 文字标注（横坡/条带名/标题；**标高**与**条带高差**均用 `MLeader`）
- 条带高差引线（`MLeader`，与标高共享避让）

本轮只消费 `CrossSectionFigure` 已有数据，不新增红线端点注记等新语义。

## 2. 核心实现

### 2.1 新增绘图模式

`RoadStandardSectionDrawService` 的 `CrossSectionDrawMode` 新增：

- `TopSurfaceWithAnnotation = 2`

语义：仅顶面几何 + 全部标注；不绘制结构厚度闭合面板。

### 2.2 样式快照与工厂

新增：

- `Domain/ValueObjects/Road/CrossSectionAnnotationStyle.cs`
- `Presentation/Factories/RoadCsDrawStyleFactory.cs`

`RoadCsDrawStyleFactory` 在每次出图前：

1. 调用 `SettingsPanelViewModel.CommitStylesToActiveDocument()`，与按「**置为当前**」等效，把「界面-设置」中的文字/标注/多重引线样式写入当前 DWG；
2. 按 `TextStyleName` / `DimStyleName` / `MLeaderStyleName` 在图中解析 `ObjectId`，并取 `ActualTextHeight`、`ActualMLeaderLandingGap`、`ActualMLeaderArrowSize`、`Precision` 作为出图参数。

不另建 `hy-rcs-*` 独立样式，与全插件共用的 0-Hy-… 样式名一致。

### 2.3 尺寸链从手绘切到 AutoCAD 原生尺寸

`RoadStandardSectionDrawService` 删除原 `Line + DBText` 手绘尺寸逻辑，改为：

- `AlignedDimension`
- 自动挂 `CrossSectionAnnotationStyle.DimensionStyleId`
- 图层走 `CrossSectionDimensionLayer`

### 2.4 文字与引线样式接入

横坡、条带名、图题等仍用 `DBText` 并挂 `TextStyleId`；**标高（`FigureHeightLabels`）与条带高差**用 `MLeaderExtensions.CreateMLeaderSinglePoint`，并挂 `CrossSectionAnnotationStyle.MLeaderStyleId`。

### 2.4a 标高 / 引线文字避让

对 `MLeader` 文字区做粗估 AABB（按字长 × 字高），自剖面锚点向右上取初始落地，若与已放置盒（外扩 margin）相交则沿 **+Y** 阶梯抬高，直至不重叠；标高与条带高差引线**共用**同一放置列表，减少互压。

### 2.5 入口改造

`RoadCsDrawSingleLineInteractor.DrawAt` 改为：

- 模式：`TopSurfaceWithAnnotation`
- 接收并透传 `CrossSectionAnnotationStyle`

`CrossSectionDrawWindow.xaml.cs` 在每次 Draw 前调用 `RoadCsDrawStyleFactory.Build(...)` 并传入 interactor。

## 3. 与既有文档衔接

- 与 `042` 对齐：保留 `SingleLine` 原语义（平面图单线投影），新增模式用于本次按钮行为升级。
- 与 `046` 对齐：高差 `MLeader` 保留并纳入同一次绘制链路。

## 4. 本轮不做

- 道路左/右红线端点注记
- 图签、日期、比例尺等标题块
- 车/树等装饰符号
