## 一、一句话定义

**HyCADTool** 是一个跑在 **AutoCAD 2025 进程内**的 .NET 插件套件，以 **Blender 风格 WPF 侧栏面板 + 命令面板 + Ribbon + 菜单栏** 四入口提供 **钢筋 / 桩基 / 底板 / 设备基础 / 道路设计（线位 / 横断面 / 纵断面 / 交叉口 / 标线 / 导出）/ 沉降计算 / 设计说明 Markdown / 标高 / 图框 / 多段线 / 块引线 / DCEL / OverKill** 等约 **130+ 条** 工程命令，定位于市政与建筑工程方向的国产 CAD 二次开发工具。

> 详细命令清单见 `src/ReCall/commands.json`，分组与短别名见 `Shell/Commands/CommandCatalog` 与 `Features/Road/Shared/RoadCommandShortAliases.cs`。

## 二、解决方案布局（11 个工程）

```
HyCADtoolGpt.sln
├── src/ReCall/                      ← 热重载常驻适配器（永不修改的"锚点"DLL）
├── src/HyCADTool/                   ← 主工程：业务命令 + 面板 + 启动 + 配置
├── src/HyCAD.BlenderUI/             ← Blender 风格 WPF 控件库（31 个主题字典）
├── src/HyCAD.BlenderUI.TestHost/    ← BlenderUI 控件独立测试宿主
├── src/HyCAD.BlenderUI.PaletteSetDemo/ ← PaletteSet 寄宿样例
├── src/HyCADTool.MarkdownEditor/    ← WebView2 + Markdig 设计说明编辑器（net8）
├── src/HyCADTool.MarkdownEditor.TestHost/  ← 编辑器独立测试宿主（x64）
├── src/HyCADTool.TextLayout/        ← Markdown→MText 文字排版（netstandard2.0）
├── src/HyCADTool.Tests/             ← 单元测试（Domain / ViewModel）
├── src/HyCADTool.Licensing/         ← RSA 公钥验证库（嵌入插件）
└── src/HyCADTool.LicenseSigner/     ← 离线签发 exe（WPF，私钥永不进仓）
```

| 工程 | TFM | 平台 | 角色 |
|------|-----|------|------|
| **ReCall** | net48 | x64 | 唯一被 AutoCAD `NETLOAD` 的 DLL；用 `Assembly.Load(byte[])` 反射加载 HyCADTool，实现"改业务代码不关 CAD" |
| **HyCADTool**（主工程） | net48 | AnyCPU + Prefer32Bit=false | 全部业务实现、面板、Ribbon/CUIX、配置、命令；NuGet：AutoCAD.NET 24.3 / Autofac / Clipper2 / NetTopologySuite / Markdig / OpenXml / QRCoder |
| **HyCAD.BlenderUI** | net48 | AnyCPU | NumericSlider / PropertyRow / IconTabBar / Outliner / BlenderWindow 等控件 + 5 套主题色 |
| **HyCADTool.MarkdownEditor** | net8.0-windows | x64 | 双 WebView2 编辑+预览，输出到主工程 `bin/Debug/net8/` |
| **HyCADTool.TextLayout** | netstandard2.0 | AnyCPU | Markdown→MText 排版核心，主工程与编辑器共用 |
| **HyCADTool.Tests** | net48 | AnyCPU | NUnit 单元测试（Domain / ViewModels / Services） |
| **HyCADTool.Licensing** | net48 | AnyCPU | RSA-XML 公钥验证 + 机器码 + 试用窗 |
| **HyCADTool.LicenseSigner** | net48 | AnyCPU | 内部 WPF 工具：离线录入机器码 / 档位 / 期限，签发 `license.lic` |

> AnyCPU + `Prefer32Bit=false` 是必须的：64 位 AutoCAD 进程加载该 DLL；32 位 VS XAML 设计器（XDesProc）加载该 DLL。任意一边写死 `x64` 都会触发 `XDG0023/XDG0003 BadImageFormatException`（详见 `hycad-project-pitfalls` skill C2 节）。

**分层准则**（详见各层 README 和 `00-AI 工作规则`）：

- **Domain**：纯算法 / 实体 / 值对象 / 枚举，**不引用** AutoCAD API。
- **Infrastructure**：AutoCAD 绘图 / 转换 / Service，依赖 Domain。
- **Presentation**：命令类 + Panel/ViewModel，编排 Domain + Infrastructure。
- 进入 `Shared/` 必须满足三条：≥3 Feature 引用 + 接口稳定 + 平台无关或 AutoCAD/WPF 通用基础设施。

## 四、双启动路径（Dev vs Production）

### 路径 A：开发模式（默认 Debug/Release）—— ReCall 热重载

```
开 AutoCAD 一次：NETLOAD ReCall.dll
        ↓
首次：在命令行输 C2 → ReCall 把 HyCADTool.dll 复制到 %TEMP%/ReCall_xxx → Assembly.Load(byte[])
        → 反射调 HyCADTool.App.Bootstrap.PluginInitializer.Initialize()
        → 注册 Autofac / 加载 config / 初始化样式图层 / 构建 Ribbon + CUIX / 注册 Operator
        → 命令表读 commands.json，141 条业务命令立即可用（80+ 真名 + 50 占位 N1~N50）
        ↓
日常：改 HyCADTool 业务代码 → VS 编译 → 命令行 C2 → 新代码生效（不关 CAD）
```

**核心机制**（见 `ReCall/Doc/Recall-说明.md`）：

| 命令 | 作用 |
|------|------|
| `C2` | 热加载 HyCADTool.dll，反射执行 `PluginInitializer.Initialize`，刷新命令表 |
| `C1` | 运行 `HyCADTool.App.Test.TestCommand.Run()`（开发联调一键入口） |
| `hyRecallSelfCheck` | 打印 ReCall / Refactored / 命令表 / 临时副本 / 关联程序集诊断快照 |
| `N1`~`N50` | 占位符。新命令测试期改 `commands.json` 映射即可，**无需关 CAD** |

**为什么需要 ReCall**：.NET CLR 加载的程序集**不能卸载**，AutoCAD 一旦 NETLOAD HyCADTool.dll 即锁文件。ReCall 这层"匿名 byte[] 加载"绕开锁定，把"改一行代码"的反馈循环从"关 CAD → 重启 → NETLOAD"压到"C2"一条命令。

### 路径 B：生产模式（`HYCAD_PRODUCTION` 编译常量）

```
dotnet build src\HyCADTool\HyCADTool.csproj -c Production
        ↓
生成的 HyCADTool.dll 直接含 [assembly: ExtensionApplication] + [assembly: CommandClass]
        ↓
客户机器：NETLOAD HyCADTool.dll → AutoCAD 自动调 ProductionExtension.Initialize
        → 同一份 PluginInitializer.Initialize → 命令立即可用
```

**关键事实**：

- 生产模式 **不需要 ReCall.dll**（2026-04-25 解耦完成）。
- 客户安装包仅含 `HyCADTool.dll + 它的 NuGet/项目依赖 + commands.json`。
- 生产 / 开发 共用 **同一份** `PluginInitializer`，业务初始化路径 100% 一致。
- 生产命令门面 `App/Production/ProductionCommandFacade.cs` 与 `ReCall/CommandFacade.cs` 必须保持 `[CommandMethod]` 同步（见两边文件头注释）。

## 五、命令注册：`commands.json` 单一事实源

```jsonc
// src/ReCall/commands.json（v2 schema）
{
  "version": 2,
  "commands": {
    "gj":  { "type": "HyCADTool.Features.Reinforcement.DrawReinforcementCommand",
             "method": "Execute",
             "category": "钢筋",
             "displayName": "绘制钢筋",
             "tooltip": "绘制双线钢筋（gj）",
             "order": 10 },
    "N1":  { "type": "HyCADTool.Features.Road.PlanAlignment.Commands.RoadAlignmentByPiCommand",
             "method": "Execute",
             "_alias": "hyRoadAlnByPi 占位" }
  }
}
```

**字段语义**：

| 字段 | 用途 |
|------|------|
| `type` | Command 类完全限定名（反射 Activator.CreateInstance） |
| `method` | 调用方法名，默认 `Execute` |
| `ctor` / `ctorEnumTypes` | 可选构造参数（含枚举） |
| `category` | 分组键，**Blender 命令面板 / Ribbon 选项卡 / CUIX 菜单**三入口共用 |
| `roadPanelGroup` | `category=道路` 时附加（工程/路线/纵断/道路/工具）控制 Hy 面板道路 Tab 折叠区 |
| `displayName` / `tooltip` / `order` | UI 元数据 |

**改 JSON 后**：ReCall 按 `mtime` 自动重载，下次该命令被输入时立即生效；**无需关 CAD，无需 C2**。

新命令完整流程见 `.cursor/skills/hycad-new-command-registration/SKILL.md`。

## 九、关键陷阱地图（请按图索骥，避免重蹈覆辙）

> 完整且权威的陷阱清单见 `.cursor/skills/hycad-project-pitfalls/SKILL.md`，本节只列总体地图。

### 9.1 WPF + PaletteSet 宿主

| 症状 | 真根因 | 修复位置 |
|------|--------|---------|
| `Badge` `XamlParseException`，`pack URI /AdWindows;component/themes/badge.xaml` 找不到资源 | ReCall AssemblyResolve 把项目传递引用的旧 AdWindows 5.0.1.2 byte[] 加载，与 AutoCAD 进程 5.1.1.1 双载入 → 类型身份割裂 | `ReCall/Recall.cs::ResolveAssembly` 宿主程序集黑名单 |
| 0xE0434352 原生致命弹窗 / "调度程序处理已暂停" | 隐式 Style 触发 / 主题字典挂到 `Application.Current.Resources` 污染 AutoCAD 控件 | 见 `.cursor/rules/05-AdWindows-WPF-PaletteSet宿主.mdc` 强制清单 |
| StaticResource 跨字典找不到 / DynamicResource 类型错配 | 主题资源必须**只在 UserControl.Resources 局部 merge**，绝不冒泡 | `wpf-paletteset-resource-pitfalls` skill |
| ResourceDictionary Sealed 后切换主题崩 | SolidColorBrush 被强冻 → 改 v3 ColorsHost host-replace 模型 | `BlenderUI/Theming/BlenderThemeManager.cs` |
| XDG0023/XDG0003 设计器加载失败 | csproj `<PlatformTarget>x64</PlatformTarget>` 让 32 位 XDesProc 无法加载 | 改 AnyCPU + `Prefer32Bit=false` |

### 9.2 AutoCAD API

- 多文档场景下不要缓存 `Database` / `MdiActiveDocument`，每次重新取。
- `Table` 创建前必须显式 `SetSize(rows, cols)` 再写 cell，否则 Title 会自动合并第一行。
- 锁定层写入必须用 `Shared/AutoCAD/Services/Road/LayerLockScope.cs` 临时解锁，`finally` 吞异常恢复。
- 道路图层注册清单分裂：`HyRoadLayers` 常量 ↔ `PluginInitializer.GetRequiredLayers()` 必须同步，否则 `Entity.Layer = "..."` 静默回落 0 层。

### 9.3 构建系统

- HyCADTool ↔ ReCall 已通过 `Reference HintPath` **断开 ProjectReference 链**（2026-04-25），AutoCAD 锁着 `ReCall.dll` 时不会拖累主工程构建。
- `<CopyLocalLockFileAssemblies>true</CopyLocalLockFileAssemblies>` 不可去：ReCall 复制到 %TEMP% 时需要平铺所有依赖。
- 生产模式 `HYCAD_PRODUCTION` 编译常量激活 `App/Production/ProductionEntry.cs`，**不要**在 Debug/Release 路径加 `[ExtensionApplication]`，否则触发"双初始化"。

### 9.4 调试方法论

- 调试类与调用点同步删除（一个 PR 内）。
- session ID / 临时埋点不能进生产代码。
- `Dispatcher.UnhandledException` handler 必须 try/catch：shutdown 流程 NRE 会升级原生致命。
- `PresentationTraceSources` Binding 错误同步阻塞 UI 线程：必须经 Debug.WriteLine 而非 `WriteMessage` 输出（见 `PluginInitializer.BindingErrorListener`）。

## 十、文档体系总览

### 10.1 顶层 `doc/` vs `docs/`

- **`doc/`**：**新文档的默认落点**（本文件所在目录）。命名 `序号-标题-YYYY-MM-DD-HHMMSS.md`。当前最早就是本文件。
- **`docs/`**：历史文档（160+ 篇），按子主题分目录：
  - `docs/road-design/` — 道路设计专题（市场调研、AI 索引、设计逻辑等）

## 十二、给 AI 代理的最短启动协议

新对话第一次接到本仓库任务时，**按这个顺序执行**：

1. **读 `01-AI热启动模式`**（已自动加载）→ 知道 C2/C1 是什么、`TestCommand.cs` 是测试入口。
2. **读 `00-AI 工作规则`**（已自动加载）→ 知道输出极简、文档命名、重构原则。
3. **如果用户说"Badge 错误 / 主题崩 / PaletteSet 报 0xE0434352"** → 立即读 `.cursor/rules/05-AdWindows-WPF-PaletteSet宿主.mdc` 与 `hycad-project-pitfalls` skill **B10/B11**。
4. **如果用户说"加新命令"** → 读 `hycad-new-command-registration` skill。
5. **如果用户说"道路 / 平面线位 / 横断面"** → 读 `docs/road-design/041-道路设计-AI上下文索引.md`。
6. **如果用户说"重构 / 命令迁移"** → 读 `hycad-refactored-migration-patterns` skill。
7. **任何子模块任务**：先看该子目录的 `README.md`（`Features/<X>/README.md`、`App/README.md`、`Shell/README.md`、`Shared/README.md`），再读对应代码。

**永远不要做**的事：

- 在 `Features/*` 加 `[CommandMethod]`（只能在 `ReCall/CommandFacade.cs` 或 `App/Production/ProductionCommandFacade.cs`）。
- 把主题字典 merge 到 `Application.Current.Resources`。
- 在 `PluginInitializer` 加 `Application.ResourceAssembly = ...` / `Assembly.Load("AdWindows")` / `WarmupAdWindowsBadgeTheme()`（这些都是历史已证伪的反向操作）。
- 在 `Refactored.Domain` 引用 `Autodesk.AutoCAD.*` 类型。
- 用反射桥接调用旧 HyCADtool 项目（必须真正移植）。
- 引用新增 NuGet 包时不加 `<ExcludeAssets>runtime</ExcludeAssets>` 检查（防 AutoCAD 宿主 dll 重复复制）。
