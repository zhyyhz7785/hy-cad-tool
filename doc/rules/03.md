# 03-开发工作流程

> **用途**：热重启+测试标准化流程，开发规范  
> **重要性**：⭐⭐⭐⭐ 高优先级  
> **更新日期**：2024-10-14

---

## 🚀 标准开发流程

```
1. 修改代码
   ↓
2. Visual Studio 编译 (Ctrl+Shift+B)
   ↓
3. AutoCAD 执行 C2 命令（热重启）
   ↓
4. AutoCAD 执行 C1 命令（测试）
   ↓
5. 检查输出和耗时
   ↓
6. 重复 1-5 直到测试通过
   ↓
7. 提交代码
```

### 核心命令

| 命令   | 功能     | 说明                                |
| ------ | -------- | ----------------------------------- |
| **C2** | 热重启   | 重新加载 `HyCADTool.Refactored.dll` |
| **C1** | 运行测试 | 执行 `TestRunner.RunAllTests()`     |

## 📝 代码开发规则

### ✅ 必须遵循

1. **极简输出原则**
   - 只输出关键信息：错误、警告、最终结果
   - 格式：`处理完成：12 → 35 曲线`

2. **性能优先原则**
   - 避免循环内输出
   - 异常处理使用空 `catch`

3. **用户体验原则**
   - 命令快速响应
   - 避免屏幕刷屏

### ❌ 禁止使用

```csharp
// ❌ 循环内详细输出
foreach (var item in items)
{
    ed.WriteMessage($"\n处理 {item.Name}...");  // ❌
}

// ❌ 详细调试信息
ed.WriteMessage($"\n尝试分割 {curve.GetType().Name}");  // ❌

// ❌ 异常信息输出（性能关键代码）
catch (Exception ex)
{
    ed.WriteMessage($"\n异常: {ex.Message}");  // ❌
}
```

### ✅ 推荐使用

```csharp
// ✅ 简洁摘要输出
ed.WriteMessage($"\n处理完成：{inputCount} → {outputCount} 对象");

// ✅ 静默处理异常
catch { return null; }
```

## 🧪 测试规则

### TestRunner 标准结构

```csharp
public void RunAllTests()
{
    LogElapsedTime("测试执行", () =>
    {
        try
        {
            // 只测试当前开发的命令
            var cmd = new CurrentCommand();
            cmd.Execute();
            _editor.WriteMessage("\n测试完成。");
        }
        catch (System.Exception ex)
        {
            _editor.WriteMessage($"\n错误：{ex.Message}");
        }
    });
}
```

### 测试管理规则

1. **一次只测试一个命令**
2. **已通过的测试要注释掉**
3. **新功能测试添加到末尾**

## 📊 性能基准

### 执行时间目标

| 数据规模           | 目标时间 | 可接受时间 | 需要优化 |
| ------------------ | -------- | ---------- | -------- |
| 小规模（< 50）     | < 100ms  | < 500ms    | > 1s     |
| 中规模（50-200）   | < 500ms  | < 2s       | > 5s     |
| 大规模（200-1000） | < 2s     | < 10s      | > 30s    |

### 输出行数建议

| 命令类型   | 建议输出行数 |
| ---------- | ------------ |
| 常用命令   | **1-3 行**   |
| 批处理命令 | 2-5 行       |

## 🔧 故障排查

### 常见问题

**C2 后仍有大量输出** → Visual Studio 重新生成 → C2 热重启

**C1 命令无响应** → 检查 TestRunner.cs 代码错误

**热重启后配置丢失** → 检查 AutofacModule.cs 和 ServiceLocator
