# 06-C# 与 AutoCAD 编码约定

> **用途**：引用 AutoCAD 的 C# 代码中避免命名空间歧义与常见错误  
> **重要性**：⭐⭐⭐ 引用 ReCall、Infrastructure、Presentation 时适用  
> **更新日期**：2026-02-08

---

## 一、Exception 歧义（必须遵守）

在引用 **Autodesk.AutoCAD** 的程序集中，`Autodesk.AutoCAD.Runtime` 定义了 `Exception`，与 `System.Exception` 冲突，会导致 **CS0104 不明确引用**。

### ✅ 正确写法

```csharp
catch (System.Exception ex)
{
    ed.WriteMessage("\n✗ 失败: " + ex.Message);
}
```

### ❌ 错误写法

```csharp
catch (Exception ex)   // CS0104：Exception 歧义
```

### 适用范围

- 所有 `catch` 块中捕获异常时，**显式使用 `System.Exception`**
- 方法签名、字段类型若为异常类型，也写 `System.Exception`
- 涉及项目：**ReCall**、**HyCADTool.Refactored**（尤其是 Infrastructure / Presentation）

---

## 二、其他可能歧义（遇到时按同样方式处理）

若出现类似 CS0104（两个命名空间下同名类型），一律用**完整类型名**消除歧义，例如：

- `System.Exception`（不用裸写 `Exception`）
- 若将来有 `System.SomeType` 与 `Autodesk.AutoCAD.XXX.SomeType` 冲突，写全名或加 `using Alias = System.SomeType;`

---

## 三、小结

| 场景           | 写法               |
|----------------|--------------------|
| 捕获一般异常   | `catch (System.Exception ex)` |
| 抛出异常       | `throw new System.Exception(...)` 或具体派生类全名 |
| 类型注解/字段  | 使用 `System.Exception` 或具体类型的完整名称     |

**规则**：在引用 AutoCAD API 的 C# 文件中，涉及 `Exception` 时一律使用 **`System.Exception`**，不写裸写 `Exception`。
