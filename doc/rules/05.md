## 一、优先级评估体系

### 1.1 评估维度

| 维度           | 权重 | 说明                   |
| -------------- | ---- | ---------------------- |
| **使用频率**   | 40%  | 基于实际用户使用统计   |
| **功能重要性** | 30%  | 核心业务流程的重要程度 |
| **技术依赖**   | 20%  | 被其他命令依赖的程度   |
| **迁移难度**   | 10%  | 实现复杂度，风险评估   |

### 1.2 评分标准

**使用频率**（基于 04-命令详细清单 的频率标记）：

- 5分：⭐⭐⭐⭐⭐ 每日必用
- 4分：⭐⭐⭐⭐ 经常使用
- 3分：⭐⭐⭐ 偶尔使用
- 2分：⭐⭐ 很少使用
- 1分：⭐ 几乎不用

**功能重要性**：

- 5分：核心业务功能（钢筋、配筋、标注）
- 4分：重要辅助功能（地脚螺栓、标高）
- 3分：一般功能（轴线、桩基）
- 2分：边缘功能（导出、统计）
- 1分：实验功能（测试命令）

**技术依赖**：

- 5分：被10+命令依赖（ZTools、BaseRein）
- 4分：被5-9命令依赖（Reinforcement）
- 3分：被2-4命令依赖（GeometryUtils）
- 2分：被1命令依赖
- 1分：独立命令

**迁移难度**：

- 1分：非常复杂（DCEL、Voronoi算法）
- 2分：比较复杂（基础配筋全流程）
- 3分：中等复杂（钢筋绘制）
- 4分：相对简单（标注、文本）
- 5分：非常简单（基础几何操作）

## 七、风险评估（基于实际命令分析）

### 7.1 高风险命令

| 命令                                             | 风险类型 | 风险描述                     | 缓解措施                     |
| ------------------------------------------------ | -------- | ---------------------------- | ---------------------------- |
| **hyb5a**                                        | 技术风险 | 基础配筋全流程，算法极其复杂 | 分步实现，充分测试，专门团队 |
| **gj**                                           | 业务风险 | 钢筋绘制核心，用户依赖度最高 | 保持向后兼容，渐进式迁移     |
| **hyz_PlacePileAndVoronoiWithLloydOptimization** | 算法风险 | Voronoi+Lloyd算法复杂度极高  | 算法专家参与，分阶段实现     |
| **hy3_Generate**                                 | 平台风险 | 三维生成涉及大量平台特定API  | 抽象三维接口，适配层设计     |

### 7.2 依赖风险分析

**核心依赖库风险**：

- **Clipper2**：多边形运算核心，需要确保跨平台兼容
- **NetTopologySuite**：几何计算基础，Blender 平台适配复杂
- **Newtonsoft.Json**：数据存储，需要统一序列化方案

**内部依赖风险**：

- **ZTools**：60+ 命令依赖，重构影响面极大
- **BaseRein**：7个配筋命令的核心，算法迁移风险高
- **Reinforcement**：12个钢筋命令依赖，参数管理复杂

**解决方案**：

- 建立依赖映射表，明确迁移顺序
- 创建适配层，隔离平台差异
- 分阶段验证，确保每个阶段稳定
