## 🏗️ 架构设计

### Clean Architecture 分层

```
┌─────────────────────────────────────────────────────────────┐
│                    Presentation Layer                        │
│                  (UI, Commands, Controllers)                 │
└────────────────────────────┬────────────────────────────────┘
                             │ 依赖
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                   Application Layer                          │
│              (Use Cases, Application Services)               │
└────────────────────────────┬────────────────────────────────┘
                             │ 依赖
                             ▼
┌─────────────────────────────────────────────────────────────┐
│                      Domain Layer                            │
│         (Entities, Value Objects, Domain Services)           │
│         ✅ 100% 平台无关，可迁移到 Blender                    │
└─────────────────────────────────────────────────────────────┘
                             ▲ 实现
                             │
┌─────────────────────────────────────────────────────────────┐
│                  Infrastructure Layer                        │
│              (AutoCAD Services, Data Access)                 │
└─────────────────────────────────────────────────────────────┘
```

### 目录结构

```
HyCADTool.Refactored/
├── Domain/                           # 领域层（平台无关）
│   ├── Entities/                     # 实体
│   ├── ValueObjects/                 # 值对象
│   ├── Services/                     # 领域服务
│   └── DataStructures/               # 数据结构
├── Infrastructure/                   # 基础设施层
│   ├── AutoCAD/                      # AutoCAD 适配器
│   └── Configuration/                # 配置管理
├── Presentation/                     # 表示层
│   └── Commands/                     # AutoCAD 命令
└── Test/                            # 测试
    └── TestRunner.cs                # 测试运行器
```

## 🚀 开发工作流程

### 标准流程

```
1. 修改代码
   ↓
2. Visual Studio 编译 (Ctrl+Shift+B)
   ↓
3. AutoCAD 执行 C2 命令（热重启）
   ↓
4. AutoCAD 执行 C1 命令（测试）
   ↓
5. 检查输出和耗时
   ↓
6. 重复 1-5 直到测试通过
   ↓
7. 提交代码
```

### 核心命令

| 命令   | 功能     | 说明                                |
| ------ | -------- | ----------------------------------- |
| **C2** | 热重启   | 重新加载 `HyCADTool.Refactored.dll` |
| **C1** | 运行测试 | 执行 `TestRunner.RunAllTests()`     |

## 🔧 故障排查

### 常见问题

**问题 1：C2 后仍看到大量调试输出**

- **原因**：使用了旧版本的 DLL
- **解决**：Visual Studio 重新生成 → C2 热重启

**问题 2：C1 命令无响应**

- **原因**：TestRunner 中的测试代码有错误
- **解决**：检查 TestRunner.cs，使用 try-catch 包装

**问题 3：热重启后配置丢失**

- **原因**：Autofac 容器未正确初始化
- **解决**：检查 AutofacModule.cs 和 ServiceLocator
