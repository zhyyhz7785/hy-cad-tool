## 一、三条主线

| 谁 | 做什么 | 结果 |
|---|---|---|
| **客户** | Setup 安装 → `hyLicense` 取机器码 → 激活 | 对应档位命令可用 |
| **你（发版）** | `Publish-Setup.ps1` | `HyCAD-Setup-x.y.z.exe` 发给客户 |
| **你（签发）** | `PackLicenseSigner.ps1` → Signer | HYC1 文本或 `license.lic` 发给客户 |

---

## 二、运行模式

| 角色 | 用什么 | 许可门闸 |
|---|---|---|
| 日常开发 | ReCall + C2 热重载（Debug） | **不生效**（故意放行） |
| 客户 / 真实自测 | Production（Setup 安装） | **生效**（每条命令经 `LicenseGate`） |

未激活时：`hy` / `HyB` / `hyLicense` / `HYJC` / `hySC` 等免费命令可用；`gj` 等缺省 tier 按 **Standard** 拦截；`hyRoad*` 等 **Professional** 命令拦截并提示激活。档位来自 `commands.json` 的 `"tier"` 字段，bundle 自动携带。

**验许可拦截必须用 Setup/Production，不能用 C2 开发包。**

## 三、路径对照（别搞混）

| 是什么 | 路径 | 谁用 |
|---|---|---|
| 客户已装插件 | `%APPDATA%\Autodesk\ApplicationPlugins\HyCAD.bundle` | AutoCAD 启动加载 |
| 发版构建产物 | `build\artifacts\HyCAD.bundle` | 开发者打包 / 自测 |
| 客户安装包 | `build\artifacts\HyCAD-Setup-x.y.z.exe` | 发给客户双击安装 |
| 签发工具目录 | `build\artifacts\LicenseSigner\` | 开发者离线签发 |
| 授权文件 | `%ProgramData%\HyCAD\license.lic` | 激活后自动写入 |
| 防回拨状态 | `%ProgramData%\HyCAD\state.bin` | 异常时可删后重启 |

**快速打开插件目录**：`Win+R` → `%APPDATA%\Autodesk\ApplicationPlugins`

支持 **Windows 64 位完整版 AutoCAD**（`PackageContents.xml` 不限 SeriesMin/Max；不含 LT / Mac）。

## 四、HyCAD.bundle 结构

```
HyCAD.bundle/
├── PackageContents.xml       ← LoadOnAutoCADStartup=True，无需 NETLOAD
├── unins000.exe              ← Setup 安装后才有
└── Contents/Win64/
    ├── HyCADTool.dll
    ├── HyCADTool.Licensing.dll
    ├── commands.json           ← 命令 + tier
    ├── HyCAD.BlenderUI.dll
    ├── config.json
    ├── Resources/
    └── _libraries/
```

**加载机制**：AutoCAD 扫描 ApplicationPlugins 下 `*.bundle`，读 `PackageContents.xml`，加载 `HyCADTool.dll`。

**切勿放入 bundle**：`ReCall.dll`、`LicenseSigner.exe`、`PrivateKey.xml`、`license.lic`。

## 五、客户安装

### 5.1 推荐：Setup.exe

1. 双击 **`HyCAD-Setup-x.y.z.exe`**（无需管理员）
2. **完全退出并重启 AutoCAD**
3. 输入 **`hyLicense`** → 复制 **8 段 × 4 位** 机器码发给你
4. 激活二选一：
   - 粘贴 **`HYC1.` 开头授权码** → 确定激活
   - **从文件导入** `license.lic`

### 5.2 备选：ZIP 手动安装

解压 `HyCAD-vX-bundle.zip`，将 **`HyCAD.bundle` 整文件夹**（含 `PackageContents.xml`）复制到 `%APPDATA%\Autodesk\ApplicationPlugins\`，重启 AutoCAD。

**不要**只复制 `Contents\Win64` 里的 dll。

### 5.3 卸载

| 方式 | 操作 |
|---|---|
| 推荐 | 再运行 Setup → 启动时选「是」纯净卸载（随后询问是否清除授权文件） |
| 开始菜单 | 「卸载 HyCAD 插件」（可勾选清除 `license.lic` / `state.bin`） |
| 其它 | bundle 内 `unins000.exe` / 手动删文件夹 |

默认卸载**只删插件**，不删 `%ProgramData%\HyCAD\` 授权文件；勾选「同时清除授权文件」后删除 `license.lic` 与 `state.bin`。

## 六、许可体系

### 6.1 架构

```
用户机器 (AutoCAD)                    开发者机器
┌─────────────────────────┐          ┌──────────────────────────┐
│ hyLicense 激活窗         │ 机器码→  │ build/artifacts/         │
│  - 8 段机器码 + 二维码   │ ←HYC1   │   LicenseSigner/         │
│  - 粘贴 HYC1 / 导入 .lic │  或.lic │   HyCADTool.LicenseSigner│
├─────────────────────────┤          │   + PrivateKey.xml       │
│ %ProgramData%\HyCAD\     │          └──────────────────────────┘
│   license.lic (JSON)      │
│   state.bin (防回拨)      │
├─────────────────────────┤
│ LicenseGate (生产门闸)    │ ← tier 来自 commands.json
└─────────────────────────┘
```

- **密码学**：RSA-2048 + SHA256；公钥内嵌 `EmbeddedPublicKey.cs`；私钥仅 `build/keys/rsa-priv.xml`（gitignore）
- **机器码**：CPU + 主板 + 系统盘卷序列 → SHA256 → Base32 → 8 组 `XXXX-XXXX`
- **HYC1**：`HYC1.` + Base64Url(GZip(JSON))，便于微信粘贴；落盘为 `license.lic` 明文 JSON
- **防回拨**：`state.bin` AES 加密；回拨 >24h 锁定；损坏亦锁定，可删 `state.bin` 后重启恢复

### 6.2 HYC1 与 license.lic

内容同为带签名的 JSON；HYC1 是压缩文本便于粘贴，激活后写入 `%ProgramData%\HyCAD\license.lic`。

### 6.3 冻结契约（变更会使已发授权作废）

- `MachineId` 算法与盐值 `HYCAD-V1-SALT`
- `LicenseCanonicalizer` 规范化规则
- license JSON 架构（v=1）与签名算法
- `HYC1.` 格式（`LicenseCodeCodec`）
- 公钥 `build/keys/rsa-pub.xml` ↔ `EmbeddedPublicKey.RsaKeyXml`

**轮换密钥**：`build\scripts\_gen-rsa-keys.ps1` → 更新 `EmbeddedPublicKey.cs` → 重编 HyCADTool + Signer。

**业务迭代唯一触点**：`commands.json` 为新命令加 `"tier"`，同步 Debug 与 Production bundle。

## 七、开发者发版

### 7.1 一键发版（仓库根目录）

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\Publish-Setup.ps1 -Version 1.0.0
```

等价于：`PackBundle.ps1`（Production 编译 + bundle）→ Inno Setup（**UTF-8 iss 自动转 GBK 再编译，防中文乱码**）→ `HyCAD-Setup-1.0.0.exe`。

**前提**：[Inno Setup 6](https://jrsoftware.org/isinfo.php)。

| 产出 | 用途 |
|---|---|
| `build\artifacts\HyCAD-Setup-1.0.0.exe` | **发给客户** |
| `build\artifacts\HyCAD.bundle` | 本地自测 / 手动拷贝 |
| `build\artifacts\HyCAD-v1.0.0-bundle.zip` | 压缩包备用 |

### 7.2 分步（调试）

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\PackBundle.ps1 -Version 1.0.0
iscc /DRepoRoot="e:\...\hy-cad-tool" /DMyAppVersion=1.0.0 build\installer\HyCAD-Setup.iss
```

### 7.3 发版前自测

1. **关闭 AutoCAD**（勿与 ReCall 混装）
2. 运行 Setup 安装
3. 删/备份 `%ProgramData%\HyCAD\license.lic`（模拟未激活）
4. 启动 CAD：`hyLicense` 可用；`gj` 被拦；`hyRoadAw` 被拦
5. Signer 签 HYC1 → 激活 → 对应命令放行

### 7.4 发版检查清单

- [ ] `Publish-Setup.ps1` 成功，0 error
- [ ] bundle 含 `HyCADTool.dll` + `HyCADTool.Licensing.dll` + `commands.json`
- [ ] Setup 安装后 CAD 自动加载（无需 NETLOAD）
- [ ] 未激活拦截 / 激活后放行
- [ ] 包内无 ReCall / 私钥 / LicenseSigner

## 八、签发授权

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\PackLicenseSigner.ps1
```

产出目录 `build\artifacts\LicenseSigner\`：

| 文件 | 说明 |
|---|---|
| `HyCADTool.LicenseSigner.exe` | 单文件（Costura 内嵌依赖） |
| `PrivateKey.xml` | 自动从 `build\keys\rsa-priv.xml` 链接（若存在） |
| `README-LicenseSigner.md` | 签发说明 |
| `issued-licenses.csv` | 台账（运行后生成，勿提交） |

运行 Signer → 填机器码 / 档位 / 期限 → **生成授权** → 发 **HYC1**（微信）或 **`license.lic`**（文件）。

**切勿发给客户**：`LicenseSigner.exe`、`PrivateKey.xml`、`build\keys\rsa-priv.xml`、`ReCall.dll`。

## 九、排障与 FAQ

| 现象 | 处理 |
|---|---|
| 装了 Setup 但 CAD 无 HyCAD 命令 | 确认 bundle 路径与 `HyCADTool.dll` 存在；**完全重启** CAD；须为 **64 位完整版 AutoCAD**；勿 NETLOAD ReCall |
| `build\artifacts` 的 bundle CAD 不加载 | 那是构建输出；须 Setup 安装或复制到 ApplicationPlugins |
| 「签名校验失败」 | `EmbeddedPublicKey.cs` 与 `rsa-pub.xml` 不同步；重编后重签 |
| 「机器码不匹配」 | 换机需按新机器码重签 |
| 「系统时间曾异常回拨」 | 校时；或删 `%ProgramData%\HyCAD\state.bin` 后重启 |
| HYC1 粘贴失败 | 确认 `HYC1.` 前缀完整；或改用「从文件导入」 |
| 激活后仍提示未授权 | 查 `license.lic` 是否存在；机器码是否一致 |
| 开发时所有命令都能用 | C2 无门闸；用 Setup/Production 验拦截 |
| 换电脑 | 机器码变，需重签 |
| 升级插件 | 覆盖安装即可，通常不必重新激活 |
