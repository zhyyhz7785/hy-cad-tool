# 069 许可证体系定稿说明

> 2026-06-13 | 配套实现已编译通过并全链路自测；签发流程详见 `src/HyCADTool.LicenseSigner/README-签发流程.md`

## 一、整体架构

```
用户机器 (AutoCAD)                          开发者机器（仅本人）
┌─────────────────────────────┐            ┌──────────────────────────┐
│ hyLicense 激活窗口            │ 机器码 →  │ LicenseSigner.exe        │
│  - 显示 8 段机器码 + 二维码    │  (微信)   │  - 单文件 exe (Costura)  │
│  - 粘贴授权码 + 确定激活       │ ← 授权码  │  - PrivateKey.xml 外置   │
│  - 备用: 导入 license.lic     │  (微信)   │  - 自校验 + 台账 CSV     │
├─────────────────────────────┤            └──────────────────────────┘
│ %ProgramData%\HyCAD\         │
│   license.lic / state.bin    │
├─────────────────────────────┤
│ LicenseGate (生产模式门闸)    │ ← 档位来自 commands.json 的 "tier"
└─────────────────────────────┘
```

- **密码学**：RSA-2048 + SHA256（PKCS#1 v1.5），公钥内嵌插件（`EmbeddedPublicKey.cs`），私钥只在签发机
- **机器码**：CPU ProcessorId + 主板序列号 + 系统盘卷序列号 → SHA256 → Base32 → 8 组 `XXXX-XXXX`
- **授权码**：`HYC1.` + Base64Url(GZip(license JSON))，纯文本可微信粘贴，解码容忍换行/空格/全角污染
- **防回拨**：`state.bin`（AES，密钥派生自机器码）记录时间高水位，回拨 >24h 锁定

## 二、关键决策

| 决策 | 理由 |
|---|---|
| 档位映射数据驱动（commands.json `tier` 字段） | 业务迭代零改许可代码；`LicenseCommandTierMap` 只查 Catalog |
| `hy/HyB/_HyExec/hyLicense` 硬编码永远免费 | 任何许可状态下用户都能打开面板/激活窗口拿机器码 |
| `HYCAD_BYPASS_LICENSE` 后门用 `#if !HYCAD_PRODUCTION` 隔离 | 旧实现编进生产版，设个环境变量即可绕过全部许可（已堵） |
| 签发端生成后立即用内嵌公钥自校验 + 解码回环 | 私钥/公钥不配对当场红字报错，杜绝发废证 |
| Costura.Fody 单文件 exe，私钥外置 | exe 外流不泄密；分发只需 exe + PrivateKey.xml |
| `Refresh()` 按 mtime + 5 分钟节流、机器码进程内缓存 | 旧实现每条命令都跑 WMI + 读盘 + 写 state.bin |
| fail-open：license 状态异常仍放行免费命令 | 许可故障不瘫痪基础功能 |

## 三、冻结契约（迭代时不许动）

以下定稿后**永不变更**，否则所有已发授权全部作废：

- `MachineId` 算法与盐值 `HYCAD-V1-SALT`
- `LicenseCanonicalizer` 规范化（去 signature → 属性名深度排序 → Formatting.None UTF-8）
- license JSON 字段架构（v=1）与签名算法
- `HYC1.` 授权码格式
- 密钥对（`build/keys/` ↔ `EmbeddedPublicKey.cs`）

**业务迭代唯一触点**：commands.json 新命令加 `"tier": "freemium|standard|professional|enterprise"`（缺省 standard），同步 `bin\Debug`。许可库、签发 exe、激活窗口一律不碰。
