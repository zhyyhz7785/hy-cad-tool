# 069 许可证体系定稿说明

> 2026-06-13 定稿；同日完成 HYC1 编解码、公钥同步、Refresh 节流、StateStore 加固等实现落地。签发操作见 `src/HyCADTool.LicenseSigner/README-签发流程.md`。

## 一、整体架构

```
用户机器 (AutoCAD)                          开发者机器（仅本人）
┌─────────────────────────────┐            ┌──────────────────────────┐
│ hyLicense 激活窗口            │ 机器码 →  │ LicenseSigner.exe        │
│  - 8 段机器码 + 二维码        │  (微信)   │  - Release 单文件 (Costura)│
│  - 粘贴 HYC1 授权码激活       │ ← HYC1   │  - PrivateKey.xml 外置   │
│  - 或导入 license.lic 文件    │  或 .lic │  - 自校验 + HYC1 输出    │
│  - LicenseCodeCodec 解码      │          │  - 台账 issued-licenses.csv│
├─────────────────────────────┤            └──────────────────────────┘
│ %ProgramData%\HyCAD\         │
│   license.lic  (JSON)         │
│   state.bin    (AES 防回拨)   │
├─────────────────────────────┤
│ LicenseGate (生产模式门闸)    │ ← 档位来自 commands.json 的 "tier"
└─────────────────────────────┘
```

- **密码学**：RSA-2048 + SHA256（PKCS#1 v1.5），公钥内嵌 `EmbeddedPublicKey.cs`，私钥只在签发机（`build/keys/rsa-priv.xml`，gitignore）
- **机器码**：CPU ProcessorId + 主板序列号 + 系统盘卷序列号 → SHA256 → Base32 → **8 组** `XXXX-XXXX`（进程内缓存，首次 WMI 后不再重复查询）
- **授权码（微信）**：`HYC1.` + Base64Url(GZip(license JSON))；`LicenseCodeCodec` 解码容忍换行/空格/全角/零宽字符；若以 `{` 开头则视为 raw JSON（兼容 `.lic` 文件内容）
- **磁盘 license**：`%ProgramData%\HyCAD\license.lic` 存 **带 signature 的 JSON**（不是 HYC1 文本）
- **防回拨**：`state.bin`（AES-CBC，密钥派生自机器码）记录时间高水位；回拨 >24h 锁定；**解密/损坏时亦锁定**（不静默重置），用户可删除 `state.bin` 后重启恢复

## 二、关键决策

| 决策 | 理由 |
|---|---|
| 档位映射数据驱动（commands.json `tier` 字段） | 业务迭代零改许可代码；`LicenseCommandTierMap` 只查 `CommandCatalog` |
| `hy/HyB/_HyExec/hyLicense` 硬编码永远 Freemium | 任何许可状态下都能打开面板/激活窗拿机器码 |
| `HYCAD_BYPASS_LICENSE` 用 `#if !HYCAD_PRODUCTION` 隔离 | Debug 可旁路；Production 包无此后门 |
| 签发端：内嵌公钥自校验 + HYC1 编解码回环 | 私钥/公钥不配对或编解码失败当场红字，杜绝发废证 |
| Costura 单文件 exe，私钥外置；Release 不自动复制私钥 | exe 外流不泄密；Release 需手动放 `PrivateKey.xml` |
| `Refresh()` 5 分钟 + `license.lic` mtime 节流；`MachineId` 进程缓存 | 避免每条门闸命令跑 WMI + 读盘 + 写 `state.bin` |
| 激活后 `Refresh(force: true)` | 导入 license 后立即刷新，不受节流影响 |
| fail-open：license 异常仍放行 Freemium 命令 | 许可故障不瘫痪基础功能 |
| `features` / `max_devices` / `migration_token` v1 预留 | 运行时仅校验 `edition`，字段写入 license 供人工可读 |

## 三、冻结契约（迭代时不许动）

以下定稿后**永不变更**，否则所有已发授权全部作废：

- `MachineId` 算法与盐值 `HYCAD-V1-SALT`
- `LicenseCanonicalizer` 规范化（去 signature → 属性名深度排序 → `Formatting.None` UTF-8）
- license JSON 字段架构（v=1）与签名算法
- `HYC1.` 授权码格式（`LicenseCodeCodec`）
- 密钥对（`build/keys/rsa-pub.xml` ↔ `EmbeddedPublicKey.RsaKeyXml`）

**轮换密钥必做**：`_gen-rsa-keys.ps1` → 更新 `EmbeddedPublicKey.cs` → 重编 HyCADTool + LicenseSigner。

**业务迭代唯一触点**：`commands.json` 新命令加 `"tier": "freemium|standard|professional|enterprise"`（缺省 standard），同步 `bin\Debug` 与 Production bundle。

## 六、排障速查

| 现象 | 处理 |
|---|---|
| 「签名校验失败或公钥不匹配」 | 检查 `EmbeddedPublicKey` 是否与当前 `rsa-pub.xml` 同步并重编 |
| 「系统时间曾异常回拨」 | 校时；或删除 `%ProgramData%\HyCAD\state.bin` 后重启 AutoCAD |
| HYC1 粘贴失败 | 确认以 `HYC1.` 开头；或改用「从文件导入」`license.lic` |
| 「机器码不匹配」 | 换机需按新机器码重签 |
