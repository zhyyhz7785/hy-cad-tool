# 070 客户安装与发版快速路径

> 2026-06-13 | 许可体系见 [069](069-许可证体系定稿说明-2026-06-13-024000.md)；bundle 路径见 [071](071-HyCAD.bundle安装与使用说明-2026-06-13-031500.md)；签发见 `src/HyCADTool.LicenseSigner/README-签发流程.md`

## 一、两种运行模式（必读）

| 角色 | 用什么 | 许可门闸 |
|---|---|---|
| 日常开发 | ReCall + C2 热重载（Debug） | **不生效**（ReCall 无 `LicenseGate`，故意放行） |
| 客户 / 自测真实体验 | Production 包（Setup.exe 安装） | **生效**（`ProductionCommandFacade` 每条命令经 `LicenseGate`） |

未激活时：免费命令（`hy` / `HyB` / `hyLicense` / `HYJC` / `hySC` 等）可用；缺省 tier 的命令（如 `gj`）按 **Standard** 拦截；道路/桩基等 **Professional** 命令会被拦截并提示「输入 hyLicense 激活」。档位数据在 `src/ReCall/commands.json` 的 `"tier"` 字段，生产 bundle 自动携带同一份 `commands.json`。

## 二、客户标准安装（3 步）

1. **运行** `HyCAD-Setup-x.y.z.exe`（Inno 向导，无需管理员；欢迎页含绿色插件说明）
2. **完全退出并重启 AutoCAD** → 命令行输入 **`hyLicense`** → 复制 **8 段 × 4 位** 机器码发给你
3. **激活（二选一）**
   - 收到 **`HYC1.` 开头授权码** → 粘贴 → **确定激活**
   - 收到 **`license.lic` 文件** → **从文件导入**

安装位置：`%APPDATA%\Autodesk\ApplicationPlugins\HyCAD.bundle`  
AutoCAD 启动时由 `PackageContents.xml` 自动加载（`LoadOnAutoCADStartup=True`）。  
License 文件：`%ProgramData%\HyCAD\license.lic`（JSON，激活后自动写入，客户无需手拷）。

**不要发给客户**：`ReCall.dll`、`LicenseSigner.exe`、`PrivateKey.xml`、`build/keys/rsa-priv.xml`。

## 三、开发者发版流水线（一条命令）

仓库根目录：

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\Publish-Setup.ps1 -Version 1.0.0
```

等价于：`PackBundle.ps1`（Production 编译 + 打 bundle）→ Inno Setup → `build\artifacts\HyCAD-Setup-1.0.0.exe`。

**前提**：本机已安装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)（`ISCC.exe` 在 PATH 或默认安装路径）。

**分步执行**（调试时用）：

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\PackBundle.ps1 -Version 1.0.0
iscc /DRepoRoot="e:\...\hy-cad-tool" /DMyAppVersion=1.0.0 build\installer\HyCAD-Setup.iss
```

**签发授权**（仅开发者机器）：

1. 编译：`dotnet build src\HyCADTool.LicenseSigner\HyCADTool.LicenseSigner.csproj -c Release`
2. Release 输出目录手动放置 `PrivateKey.xml`（Debug 构建可从 `build\keys\rsa-priv.xml` 自动链接）
3. 运行 `HyCADTool.LicenseSigner.exe` → 粘贴完整机器码（32 位）→ 选档位/期限 → **生成授权**
4. 交付：**复制 HYC1 授权码**（微信）或 **保存 license.lic**（文件）
5. 台账：exe 同目录 `issued-licenses.csv`（仅元数据，不含完整授权码）

**轮换 RSA 密钥**：`build\scripts\_gen-rsa-keys.ps1` → 同步 `EmbeddedPublicKey.cs` → 重编主工程与 Signer。

## 四、发版前自测（模拟新用户）

1. **关闭 AutoCAD**（Production 与 ReCall 不要混装同进程）
2. 执行 `Publish-Setup.ps1 -Version x.y.z`，本机运行 Setup.exe 安装
3. 删除或备份 `%ProgramData%\HyCAD\license.lic`（模拟未激活；可选删 `state.bin` 避免回拨锁定干扰）
4. 启动 AutoCAD：
   - `hyLicense` 可用，显示未激活/免费版
   - `gj` 应被拦（需 Standard）
   - `hyRoadAw` 应被拦（需 Professional）
5. Signer 生成 HYC1 → 激活窗粘贴 → 对应档位命令应放行

快捷替代（仅验 DLL，非正式交付）：`dotnet build src\HyCADTool\HyCADTool.csproj -c Production` 后 NETLOAD `bin\Production\HyCADTool.dll`。

## 五、常见问题

**Q：开发时为什么所有命令都能用？**  
A：C2 走 ReCall，无许可门闸。要验拦截必须用 Production / Setup.exe。

**Q：换电脑怎么办？**  
A：机器码变了，需重新发机器码，用 LicenseSigner 按新机器码重签 HYC1 或 license.lic。

**Q：升级插件要重新激活吗？**  
A：不需要。`license.lic` 与插件版本无关，覆盖安装 bundle 即可。

**Q：客户只有 ZIP 没有 Setup.exe？**  
A：解压 `HyCAD-vX-bundle.zip`，将 `HyCAD.bundle` 整文件夹复制到 `%APPDATA%\Autodesk\ApplicationPlugins\`（详见 071）。

**Q：如何卸载？**  
A：再次运行 Setup.exe → **是=卸载 / 否=覆盖 / 取消**；或开始菜单「卸载 HyCAD 插件」；或运行 `unins000.exe`。均不删除 `license.lic`。

**Q：提示「系统时间曾异常回拨」？**  
A：先校时；仍提示则删除 `%ProgramData%\HyCAD\state.bin` 后重启 AutoCAD（见 069 §六）。

**Q：HYC1 和 license.lic 有什么区别？**  
A：内容同为 signed JSON；HYC1 是 GZip+Base64Url 压缩文本便于微信粘贴；落盘 `license.lic` 为 JSON 明文。
