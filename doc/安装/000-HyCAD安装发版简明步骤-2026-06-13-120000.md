# 000 HyCAD 安装与发版 — 简明步骤

> 本页只列**主流程**；完整说明见 [001](001-HyCAD安装发版与许可体系-2026-06-13-140000.md)

---

## 三条主线

| 谁 | 做什么 | 结果 |
|---|---|---|
| **客户** | 装 Setup → `hyLicense` 取机器码 → 激活 | AutoCAD 里可用对应档位命令 |
| **你（发版）** | `Publish-Setup.ps1` | 得到客户安装包 `.exe` |
| **你（签发）** | `PackLicenseSigner.ps1` → 运行 Signer | 得到 HYC1 文本或 `license.lic` |

---

## 一、客户安装

1. 双击 **`HyCAD-Setup-x.y.z.exe`**（无需管理员）
2. **完全退出并重启 AutoCAD** → 命令行输入 **`hyLicense`** → 复制 **8 段机器码** 发给你
3. 收到授权后二选一：**粘贴 `HYC1.` 授权码** · **从文件导入 `license.lic`**

装好后插件在 `%APPDATA%\Autodesk\ApplicationPlugins\HyCAD.bundle`，CAD 启动自动加载。

---

## 二、开发者发版

在**仓库根目录**执行（版本号按需改）：

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\Publish-Setup.ps1 -Version 1.0.0
```

| 产出 | 用途 |
|---|---|
| `build\artifacts\HyCAD-Setup-1.0.0.exe` | **发给客户** |
| `build\artifacts\HyCAD.bundle` | 本地自测 / 手动拷贝 |

前提：本机已装 [Inno Setup 6](https://jrsoftware.org/isinfo.php)。

---

## 三、签发授权

在**仓库根目录**执行：

```powershell
powershell -ExecutionPolicy Bypass -File build\scripts\PackLicenseSigner.ps1
```

然后运行：

```
build\artifacts\LicenseSigner\HyCADTool.LicenseSigner.exe
```

填机器码、档位、期限 → **生成授权** → 发客户 **HYC1 文本**（微信方便）或 **`license.lic` 文件**。

同目录另有 `PrivateKey.xml`（来自 `build\keys\rsa-priv.xml`）和 `README-LicenseSigner.md`。
