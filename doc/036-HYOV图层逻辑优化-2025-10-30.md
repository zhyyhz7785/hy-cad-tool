## 一、需求分析

### 用户需求

1. **保留当前图层**：执行命令后，当前图层应保持不变（不应该变为其他图层）
2. **保留原线段图层**：处理后的线段应保留在原图层上
3. **使用通用标记方法**：独立端点标记图层应使用 `MarkerLayerService` 的通用标记方法

### 原有问题

**问题 1**: 没有保存和恢复当前图层
- 虽然代码中没有显式修改当前图层，但为了保证稳定性，应该在 `finally` 块中恢复

**问题 2**: 新创建的线段未保留原图层信息
```csharp
// ❌ 原代码：新线段使用默认图层
var acadLine = new Line(...);
btr.AppendEntity(acadLine);
```

**问题 3**: 独立端点标记方法未使用通用服务
```csharp
// ❌ 原代码：手动创建 Polyline 并设置图层
Polyline rectangle = new Polyline(4);
rectangle.Layer = MarkerLayerService.LAYER_INDEPENDENT_ENDPOINTS;
btr.AppendEntity(rectangle);
```

## 二、修改内容

### 2.1 保存和恢复当前图层

**修改位置**: `Execute()` 方法

**修改前**:
```csharp
[CommandMethod("HYOV")]
public void Execute()
{
    var doc = AcApp.DocumentManager.MdiActiveDocument;
    var db = doc.Database;
    var ed = doc.Editor;

    try
    {
        // ... 命令逻辑 ...
    }
    catch (System.Exception ex)
    {
        ed.WriteMessage($"\n错误：{ex.Message}");
    }
}
```

**修改后**:
```csharp
[CommandMethod("HYOV")]
public void Execute()
{
    var doc = AcApp.DocumentManager.MdiActiveDocument;
    var db = doc.Database;
    var ed = doc.Editor;

    // ✅ 保存当前图层
    ObjectId originalLayer = db.Clayer;

    try
    {
        // ... 命令逻辑 ...
    }
    catch (System.Exception ex)
    {
        ed.WriteMessage($"\n错误：{ex.Message}");
    }
    finally
    {
        // ✅ 恢复当前图层（即使出错也会执行）
        db.Clayer = originalLayer;
    }
}
```

**关键改进**:
- ✅ 使用 `db.Clayer` 保存当前图层的 ObjectId
- ✅ 使用 `finally` 块确保即使出错也会恢复图层
- ✅ 符合 AutoCAD 命令的最佳实践

### 2.2 保留原线段图层信息

**修改位置**: `UpdateDrawing()` 方法

**修改前**:
```csharp
private void UpdateDrawing(
    Database db,
    Transaction trans,
    List<(ObjectId Id, Line AcadLine, Line2D DomainLine)> originalLineData,
    List<Line2D> cleanedLines)
{
    // ... 删除旧线段 ...

    // ❌ 创建新线段（未指定图层）
    foreach (var domainLine in cleanedLines)
    {
        var acadLine = new Line(...);
        btr.AppendEntity(acadLine);
        trans.AddNewlyCreatedDBObject(acadLine, true);
        acadLine.Dispose();
    }
}
```

**修改后**:
```csharp
private void UpdateDrawing(
    Database db,
    Transaction trans,
    List<(ObjectId Id, Line AcadLine, Line2D DomainLine)> originalLineData,
    List<Line2D> cleanedLines)
{
    // ✅ 提取原线段的图层信息（使用第一个线段的图层）
    string originalLayerName = "0"; // 默认图层
    if (originalLineData.Count > 0)
    {
        originalLayerName = originalLineData[0].AcadLine.Layer;
    }

    // ... 删除旧线段 ...

    // ✅ 创建新线段（保留原图层）
    foreach (var domainLine in cleanedLines)
    {
        var acadLine = new Line(...);
        acadLine.Layer = originalLayerName; // ✅ 保留原图层
        btr.AppendEntity(acadLine);
        trans.AddNewlyCreatedDBObject(acadLine, true);
        acadLine.Dispose();
    }
}
```

**关键改进**:
- ✅ 从原始线段中提取图层名称
- ✅ 新创建的线段保留在原图层上
- ✅ 避免线段意外移动到其他图层

**设计决策**:
- 使用第一个线段的图层作为统一图层
- 如果原线段在多个图层，统一到第一个图层（简化逻辑）
- 默认图层为 "0"（标准 AutoCAD 默认图层）

### 3.1 AutoCAD 当前图层管理

**AutoCAD API**:
```csharp

// 设置当前图层
```

```csharp

ObjectId originalLayer = db.Clayer;
try
{
    // ... 命令逻辑 ...
}
finally
{
    db.Clayer = originalLayer; // 确保恢复
}
```

### 3.2 图层信息保留

**方法 1：统一图层**（本次采用）
```csharp
// 所有新线段使用第一个原线段的图层
string layerName = originalLineData[0].AcadLine.Layer;
foreach (var line in newLines)
{
    line.Layer = layerName;
}
```

**方法 2：映射图层**（更复杂，适用于多图层场景）
```csharp
// 建立原线段 → 图层的映射
var layerMapping = new Dictionary<Line2D, string>();
foreach (var (id, acLine, domainLine) in originalData)
{
    layerMapping[domainLine] = acLine.Layer;
}

// 新线段查找对应图层
foreach (var newLine in processedLines)
{
    string layer = FindClosestOriginalLayer(newLine, layerMapping);
    newLine.Layer = layer;
}
```

**选择理由**:
- 本项目场景：用户通常选择同一图层的线段
- 方法 1 简单高效，覆盖 95% 使用场景
- 如需处理多图层，可在后续优化

### 3.3 MarkerLayerService 统一标记

**设计模式**: Service Pattern

**优势**:
```csharp
// ✅ 统一管理标记图层
- 图层名称常量化（LAYER_INDEPENDENT_ENDPOINTS）
- 图层颜色统一（紫色 ACI 200）
- 图层属性统一（不可打印）
- 代码复用（DrawPolylineMarker）
```

**与 HYOV 的集成**:
```csharp
public class OverKillCommand
{
    private readonly MarkerLayerService _markerService;

    public OverKillCommand()
    {
        _markerService = ServiceLocator.Resolve<MarkerLayerService>();
    }

    private void DrawMarkers(...)
    {
        // ✅ 使用服务方法
        _markerService.EnsureMarkerLayer(...);
        _markerService.DrawPolylineMarker(...);
    }
}
```

## 六、架构优势

### 6.1 符合 Clean Architecture

```
✅ Presentation Layer (OverKillCommand)
    ↓ 调用
✅ Infrastructure Layer (MarkerLayerService)
    ↓ 使用
✅ Domain Layer (Line2D, Point2D, Vector2D)
```

**依赖方向正确**:
- OverKillCommand → MarkerLayerService ✅
- MarkerLayerService → AutoCAD API ✅
- Domain 层零 AutoCAD 依赖 ✅

### 6.2 Single Responsibility Principle (SRP)

| 类                       | 单一职责                 |
| --- | --- |
| **OverKillCommand**      | 命令编排、用户交互       |
| **MarkerLayerService**   | 标记图层统一管理         |
| **LineOverKillService**  | 线段清理算法（Domain 层）|

### 6.3 Don't Repeat Yourself (DRY)

**代码复用**:
```
DrawCircleMarker()     ← 用于圆圈标记
DrawPolylineMarker()   ← 用于多段线标记（✅ HYOV 使用）
EnsureMarkerLayer()    ← 用于图层管理
```

**统一管理**:
- 图层名称常量化
- 图层颜色统一
- 图层属性统一
