# HYDCEL 新简化架构完成报告

> **完成时间**：2025-10-30  
> **架构版本**：v4.0  
> **关键特性**：曲线简化+映射字典+灵活恢复

---

## 📋 概述

根据用户需求，放弃了之前的**三角化+辅助边跳过**方案，重新设计并实现了**基于映射字典的曲线简化架构**。新方案具有以下优势：

1. **清晰分离**：曲线简化与DCEL处理完全解耦
2. **灵活控制**：用户可选择恢复原曲线或使用简化线段
3. **精度可调**：Arc/Ellipse/Spline分段数可配置
4. **扩展性强**：易于支持新的曲线类型

---

## 🏗️ 新架构设计

### 架构流程

```
1. 曲线提取与简化
   ↓
   原始曲线 (Arc/Ellipse/Spline)
   ↓
   [CurveSimplificationService]
   ↓
   连续线段 (List<Line2D>)
   
2. 建立映射字典
   ↓
   SimplifiedCurveMapping
   {
     OriginalCurve: Arc2D/Ellipse2D/Spline2D
     SimplifiedSegments: List<Line2D>
   }
   
3. DCEL处理
   ↓
   使用简化线段运行DCEL
   ↓
   DCELGraph
   
4. 渲染恢复
   ↓
   根据映射字典
   ↓
   - restoreOriginal=true → 恢复原曲线
   - restoreOriginal=false → 使用简化线段
```

## 📦 新增核心组件

### 1. CurveSimplificationService（Domain层）

**位置**：`Domain/Services/CurveSimplificationService.cs`

**职责**：将复杂曲线简化为连续线段

**方法**：
```csharp
// Arc简化（自动计算分段数：每15度一段，最少4段）
List<Line2D> SimplifyArc(Arc2D arc, int? segmentCount = null)

// Ellipse简化（根据周长估算，最少16段）
List<Line2D> SimplifyEllipse(Ellipse2D ellipse, int? segmentCount = null)

// Spline简化（每个控制点区间8段，最少16段）
List<Line2D> SimplifySpline(Spline2D spline, int? segmentCount = null)
```

**简化策略**：
- **Arc**：均匀角度分割
- **Ellipse**：参数化采样
- **Spline**：控制点线性插值（简化版，实际应使用B样条算法）

### 2. SimplifiedCurveMapping（Domain层值对象）

**位置**：`Domain/ValueObjects/Geometry/SimplifiedCurveMapping.cs`

**职责**：存储原始曲线与简化线段的映射关系

**属性**：

**方法**：

### 5. DCELRenderer 扩展

**新增接口方法**（IDCELRenderer）：
```csharp
void RenderWithMappings(
    DCELGraph graph,
    List<SimplifiedCurveMapping> mappings,
    string outerLayer = "dcelOuter",
    string innerLayer = "dcelInner",
    bool restoreOriginal = true)
```

**核心实现方法**：

#### TryBuildPolylineWithOriginalCurves
```csharp
private void TryBuildPolylineWithOriginalCurves(
    Polyline polyline,
    List<HalfEdge> halfEdges,
    List<SimplifiedCurveMapping> mappings)
```

**逻辑**：
1. 遍历Face的每条半边
2. 尝试在映射字典中查找匹配的简化曲线序列
3. 如果找到匹配：
   - **Arc类型**：计算bulge，恢复为Polyline的弧段
   - **Ellipse/Spline**：使用简化线段（TODO：实现原生恢复）
4. 如果没找到匹配：使用直线

#### FindMatchingMapping
```csharp
private SimplifiedCurveMapping FindMatchingMapping(
    Line2D edgeLine,
    List<HalfEdge> allHalfEdges,
    int startIndex,
    List<SimplifiedCurveMapping> mappings,
    double tolerance,
    out int consumedEdgeCount)
```

**逻辑**：
- 遍历所有映射
- 调用`TryMatchSimplifiedSequence`尝试匹配简化线段序列
- 返回匹配的映射和消耗的边数

#### TryMatchSimplifiedSequence
```csharp
private (bool matched, int count) TryMatchSimplifiedSequence(
    Line2D firstEdge,
    List<HalfEdge> allHalfEdges,
    int startIndex,
    List<Line2D> simplifiedSegments,
    double tolerance)
```

**逻辑**：
- 正向匹配：逐个比较DCEL半边与简化线段
- 如果所有线段都匹配（在容差范围内），返回`(true, count)`

#### CalculateBulgeFromArc
```csharp
private double CalculateBulgeFromArc(Arc2D arc)
{
    var sweepAngle = arc.SweepAngle * Math.PI / 180.0;
    return Math.Tan(sweepAngle / 4.0);
}
```

**公式**：`Bulge = tan(θ/4)`，其中θ为圆心角（弧度）

## ⚙️ 简化精度配置

### 自动计算策略

| 曲线类型   | 自动分段规则                       | 最小段数 |
| ---------- | ---------------------------------- | -------- |
| **Arc**    | 每15度一段                         | 4段      |
| **Ellipse** | 根据椭圆周长估算（周长/50）       | 16段     |
| **Spline** | 每个控制点区间8段                  | 16段     |

### 用户自定义精度

在`DCELCommand.Execute`中可配置：
```csharp
var (segments, mappings) = _curveExtractor.ExtractAndSimplify(
    curveIds, 
    simplificationService, 
    tolerance,
    arcSegmentCount: 8,       // 自定义Arc分段数
    ellipseSegmentCount: 32,  // 自定义Ellipse分段数
    splineSegmentCount: 64    // 自定义Spline分段数
);
```

**建议配置**：
- **高精度**：`arcSegmentCount: 16, ellipseSegmentCount: 64`
- **平衡**：`arcSegmentCount: null`（自动）
- **低精度（性能优先）**：`arcSegmentCount: 4, ellipseSegmentCount: 16`

### 2. 逆向匹配

**当前状态**：只支持正向匹配（DCEL边方向 = 简化线段方向）  
**目标**：支持逆向匹配

**实现思路**：
在`TryMatchSimplifiedSequence`中添加逆向匹配逻辑：
```csharp
// 逆向匹配
bool reverseMatch = true;
for (int i = 0; i < simplifiedSegments.Count; i++)
{
    var halfEdge = allHalfEdges[(startIndex + i) % allHalfEdges.Count];
    var simplified = simplifiedSegments[simplifiedSegments.Count - 1 - i];
    
    if (halfEdgeStart.DistanceTo(simplified.EndPoint) >= tolerance ||
        halfEdgeEnd.Value.DistanceTo(simplified.StartPoint) >= tolerance)
    {
        reverseMatch = false;
        break;
    }
}

if (reverseMatch)
    return (true, simplifiedSegments.Count, reversed: true);
```

**注意**：Arc逆向时需要反转bulge符号

---

### 3. 部分匹配

**当前状态**：只匹配完整的简化线段序列  
**目标**：支持部分匹配（Arc被DCEL分割的情况）

**实现思路**：
- 记录Arc的起始角度和结束角度
- 当匹配到部分线段时，计算对应的子弧
- 重新计算子弧的bulge值

**适用场景**：
- 圆角矩形被其他线条切割
- 圆被复杂边界分割
