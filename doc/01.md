## 二、桩位 Voronoi 优化命令（PileVoronoiOptimizationCommand）

### 功能
- 选择多边形轮廓
- 输入桩参数（直径、置换率、数量）
- 使用 Lloyd 算法优化桩位（4500 次迭代）
- 绘制 Voronoi 图和桩圆

### 架构（三层分离）

#### Domain 层
```
Domain/Services/VoronoiOptimizationService.cs
  ├─ CreateVoronoiDiagram()          // 创建 Voronoi 图
  ├─ ApplyLloydOptimization()        // Lloyd 算法优化
  ├─ GenerateRandomPointsInsidePolygon()  // 随机点生成
  └─ GetPointsInsidePolygon()        // 点过滤
```

#### Infrastructure 层
```
Infrastructure/AutoCAD/Helpers/PolylineHelper.cs
  ├─ PromptAndGetPolygon()           // 选择多段线 → NTS Polygon
  ├─ ConvertToNtsPolygon()           // AutoCAD → NTS 转换
  ├─ ConvertToAcadPolyline()         // NTS → AutoCAD 转换
  └─ DrawPolygon()                   // 绘制 Polygon
```

#### Presentation 层
```
Presentation/Commands/PileVoronoiOptimizationCommand.cs
  ├─ Execute()                       // 自动生成随机初始点
  ├─ ExecuteWithExistingCircles()    // 使用已有圆作为初始点
  ├─ ExecuteOptimizationAndDraw()    // 优化 + 绘制
  └─ GetPileParameters()             // 用户输入参数
```

### 调用方式
- 桩面板按钮：
  - **桩位Voronoi优化**（自动生成初始点）
  - **桩位优化(已有圆)**（基于已有圆优化）
- 或直接实例化：
  ```csharp
  new PileVoronoiOptimizationCommand().Execute();
  new PileVoronoiOptimizationCommand().ExecuteWithExistingCircles();
  ```

## 五、关键技术点

### 1. NetTopologySuite (NTS) 集成
- 使用 NTS `Polygon`、`Coordinate` 进行几何计算
- `VoronoiDiagramBuilder` 生成 Voronoi 图
- AutoCAD ↔ NTS 双向转换（`PolylineHelper`）

### 2. Lloyd 算法优化
- 迭代 4500 次（可配置）
- 每次迭代：
  1. 生成 Voronoi 图
  2. 计算每个单元质心
  3. 质心作为新桩位
  4. 处理边界点（移动到多边形内）
  5. 补充缺失点（保持桩数不变）

### 3. 命令路由机制
- 面板按钮 → `SendCommand()` → `SettingsPanelViewModel.PendingCommand`
- 触发 `C1` → `TestCommand.Run()` → 执行命令（AutoCAD 线程）

### 测试圆分组标注
1. 在 AutoCAD 中绘制若干圆和文字（文字内容为标高数字）
2. C2 重载插件
3. C1 打开桩面板
4. 点击 **圆分组标注**
5. 选择是否标注标高（是/否）
6. 框选圆和文字
7. 检查：
   - 圆按标高分组到不同图层（颜色渐变）
   - 引线标注显示编号（A1, B1, ...）
   - 生成统计表格

### 测试桩位 Voronoi 优化
1. 在 AutoCAD 中绘制闭合多段线（作为桩布置区域）
2. C2 重载插件
3. C1 打开桩面板
4. 点击 **桩位Voronoi优化**
5. 选择多段线
6. 输入参数：
   - 桩根数（0 表示自动计算）
   - 桩直径（如 400mm）
   - 置换率（如 2.2%）
7. 等待优化完成（约 10-30 秒）
8. 检查：
   - 图层 `00-HY-桩` 中绘制圆
   - 图层 `00-HY-Voronoi` 中绘制 Voronoi 区域
   - 桩位分布均匀

4. 点击 **桩位优化(已有圆)**
5. 选择多段线
6. 选择圆
7. 输入桩直径和置换率
8. 检查优化后的桩位和 Voronoi 图

## 九、注意事项

### 1. Lloyd 优化耗时
- 4500 次迭代约需 10-30 秒（取决于桩数）
- 可在 `PileVoronoiOptimizationCommand.ExecuteOptimizationAndDraw()` 中调整迭代次数

### 2. 多边形要求
- 必须是闭合的 `Polyline`
- 不支持带弧段的多段线（NTS 限制）
- 复杂多边形可能导致优化失败

### 3. 图层命名
- 圆分组：`00_hy_Z_A`, `00_hy_Z_B`, ...
- Voronoi：`00-HY-Voronoi`
- 桩：`00-HY-桩`
