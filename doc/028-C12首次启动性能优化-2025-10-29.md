# C12 (HYOVSET) 首次启动性能优化

> **日期**: 2025-10-29  
> **问题**: C12 命令首次启动需要 **11 秒**（创建窗口 5 秒 + 显示 6 秒）  
> **优化目标**: 减少首次启动时间到 < 2 秒  
> **状态**: ✅ 已实施 WPF 预热机制

---

## 🔍 问题分析

### 用户反馈数据

```
命令: C12
=== HYOVSET 启动时间分析 ===
[1-创建窗口] 5020 毫秒  ← 🔥 时间黑洞！
[2-显示窗口] 5918 毫秒  ← 包含用户操作
[总时间] 11040 毫秒
```

### 根本原因

**WPF 框架首次加载慢** - 典型的 .NET WPF 冷启动问题

当首次创建 WPF 窗口时，.NET Framework 需要：

1. **加载 WPF 核心程序集**
   - `PresentationCore.dll` (~4 MB)
   - `PresentationFramework.dll` (~6 MB)
   - `WindowsBase.dll` (~3 MB)
   - `System.Xaml.dll` (~1 MB)

2. **JIT 编译**
   - 这些 DLL 的方法首次调用需要 JIT 编译
   - 涉及数千个方法的编译

3. **WPF 框架初始化**
   - 视觉树系统
   - 布局引擎
   - 数据绑定引擎
   - 样式系统

### XAML 文件分析

`HyovSettingsWindow.xaml` 本身很简单（112 行），不是性能瓶颈：
- 基础控件（GroupBox, StackPanel, TextBox, CheckBox, Button）
- 没有复杂的样式、动画或自定义控件
- 没有大量的数据绑定

**结论**: 问题不在 XAML，而在 WPF 框架加载。

## 🔧 优化方案

### 方案 1: WPF 预热（已实施）⭐

**原理**: 在 C2 热重启时预先创建一个虚拟窗口，强制 WPF 框架加载到内存。

**实现位置**: `ReCall/Recall.cs`

```csharp
/// <summary>
/// WPF 框架预热（解决首次创建窗口慢的问题）
/// </summary>
private void WarmupWPF(Autodesk.AutoCAD.EditorInput.Editor ed)
{
    try
    {
        var warmupWatch = System.Diagnostics.Stopwatch.StartNew();
        ed?.WriteMessage("\n开始 WPF 框架预热...");
        
        // 创建并立即关闭一个虚拟窗口，强制 WPF 框架加载
        var warmupWindow = new System.Windows.Window
        {
            Width = 1,
            Height = 1,
            WindowStyle = System.Windows.WindowStyle.None,
            ShowInTaskbar = false,
            ShowActivated = false,
            Visibility = System.Windows.Visibility.Hidden
        };
        warmupWindow.Show();
        warmupWindow.Close();
        
        warmupWatch.Stop();
        ed?.WriteMessage($"\n✓ WPF 预热完成（耗时 {warmupWatch.ElapsedMilliseconds} 毫秒）");
    }
    catch (System.Exception ex)
    {
        ed?.WriteMessage($"\n⚠️ WPF 预热失败: {ex.Message}（不影响正常使用）");
    }
}
```

**调用时机**: 在 `Reload()` 方法中，`LoadTestCommands()` 之后

```csharp
// 加载测试命令（C11-C19）
LoadTestCommands(targetFilePath);

// 预热 WPF 框架（解决首次创建窗口慢的问题）
WarmupWPF(ed);

ed.WriteMessage("\n✓ 插件加载成功！");
```
