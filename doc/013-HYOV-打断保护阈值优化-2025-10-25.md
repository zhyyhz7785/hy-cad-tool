# HYOV 打断保护阈值优化报告

> **日期**: 2025-10-25  
> **问题**: 长度为 9mm 的线段被删除  
> **原因**: 打断保护阈值（0.5mm）小于过滤阈值（5.0mm）  
> **解决方案**: 将打断保护阈值设置为与过滤阈值一致

---

## 🐛 问题描述

### 用户反馈

```
第0步-预清理：6 → 5 线段
第1步-打断相交：5 → 8 线段
第2步-端点延伸：8 → 8 线段
第3步-端点到线：8 → 8 线段
第4步-过滤短线段：8 → 7（保留 ≥ 5.000000）
第5步-删除重复：7 → 7 线段
找到 2 个独立端点，已标记
最终结果：6 → 7 线段

注意删除了线段长度是 9 的线段，为什么？
```

### 几何情况

根据用户提供的图形：

```
        +
        │
        │
     ┌──┴──┐
     │     │  椭圆
     └─────┘
        │
        │
────────┼────────  水平线
        │
        ╱  白色斜线（长度 9mm）
       ╱
```

**关键线段**：
- 白色斜线：长度约 9mm
- 垂直线：穿过多个图形

## 🔍 问题分析

### 执行流程追踪

#### 步骤0：预清理
```
输入：6 条线段
输出：5 条线段（合并了1条重复/共线线段）
```

#### 步骤1：打断相交
```
输入：5 条线段
处理：在相交点打断线段
输出：8 条线段（增加了3条）
```

**可能情况**：
- 垂直线与水平线相交 → 垂直线被打断成2段
- 垂直线与椭圆相交 → 垂直线被打断成更多段

#### 步骤2：端点延伸
```
输入：8 条线段
处理：延伸端点距离很近的线段
输出：8 条线段（没有变化）
```

**说明**：没有端点距离 ≤ 10mm 的线段对

#### 步骤3：端点到线延伸 ⚠️ **问题发生在这里**
```
输入：8 条线段
处理：延伸端点到线段，并打断线段
输出：8 条线段（数量没变，但内容变了）
```

**关键逻辑**：

```csharp
// 检查端点到线段的距离
double distEnd = PointToLineSegmentDistance(currentLine.EndPoint, otherLine);

if (distEnd > tolerance && distEnd <= maxDistance)  // 距离 ≤ 10mm
{
    // 计算交点
    var intersection = currentLine.GetIntersectionWithInfiniteLine(otherLine, tolerance);
    
    if (intersection != default && otherLine.IsPointOnSegment(intersection, tolerance))
    {
        // 延伸当前线段到交点
        currentLine = new Line2D(currentLine.StartPoint, intersection);
        
        // 打断 otherLine（白色斜线）
        double segmentA = param * length;        // 打断后的第一段
        double segmentB = (1 - param) * length;  // 打断后的第二段
        
        // 旧逻辑：只要两段都 >= 0.5mm 就打断
        if (segmentA >= 0.5 && segmentB >= 0.5)
        {
            lineList[j] = segment1;
            lineList.Add(segment2);
        }
    }
}
```

**问题场景**：

```
椭圆的端点距离白色斜线 8mm（≤ 10mm）
↓
延伸椭圆端点到白色斜线，交点在 P
↓
打断白色斜线：
  - 第一段：起点 → P，长度 4mm（≥ 0.5mm ✅）
  - 第二段：P → 终点，长度 5mm（≥ 0.5mm ✅）
↓
打断成功！白色斜线被分成 4mm + 5mm 两段
```

#### 步骤4：过滤短线段 ⚠️ **删除发生在这里**
```
输入：8 条线段
处理：删除长度 < 5.0mm 的线段
输出：7 条线段（删除了1条）
```

**删除的线段**：
- 第一段：4mm < 5mm ❌ **被删除**
- 第二段：5mm ≥ 5mm ✅ 保留

**结果**：
- 原本长度 9mm 的白色斜线，被打断后只剩下 5mm 的一段
- 另外 4mm 的一段被删除了

## 🎯 问题根源

### 参数不一致

| 参数名称              | 旧值   | 用途                   | 问题                       |
| --------------------- | ------ | ---------------------- | -------------------------- |
| `minBreakThreshold`   | 0.5mm  | 打断保护阈值           | 太小，允许打断成 4mm 的段  |
| `minLineLength`       | 5.0mm  | 过滤阈值               | 较大，删除 < 5mm 的线段    |
| **差值**              | **4.5mm** | **不一致区间**         | **4mm 的线段被打断但被删除** |

### 逻辑冲突

```
打断保护阈值（0.5mm）< 过滤阈值（5.0mm）
↓
允许打断成 0.5mm ~ 5.0mm 的线段
↓
这些线段在步骤4被删除
↓
用户困惑：为什么打断后又删除？
```

### 几何意义

```
原始线段：长度 9mm
  A────────────────B

步骤3打断（交点 P 距离 A 为 4mm）：
  A────P──────────B
  4mm  5mm

步骤4过滤：
  (删除)  P──────────B
          5mm

最终结果：
  原本 9mm 的线段只剩 5mm
  丢失了 4mm 的部分
```

**核心思想**：将打断保护阈值设置为与过滤阈值一致

## 📊 参数配置建议

### 推荐配置

| 场景       | minLineLength | minBreakThreshold | 说明                   |
| ---------- | ------------- | ----------------- | ---------------------- |
| 精细图纸   | 3.0mm         | 3.0mm             | 保留较短线段           |
| 一般图纸   | 5.0mm         | 5.0mm             | 标准配置（推荐）       |
| 粗略图纸   | 10.0mm        | 10.0mm            | 只保留较长线段         |

### 配置原则

```
minBreakThreshold = minLineLength

原因：
1. 避免打断后立即被过滤
2. 保持逻辑一致性
3. 用户预期：设置 minLength = 5mm，就不应该打断成 < 5mm 的段
```

## 🎯 总结

### 问题根源

```
打断保护阈值（0.5mm）< 过滤阈值（5.0mm）
↓
允许打断成 0.5mm ~ 5.0mm 的线段
↓
这些线段在步骤4被删除
↓
用户困惑：9mm 的线段为什么被删除了？
```

### 解决方案

```
minBreakThreshold = minLineLength = 5.0mm
↓
不允许打断成 < 5.0mm 的线段
↓
所有打断后的线段都 >= 5.0mm
↓
步骤4不会删除任何打断后的线段
↓
逻辑一致，用户预期符合
```

### 关键改进

1. ✅ **参数统一**：`minBreakThreshold = minLineLength`
2. ✅ **逻辑一致**：打断和过滤使用相同的阈值
3. ✅ **用户友好**：输出显示保护阈值
4. ✅ **向后兼容**：默认值仍为 0.5mm，不影响旧代码

### 预期效果

- ✅ 9mm 的线段不会被删除
- ✅ 只有在打断后两段都 >= 5mm 时才打断
- ✅ 用户设置 minLength = 5mm，就不会产生 < 5mm 的线段
- ✅ 逻辑清晰，易于理解和调试
