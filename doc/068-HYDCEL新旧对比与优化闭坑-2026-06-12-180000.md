## 1. 为何生成新方法

HYDCEL 从选定曲线构建 **DCEL（Doubly Connected Edge List，双向连通边表）**，识别闭合区域并绘制外轮廓/内孔。

2026-06 对旧实现做全链路审查，发现 **5 类几何算法漏洞 + 3 处 O(E²) 性能热点 + 容差/渲染分裂**。旧代码在纯直线大数据集上「面数碰巧一致」，但构建耗时随边数平方级恶化；含弧场景会出现 **补弧、顶点分裂、反向 bulge 错误** 等静默几何偏差。

**新方法目标**：

1. **正确性**：Bulge/跨 0° 弧/整圆/反向遍历的 bulge 恢复与构建容差一致  
2. **性能**：构建阶段从 O(E²) 降为 O(E log E) 量级（排序主导）  
3. **可验证**：`HYDCELSET` 开 `VerboseTiming` 输出 7 段耗时；DEBUG 下拓扑 `Validate`

## 2. 实测对比（22816 直线网格，2026-06-12）

| 指标 | 新 (N12) | 旧 (N13) | 结论 |
|------|----------|----------|------|
| 输入 | 22816 实体 → 22816 段，曲线 0 | 同左 | — |
| 顶点 | 22448 | 22448 | 一致 |
| 边 | 22448 | 22448 | 一致 |
| 面 | 2816（1408 外 + 1408 内） | 同左 | **几何等价** |
| 拓扑验证 | 通过 | 通过 | 一致 |
| **DCEL 构建** | **66 ms (44.9%)** | **1315 ms (84.7%)** | **旧/新 ≈ 19.9×** |
| 提取+简化 | 26 ms | 137 ms | 旧/新 5.3×（旧路径冗余） |
| 渲染 | 49 ms | 96 ms | 旧/新 2.0× |
| **合计含渲染** | **147 ms** | **1552 ms** | **旧/新 ≈ 10.6×** |
| 合计不含渲染 | 94 ms | 1454 ms | 旧/新 ≈ 15.5× |

**本数据集结论**：纯直线、容差 0.01、不恢复原曲线 —— **拓扑完全一致，优势几乎全部来自 DCEL 构建阶段**。

**尚未在本数据集验证的差异**（须另测含弧/圆/椭圆）：

- 多段线负 bulge 圆心计算  
- 跨 0° 独立 Arc 离散方向  
- 整圆恢复（旧版 bulge=∞）  
- 反向遍历面的 bulge 符号  
- 构建/匹配容差分裂导致弧静默变直线

## 3. 旧实现缺陷 → 新实现对策（闭坑对照表）

| # | 旧代码错误 | 症状 | 新实现 | 禁止再犯 |
|---|-----------|------|--------|----------|
| **P1** | `BulgeToArc` 用弓高 sagitta 当圆心距 apothem；负 bulge 方向错；起止角各自 `[0,2π)` 归一化 | 含弧多段线简化几何全错 | 唯一 `BulgeToArc2D`：apothem=`radius-sagitta`，CCW 规范（负 bulge 交换起止角） | **禁止** 第二套 Bulge 转换；**禁止** sagitta 当 apothem |
| **P2** | `Arc` 实体 `EndAngle<StartAngle`（跨 0°）未 `+=2π` | 离散成补弧（弧画到圆另一侧） | `ToArc2D` 构造前归一化 | AutoCAD 弧进 `Arc2D` **必须** CCW 扫掠角 |
| **P3** | 整圆单条 `Arc2D(0,2π)` | 恢复模式 bulge=tan(π/2)=∞，面被丢弃 | 拆两个半圆 mapping | 整圆 **必须** 拆半圆再恢复 |
| **P4** | `Point2DEqualityComparer`：`Equals` 容差比较，`GetHashCode` 网格取整 | 容差内两点不同哈希桶 → 顶点分裂 → 面偶发不闭合 | `Equals`/`GetHashCode` **同一量化函数** | Dictionary 键比较器 **必须** 量化语义一致 |
| **P5** | 匹配容差 1e-3，构建容差 0.01 | 顶点合并后偏移超匹配容差 → 弧恢复变直线 | `DCELSettings.Tolerance` 贯穿构建与匹配（匹配取 2×） | 构建/渲染匹配 **必须** 同源容差 |
| **P6** | 反向弧：构造交换起止角的 `Arc2D` | `SweepAngle` 恒正 → 永远是逆时针补弧 | 仅翻转 bulge 符号 `±tan(sweep/4)` | **禁止** 用交换角度「反转 Arc2D」表达顺时针 |
| **P7** | `RemoveIsolatedVertices` 每轮全表扫描 + `MaxIterations=1000` | 22816 边构建 ~1.3s；长悬挂链可能剪不干净 | 队列式度数剥离 O(V+E)，无迭代上限 | 图清理 **禁止** 固定小迭代上限 + 全表重复扫 |
| **P8** | `BuildFacesFromHalfEdges` 每轮 `FirstOrDefault` 全扫 | O(E²) 面遍历 | 排序后索引推进 | 面构建 **禁止** 每轮线性找起始边 |
| **P9** | `Render()` 全局 `Distinct` 顶点 | 「8 字形」合法面顶点被误删 | 仅去相邻重复点 | 面顶点 **禁止** 全局 Distinct |
| **P10** | 零长/重复线段不过滤 | 自环半边、重复边 | 入口过滤零长 + 无向边去重 | 进 DCEL 前 **必须** 过滤退化段 |
