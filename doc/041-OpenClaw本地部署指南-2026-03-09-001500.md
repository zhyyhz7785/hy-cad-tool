# OpenClaw + Ollama 本地部署指南（Win11）

> **硬件环境**：i9-12900KF / 64GB DDR4 / RTX 3080 10GB / Win11  
> **目标**：本地部署 OpenClaw Agent，使用 `qwen2.5:14b` 作为推理模型  
> **日期**：2026-03-09

---

## 一、磁盘规划

### 容量需求

| 组件 | 大小 | 说明 |
|---|---|---|
| Ollama 程序 | ~200 MB | 安装包 + 运行时 |
| `qwen2.5:14b` 模型 | **~9 GB** | Q4_K_M 量化，默认版本 |
| `qwen2.5:7b`（可选备用） | ~4.5 GB | 快速响应场景 |
| OpenClaw CLI | ~300 MB | npm 全局包 + 依赖 |
| Node.js 运行时 | ~200 MB | LTS 版本 |
| **合计（最小）** | **~10 GB** | 仅装一个 14B 模型 |
| **合计（推荐）** | **~15 GB** | 14B + 7B 双模型 + 余量 |

### 路径规划建议

```
C:\                          ← 系统盘，不放模型
├── Program Files\Ollama\    ← Ollama 程序（安装时默认）
│
D:\ 或 E:\                   ← 数据盘，放模型和配置
├── OllamaModels\            ← 模型存储（通过环境变量指定）
│   └── blobs\               ← Ollama 自动创建
├── OpenClaw\                ← OpenClaw 工作目录（可选）
```

**核心原则**：模型文件 9GB+ 起步，放数据盘（D: 或 E:），不占 C 盘空间。

## 二、安装 Ollama

### 2.1 下载安装

1. 打开浏览器访问：https://ollama.com/download/windows
2. 下载 `OllamaSetup.exe`
3. 双击运行，默认选项安装即可（无需管理员权限）

### 2.2 验证安装

打开 PowerShell：

```powershell
ollama --version
```

应输出类似 `ollama version 0.x.x`。

### 2.3 修改模型存储路径（重要）

默认模型存放在 `C:\Users\你的用户名\.ollama\models`，会占满 C 盘。必须改到数据盘。

**步骤**：

1. 按 `Win + I` 打开设置 → 搜索"环境变量" → 点击"编辑账户的环境变量"
2. 在"用户变量"区域点击 **新建**：
   - 变量名：`OLLAMA_MODELS`
   - 变量值：`E:\OllamaModels`（改成你想要的路径）
3. 点击 **确定** 保存
4. **右键任务栏 Ollama 图标 → Quit**，然后重新启动 Ollama

验证路径生效：

```powershell
ollama list
# 此时应显示空列表，模型将下载到新路径
```

### 2.4 设置上下文窗口（重要）

OpenClaw Agent 需要较大的上下文窗口，Ollama 默认只有 2048 太小。

同样在"用户环境变量"中新建：

- 变量名：`OLLAMA_NUM_CTX`
- 变量值：`16384`

> 16K 上下文对 Agent 任务够用，且 10GB VRAM 跑 14B 模型时不会 OOM。  
> 如果显存告警，可降为 `8192`。

## 三、下载模型

### 3.1 主力模型

```powershell
ollama pull qwen2.5:14b
```

下载约 9GB，视网速需要 5-30 分钟。

### 3.2 备用模型（可选）

```powershell
# 速度优先的轻量模型
ollama pull qwen2.5:7b

# 代码专用版（如果经常让 Agent 写代码）
ollama pull qwen2.5-coder:14b
```

### 3.3 验证模型

```powershell
# 查看已下载的模型
ollama list

# 快速测试（应在几秒内响应）
ollama run qwen2.5:14b "你好，请用一句话介绍自己"
```

测试完毕按 `Ctrl+D` 或输入 `/bye` 退出。

## 四、安装 OpenClaw

### 4.1 前置依赖：Node.js

如果还没装 Node.js：

```powershell
# 方式一：winget（推荐）
winget install OpenJS.NodeJS.LTS

# 方式二：手动下载
# https://nodejs.org → 下载 LTS 版本安装
```

验证：

```powershell
node --version    # 应 >= 18.x
npm --version     # 应 >= 9.x
```

### 4.2 安装 OpenClaw CLI

```powershell
npm install -g @openclaw/cli
```

验证：

```powershell
openclaw --version
```

### 4.3 初始化配置

```powershell
openclaw onboard
```

引导程序会问几个问题：

| 问题 | 选择 |
|---|---|
| AI Provider | 选 **Ollama (Local)** |
| Model | 输入 `qwen2.5:14b` |
| API URL | `http://127.0.0.1:11434` |

## 五、配置 OpenClaw 连接 Ollama

如果需要手动编辑配置文件：

**配置文件位置**：`%USERPROFILE%\.openclaw\openclaw.json`

```json
{
  "models": {
    "providers": {
      "ollama": {
        "baseUrl": "http://127.0.0.1:11434/v1",
        "apiKey": "ollama-local",
        "api": "openai-responses",
        "models": [
          {
            "id": "qwen2.5:14b",
            "name": "Qwen 2.5 14B",
            "contextWindow": 16384,
            "maxOutput": 4096
          },
          {
            "id": "qwen2.5:7b",
            "name": "Qwen 2.5 7B (Fast)",
            "contextWindow": 16384,
            "maxOutput": 4096
          }
        ]
      }
    },
    "defaults": {
      "model": {
        "primary": "ollama/qwen2.5:14b"
      }
    }
  }
}
```

**关键配置说明**：

| 字段 | 值 | 注意 |
|---|---|---|
| `baseUrl` | `http://127.0.0.1:11434/v1` | 必须带 `/v1` |
| `apiKey` | 任意非空字符串 | Ollama 不校验，但字段不能省 |
| `api` | `openai-responses` | 必须指定，否则 Tool Calling 不工作 |
| `contextWindow` | `16384` | 与环境变量 `OLLAMA_NUM_CTX` 一致 |
| model `id` | 必须与 `ollama list` 输出完全一致 | 包括 tag（`:14b`） |

## 七、日常使用

### 启动顺序

1. **Ollama**：开机自启（安装后默认），无需手动操作
2. **OpenClaw**：按需启动

```powershell
# 启动 Agent
openclaw start

# 或直接对话
openclaw chat "你的指令"
```

### 切换模型

```powershell
# 临时用 7B（快速任务）
openclaw chat --model ollama/qwen2.5:7b "快速回答一个问题"

# 改默认模型
# 编辑 openclaw.json 中的 defaults.model.primary
```

### 显存不足时的应急方案

如果跑 14B 时 AutoCAD 等软件显存不够：

```powershell
# 方案一：临时切 7B（省 4GB 显存）
openclaw chat --model ollama/qwen2.5:7b "..."

# 方案二：停掉 Ollama 释放显存
# 右键任务栏 Ollama 图标 → Quit
```

## 九、故障排查

| 问题 | 排查 |
|---|---|
| `ollama` 命令找不到 | 重启 PowerShell，或检查 PATH 是否包含 Ollama |
| 模型下载慢 | 考虑使用代理：设置 `HTTPS_PROXY` 环境变量 |
| OpenClaw Tool Calling 失败 | 确认 `api` 字段为 `openai-responses`；确认模型 ID 精确匹配 |
| 显存 OOM | 降低 `OLLAMA_NUM_CTX` 到 `8192`，或切换 7B 模型 |
| 响应乱码/中英混杂 | 在 OpenClaw 的 system prompt 中明确要求"使用中文回复" |
| Ollama 端口被占 | `netstat -ano | findstr 11434` 查看占用进程 |
