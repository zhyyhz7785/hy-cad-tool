# OpenClaw 使用说明（本地 Ollama + qwen3:14b）

> 本文只讲「日常怎么用」，安装与网络细节见 `041-OpenClaw本地部署指南-2026-03-09-003724.md`。

适用前提：

- Windows 侧 Ollama 已安装并能在 PowerShell 里看到模型：
  - `curl.exe http://127.0.0.1:11434/api/tags`
- WSL2 Ubuntu 中已安装好 OpenClaw，且配置了：
  - `baseUrl = http://172.27.160.1:11434`（示例，为你的宿主机 IP）
  - 默认模型：`ollama/qwen3:14b`（或你实际设置的）

---

## 1. 每次使用的启动步骤

### 1.1 启动 WSL 和 Gateway

在 Windows PowerShell 中：

```powershell
wsl
```

进入 WSL 终端后（当前为 `root@Administrator`）：

```bash
# 检查 gateway 状态
openclaw gateway status
```

- 若已是 `running`，可直接跳到 **1.2**。
- 若不是 running，启动：

```bash
openclaw gateway
```

> 提示：`openclaw gateway` 前台运行时当前终端会被占用，习惯上可以开一个新 Terminal 窗口来跑 TUI 或其它命令。

### 1.2 启动 TUI（终端对话界面）

在 WSL 中打开一个**新的**终端会话（或新标签）：

```bash
openclaw tui
```

看到类似：

```text
openclaw tui - ws://127.0.0.1:18789 - agent main - session main
gateway connected | idle
agent main | session main | unknown | tokens ?/33k
```

即可开始对话，在底部输入内容回车即可发送。

### 1.3 启动 Web 控制台（可选）

如果更习惯浏览器界面，在 WSL 中执行：

```bash
openclaw dashboard
```

会自动打开浏览器访问网关面板（默认 `http://127.0.0.1:18789/`）。

## 2. 日常对话与模型

### 2.1 确认当前默认模型

在 WSL 中执行：

```bash
openclaw models list
```

示例输出（简化）：

```text
Model               Input   Ctx    Local Auth  Tags
ollama/qwen3:14b    text    32k    no    yes   default
```

- `ollama/qwen3:14b` 行带有 `default` 标签，表示当前默认模型。
- `Auth yes` 表示配置与连通正常。

查看所有已注册的 Ollama 模型（包括非默认）：

```bash
openclaw models list --all
```

### 2.2 在 TUI 中发起对话

在 `openclaw tui` 界面中输入内容回车即可，例如：

```text
你好，请用中文回答。你是什么模型？只要一句话介绍自己。
```

如果配置使用的是 `qwen3:14b`，模型一般会在数秒到十几秒内给出回答（首次加载可能更慢）。

### 2.3 切换默认模型（如果你有多个本地模型）

假设 `openclaw.json` 里已经为 Ollama 注册了多个模型（如 `gemma3:12b`、`qwen3:8b` 等），可以这样切换默认：

```bash
openclaw config set agents.defaults.model ollama/gemma3:12b
openclaw models list
```

再次查看时，`default` 标签会落在新的模型上。

> 提示：切换默认模型只是改变「不显式指定时默认用谁」，实际调用也可以在一些高级用法中单独指定模型。

## 3. 常用命令速查

在 WSL 的 Ubuntu 中：

- **查看 OpenClaw 全部命令帮助**

  ```bash
  openclaw --help
  ```

- **检查健康情况 / 自动修复**

  ```bash
  openclaw doctor
  openclaw doctor --fix
  ```

- **查看当前 Gateway 状态**

  ```bash
  openclaw gateway status
  ```

- **启动 Gateway（前台）**

  ```bash
  openclaw gateway
  ```

- **打开终端 UI（TUI）对话**

  ```bash
  openclaw tui
  ```

- **打开 Web 控制台**

  ```bash
  openclaw dashboard
  ```

- **查看/管理模型**

  ```bash
  openclaw models list          # 常用/默认模型
  openclaw models list --all    # 所有已注册模型
  ```

- **查看会话列表**

  ```bash
  openclaw sessions list
  ```

## 4. 暂时停用 OpenClaw

### 4.1 关闭 TUI

在 `openclaw tui` 的终端窗口中：

```text
Ctrl + C
```

### 4.2 停止 Gateway 服务

在 WSL 中：

```bash
openclaw gateway stop || systemctl --user stop openclaw-gateway
openclaw gateway status
```

`status` 显示 stopped 即可。

### 4.3 完全停止 WSL（当天不用时）

在 Windows PowerShell 中：

```powershell
wsl --shutdown
```

## 5. 简单故障排查

### 5.1 TUI 显示 connected，但长时间没回复

按顺序检查：

1. 在 Windows PowerShell 中看 Ollama 是否在跑：

   ```powershell
   curl.exe http://127.0.0.1:11434/api/ps
   ```

   - 若有 `qwen3:14b` 等正在运行，说明还在生成，耐心等待即可。

2. 在 WSL 中确认仍能访问 Ollama：

   ```bash
   curl http://172.27.160.1:11434/api/tags
   ```

   - 若无输出或报错，先恢复 Ollama 或网络，再重启 `openclaw gateway`。

3. 运行自检与修复：

   ```bash
   openclaw doctor --fix
   ```

### 5.2 `openclaw` 报配置错误（config invalid）

1. 确认配置文件存在且内容为有效 JSON：

   ```bash
   cat ~/.openclaw/openclaw.json
   ```

2. 若之前误把命令行输出写进了 JSON（常见错误），可以参照部署指南 `041` 中的示例重新覆盖写入一份干净的配置，然后：

   ```bash
   openclaw doctor --fix
   openclaw models list
   ```

### 5.3 WSL 里访问 `127.0.0.1:11434` 报错

原因是：WSL 自己的 `127.0.0.1` 和 Windows 的 `127.0.0.1` 不是同一个地址。

- 在 WSL 中应该用宿主机 IP，例如：

  ```bash
  curl http://172.27.160.1:11434/api/tags
  ```

- 在 `openclaw.json` 里相应地使用：

  ```json
  "baseUrl": "http://172.27.160.1:11434"
  ```

详情可参考 `041` 文档中关于网络与 `OLLAMA_HOST` 的解释。

## 6. 推荐的日常使用流程小抄

1. **启动**
   - Windows PowerShell：`wsl`
   - WSL：`openclaw gateway status`，如未 running 则执行 `openclaw gateway`
   - 新终端：`openclaw tui`
2. **确认模型**
   - `openclaw models list`，确认默认是 `ollama/qwen3:14b`
3. **开始对话**
   - 在 TUI 里输入中文问题/任务说明
4. **完成后关闭**
   - TUI：`Ctrl + C`
   - WSL（可选）：Windows PowerShell 中 `wsl --shutdown`

这样即可在本机稳定使用 OpenClaw + 本地 Ollama 模型，而无需每次重新阅读长文档。
