## 概述

### 三个步骤的职责

```
输入：原始线段集合
  ↓
┌─────────────────────────────────────────┐
│ 步骤1：打断相交线段                      │
│ - 找到所有相交点                         │
│ - 在相交点处打断线段                     │
│ - 避免产生极短线段（< 0.5mm）            │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ 步骤2：端点延伸                          │
│ - 找到端点距离很近的线段对               │
│ - 延伸到交点（FILLET R=0）               │
│ - 只处理端点距离 ≤ MaxExtendDistance     │
└─────────────────────────────────────────┘
  ↓
┌─────────────────────────────────────────┐
│ 步骤3：端点到线延伸                      │
│ - 找到端点接近线段的情况                 │
│ - 延伸端点到线段                         │
│ - 打断被延伸到的线段                     │
│ - 只处理距离 ≤ MaxExtendDistance         │
└─────────────────────────────────────────┘
  ↓
输出：处理后的线段集合（未过滤）
```

### 关键参数

| 参数名称          | 默认值 | 作用范围     | 说明                           |
| ----------------- | ------ | ------------ | ------------------------------ |
| tolerance         | 1e-6   | 所有步骤     | 几何容差（点重合判断）         |
| minBreakThreshold | 0.5    | 步骤1、3     | 打断保护阈值（避免极短线段）   |
| maxDistance       | 10.0   | 步骤2、3     | 端点延伸最大距离               |
| minLength         | 5.0    | 统一过滤步骤 | 最小线段长度（最终过滤使用）   |

## 步骤1：打断相交线段

### 几何原理

**目标**：在所有线段的相交点处打断线段，使得没有线段相交。

**输入**：
```
Line1: A─────────B
         ╲
          ╲
           ╲
Line2:      C─────D
```

**输出**：
```
Line1a: A────P
Line1b:      P────B
Line2a: C────P
Line2b:      P────D

其中 P 是交点
```

### 代码实现

**主方法**：`BreakAtIntersections`

```csharp
public List<Line2D> BreakAtIntersections(IEnumerable<Line2D> lines, double tolerance)
{
    var lineList = lines.ToList();
    
    // 使用固定阈值 0.5mm 避免产生极短线段
    const double minBreakThreshold = 0.5;
    var brokenLines = SplitAtIntersections(lineList, tolerance, minBreakThreshold);
    
    return brokenLines;  // 不过滤，直接返回
}
```

**核心算法**：`SplitAtIntersections`

```csharp
private List<Line2D> SplitAtIntersections(List<Line2D> lines, double tolerance, double minBreakThreshold = 0.5)
{
    // 1. 存储每条线段的分割点（使用投影参数）
    var splitParams = new Dictionary<int, List<double>>();
    
    // 2. 初始化
    for (int i = 0; i < lines.Count; i++)
    {
        splitParams[i] = new List<double>();
    }
    
    // 3. 计算所有交点
    for (int i = 0; i < lines.Count; i++)
    {
        for (int j = i + 1; j < lines.Count; j++)
        {
            var intersection = lines[i].GetIntersection(lines[j], tolerance);
            if (intersection != default)
            {
                // 计算交点在两条线段上的投影参数
                double param1 = GetProjectionParameter(lines[i], intersection);
                double param2 = GetProjectionParameter(lines[j], intersection);
                
                // 智能打断：检查打断后的两段长度
                double length1 = lines[i].Length;
                double length2 = lines[j].Length;
                
                // 对于 line1：检查打断后的两段长度
                double segment1A = param1 * length1;        // 起点到交点的长度
                double segment1B = (1 - param1) * length1;  // 交点到终点的长度
                
                if (segment1A >= minBreakThreshold && segment1B >= minBreakThreshold)
                {
                    splitParams[i].Add(param1);
                }
                
                // 对于 line2：检查打断后的两段长度
                double segment2A = param2 * length2;
                double segment2B = (1 - param2) * length2;
                
                if (segment2A >= minBreakThreshold && segment2B >= minBreakThreshold)
                {
                    splitParams[j].Add(param2);
                }
            }
        }
    }
    
    // 4. 分割线段
    var result = new List<Line2D>();
    for (int i = 0; i < lines.Count; i++)
    {
        if (splitParams[i].Count == 0)
        {
            result.Add(lines[i]);  // 没有交点，保留原线段
        }
        else
        {
            var segments = SplitLineAtParameters(lines[i], splitParams[i]);
            result.AddRange(segments);  // 有交点，分割线段
        }
    }
    
    return result;
}
```

### 几何细节

#### 1. 投影参数计算

**定义**：投影参数 `t` 表示点在线段上的相对位置
- `t = 0.0` → 起点
- `t = 0.5` → 中点
- `t = 1.0` → 终点

**计算方法**：

```csharp
private double GetProjectionParameter(Line2D line, Point2D point)
{
    Vector2D lineVec = line.Direction;  // 线段方向向量
    Vector2D pointVec = new Vector2D(point.X - line.StartPoint.X, point.Y - line.StartPoint.Y);
    
    double lineLength = line.Length;
    if (lineLength < 1e-10) return 0.0;
    
    // 投影公式：t = (pointVec · lineVec) / |lineVec|²
    double projection = lineVec.Dot(pointVec) / (lineLength * lineLength);
    return Math.Max(0.0, Math.Min(1.0, projection));
}
```

**几何意义**：

```
Line: A────────────────B
      ↑       ↑        ↑
      t=0    t=0.5    t=1

Point P 在线段上的投影参数：
t = |AP| / |AB|
```

#### 2. 智能打断判断

**问题**：如果交点太接近端点，打断会产生极短线段

**示例**：

```
Line: A──────────────B
      ↑             ↑
      P1           P2
      
P1 距离 A 很近（0.1mm）
P2 距离 B 很近（0.1mm）

如果打断：
- A→P1 长度 = 0.1mm（极短，无用）
- P1→B 长度 = 99.9mm（正常）
```

**解决方案**：使用绝对距离判断

```csharp
double segment1A = param1 * length1;        // 起点到交点的绝对长度
double segment1B = (1 - param1) * length1;  // 交点到终点的绝对长度

// 只有两段长度都 >= 0.5mm 才打断
if (segment1A >= 0.5 && segment1B >= 0.5)
{
    splitParams[i].Add(param1);
}
```

**对比**：

| 方法           | 判断条件                     | 问题                           |
| -------------- | ---------------------------- | ------------------------------ |
| 旧方法（相对） | `param > 0.01 && param < 0.99` | 短线段（10mm）仍会在端点附近打断 |
| 新方法（绝对） | `segmentA >= 0.5 && segmentB >= 0.5` | 统一标准，避免极短线段         |

#### 3. 分割线段

**输入**：
- 线段：A─────────B（长度 100mm）
- 分割参数：[0.3, 0.7]

**输出**：
```
Segment1: A────P1 (0 → 0.3, 长度 30mm)
Segment2: P1───P2 (0.3 → 0.7, 长度 40mm)
Segment3: P2───B (0.7 → 1.0, 长度 30mm)
```

**代码**：

```csharp
private List<Line2D> SplitLineAtParameters(Line2D line, List<double> parameters)
{
    // 添加起点和终点参数
    var allParams = new List<double> { 0.0 };
    allParams.AddRange(parameters);
    allParams.Add(1.0);
    
    // 排序并去重
    allParams = allParams.Distinct().OrderBy(p => p).ToList();
    
    // 创建线段
    var segments = new List<Line2D>();
    for (int i = 0; i < allParams.Count - 1; i++)
    {
        double t1 = allParams[i];
        double t2 = allParams[i + 1];
        
        if (Math.Abs(t2 - t1) > 1e-10)
        {
            Point2D p1 = line.StartPoint.Add(line.Direction * t1);
            Point2D p2 = line.StartPoint.Add(line.Direction * t2);
            segments.Add(new Line2D(p1, p2));
        }
    }
    
    return segments;
}
```

### 几何案例

#### 案例1：标准相交

**输入**：
```
Line1: (0,0) → (10,0)   水平线
Line2: (5,-5) → (5,5)   垂直线
```

**处理过程**：
1. 计算交点：P = (5, 0)
2. 计算投影参数：
   - Line1: param1 = 5/10 = 0.5
   - Line2: param2 = 5/10 = 0.5
3. 检查长度：
   - Line1: segment1A = 0.5 × 10 = 5mm ✅, segment1B = 0.5 × 10 = 5mm ✅
   - Line2: segment2A = 0.5 × 10 = 5mm ✅, segment2B = 0.5 × 10 = 5mm ✅
4. 打断：
   - Line1 → Line1a: (0,0)→(5,0), Line1b: (5,0)→(10,0)
   - Line2 → Line2a: (5,-5)→(5,0), Line2b: (5,0)→(5,5)

**输出**：4条线段

#### 案例2：端点附近相交（不打断）

**输入**：
```
Line1: (0,0) → (10,0)   长度 10mm
Line2: (0.3,-5) → (0.3,5)  垂直线，距离 Line1 起点 0.3mm
```

**处理过程**：
1. 计算交点：P = (0.3, 0)
2. 计算投影参数：
   - Line1: param1 = 0.3/10 = 0.03
3. 检查长度：
   - Line1: segment1A = 0.03 × 10 = 0.3mm ❌ < 0.5mm
   - Line1: segment1B = 0.97 × 10 = 9.7mm ✅
4. **不打断** Line1（避免产生 0.3mm 的极短线段）

**输出**：2条线段（保持原样）

#### 案例3：多个交点

**输入**：
```
Line1: (0,0) → (10,0)
Line2: (3,-5) → (3,5)
Line3: (7,-5) → (7,5)
```

**处理过程**：
1. Line1 与 Line2 相交于 (3,0)，param1 = 0.3
2. Line1 与 Line3 相交于 (7,0)，param1 = 0.7
3. Line1 的分割参数：[0.3, 0.7]
4. 分割 Line1：
   - (0,0)→(3,0)
   - (3,0)→(7,0)
   - (7,0)→(10,0)

**输出**：7条线段（Line1 分3段，Line2、Line3 各分2段）

## 步骤2：端点延伸

### 几何原理

**目标**：找到端点距离很近的线段对，延伸到它们的交点（FILLET R=0）。

**输入**：
```
Line1: A─────B
              ↘ (距离 d)
               ↘
Line2:          C─────D

端点距离：d = |B - C|
```

**输出**（如果 d ≤ maxDistance）：
```
Line1: A─────────P
                 ↓
Line2:           P─────D

其中 P 是 Line1 和 Line2 无限延长线的交点
```

### 代码实现

**主方法**：`ExtendNearEndpoints`

```csharp
public List<Line2D> ExtendNearEndpoints(IEnumerable<Line2D> lines, double tolerance, double maxDistance = 10.0)
{
    var lineList = lines.ToList();
    var result = new List<Line2D>();
    var processed = new HashSet<int>();

    for (int i = 0; i < lineList.Count; i++)
    {
        if (processed.Contains(i))
        {
            result.Add(lineList[i]);
            continue;
        }
        
        Line2D currentLine = lineList[i];
        bool extended = false;
        
        // 检查与其他线段的端点距离
        for (int j = 0; j < lineList.Count; j++)
        {
            if (i == j || processed.Contains(j)) continue;
            
            Line2D otherLine = lineList[j];
            
            // 检查四种端点组合
            var nearPairs = new[]
            {
                (currentLine.EndPoint, otherLine.StartPoint, true, true),    // current.End - other.Start
                (currentLine.EndPoint, otherLine.EndPoint, true, false),     // current.End - other.End
                (currentLine.StartPoint, otherLine.StartPoint, false, true), // current.Start - other.Start
                (currentLine.StartPoint, otherLine.EndPoint, false, false)   // current.Start - other.End
            };
            
            foreach (var (p1, p2, isCurrentEnd, isOtherStart) in nearPairs)
            {
                double distance = p1.DistanceTo(p2);
                
                // 关键判断：只处理距离在 (tolerance, maxDistance] 范围内的端点对
                if (distance > tolerance && distance <= maxDistance)
                {
                    // 计算无限延长线的交点
                    var intersection = currentLine.GetIntersectionWithInfiniteLine(otherLine, tolerance);

                    if (intersection != default)
                    {
                        // 延伸当前线段到交点
                        if (isCurrentEnd)
                        {
                            currentLine = new Line2D(currentLine.StartPoint, intersection);
                        }
                        else
                        {
                            currentLine = new Line2D(intersection, currentLine.EndPoint);
                        }
                        
                        // 延伸另一条线段到交点
                        if (isOtherStart)
                        {
                            lineList[j] = new Line2D(intersection, otherLine.EndPoint);
                        }
                        else
                        {
                            lineList[j] = new Line2D(otherLine.StartPoint, intersection);
                        }
                        
                        extended = true;
                        break;
                    }
                }
            }
            
            if (extended) break;
        }
        
        result.Add(currentLine);
        processed.Add(i);
    }

    return result;
}
```

### 几何细节

#### 1. 四种端点组合

**为什么要检查四种组合？**

因为两条线段有 4 个端点，任意两个端点都可能接近：

```
Line1: A─────B
Line2: C─────D

四种组合：
1. B - C (End - Start)   最常见：首尾相接
2. B - D (End - End)     两条线段尾部接近
3. A - C (Start - Start) 两条线段头部接近
4. A - D (Start - End)   交叉接近
```

**示例**：

```
组合1 (End - Start)：
Line1: ─────B
            ↘ d
             C─────
Line2:

组合2 (End - End)：
Line1: ─────B
            ↙ d
       D─────
Line2:

组合3 (Start - Start)：
       A─────
Line1: ↘ d
        C─────
Line2:

组合4 (Start - End)：
       A─────
Line1: ↙ d
  ─────D
Line2:
```

#### 2. 距离判断

**关键代码**：

```csharp
if (distance > tolerance && distance <= maxDistance)
```

**几何意义**：

```
tolerance = 1e-6 (0.000001mm)
maxDistance = 10.0mm

处理范围：0.000001mm < distance ≤ 10.0mm

不处理的情况：
1. distance ≤ 1e-6：端点已经重合，无需延伸
2. distance > 10.0：端点太远，不延伸
```

**这就是您遇到的问题的根源**：

```
如果设置：
maxDistance = 10.0mm
minLength = 5.0mm

线段长度 = 8.0mm
端点距离 = 12.0mm

结果：
- 端点距离 12.0 > 10.0 → 不延伸
- 线段保持 8.0mm → 通过过滤（8.0 > 5.0）
- 但线段仍然是断开的！
```

#### 3. 无限延长线交点

**计算方法**：

```csharp
var intersection = currentLine.GetIntersectionWithInfiniteLine(otherLine, tolerance);
```

**几何原理**：

```
Line1: A─────B (有限线段)
       ↘
        ↘ (延长)
         ↘
          P (交点)
         ↗
        ↗ (延长)
       ↗
Line2: C─────D (有限线段)

计算步骤：
1. 将 Line1 和 Line2 视为无限直线
2. 计算两条直线的交点 P
3. 延伸线段到 P
```

**数学公式**：

```
Line1: P = A + t1 * (B - A)
Line2: P = C + t2 * (D - C)

求解：
A + t1 * (B - A) = C + t2 * (D - C)

得到 t1 和 t2，代入得交点 P
```

#### 4. 延伸操作

**延伸当前线段**：

```csharp
if (isCurrentEnd)
{
    // 延伸终点
    currentLine = new Line2D(currentLine.StartPoint, intersection);
}
else
{
    // 延伸起点
    currentLine = new Line2D(intersection, currentLine.EndPoint);
}
```

**几何效果**：

```
延伸终点：
Before: A─────B
After:  A─────────P

延伸起点：
Before:       B─────C
After:  P─────────C
```

### 几何案例

#### 案例1：标准端点延伸（距离 5mm）

**输入**：
```
Line1: (0,0) → (10,0)   水平线
Line2: (15,0) → (25,5)  斜线

端点距离：|Line1.End - Line2.Start| = |(10,0) - (15,0)| = 5mm
```

**处理过程**：
1. 检查端点距离：5mm ≤ 10mm ✅
2. 计算无限延长线交点：
   - Line1 延长线：y = 0
   - Line2 延长线：y = 0.5(x - 15)
   - 交点：P = (15, 0)
3. 延伸：
   - Line1: (0,0) → (15,0)
   - Line2: (15,0) → (25,5)

**输出**：两条线段在 (15,0) 连接

#### 案例2：端点距离过大（距离 12mm，不延伸）

**输入**：
```
Line1: (0,0) → (10,0)
Line2: (22,0) → (32,5)

端点距离：|(10,0) - (22,0)| = 12mm
```

**处理过程**：
1. 检查端点距离：12mm > 10mm ❌
2. **不延伸**

**输出**：两条线段保持原样，中间有 12mm 的间隙

**这就是您看到的问题**：
- 短线段（长度 8mm）如果与其他线段的端点距离 > 10mm
- 无法延伸连接
- 保持原样进入过滤步骤
- 如果长度 < 5mm，会被删除
- 如果长度 ≥ 5mm，会被保留（但仍然是断开的）

#### 案例3：端点已重合（距离 0.0001mm）

**输入**：
```
Line1: (0,0) → (10,0)
Line2: (10.0001,0) → (20,5)

端点距离：0.0001mm
```

**处理过程**：
1. 检查端点距离：0.0001mm ≤ 1e-6 ❌
2. **不延伸**（端点已经足够接近，视为重合）

**输出**：保持原样

#### 案例4：多个候选（选择最近的）

**输入**：
```
Line1: (0,0) → (10,0)
Line2: (15,0) → (25,5)   距离 5mm
Line3: (13,0) → (23,5)   距离 3mm
```

**处理过程**：
1. 检查 Line1 与 Line2：距离 5mm ✅
2. 检查 Line1 与 Line3：距离 3mm ✅
3. **只延伸一次**（代码中 `if (extended) break;`）
4. 延伸到第一个找到的（Line2）

**输出**：Line1 延伸到 Line2，Line3 保持原样

## 步骤3：端点到线延伸

### 几何原理

**目标**：找到端点接近线段的情况，延伸端点到线段，并打断线段。

**输入**：
```
Line1: A─────B
        ↘
         ↘
          ↘
Line2:     ───C─────D───

端点到线段的距离：d = |B 到 Line2 的垂直距离|
```

**输出**（如果 d ≤ maxDistance）：
```
Line1: A─────────P
                 ↓
Line2a:    ───C──P
Line2b:          P──D───

其中 P 是 Line1 延长线与 Line2 的交点
```

### 代码实现

**主方法**：`ExtendEndpointToLine`

```csharp
public List<Line2D> ExtendEndpointToLine(IEnumerable<Line2D> lines, double tolerance, double maxDistance = 10.0)
{
    const double minBreakThreshold = 0.5;  // 固定阈值，避免产生极短线段
    
    var lineList = lines.ToList();
    var result = new List<Line2D>();

    for (int i = 0; i < lineList.Count; i++)
    {
        Line2D currentLine = lineList[i];
        bool extended = false;
        
        // 检查当前线段的两个端点到其他线段的距离
        for (int j = 0; j < lineList.Count; j++)
        {
            if (i == j) continue;
            
            Line2D otherLine = lineList[j];
            
            // 检查起点到 otherLine 的距离
            double distStart = DistanceCalculator.PointToLineSegmentDistance(
                currentLine.StartPoint, otherLine.StartPoint, otherLine.EndPoint);
            
            // 检查终点到 otherLine 的距离
            double distEnd = DistanceCalculator.PointToLineSegmentDistance(
                currentLine.EndPoint, otherLine.StartPoint, otherLine.EndPoint);
            
            // 处理起点
            if (distStart > tolerance && distStart <= maxDistance)
            {
                // 计算交点（currentLine 的无限延长线与 otherLine 的交点）
                var intersection = currentLine.GetIntersectionWithInfiniteLine(otherLine, tolerance);
                
                if (intersection != default && otherLine.IsPointOnSegment(intersection, tolerance))
                {
                    // 延伸当前线段的起点到交点
                    currentLine = new Line2D(intersection, currentLine.EndPoint);
                    
                    // 在交点处智能打断 otherLine（检查打断后的两段长度）
                    double param = GetProjectionParameter(otherLine, intersection);
                    double length = otherLine.Length;
                    double segmentA = param * length;        // 起点到交点
                    double segmentB = (1 - param) * length;  // 交点到终点
                    
                    // 只有两段长度都 >= minBreakThreshold 才打断
                    if (segmentA >= minBreakThreshold && segmentB >= minBreakThreshold)
                    {
                        // 分割成两段
                        Line2D segment1 = new Line2D(otherLine.StartPoint, intersection);
                        Line2D segment2 = new Line2D(intersection, otherLine.EndPoint);
                        
                        // 替换 otherLine
                        lineList[j] = segment1;
                        lineList.Add(segment2);
                    }
                    
                    extended = true;
                    break;
                }
            }
            
            // 处理终点（逻辑相同）
            if (!extended && distEnd > tolerance && distEnd <= maxDistance)
            {
                // ... 类似的处理逻辑
            }
            
            if (extended) break;
        }
        
        result.Add(currentLine);
    }

    return result;
}
```

### 几何细节

#### 1. 点到线段的距离

**计算方法**：`PointToLineSegmentDistance`

```csharp
public static double PointToLineSegmentDistance(Point2D point, Point2D lineStart, Point2D lineEnd)
{
    // 1. 计算点到直线的投影参数
    Vector2D lineVec = new Vector2D(lineEnd.X - lineStart.X, lineEnd.Y - lineStart.Y);
    Vector2D pointVec = new Vector2D(point.X - lineStart.X, point.Y - lineStart.Y);
    
    double lineLengthSquared = lineVec.Dot(lineVec);
    if (lineLengthSquared < 1e-10) return point.DistanceTo(lineStart);
    
    double t = pointVec.Dot(lineVec) / lineLengthSquared;
    t = Math.Max(0.0, Math.Min(1.0, t));  // 限制在 [0, 1]
    
    // 2. 计算投影点
    Point2D projection = new Point2D(
        lineStart.X + t * lineVec.X,
        lineStart.Y + t * lineVec.Y
    );
    
    // 3. 返回点到投影点的距离
    return point.DistanceTo(projection);
}
```

**几何原理**：

```
情况1：投影在线段内部
Line: A──────────P──────B
              ↑
              ↓ d (垂直距离)
              ↓
            Point

距离 = |Point - P|

情况2：投影在线段外部（左侧）
Line:        A──────────B
      ↑
      P (投影点)
      ↑
    Point

距离 = |Point - A| (到端点的距离)

情况3：投影在线段外部（右侧）
Line: A──────────B
                      ↑
                      P (投影点)
                      ↑
                    Point

距离 = |Point - B| (到端点的距离)
```

**延伸当前线段**：

```csharp
currentLine = new Line2D(intersection, currentLine.EndPoint);
```

**打断另一条线段**：

**几何效果**：

## 参数影响分析

### 参数关系

```
tolerance (1e-6)
    ↓
    用于判断点是否重合、线段是否共线
    
minBreakThreshold (0.5mm)
    ↓
    打断时避免产生极短线段
    
maxDistance (10.0mm)
    ↓
    延伸的最大距离范围
    ↓
    决定哪些线段可以连接
    
minLength (5.0mm)
    ↓
    最终过滤的阈值
    ↓
    决定哪些线段被删除
```

### 推荐关系

**基本原则**：`maxDistance ≈ minLength × 2~4`

**原因**：

1. **maxDistance 太小**：
   - 很多短线段无法连接
   - 最终被过滤删除
   - 结果不连续

2. **maxDistance 太大**：
   - 连接过于激进
   - 可能连接不应该连接的线段
   - 结果不准确

3. **minLength 太小**：
   - 保留太多短线段
   - 结果杂乱

4. **minLength 太大**：
   - 删除太多有效线段
   - 结果不完整

## 总结

### 三步骤对比

| 步骤     | 输入条件               | 几何操作               | 输出结果         | 关键参数          |
| -------- | ---------------------- | ---------------------- | ---------------- | ----------------- |
| 步骤1    | 线段相交               | 在交点处打断           | 更多线段         | minBreakThreshold |
| 步骤2    | 端点距离 ≤ maxDistance | 延伸到交点             | 线段变长         | maxDistance       |
| 步骤3    | 端点到线 ≤ maxDistance | 延伸端点，打断线段     | 线段变长，更多段 | maxDistance       |
| 统一过滤 | 所有线段               | 删除长度 < minLength   | 更少线段         | minLength         |

### 关键要点

1. **步骤1**：无条件打断相交，但避免极短线段（0.5mm）
2. **步骤2**：只延伸端点距离 ≤ maxDistance 的线段对
3. **步骤3**：只延伸端点到线距离 ≤ maxDistance 的情况
4. **统一过滤**：最后删除长度 < minLength 的短线段

### 参数配置原则

```
maxDistance ≈ minLength × 2~4

推荐配置：
- 精细：maxDistance = 10.0, minLength = 3.0
- 一般：maxDistance = 15.0, minLength = 5.0
- 粗略：maxDistance = 30.0, minLength = 10.0
```

### 常见问题

**Q：为什么设置 minLength = 5.0，但长度 8.0 的线段也被删除了？**

A：不是被删除，而是无法连接。如果端点距离 > maxDistance，线段无法延伸连接，保持原样。如果长度 < minLength，最终被过滤删除。

**Q：如何让更多短线段连接起来？**

A：增大 maxDistance 参数，例如从 10.0 改为 15.0 或 20.0。

**Q：如何减少杂乱的短线段？**

A：增大 minLength 参数，例如从 5.0 改为 8.0 或 10.0。
