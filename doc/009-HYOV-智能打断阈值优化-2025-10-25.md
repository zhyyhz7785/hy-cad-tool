# HYOV 智能打断阈值优化报告

> **日期**: 2025-10-25  
> **改进**: 从相对参数阈值改为绝对距离阈值  
> **影响**: 避免打断时产生极短的无用线段

---

## 📋 问题描述

### 原有逻辑

**相对参数阈值 (0.01/0.99)**：

```csharp
// 旧代码
if (param > 0.01 && param < 0.99)
{
    // 只有交点在线段的 1% ~ 99% 范围内才打断
}
```

**问题**：
- `param` 是相对位置（0.0 = 起点，1.0 = 终点）
- 对于不同长度的线段，0.01 对应的实际距离差异巨大：
  - **长线段 (100 单位)**：0.01 × 100 = 1.0 单位 ✅ 合理
  - **短线段 (10 单位)**：0.01 × 10 = 0.1 单位 ⚠️ 太小
  - **极短线段 (3 单位)**：0.01 × 3 = 0.03 单位 ❌ 几乎无效

**结果**：
- 短线段仍然会在接近端点处被打断
- 产生大量长度 < 1.0 的极短线段
- 后续需要再次过滤，效率低下

---

## ✅ 改进方案

### 新逻辑：绝对距离阈值

**使用 `minSegmentLength` 参数**：

```csharp
// 新代码
double length = line.Length;
double segmentA = param * length;        // 起点到交点的长度
double segmentB = (1 - param) * length;  // 交点到终点的长度

// 只有两段长度都 >= minSegmentLength 才打断
if (segmentA >= minSegmentLength && segmentB >= minSegmentLength)
{
    // 打断线段
}
```

**优势**：
- **绝对距离判断**：无论线段长度，都使用统一的最小长度标准
- **避免产生极短线段**：打断前就检查，而不是打断后再删除
- **提高效率**：减少无用的打断和后续过滤

## 🔧 实现细节

### 1. SplitAtIntersections 方法

**修改前**：

```csharp
private List<Line2D> SplitAtIntersections(List<Line2D> lines, double tolerance)
{
    // ...
    if (param1 > 0.01 && param1 < 0.99)  // ❌ 相对参数
    {
        splitParams[i].Add(param1);
    }
}
```

**修改后**：

```csharp
private List<Line2D> SplitAtIntersections(List<Line2D> lines, double tolerance, double minSegmentLength = 0.5)
{
    // ...
    double length1 = lines[i].Length;
    double segment1A = param1 * length1;        // 起点到交点
    double segment1B = (1 - param1) * length1;  // 交点到终点
    
    // ✅ 绝对距离判断
    if (segment1A >= minSegmentLength && segment1B >= minSegmentLength)
    {
        splitParams[i].Add(param1);
    }
}
```

### 3. BreakAndCleanLines 方法

**传递 minSegmentLength 参数**：

```csharp
public List<Line2D> BreakAndCleanLines(IEnumerable<Line2D> lines, double tolerance, double minLength = 5.0)
{
    // 使用 minLength/2 作为打断阈值
    // 因为打断后会再次过滤，所以可以稍微宽松一些
    double minSegmentLength = Math.Max(0.5, minLength / 2);
    var brokenLines = SplitAtIntersections(lineList, tolerance, minSegmentLength);
    
    // 再次过滤
    var result = brokenLines.Where(line => line.Length >= minLength).ToList();
    return result;
}
```

**为什么使用 `minLength / 2`？**

- **打断阈值**：`minLength / 2`（例如 5.0 / 2 = 2.5）
  - 避免产生长度 < 2.5 的极短线段
- **过滤阈值**：`minLength`（例如 5.0）
  - 最终保留长度 >= 5.0 的有效线段

**双重保护**：
1. **打断时**：避免产生 < 2.5 的极短线段
2. **过滤时**：删除 < 5.0 的短线段

## 🎯 参数说明

### minSegmentLength 参数

**默认值**：`0.5`（最小 0.5 单位）

**计算方式**：

```csharp
// 在 BreakAndCleanLines 中
double minSegmentLength = Math.Max(0.5, minLength / 2);

// 在 OverKillCommand 中
double minSegmentLength = Math.Max(0.5, settings.MinLineLength / 2);
```

**示例**：

| MinLineLength | minSegmentLength | 说明                       |
| ------------- | ---------------- | -------------------------- |
| 3.0           | 1.5              | 避免产生 < 1.5 的极短线段  |
| 5.0           | 2.5              | 避免产生 < 2.5 的极短线段  |
| 10.0          | 5.0              | 避免产生 < 5.0 的短线段    |
| 0.2           | 0.5              | 最小值保护（不小于 0.5）   |
