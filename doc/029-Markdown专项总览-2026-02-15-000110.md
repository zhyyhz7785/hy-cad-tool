# Markdown 专项总览

## 1. 文档目标

本文档用于统一说明 `HyCADTool` 中 Markdown 导入/编辑链路的目标、边界、阅读顺序与术语口径。  
本套文档聚焦 `HyCADTool.Refactored` + `HyCADTool.MarkdownEditor`，不覆盖其他业务命令模块。

## 2. 专项范围

- 命令入口：`hymd`（新建导入）与 `hymdE`（二次编辑，当前通过测试入口驱动）。
- 编辑器桥接：`EditorLoader` 反射加载 `HyCADTool.MarkdownEditor.dll`。
- 文本处理：分栏、表格抽取、MText 渲染。
- AutoCAD 落图：`MText + Table` 混合实体写入、组标识、元数据存储。
- 回归验证：`RegressionSamples` 与 `C2 -> C1` 测试流程。

## 3. 非目标

- 不讨论 `HyCADTool.Refactored` 其他命令（钢筋、设备基础、标高等）的实现细节。
- 不提供 AutoCAD 通用 API 教程。
- 不替代代码注释；文档主要解释“为什么”和“模块协作关系”。

## 4. 阅读顺序

1. `029` 总览（本文）  
2. `030` 命令与调用链  
3. `031` 分栏与渲染内核  
4. `032` AutoCAD 落图机制  
5. `033` MarkdownEditor 与预览统计  
6. `034` 配置映射与扩展点  
7. `035` 测试回归与排障

## 5. 核心术语

- `MarkdownSource`：原始 Markdown 文本。
- `ColumnParagraphIndices`：预览阶段生成的“按栏段落索引分组”字符串，如 `0,1,2|3,4`。
- `columnMarkdowns`：按栏拆分后的 Markdown 数组。
- `columnContents`：按栏渲染后的 MText 内容数组（已去除顶层表格块）。
- `GroupId`：同一份设计说明实体组标识，键名 `HyDesignSpec_Group`。
- `Metadata`：保存于扩展字典/XRecord 的 `HyDesignSpec_MD`（源码）与 `HyDesignSpec_CFG`（配置）。

## 6. 能力边界（当前实现）

- 已支持：
  - 标题、段落、列表、引用、分隔线、代码块、表格（表格可转 AutoCAD `Table`）。
  - 二次编辑读取源码与配置，并执行重建更新。
- 已知限制：
  - 预览栏分配可能给出空栏（这是预览分配结果，不一定是后端错误）。
  - 图片/复杂富文本在 AutoCAD 中不能完全等价呈现。
  - `hymdE` 在 Refactored 架构下不作为直接命令注册，通常通过测试入口执行。

## 7. 架构总览

```mermaid
flowchart LR
  userCmd[UserCommand hymd_hymdE] --> cmdLayer[DesignSpecCommand_DesignSpecEditCommand]
  cmdLayer --> editorLoader[EditorLoader]
  editorLoader --> markdownEditor[MarkdownEditor EditorWindow]
  markdownEditor --> previewStats[PreviewStats ColumnParagraphIndices]
  previewStats --> splitter[MarkdownColumnSplitter]
  splitter --> tableExtractor[MarkdownTableExtractor]
  tableExtractor --> renderer[MarkdownToMTextRenderer]
  renderer --> cadService[DesignSpecService]
  cadService --> cadEntities[MText_And_Table]
```

- 常用回归样例：
  - `HyCADTool.MarkdownEditor/RegressionSamples/04-code-block.md`
  - `HyCADTool.MarkdownEditor/RegressionSamples/05-table-heavy.md`
  - `HyCADTool.MarkdownEditor/RegressionSamples/06-long-doc.md`
