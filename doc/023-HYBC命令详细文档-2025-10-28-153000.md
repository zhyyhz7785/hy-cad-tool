## 命令概述

### 基本信息

| 项目 | 内容 |
|------|------|
| **命令简写** | `HYBC` |
| **命令全称** | BreakCurvesCommand |
| **所属模块** | 图形处理 |
| **使用频率** | ⭐⭐⭐⭐ 高频命令 |
| **优先级** | ⭐⭐⭐⭐⭐ 核心功能 |

### 核心功能

**在曲线交点处自动打断曲线**，将相交的曲线分割为多个独立的曲线段。

**典型应用场景**：
- 复杂图形清理（重叠线段处理）
- 配筋图前处理（分割钢筋线）
- 为 HYOV 命令准备数据
- C15 命令链的第一步

```
   └── 删除原始曲线
   ↓
4. 更新图纸
   └── 显示处理结果
```

### 性能优化技术

#### 1. 空间索引（关键优化）

**问题**：暴力计算交点的时间复杂度 O(n²)
```csharp
// ❌ 暴力算法：2247条曲线 → 5,036,256 次比较
for (int i = 0; i < curves.Count; i++)
    for (int j = i + 1; j < curves.Count; j++)
        CalculateIntersection(curves[i], curves[j]);
```

**解决方案**：网格空间索引
```csharp
// ✅ 空间索引：只检查相邻网格
var index = _spatialIndexService.BuildIndex(curves, getBounds, gridSize: 1000);
var nearby = _spatialIndexService.GetNearbyIndices(bounds, index, gridSize, searchRadius);
// 实际比较次数减少 90%+
```

**性能提升**：
- 构建索引：22ms
- 并行计算交点：14ms
- **总提升：70-90%**

## 技术实现

### 核心算法

#### 1. 空间索引构建

```csharp
public class SpatialIndexService<T>
{
    /// <summary>
    /// 构建网格索引
    /// </summary>
    public Dictionary<(long, long), List<int>> BuildIndex(
        List<T> items,
        Func<T, (double minX, double minY, double maxX, double maxY)> getBounds,
        double gridSize)
    {
        var index = new Dictionary<(long, long), List<int>>();
        
        for (int i = 0; i < items.Count; i++)
        {
            var bounds = getBounds(items[i]);
            
            // 计算对象占据的网格范围
            long minGridX = (long)Math.Floor(bounds.minX / gridSize);
            long maxGridX = (long)Math.Floor(bounds.maxX / gridSize);
            long minGridY = (long)Math.Floor(bounds.minY / gridSize);
            long maxGridY = (long)Math.Floor(bounds.maxY / gridSize);
            
            // 将对象索引添加到所有占据的网格
            for (long gx = minGridX; gx <= maxGridX; gx++)
            {
                for (long gy = minGridY; gy <= maxGridY; gy++)
                {
                    var key = (gx, gy);
                    if (!index.ContainsKey(key))
                        index[key] = new List<int>();
                    index[key].Add(i);
                }
            }
        }
        
        return index;
    }
}
```

**关键参数**：
- `gridSize = 1000` - 网格大小（mm）
- `searchRadius = 100` - 搜索半径扩展

#### 2. 交点计算与去重

```csharp
// 并行计算交点
var intersectionDict = new ConcurrentDictionary<int, ConcurrentBag<Point3d>>();

Parallel.ForEach(curveIndices, i =>
{
    var nearbyIndices = GetNearbyIndices(curve[i], spatialIndex);
    
    foreach (var j in nearbyIndices)
    {
        if (i >= j) continue; // 避免重复计算
        
        var points = CalculateIntersection(curve[i], curve[j]);
        
        // 线程安全的添加
        foreach (var pt in points)
        {
            intersectionDict.GetOrAdd(i, _ => new ConcurrentBag<Point3d>()).Add(pt);
        }
    }
});
```

#### 3. 曲线分割

```csharp
public List<Curve> SplitCurve(Curve curve, List<Point3d> splitPoints)
{
    if (splitPoints.Count == 0)
        return new List<Curve> { curve.Clone() as Curve };
    
    // 按参数排序分割点
    var sortedParams = splitPoints
        .Select(pt => curve.GetParameterAtPoint(pt))
        .OrderBy(param => param)
        .ToList();
    
    // 分割曲线
    var segments = new List<Curve>();
    double startParam = curve.StartParam;
    
    foreach (var param in sortedParams)
    {
        if (Math.Abs(param - startParam) > 1e-6)
        {
            var segment = curve.GetSplitCurves(
                new DoubleCollection(new[] { startParam, param })
            )[0] as Curve;
            segments.Add(segment);
        }
        startParam = param;
    }
    
    // 添加最后一段
    if (Math.Abs(startParam - curve.EndParam) > 1e-6)
    {
        var lastSegment = curve.GetSplitCurves(
            new DoubleCollection(new[] { startParam, curve.EndParam })
        )[0] as Curve;
        segments.Add(lastSegment);
    }
    
    return segments;
}
```

### Q1: 命令执行后 AutoCAD 死机？

**原因**：Document 对象被错误释放，导致 `eInvalidInput` 异常。

**解决方案**：
```csharp
// ❌ 错误
using (var doc = Application.DocumentManager.MdiActiveDocument)

// ✅ 正确
var doc = Application.DocumentManager.MdiActiveDocument;
```

**状态**：✅ 已在 v2.0 中修复

---

### Q2: 处理大数据集时很慢？

**原因**：没有使用空间索引，交点计算为 O(n²) 复杂度。

**解决方案**：
- ✅ 启用空间索引（默认开启）
- ✅ 调整网格大小参数（gridSize）
- ✅ 使用并行计算

**性能对比**：
- 无优化：2247 曲线 → 约 2000ms
- 空间索引：2247 曲线 → 98ms
- **提升 20 倍**
