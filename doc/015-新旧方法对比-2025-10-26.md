# 三维建模方法对比

> **日期**: 2025-10-26  
> **对比**: C14（原方法）vs C15（新方法）

---

## 🔄 核心思路对比

### 原方法（C14）：基于相邻边识别

```
1. 遍历每个多边形的每条边
2. 检查是否为土壤边界（外轮廓）
3. 检查是否与其他多边形相邻
4. 记录相邻多边形和重合边
5. 根据相邻关系生成墙体
   └─ 需要处理墙体连接、接缝等
```

**问题**：
- ❌ 一条长边被多个短边相邻时逻辑复杂
- ❌ 需要处理墙体连接（Miter, Bevel, Round）
- ❌ 相邻边匹配容易出错

### 新方法（C15）：基于表面和扩张

```
1. 上表面 = 多边形 @ 标高
2. 下表面 = 根据标高规则计算
3. 墙体 = 多边形外侧扩张 300mm
4. 底板 = 多边形内部，厚度 400mm
5. 0.000 平面 = 土壤分界线
```

**优势**：
- ✅ **不需要识别相邻边**
- ✅ 逻辑简单清晰
- ✅ 墙体自动外扩，无需处理连接
- ✅ 土壤接触面识别简单

## 🎯 适用场景

- ✅ 复杂基础结构
- ✅ 精确墙体连接要求
- ✅ 多个基础相邻
- ✅ 需要精确土壤接触面

- ✅ 快速建模

## 🔧 技术对比

### 原方法（C14）核心代码

```csharp
// 1. 识别相邻边
foreach (var otherPolygon in Polygons)
{
    for (int j = 0; j < otherPolygon.NumberOfVertices; j++)
    {
        var otherEdge = new Line(otherStart, otherEnd);
        if (IsLineEqual(edge, otherEdge, tolerance) || 
            IsLineEqual(edge, ReverseLine(otherEdge), tolerance))
        {
            adjacentPolygon = otherPolygon;
            coincidentEdge = otherEdge;
            break; // ❌ 只记录第一个匹配
        }
    }
}

// 2. 生成墙体（基于边界条件）
var wall = Wall3D.CreateNormalWall(
    bufferRegion,
    thickness,
    innerElevation,
    outerElevation);
```

### 新方法（C15）核心代码

```csharp
// 1. 计算下表面
var bottomElevation = topElevation.Value >= 0 
    ? Elevation.FromMillimeters(-400.0)
    : Elevation.FromMillimeters(topElevation.Value - 400.0);

// 2. 墙体外扩
var wallRegion = polygon.Offset(300.0, isOutward: true);

// 3. 生成墙体（外轮廓 - 内轮廓）
var wallSolid = WallSolid3D.Create(
    outerPolygon: wallRegion,
    innerPolygon: polygon,
    bottomElevation,
    topElevation,
    contactsWithSoil: bottomElevation.Value < 0);
```

## 🎨 可视化对比

### 原方法（C14）

```
多边形A ─────┬───── 多边形B
            │
        相邻边识别
            │
        墙体连接处理
            │
        生成墙体
```

**特点**：
- 墙体精确贴合
- 连接处理（Miter/Bevel）
- 逻辑复杂

### 新方法（C15）

```
多边形 ────> 外扩300mm ────> 墙体
   │
   └──> 下表面规则 ────> 底板
```

**特点**：
- 墙体连续外扩
- 无需连接处理
- 逻辑简单

## 💡 使用建议

### 推荐使用 C14（原方法）：
1. **复杂工程项目**
   - 多个基础相互连接
   - 需要精确墙体连接
   
2. **精确建模要求**
   - 土壤接触面精确计算
   - 墙体厚度变化

### 推荐使用 C15（新方法）：
1. **简单独立基础**
   - 单个基础
   - 无复杂连接
   
2. **快速建模**
   - 方案设计阶段
   - 快速验证

3. **测试和学习**
   - 理解三维建模原理
   - 代码简单易懂
