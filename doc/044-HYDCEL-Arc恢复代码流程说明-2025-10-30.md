```csharp
private CurveSegment2D ExtractArcSegment(Arc arc)
{
    var center = new Point2D(arc.Center.X, arc.Center.Y);
    var arc2d = new Arc2D(center, arc.Radius, arc.StartAngle, arc.EndAngle);
    
    // 计算bulge（保留方向）
    double sweepAngle = arc.EndAngle - arc.StartAngle;
    double bulge = Math.Tan(sweepAngle / 4.0);
    
    return new CurveSegment2D(arc2d, isFromFullCircle: false, originalBulge: bulge);
}
```

**对于Arc(136°, 316°)**：
- `sweepAngle = 316° - 136° = 180° = π`
- `bulge = Math.Tan(π/4) ≈ 1.0`
- `SimplifiedLine`: `Line2D(起点136°, 终点316°)` **← 正常，是圆的割线**

**问题点1：Circle的SimplifiedLine起点=终点**
- 对于Circle，`SimplifiedLine.StartPoint = SimplifiedLine.EndPoint`（都在0°）
- 任何DCEL半边的起点/终点都可能匹配到这个点
- 导致**错误的正向/反向匹配**

#### 3.2 Arc部分匹配（第273-329行）

```csharp
// 圆弧匹配：检查圆心和半径
if (segment.Type == CurveSegmentType.Arc && segment.OriginalArc.HasValue)
{
    var arc = segment.OriginalArc.Value;
    
    // 快速过滤：检查圆心位置
    double midX = (start.X + end.X) / 2.0;
    double midY = (start.Y + end.Y) / 2.0;
    var midPoint = new Point2D(midX, midY);
    double distMidToCenter = midPoint.DistanceTo(arc.Center);
    
    if (distMidToCenter > arc.Radius * 1.5)
        continue; // ✅ 正常跳过不同圆
    
    // 检查起点和终点是否都在圆上
    double distStart = Math.Abs(start.DistanceTo(arc.Center) - arc.Radius);
    double distEnd = Math.Abs(end.DistanceTo(arc.Center) - arc.Radius);

    if (distStart < tolerance && distEnd < tolerance)
    {
        // ⚠️ 关键点2：重新计算角度（破坏原始Arc形状）
        double startAngle = Math.Atan2(start.Y - arc.Center.Y, start.X - arc.Center.X);
        double endAngle = Math.Atan2(end.Y - arc.Center.Y, end.X - arc.Center.X);
        
        // 使用叉积判断方向
        double cross = vx1 * vy2 - vy1 * vx2;
        
        if (cross > 0)
        {
            // 逆时针：短弧
            if (endAngle <= startAngle)
                endAngle += 2 * Math.PI;
        }
        else if (cross < 0)
        {
            // 顺时针：长弧
            if (endAngle >= startAngle)
                endAngle -= 2 * Math.PI;
        }
        
        // ⚠️ 关键点3：创建新的Arc，而不是使用原始Arc
        var partialArc = new Arc2D(arc.Center, arc.Radius, startAngle, endAngle);
        double partialSweep = endAngle - startAngle;
        double partialBulge = Math.Tan(partialSweep / 4.0);
        
        isReversed = false;
        return new CurveSegment2D(partialArc, isFromFullCircle: segment.IsFromFullCircle, originalBulge: partialBulge);
    }
}
```

**问题点2：重新计算的角度可能是完整圆**
- 对于Circle，如果DCEL半边恰好是直径，`startAngle`和`endAngle`可能相差180°
- 但叉积判断可能导致`endAngle`调整为`startAngle + 2π`或`startAngle - 2π`
- 结果：生成360°的完整圆

## 🔍 可能的问题根源

### 问题A：SimplifiedLine匹配逻辑错误

**症状**：Circle的SimplifiedLine起点=终点，导致错误匹配

**解决方案**：
1. 在SimplifiedLine匹配阶段，**跳过Circle**（只匹配普通Arc）
2. 强制Circle进入"部分匹配"逻辑

### 问题B：角度计算导致完整圆

**症状**：`endAngle`调整后，`partialSweep`可能为±2π

**解决方案**：
1. 添加检查：如果`|partialSweep| > π`，说明是长弧（不应该出现）
2. 对于原始Arc(136°, 316°)，应该直接使用原始角度，不要重新计算

### 问题C：Circle和Arc区分不足

**症状**：无法区分完整Circle和被分割的Arc段

**解决方案**：
1. 检查`segment.IsFromFullCircle`标志
2. 对于Circle，必须为每个DCEL半边创建部分Arc
3. 对于Arc，尽量保留原始形状
