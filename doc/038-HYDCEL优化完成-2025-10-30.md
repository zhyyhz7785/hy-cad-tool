## 一、优化需求

根据架构分析和用户反馈，确定以下优化方向：

1. ❌ **不需要保留图层**：HYDCEL 是新增图形，不删除旧图形，无需保存恢复当前图层
2. ✅ **精简输出信息**：从 7 行精简到 2 行
3. ❌ **不引入 Workflow**：遵循 YAGNI 原则
4. ✅ **统一图层管理**：使用 `ILayerManager` 服务

### 2.2 统一图层管理

**优化目标**: 使用 `ILayerManager` 服务统一管理图层

**修改位置**: `DCELRenderer.cs`

#### 修改前（手动图层管理）:
```csharp
public class DCELRenderer : IDCELRenderer
{
    public void Render(DCELGraph graph, string outerLayer, string innerLayer)
    {
        using (var tr = db.TransactionManager.StartTransaction())
        {
            // ❌ 手动管理图层
            EnsureLayerExists(tr, db, outerLayer, 1);
            EnsureLayerExists(tr, db, innerLayer, 2);
            
            // ... 渲染逻辑 ...
        }
    }
    
    // ❌ 重复实现图层创建逻辑（18 行代码）
    private void EnsureLayerExists(Transaction tr, Database db, string layerName, short colorIndex)
    {
        var lt = (LayerTable)tr.GetObject(db.LayerTableId, OpenMode.ForRead);
        if (!lt.Has(layerName))
        {
            lt.UpgradeOpen();
            var newLayer = new LayerTableRecord
            {
                Name = layerName,
                Color = Color.FromColorIndex(ColorMethod.ByAci, colorIndex)
            };
            lt.Add(newLayer);
            tr.AddNewlyCreatedDBObject(newLayer, true);
            lt.DowngradeOpen();
        }
    }
}
```

#### 修改后（统一图层管理）:
```csharp
public class DCELRenderer : IDCELRenderer
{
    private readonly ILayerManager _layerManager;

    /// <summary>
    /// 构造函数（支持依赖注入）
    /// </summary>
    public DCELRenderer(ILayerManager layerManager = null)
    {
        _layerManager = layerManager ?? new LayerManager();
    }

    public void Render(DCELGraph graph, string outerLayer, string innerLayer)
    {
        using (var tr = db.TransactionManager.StartTransaction())
        {
            // ✅ 使用统一的图层管理服务
            _layerManager.EnsureLayer(tr, outerLayer, 1); // 红色
            _layerManager.EnsureLayer(tr, innerLayer, 2);  // 黄色
            
            // ... 渲染逻辑 ...
        }
    }
    
    // ✅ 删除重复的 EnsureLayerExists 方法（18 行代码）
}
```

**关键改进**:
- ✅ 使用 `ILayerManager` 接口（支持依赖注入）
- ✅ 删除重复的图层创建代码（18 行）
- ✅ 与其他命令（HYOV、HYBC 等）保持一致
- ✅ 符合 DRY 原则（Don't Repeat Yourself）

**代码减少**:
```
删除: 18 行（EnsureLayerExists 方法）
添加: 7 行（构造函数 + 字段声明）
净减少: 11 行 ✅
```

### 2.4 图层保留分析

**用户确认**: ❌ **不需要保留图层**

**原因分析**:

| 命令      | 操作类型     | 图层保留需求 | 理由                         |
| --- | --- | --- | --- |
| **HYOV**  | 删除旧+添加新| ✅ 需要       | 新线段需要保留在原图层       |
| **HYBC**  | 删除旧+添加新| ✅ 需要       | 新曲线需要保留在原图层       |
| **HYDCEL**| 只添加新图形 | ❌ 不需要     | 新图形创建在专用图层（dcelOuter/dcelInner）|

**关键区别**:
```
HYOV/HYBC:
  选择图层 A 的线段 → 删除 → 在图层 A 创建新线段 ✅
  需要保留原图层信息

HYDCEL:
  选择任意图层的曲线 → 不删除 → 在专用图层创建多边形 ✅
  不需要保留原图层信息
```

**结论**: HYDCEL 不需要保存和恢复当前图层。
