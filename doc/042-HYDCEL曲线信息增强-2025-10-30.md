# HYDCEL 曲线信息增强 - 完整圆支持

> **完成日期**: 2025-10-30  
> **问题**: 完整圆被 DCEL 分割后无法正确恢复  
> **解决方案**: 记录额外信息 + 使用叉积判断方向

---

## 一、问题分析

### 用户反馈
圆形的左上角部分显示不正确，怀疑"记录的信息缺少一些"。

### 根本原因
当完整圆（Circle）被 DCEL 分割成多个弧段时：
1. **信息丢失**：只记录了起点和终点，丢失了原始圆的完整信息
2. **方向判断错误**：无法准确判断分割后的弧段应该是"小弧"还是"大弧"
3. **缺少标记**：不知道这个弧段来自完整圆还是普通圆弧

## 二、解决方案

### 2.1 增强 CurveSegment2D

添加 `IsFromFullCircle` 标记：

**文件**: `Domain/ValueObjects/Geometry/CurveSegment2D.cs`

```csharp
public class CurveSegment2D
{
    // ... 其他属性 ...
    
    /// <summary>
    /// 是否来自完整圆（用于部分匹配时判断方向）
    /// </summary>
    public bool IsFromFullCircle { get; }
    
    /// <summary>
    /// 构造函数：圆弧
    /// </summary>
    public CurveSegment2D(Arc2D arc, bool isFromFullCircle = false)
    {
        Type = CurveSegmentType.Arc;
        SimplifiedLine = new Line2D(arc.StartPoint, arc.EndPoint);
        OriginalArc = arc;
        IsFromFullCircle = isFromFullCircle; // 记录是否来自完整圆
    }
}
```

**作用**: 标记圆弧是否来自完整圆，用于后续智能匹配

### 2.3 智能方向判断（叉积法）

**文件**: `Infrastructure/AutoCAD/Services/DCELRenderer.cs`

当匹配到来自完整圆的弧段时，使用**叉积**判断方向：

```csharp
// 如果来自完整圆，使用叉积判断顺逆时针
if (segment.IsFromFullCircle)
{
    // 计算从圆心到起点的向量
    double vx1 = start.X - arc.Center.X;
    double vy1 = start.Y - arc.Center.Y;
    
    // 计算从圆心到终点的向量
    double vx2 = end.X - arc.Center.X;
    double vy2 = end.Y - arc.Center.Y;
    
    // 叉积：正值表示逆时针，负值表示顺时针
    double cross = vx1 * vy2 - vy1 * vx2;
    
    // 根据叉积判断扫掠方向
    if (cross > 0)
    {
        // 逆时针：使用较小的正角度
        if (endAngle < startAngle)
            endAngle += 2 * Math.PI;
    }
    else
    {
        // 顺时针：使用负角度
        if (endAngle > startAngle)
            endAngle -= 2 * Math.PI;
    }
}
```

#### 叉积几何意义

```
        终点 (vx2, vy2)
            ↗
           /
          /
    圆心 ●
          \
           \
            ↘
        起点 (vx1, vy1)

叉积 = vx1 * vy2 - vy1 * vx2

- 正值：逆时针旋转（从起点到终点）
- 负值：顺时针旋转
- 零值：共线（不应出现在圆弧上）
```

     - 添加到 Polyline

## 四、技术细节

### 4.1 叉积公式

对于二维向量：
- **v1 = (vx1, vy1)**：从圆心到起点
- **v2 = (vx2, vy2)**：从圆心到终点

**叉积**（z 分量）：
```
cross = vx1 * vy2 - vy1 * vx2
```

**结果判断**：
- `cross > 0`：从 v1 到 v2 是**逆时针**旋转
- `cross < 0`：从 v1 到 v2 是**顺时针**旋转

### 4.2 角度调整逻辑

**逆时针情况**（cross > 0）：
```csharp
// 确保 endAngle > startAngle（正角度）
if (endAngle < startAngle)
    endAngle += 2 * Math.PI;

// 示例：startAngle = 330°, endAngle = 30°
// 调整后：endAngle = 390° (30° + 360°)
// 扫掠角 = 60°（逆时针）
```

**顺时针情况**（cross < 0）：
```csharp
// 确保 endAngle < startAngle（负角度）
if (endAngle > startAngle)
    endAngle -= 2 * Math.PI;

// 示例：startAngle = 30°, endAngle = 330°
// 调整后：endAngle = -30° (330° - 360°)
// 扫掠角 = -60°（顺时针）
```

## 八、理论基础

### 为什么需要叉积？

在平面几何中，给定圆心和两个圆上的点，有**两条可能的圆弧**：
- **小弧**（短路径）：角度 < 180°
- **大弧**（长路径）：角度 > 180°

**问题**：DCEL 的半边有方向，我们需要知道是按照这个方向的小弧还是大弧。

**解决**：
1. **叉积**告诉我们 DCEL 半边是顺时针还是逆时针遍历圆
2. 根据这个信息，选择正确的扫掠角度

### 为什么之前的"更短路径"不对？

之前逻辑：
```csharp
// 错误：总是选择更短的路径
if (arcLength1 < arcLength2)
    return arc1; // 小弧
else
    return arc2; // 大弧
```

**问题**：DCEL 可能需要"大弧"来正确表示面的边界，但我们总是给它"小弧"。

**现在**：使用叉积判断 DCEL 遍历方向，返回与之匹配的弧。
