# 01 — 配置体系总览

## 1. 核心结论（30 秒）

HyCAD 插件侧存在 **两套相互独立、用途不同** 的持久化配置来源：

1. **`hy-settings.json`（用户级，AppData）**  
   - 由 `SettingsPanelViewModel` 读写。  
   - 覆盖：**比例、单位与精度、文字/标注/引线样式参数、用户图层表（`UserLayerSettings`）、钢筋参数、道路默认与桩号标注、Blender 主题与 UI 缩放、设备数据路径** 等。  
   - **绝大多数**业务命令通过 `SettingsPanelViewModel.Current` 读参数。

2. **`config.json`（部署级，通常与 DLL 同目录或开发输出目录）**  
   - 由 `GlobalConfigurationService` / `ModuleConfigurationService` + `JsonConfigurationLoader` 读取。  
   - 覆盖：**全局容差、路径、全局样式结构的旧格式**、以及 **桩基模块默认**（`PileConfigData`）等。  
   - 仓库内示例见：`HyCADTool.Refactored/config.json`。

**比例（Scale）的唯一业务真相源**在运行时应以 `SettingsPanelViewModel.Current.Scale` 为准；`ConfigurationService.GetScale()` 已明确优先读 VM，再回退全局配置。

```78:84:HyCADTool.Refactored/Infrastructure/Configuration/ConfigurationService.cs
        /// <summary>
        /// 获取当前比例 — 唯一真相源：SettingsPanelViewModel
        /// </summary>
        public double GetScale()
        {
            return SettingsPanelViewModel.Current?.Scale ?? _globalConfigService.Scale;
        }
```

## 2. 文件路径一览

| 文件 | 典型绝对路径 | 说明 |
|------|----------------|------|
| `hy-settings.json` | `%APPDATA%\HyCADTool\hy-settings.json` | 用户目录，避免热重载时路径漂移 |
| `hy-pile-settings.json` | 同上目录 | 桩基面板独立持久化 |
| `hy-settlement-settings.json` | 同上目录 | 沉降计算面板独立持久化 |
| `config.json` | `Assembly.Location` 所在目录优先，其次当前目录、BaseDirectory 等（见各 Service 的 `FindConfigFile`） | 部署/开发机旁路配置 |

`hy-settings.json` 路径由静态方法统一给出：

```1141:1153:HyCADTool.Refactored/Presentation/ViewModels/SettingsPanelViewModel.cs
        /// <summary>
        /// 获取设置文件路径（%APPDATA%\HyCADTool\hy-settings.json）
        /// 使用 AppData 而非 Assembly 目录，避免热重载时路径不稳定
        /// </summary>
        public static string GetSettingsFilePath()
        {
            if (_settingsFilePath != null) return _settingsFilePath;
            var appDataDir = Path.Combine(
                Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData),
                "HyCADTool");
            Directory.CreateDirectory(appDataDir);
            _settingsFilePath = Path.Combine(appDataDir, "hy-settings.json");
            return _settingsFilePath;
        }
```

## 3. 启动时加载顺序（概念）

`PluginInitializer.Initialize()` 中（概念流程，与源码顺序一致）：

1. **Autofac 容器**注册（含 `ConfigurationService`、`GlobalConfigurationService`、`ModuleConfigurationService` 等）。
2. **`ConfigurationService.LoadAll()`**  
   - `GlobalConfigurationService.LoadConfiguration()` → 读 `config.json`（若存在且合法）。  
   - `ModuleConfigurationService.LoadAllConfigurations()` → 读模块段（如桩基）。
3. **`InitializeStylesAndLayers()`**  
   - 对当前文档：`SettingsPanelViewModel.GetOrCreate` → **`LoadSettings()` 读 `hy-settings.json`**。  
   - `EnsureStylesApplied()` → 按 VM 参数创建/更新 AutoCAD 样式。  
   - `ILayerService.EnsureUserLayerItems(LayerCatalogItems)` → 按 `hy-settings` 中的用户图层表创建/更新图层（默认表见 `LayerCatalogFactory`；见 [04-图层与样式初始化](./04-图层与样式初始化.md)）。
4. 插件在启动日志中打印 **设置文件路径**（便于用户定位）：

## 4. 多文档与「单文件」关系

- `SettingsPanelViewModel` **按文档名**维护实例（`GetOrCreate(documentName, styleService)`），但 **持久化文件始终是同一个** `hy-settings.json`。  
- 因此：**切换 DWG 不会切换配置文件**；各文档实例在构造/激活时从同一 JSON 加载，通常表现一致。

## 5. 与「图层」的关系

- **默认可编辑图层表**由 `LayerCatalogFactory` + `HyRoadLayers.GetAll()` 合并得到；用户修改后持久化在 **`hy-settings.json` 的 `UserLayerSettings`**，由 `UserLayerSettingsMerger` 与默认表合并（新增语义行自动补齐）。  
- 道路模块通过 `HyRoadLayers.*Layer` **属性**经 `UserLayerNameResolver` 解析为当前层名（用户可改名）。  
- 详见 [04-图层与样式初始化](./04-图层与样式初始化.md)、[09-新增设置扩展规范](./09-新增设置扩展规范.md)。
