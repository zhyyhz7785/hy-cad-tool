# 04 — 图层与样式初始化

## 1. 总原则

- **AutoCAD 图层（名称 + ACI 颜色）** 不在 `hy-settings.json` 中配置，而在 **C# 代码** 中集中维护。  
- 插件在文档首次初始化时调用 `ILayerService.CreateMultipleLayers(...)` 批量创建。  
- **文字/标注/多重引线/表格** 等样式由 `SettingsPanelViewModel` 参数驱动，在 `EnsureStylesApplied()` 中写入当前图形（与 `hy-settings.json` 一致）。

入口：`PluginInitializer.EnsureCurrentDocumentResourcesInitialized`：

```634:652:HyCADTool.Refactored/Presentation/PluginInitializer.cs
        private void EnsureCurrentDocumentResourcesInitialized(bool force)
        {
            var doc = AcApp.DocumentManager.MdiActiveDocument;
            if (doc == null) return;

            string documentName = doc.Name ?? "default";
            if (!force && _initializedDocuments.Contains(documentName))
                return;

            try
            {
                var styleService = ServiceLocator.Resolve<Domain.Interfaces.IStyleService>();
                var layerService = ServiceLocator.Resolve<Domain.Interfaces.ILayerService>();

                var vm = ViewModels.SettingsPanelViewModel.GetOrCreate(documentName, styleService);
                vm.LoadSettings();
                vm.EnsureStylesApplied();

                layerService.CreateMultipleLayers(GetRequiredLayers());
                _initializedDocuments.Add(documentName);
            }
```

## 3. `HyRoadLayers`（道路模块权威常量）

**文件**：`HyCADTool.Refactored/Infrastructure/AutoCAD/Xdata/HyRoadLayers.cs`

- 提供所有道路相关 **图层名字符串** 与 **颜色常量**。  
- `GetAll()` 返回 **完整** `(name, color)` 数组（含横断面 9 层、M10 平面 3 层、预览/原线等）。  
- 注释中说明了各图层语义（平面线位、纵断面、交叉口、缘石坡道、停止线、横断面分层等）。

若需 **单表复制**，可直接以源码 `GetAll()` 为准（约 L153–186）。

## 4. 域模型 `LayerConfig` 与 CSV 遗留

| 项 | 说明 |
|----|------|
| `Domain/ValueObjects/Configuration/Global/LayerConfig.cs` | 平台无关的图层 DTO（名称、颜色、线型、线宽等）。 |
| `CsvConfigurationLoader.LoadLayerConfigurations()` | 从旧式 CSV 读 `Type == "Layer"` 行。 |
| 当前仓库 | **未发现** 对 `new CsvConfigurationLoader(...)` 的引用，CSV 路径 **未接入** 主启动流程。 |

结论：**图层不以 CSV 为运行时真相源**；保留类可用于迁移或工具。

## 5. 样式初始化（与图层并列）

- `SettingsPanelViewModel.LoadSettings()` 读取 `hy-settings.json`。  
- `EnsureStylesApplied()`（在 VM 内）根据脏标记创建/更新 AutoCAD 文字样式、标注样式、多重引线等。  
- 具体样式名与参数以 `SettingsPanelViewModel` 属性及 `IStyleService` 实现为准。

---

## 6. 修改图层时的检查清单

1. 若图层属于 **通用 + 道路子集**：改 `PluginInitializer.GetRequiredLayers()`。  
2. 若图层属于 **道路扩展**（交叉口、横断面等）：改 **`HyRoadLayers`**，并确认是否需在 `GetRequiredLayers()` 或具体服务的 `EnsureLayer` 中创建。  
3. 搜索图层名字符串的全局引用，避免命令写死旧名。  
4. **勿**在 ResourceDictionary 中改图层（图层与 WPF 无关）。
