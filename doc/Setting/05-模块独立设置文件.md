# 05 — 模块独立设置文件（AppData）

除 `hy-settings.json` 外，部分面板使用 **独立 JSON**，仍位于：

`%APPDATA%\HyCADTool\`

目录在首次写入前由代码 `Directory.CreateDirectory` 创建。

---

## 1. `hy-pile-settings.json`

**写入方**：`PilePanelViewModel.SaveSettings()`  
**路径逻辑**：`HyCADTool.Refactored/Presentation/ViewModels/PilePanelViewModel.cs`

| 属性（`PileSettingsData`） | 含义（简述） |
|---------------------------|--------------|
| `DiameterOrEdge` | 桩径或边长 |
| `MinPileCenterDistance` | 最小桩心距 |
| `InputDisplacementRate` | 位移率等输入 |
| `PileArrangeRate` | 布置率 |
| `InputDistanceFromContour` | 距轮廓距离 |
| `MarginUp` / `Down` / `Left` / `Right` | 四向边距 |
| `NX` / `NY` | 阵列数量 |
| `IsRectangular` / `IsCircular` | 布置形状开关 |
| `IsCirclePile` / `IsRectPile` | 桩型开关 |
| `ManualControl` | 手动控制 |
| `MarkerElevation` | 标记标高 |
| `MarkerTextHeightScale` | 标记文字高度比例 |

**与 `config.json` 的关系**：`config.json` 中 `PileConfigData` 提供 **模块级默认**；面板持久化以 **`hy-pile-settings.json`** 为准（用户调参）。`ConfigurationService` / `JsonConfigurationLoader` 读的是部署配置，二者层次不同。

## 3. 为何拆成多个 JSON？

| 原因 | 说明 |
|------|------|
| 职责分离 | 主设置（`hy-settings`）已很大；桩基/沉降参数变更频率与生命周期不同。 |
| 加载性能 | 打开对应面板再加载，避免主 VM 过度膨胀。 |
| 备份与迁移 | 用户可单独复制某一模块设置。 |
