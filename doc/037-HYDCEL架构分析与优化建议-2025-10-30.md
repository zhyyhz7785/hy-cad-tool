## 三、架构问题

### 3.1 命令复杂度 - 中等偏高

**Execute() 方法**：162 行（其中命令逻辑 ~100 行）

```csharp
[CommandMethod("HYDCEL")]
public void Execute()
{
    // 1. 选择曲线（15 行）
    // 2. 提取曲线 ID（10 行）
    // 3. 提取线段（10 行）
    // 4. 构建 DCEL（5 行）
    // 5. 输出统计（15 行）
    // 6. 输出分类（10 行）
    // 7. 验证拓扑（10 行）
    // 8. 渲染 AutoCAD（5 行）
    // 9. 错误处理（20 行）
}
```

**根据架构规范**:
```
简单命令（< 50 行） → Command 直接调用服务
中等命令（50-150 行） → 可选 Workflow（当前 HYDCEL）
复杂命令（> 150 行） → 强烈建议 Workflow
```

### 3.2 图层管理问题

❌ **未保存和恢复当前图层**:
```csharp
// ❌ 当前代码：未保存当前图层
[CommandMethod("HYDCEL")]
public void Execute()
{
    try
    {
        // ... 命令逻辑 ...
        _dcelRenderer.Render(graph, "dcelOuter", "dcelInner");
    }
    catch { ... }
}
```

**问题**: 
- `DCELRenderer.Render()` 会创建并可能切换图层
- 如果用户在其他图层工作，执行命令后当前图层会改变

### 3.3 输出冗余

**当前输出**（7 行）:

### 🟡 建议 3：引入 Workflow（可选）

**优先级**: ⭐⭐⭐ 中等  
**工作量**: 30 分钟  
**影响**: 可测试性、可复用性提升

**是否需要 Workflow？**

**不需要的理由**:
- ✅ 命令逻辑清晰（8 个步骤）
- ✅ 已经有良好的服务抽象
- ✅ 代码可读性良好
- ✅ 没有其他命令需要复用这个流程

**需要的理由**:
- ⚠️ Execute() 方法 ~100 行（接近阈值）
- ⚠️ 统计输出、分类、验证逻辑可能复用
- ⚠️ 便于单元测试（可以 mock Workflow）

**决策**: ⏸️ **暂不实现**（YAGNI 原则）
- 当前架构已经足够清晰
- 如果未来有其他命令需要 DCEL 处理，再考虑 Workflow

**如果需要实现 Workflow，结构如下**:

```csharp
namespace HyCADTool.Refactored.Infrastructure.AutoCAD.Workflows
{
    public class DCELWorkflow
    {
        private readonly ICurveSegmentExtractor _curveExtractor;
        private readonly IDCELBuilderService _dcelBuilder;
        private readonly IDCELRenderer _dcelRenderer;
        
        public DCELWorkflow(
            ICurveSegmentExtractor curveExtractor,
            IDCELBuilderService dcelBuilder,
            IDCELRenderer dcelRenderer)
        {
            _curveExtractor = curveExtractor;
            _dcelBuilder = dcelBuilder;
            _dcelRenderer = dcelRenderer;
        }
        
        public DCELResult Execute(
            List<ObjectId> curveIds,
            double tolerance,
            string outerLayer = "dcelOuter",
            string innerLayer = "dcelInner")
        {
            // 1. 提取线段
            var segments = _curveExtractor.ExtractSegments(curveIds, tolerance);
            
            // 2. 构建 DCEL
            var graph = _dcelBuilder.BuildFromSegments(segments, new Tolerance(tolerance));
            
            // 3. 验证拓扑
            var isValid = graph.Validate(out var errors);
            
            // 4. 渲染
            _dcelRenderer.Render(graph, outerLayer, innerLayer);
            
            // 5. 返回结果
            return new DCELResult
            {
                Graph = graph,
                SegmentCount = segments.Count,
                IsValid = isValid,
                ValidationErrors = errors
            };
        }
    }
    
    public class DCELResult
    {
        public DCELGraph Graph { get; set; }
        public int SegmentCount { get; set; }
        public bool IsValid { get; set; }
        public List<string> ValidationErrors { get; set; }
    }
}
```

**简化后的 DCELCommand**:
```csharp
public class DCELCommand
{
    private readonly DCELWorkflow _workflow;
    
    public DCELCommand()
    {
        _workflow = new DCELWorkflow(
            new CurveSegmentExtractor(),
            new DCELBuilderService(),
            new DCELRenderer());
    }
    
    [CommandMethod("HYDCEL")]
    public void Execute()
    {
        var doc = Application.DocumentManager.MdiActiveDocument;
        var db = doc.Database;
        var ed = doc.Editor;
        ObjectId originalLayer = db.Clayer;
        
        try
        {
            // 1. 选择曲线
            var curveIds = SelectCurves(ed);
            if (curveIds == null) return;
            
            // 2. 执行 Workflow
            var stopwatch = Stopwatch.StartNew();
            var result = _workflow.Execute(curveIds, tolerance: 0.01);
            stopwatch.Stop();
            
            // 3. 输出结果
            var stats = result.Graph.GetStatistics();
            var outerCount = result.Graph.Faces.Count(f => f.IsOuter);
            var innerCount = stats.FaceCount - outerCount;
            
            ed.WriteMessage($"\nDCEL 完成：{stats.FaceCount} 面（{outerCount} 外 + {innerCount} 内）");
            
            if (!result.IsValid)
                ed.WriteMessage($"\n⚠️ 拓扑验证失败（{result.ValidationErrors.Count} 个问题）");
            
            ed.WriteMessage($"\nINFO: DCEL处理 耗时 {stopwatch.ElapsedMilliseconds} 毫秒");
        }
        catch (Exception ex)
        {
            ed.WriteMessage($"\n错误：{ex.Message}");
        }
        finally
        {
            db.Clayer = originalLayer;
        }
    }
    
    private List<ObjectId> SelectCurves(Editor ed) { ... }
}
```

private void EnsureLayerExists(Transaction tr, Database db, string layerName, short colorIndex)
{
    LayerTable lt = (LayerTable)tr.GetObject(db.LayerTableId, OpenMode.ForRead);
    if (!lt.Has(layerName))
    {
        lt.UpgradeOpen();
        LayerTableRecord ltr = new LayerTableRecord();
        ltr.Name = layerName;
        ltr.Color = Color.FromColorIndex(ColorMethod.ByAci, colorIndex);
        lt.Add(ltr);
        tr.AddNewlyCreatedDBObject(ltr, true);
    }
}
