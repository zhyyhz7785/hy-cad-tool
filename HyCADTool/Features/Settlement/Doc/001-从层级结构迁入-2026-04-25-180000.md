# 001 — 从 Domain/Infrastructure/Presentation 迁入 Features/Settlement

## 起因

沉降功能文件分散在 6 个目录，按功能查找困难。

## 决策

统一迁入 `HyCADTool/Features/Settlement/`，命名空间 `HyCADTool.Features.Settlement`。

## 涉及文件

- 原 `Domain/Models/Settlement/*` → 本目录
- 原 `Domain/Services/SettlementCalculationService.cs`、`SettlementReportGenerator.cs` → 本目录
- 原 `Infrastructure/AutoCAD/Services/SettlementTableService.cs` → 本目录
- 原 `Presentation/Commands/SettlementCalculationCommand.cs`、`Views/Settlement*.{xaml,cs}`、`ViewModels/SettlementPanelViewModel.cs` → 本目录

## 外部引用调整

- `BearingCapacityService`、`PileStructuralService`、`MarkdownTableParser`：`using HyCADTool.Features.Settlement`
- `ReCall/commands.json`：`HYJC` / `hySC` 的 `type` 指向 `HyCADTool.Features.Settlement.SettlementCalculationCommand`
- `HyCADTool.csproj`：`Page` 项指向 `Features\Settlement\*.xaml`

## 验证

- `dotnet build HyCADtoolGpt.sln -c Debug`
- AutoCAD：C2 后执行 HYJC
