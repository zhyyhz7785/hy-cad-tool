# 测试命令配置说明（C11-C19）

## 功能说明

`Recall.cs` 提供了 9 个可配置的测试命令槽位（C11-C19），支持热重启。

## 配置方法

在 `Recall.cs` 的 `TEST_COMMANDS` 数组中配置：

```csharp
private static readonly (string Command, string ClassName, string MethodName)[] TEST_COMMANDS = new[]
{
    ("C11", "完整类名", "方法名"),
    ("C12", "完整类名", "方法名"),
    // ... C13-C19
};
```

### 参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| Command | 命令名称 | `"C11"` |
| ClassName | 完整类名（含命名空间） | `"HyCADTool.Refactored.Presentation.Commands.OverKillCommand"` |
| MethodName | 要调用的方法名 | `"Execute"` |

### 留空槽位

如果某个槽位不需要使用，留空即可：

```csharp
("C13", "", ""),  // 预留槽位，未配置
```

## 使用流程

### 1. 配置测试命令

编辑 `Recall.cs` 中的 `TEST_COMMANDS`：

```csharp
("C13", "HyCADTool.Refactored.Presentation.Commands.YourCommand", "YourMethod"),
```

### 2. 编译项目

Visual Studio 重新生成解决方案

### 3. AutoCAD 执行 C2

```
命令: C2
> 显示已加载的测试命令列表
```

### 4. 使用测试命令

```
命令: C13
> 执行您配置的命令
```

## 热重启原理

### 为什么支持热重启？

```
C11-C19 命令 → Recall.cs 中的方法（固定）
                    ↓
                通过反射调用
                    ↓
            最新加载的 DLL 中的方法 ✅
```

### 与直接命令的区别

| 特性 | 测试命令（C11-C19） | 直接命令（HYOV） |
|------|-------------------|-----------------|
| **支持热重启** | ✅ 是 | ❌ 否 |
| **调用方式** | 反射调用 | 直接调用 |
| **代码版本** | 最新编译的 | 第一次加载的 |
| **使用场景** | 开发测试 | 用户使用 |

## 注意事项

### 1. 类名必须完整

❌ 错误：`"OverKillCommand"`  
✅ 正确：`"HyCADTool.Refactored.Presentation.Commands.OverKillCommand"`

### 2. 方法必须是 public

```csharp
// ✅ 正确
public void Execute() { }

// ❌ 错误（private 方法无法通过反射调用）
private void Execute() { }
```

### 3. 方法不能有参数

```csharp
// ✅ 正确
public void Execute() { }

// ❌ 错误（带参数的方法无法配置）
public void Execute(string param) { }
```

### 4. 需要无参构造函数

```csharp
// ✅ 正确（默认构造函数）
public class MyCommand { }

// ✅ 正确（显式无参构造函数）
public class MyCommand 
{
    public MyCommand() { }
}

// ❌ 错误（只有有参构造函数）
public class MyCommand 
{
    public MyCommand(string param) { }
}
```

## 常见问题

### Q: 配置后没有显示？

**A**: 检查以下几点：
1. 类名是否完整（包含命名空间）
2. 方法名是否正确
3. 是否执行了 C2 重新加载
4. 查看 AutoCAD 命令行是否有警告信息

### Q: 执行命令时报错？

**A**: 常见原因：
1. 方法不是 public
2. 方法有参数
3. 类没有无参构造函数
4. DLL 未编译或路径错误

### Q: 如何添加更多命令？

**A**: 目前支持 C11-C19 共 9 个槽位。如需更多，可以：
1. 在 `TEST_COMMANDS` 数组中添加更多条目
2. 在 `ReCallClass` 末尾添加对应的 `[CommandMethod]`
3. 例如：`[CommandMethod("C20")] public void ExecuteC20() => ExecuteTestCommand("C20");`
