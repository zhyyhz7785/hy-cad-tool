# HyCADTool.MarkdownEditor — 配置参数与扩展指南

## 1. EditorConfig 完整参数速查表

所有排版参数均通过 `EditorConfig` 在主项目与编辑器之间传递（JSON 序列化），同时双向绑定到 `EditorViewModel` 的对应属性。

### 1.1 出图与预览

| 参数 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|------|------|--------|------|------|------|
| `DrawScale` | double | 100 | 1–250 | — | 出图比例，影响 CAD 输出时的缩放 |
| `PreviewScale` | double | 1.0 | 0.1–5.0 | — | 预览区缩放倍率，仅影响显示 |

### 1.2 栏位布局

| 参数 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|------|------|--------|------|------|------|
| `ColumnCount` | int | 1 | 1–10 | — | 分栏数量 |
| `ColumnGutter` | double | 10 | 0+ | mm | 栏间距 |
| `CharsPerColumn` | int[] | null | — | 字 | 每栏字数数组，长度应等于 ColumnCount；null 时自动计算 |
| `TotalHeight` | double | 200 | 20+ | mm | 内容区总高度 |

### 1.3 字体

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `FontFileName` | string | — | SHX 字体文件名（CAD 用） |
| `BigFontFileName` | string | — | 大字体文件名（CAD 中文支持） |
| `BoldFontName` | string | — | 粗体字体名称 |
| `PreviewFontFamily` | string | — | 预览区 CSS font-family |

### 1.4 排版尺寸

| 参数 | 类型 | 默认值 | 范围 | 单位 | 说明 |
|------|------|--------|------|------|------|
| `TextSize` | double | 3.5 | 0.5+ | mm | 正文字号（CAD 实际高度） |
| `TextXScale` | double | 0.7 | 0.1+ | — | 字宽缩放因子（<1 窄体，>1 宽体） |

### 1.5 标题倍率与行距

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `H1Scale` | double | 1.6 | H1 字号 = TextSize × H1Scale |
| `H2Scale` | double | 1.3 | H2 字号 = TextSize × H2Scale |
| `H3Scale` | double | 1.1 | H3 字号 = TextSize × H3Scale |
| `LineSpacingFactor` | double | 1.2 | 行距 = 字号 × LineSpacingFactor |

### 1.6 段落间距

所有间距单位为 mm，作用于预览和 CAD 输出。

| 参数 | 类型 | 说明 |
|------|------|------|
| `H1SpaceBefore` | double | H1 标题段前间距 |
| `H1SpaceAfter` | double | H1 标题段后间距 |
| `H2SpaceBefore` | double | H2 标题段前间距 |
| `H2SpaceAfter` | double | H2 标题段后间距 |
| `H3SpaceBefore` | double | H3 标题段前间距 |
| `H3SpaceAfter` | double | H3 标题段后间距 |
| `PSpaceAfter` | double | 正文段落段后间距 |
| `LiSpaceAfter` | double | 列表项段后间距 |
| `QuoteSpaceBefore` | double | 引用块段前间距 |
| `QuoteSpaceAfter` | double | 引用块段后间距 |

### 1.7 页面设置

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `PagePreset` | string | "A4" | 页面预设，可选值见下表 |
| `PageWidthMm` | double | 210 | 页面宽度 (mm)，选择预设后自动设置 |
| `PageHeightMm` | double | 297 | 页面高度 (mm)，选择预设后自动设置 |
| `IsLandscape` | bool | false | 横向模式（交换宽高） |

#### 页面预设尺寸

| 预设 | 纵向 (宽×高 mm) | 横向 (宽×高 mm) |
|------|-----------------|-----------------|
| A0 | 841 × 1189 | 1189 × 841 |
| A1 | 594 × 841 | 841 × 594 |
| A2 | 420 × 594 | 594 × 420 |
| A3 | 297 × 420 | 420 × 297 |
| A4 | 210 × 297 | 297 × 210 |

### 1.8 页边距

| 参数 | 类型 | 单位 | 说明 |
|------|------|------|------|
| `MarginLeftMm` | double | mm | 左边距 |
| `MarginRightMm` | double | mm | 右边距 |
| `MarginTopMm` | double | mm | 上边距 |
| `MarginBottomMm` | double | mm | 下边距 |

### 1.9 图框样式

| 参数 | 类型 | 范围 | 单位 | 说明 |
|------|------|------|------|------|
| `BorderWidth` | double | 0.5–5 | mm | 图框边框线宽 |
| `HandleWidth` | double | 1–10 | mm | 栏分隔手柄宽度（非活动态） |
| `HandleActiveWidth` | double | 6–14 | mm | 栏分隔手柄宽度（活动/拖拽态） |

## 2. 主题系统

### 2.1 主题切换

```csharp
// 在 EditorWindow 中切换主题
ThemeManager.ApplyTheme("dark");   // 暗色主题
ThemeManager.ApplyTheme("light");  // 亮色主题
```

### 2.3 自定义主题

要添加新主题，在 `ThemeManager` 中新增颜色方案：

```csharp
// ThemeManager.cs 中添加新主题
case "custom":
    Apply(new ThemeColors
    {
        BgRoot = Color.FromRgb(0x1a, 0x1a, 0x2e),
        BgPanel = Color.FromRgb(0x16, 0x21, 0x3e),
        // ... 定义所有颜色
    });
    break;
```

## 3. Vditor 编辑器配置

### 3.1 当前配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| 版本 | 3.10.8 | Vditor 版本 |
| 模式 | IR (Instant Rendering) | 即时渲染模式 |
| 主题 | dark | 暗色主题（固定） |
| 语言 | zh_CN | 中文界面 |
| 计数器 | 禁用 | `counter.enable = false` |

### 3.2 工具栏配置

当前启用的工具栏按钮：

```
headings | bold | italic | strike | list | ordered-list |
quote | code | inline-code | link | table | upload |
undo | redo
```

### 3.3 CDN 与缓存策略

```
优先级 1: 本地缓存
  路径: %LocalAppData%/HyCADTool/VditorDist/3.10.8/dist/
  通过 WebView2 虚拟主机映射提供

优先级 2: npmmirror (淘宝镜像)
  URL: https://registry.npmmirror.com/vditor/-/vditor-3.10.8.tgz
  适合中国大陆网络环境

优先级 3: npm 官方
  URL: https://registry.npmjs.org/vditor/-/vditor-3.10.8.tgz

优先级 4: CDN 回退
  URL: https://cdn.jsdelivr.net/npm/vditor@3.10.8
  下载失败时直接使用 CDN
```

### 3.4 修改 Vditor 配置

编辑 `VditorHtmlTemplate.cs` 中的 `Build()` 方法：

```csharp
// 修改工具栏
toolbar: ["headings", "bold", "italic", /* 添加或移除按钮 */],

// 修改模式（ir=即时渲染, sv=分屏, wysiwyg=所见即所得）
mode: "ir",

// 修改主题
theme: "dark",  // "dark" | "classic"

// 修改语言
lang: "zh_CN",  // "zh_CN" | "en_US" | "ja_JP" 等
```

## 5. 工作区模式

编辑器支持三种工作区模式，通过视图菜单切换：

### 5.1 写作模式

```
┌──────────────────────────────────────┐
│ TitleBar                             │
├──────────┬───────────────────────────┤
│ LeftPanel│     EditorWebView         │
│ (大纲)   │     (Vditor 全宽)         │
│          │                           │
└──────────┴───────────────────────────┘
```

- 编辑器占满右侧空间
- 预览面板隐藏
- 适合专注写作

### 5.2 排版模式

```
┌──────────────────────────────────────────────────┐
│ TitleBar                                         │
├──────────┬──────────────┬──┬─────────────────────┤
│ LeftPanel│ EditorWebView│  │ PreviewPanelControl  │
│ (设置)   │              │  │ (标尺 + 图纸预览)     │
│          │              │  │                      │
└──────────┴──────────────┴──┴─────────────────────┘
```

- 编辑器与预览并排显示
- 左侧面板默认显示设置选项卡
- 标尺可见
- 适合调整排版参数

### 5.3 校对模式

```
┌──────────────────────────────────────────────────┐
│ TitleBar                                         │
├──────────────────────────────────────────────────┤
│              PreviewPanelControl                  │
│              (图纸预览全宽)                        │
│                                                  │
└──────────────────────────────────────────────────┘
```

- 预览面板占满窗口
- 编辑器和左侧面板隐藏
- 适合最终校对排版效果

## 7. 持久化存储详解

### 7.1 左侧面板状态

**路径**：`%LocalAppData%/HyCADTool/MarkdownEditor/left-panel-state.json`

```json
{
  "SortMode": "ModifiedDesc",
  "RecentDirectories": [
    "C:\\docs\\project-a",
    "C:\\docs\\project-b"
  ]
}
```

- `SortMode`：文件树排序方式（NameAsc / NameDesc / ModifiedDesc / ModifiedAsc）
- `RecentDirectories`：最近打开的目录列表，上限 12 条，FIFO 淘汰

### 7.2 Vditor 缓存

**路径**：`%LocalAppData%/HyCADTool/VditorDist/3.10.8/dist/`

包含 Vditor 编辑器的完整前端资源（JS/CSS/字体/图标等），首次使用时自动下载。

清除缓存方法：删除上述目录，下次启动编辑器时会自动重新下载。

## 8. 扩展开发指南

### 8.1 添加新的编辑器操作

1. 在 `VditorJsHelper.cs` 中添加 JS 调用方法：

```csharp
public static async Task MyNewActionAsync(WebView2 webView)
{
    await webView.CoreWebView2.ExecuteScriptAsync(
        "vditor.tip('Hello!', 2000)");
}
```

2. 在 `EditorViewModel.ExecuteEditorActionAsync()` 中注册路由：

```csharp
case "MyNewAction":
    await VditorJsHelper.MyNewActionAsync(webView);
    break;
```

3. 在 `TitleBarControl.xaml` 中添加菜单项：

```xml
<MenuItem Header="我的操作"
          Command="{Binding EditorActionCommand}"
          CommandParameter="MyNewAction" />
```

### 8.2 添加新的预览消息类型

1. 在预览 JS 中发送消息（`PreviewHtmlRenderer.BuildDynamicJs()`）：

```javascript
window.chrome.webview.postMessage({
    type: "myCustomMessage",
    data: { /* 自定义数据 */ }
});
```

2. 在 `PreviewManager.TryHandlePreviewWebMessage()` 中处理：

```csharp
case "myCustomMessage":
    var data = msg["data"];
    // 处理自定义消息
    return true;
```

### 8.3 添加新的排版参数

1. 在 `EditorConfig` 中添加属性：

```csharp
public double MyNewParam { get; set; } = 1.0;
```

2. 在 `EditorViewModel` 中添加绑定属性：

```csharp
private double _myNewParam = 1.0;
public double MyNewParam
{
    get => _myNewParam;
    set { _myNewParam = value; OnPropertyChanged(); }
}
```

3. 在 `BuildConfig()` 中序列化：

```csharp
MyNewParam = this.MyNewParam,
```

4. 在 `SettingsPanelControl.xaml` 中添加 UI：

```xml
<TextBox Text="{Binding MyNewParam, UpdateSourceTrigger=PropertyChanged}"
         helpers:TextBoxHelper.EnableCustomHandlers="True"
         helpers:TextBoxHelper.ScrollStep="0.1" />
```

5. 在 `PreviewHtmlRenderer.BuildDynamicCss()` 中使用：

```csharp
var myParam = config.MyNewParam;
css += $".my-class {{ property: {myParam}mm; }}";
```
