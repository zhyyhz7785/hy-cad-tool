# HyCADTool.MarkdownEditor — 项目概述与快速上手

## 1. 项目简介

`HyCADTool.MarkdownEditor` 是一个基于 WPF + WebView2 的 Markdown 所见即所得编辑器，专为 CAD 工程图纸的技术文档编排场景设计。它作为独立库被主项目 `HyCADTool.Refactored` 通过反射调用，提供 Markdown 编辑、分栏图纸预览、实时同步 AutoCAD 等能力。

### 核心特性

- **双面板编辑**：左侧 Vditor 即时渲染编辑器 + 右侧分栏图纸预览
- **图纸级排版**：支持 A0–A4 页面预设、多栏布局、毫米级边距控制
- **实时预览**：编辑内容 220ms 防抖后自动刷新预览
- **AutoCAD 同步**：手动/实时同步编辑结果到 CAD 图纸
- **主题切换**：GitHub 风格暗色/亮色主题
- **文件管理**：内置文件树、大纲导航、最近目录记忆
- **丰富格式**：标题、粗体、斜体、表格、代码块、数学公式（KaTeX）、脚注等

### 技术栈

| 组件 | 版本 | 用途 |
|------|------|------|
| .NET | 8.0 (net8.0-windows, x64) | 运行时框架 |
| WPF | — | UI 框架 |
| Microsoft.Web.WebView2 | 1.0.3065.39 | 嵌入式浏览器控件 |
| Vditor | 3.10.8 | Markdown 即时渲染编辑器 |
| Markdig | 0.37.0 | Markdown 解析与 HTML 转换 |
| Newtonsoft.Json | 13.0.3 | JSON 序列化协议 |
| HyCADTool.TextLayout | — | CAD 文本布局引擎（可选） |

## 3. 调用方式

### 3.1 模态对话框（推荐）

```csharp
// 构造输入
var input = new EditorInput
{
    Markdown = "# 标题\n正文内容...",
    Config = new EditorConfig
    {
        ColumnCount = 2,
        PagePreset = "A3",
        IsLandscape = true,
        TextSize = 3.5,
        DrawScale = 100
    },
    CurrentFilePath = @"C:\docs\spec.md"
};

string inputJson = JsonConvert.SerializeObject(input);
long ownerHandle = /* 父窗口 HWND */;

// 反射调用
string resultJson = EditorLauncher.ShowDialog(inputJson, ownerHandle);

// 解析结果
var result = JsonConvert.DeserializeObject<EditorResult>(resultJson);
if (result.Confirmed)
{
    string markdown = result.Markdown;
    EditorConfig config = result.Config;
    // 处理编辑结果...
}
```

### 3.2 非模态窗口

```csharp
// 打开非模态窗口
bool opened = EditorLauncher.ShowNonModal(inputJson, ownerHandle);

// 注册同步回调（接收实时编辑结果）
EditorLauncher.RegisterSyncCallbacks(
    manualSyncCallback: resultJson => { /* 手动同步 */ },
    liveSyncCallback:   resultJson => { /* 实时同步（900ms 防抖） */ }
);

// 检查窗口是否仍然打开
bool isOpen = EditorLauncher.IsNonModalOpen();

// 清理回调
EditorLauncher.ClearSyncCallbacks();
```

## 4. 构建与输出

### 构建配置

- 目标框架：`net8.0-windows`
- 平台：`x64`
- 输出路径：`../HyCADTool.Refactored/bin/$(Configuration)/net8/`

- 构建后自动复制 `WebView2Loader.dll` 到输出根目录
