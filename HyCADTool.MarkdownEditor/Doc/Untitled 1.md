### 差异来源（核心问题）

| 维度     | 编辑器（Vditor）       | 预览器（Markdig）                   | 差异严重度                           |
| :------- | :--------------------- | :---------------------------------- | :----------------------------------- |
| 渲染引擎 | Vditor 内置 (Lute)     | Markdig (C#)                        | 高 -- 两套完全独立的 Markdown 解析器 |
| 字体     | 浏览器默认（未指定）   | Microsoft YaHei（可配置）           | 中                                   |
| 字号     | Vditor 默认（约 16px） | TextSize × PreviewScale（约 2.5px） | 高 -- 单位体系不同                   |
| 行高     | Vditor 默认            | LineSpacingFactor = 1.2             | 中                                   |
| CSS 样式 | Vditor 主题（dark）    | 完全自定义 CSS 模拟 CAD 排版        | 高                                   |
| 分栏     | 无                     | 有（JS 分栏 + 拖拽）                | 高                                   |
| 用途     | 写作体验               | 模拟 AutoCAD 最终输出               | 根本不同                             |

结论：两者差异大是"设计意图"造成的 -- 编辑器负责"写作体验"，预览器负责"模拟 CAD 输出"，它们本来就在做不同的事。
