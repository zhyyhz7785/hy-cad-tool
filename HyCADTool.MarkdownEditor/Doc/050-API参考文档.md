# HyCADTool.MarkdownEditor — API 参考文档

## 1. 对外公共 API — EditorLauncher

`EditorLauncher` 是本模块对外的唯一入口，所有方法均为 `public static`。

### 1.1 ShowDialog

```csharp
public static string ShowDialog(string inputJson, long ownerHandle)
```

以模态对话框方式打开编辑器。

| 参数 | 类型 | 说明 |
|------|------|------|
| `inputJson` | `string` | `EditorInput` 的 JSON 序列化字符串 |
| `ownerHandle` | `long` | 父窗口 HWND（传 0 表示无父窗口） |

**返回值**：`EditorResult` 的 JSON 字符串。用户取消时 `Confirmed = false`。

### 1.2 ShowNonModal

```csharp
public static bool ShowNonModal(string inputJson, long ownerHandle)
```

以非模态窗口方式打开编辑器。若已有非模态窗口打开，则激活已有窗口并返回 `false`。

| 参数 | 类型 | 说明 |
|------|------|------|
| `inputJson` | `string` | `EditorInput` 的 JSON 序列化字符串 |
| `ownerHandle` | `long` | 父窗口 HWND |

**返回值**：`true` 表示成功打开新窗口，`false` 表示已有窗口存在。

### 1.3 IsNonModalOpen

```csharp
public static bool IsNonModalOpen()
```

检查非模态窗口是否仍然打开。

### 1.4 RegisterSyncCallbacks

```csharp
public static void RegisterSyncCallbacks(
    Action<string> manualSyncCallback,
    Action<string> liveSyncCallback)
```

注册同步回调，用于接收编辑器的实时编辑结果。

| 参数 | 类型 | 说明 |
|------|------|------|
| `manualSyncCallback` | `Action<string>` | 用户点击"同步 CAD"按钮时触发，参数为 `EditorResult` JSON |
| `liveSyncCallback` | `Action<string>` | 编辑内容变更后 900ms 防抖触发，参数为 `EditorResult` JSON |

### 1.5 ClearSyncCallbacks

```csharp
public static void ClearSyncCallbacks()
```

清除已注册的同步回调。

## 2. 数据契约 — Models/EditorContract

### 2.1 EditorInput

编辑器输入参数。

```csharp
public class EditorInput
{
    public string Markdown { get; set; }          // 初始 Markdown 文本
    public EditorConfig Config { get; set; }      // 编辑器配置
    public string CurrentFilePath { get; set; }   // 当前文件路径（可选）
}
```

### 2.2 EditorResult

编辑器输出结果。

```csharp
public class EditorResult
{
    public bool Confirmed { get; set; }           // 用户是否确认（true=确认，false=取消）
    public string Markdown { get; set; }          // 编辑后的 Markdown 文本
    public EditorConfig Config { get; set; }      // 编辑后的配置参数
    public int[] CharsPerColumn { get; set; }     // 每栏字数数组
    public int[][] ColumnParagraphIndices { get; set; }  // 每栏段落索引
    public PreviewStats PreviewStats { get; set; } // 预览统计信息
}
```

### 2.3 EditorConfig

编辑器配置参数（40+ 个属性），分为以下类别：

#### 出图与预览

| 属性 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `DrawScale` | `double` | 100 | 1–250 | 出图比例 |
| `PreviewScale` | `double` | 1.0 | 0.1–5.0 | 预览缩放比例 |

#### 栏位布局

| 属性 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `ColumnCount` | `int` | 1 | 1–10 | 栏数 |
| `ColumnGutter` | `double` | 10 | 0+ | 栏间距 (mm) |
| `CharsPerColumn` | `int[]` | null | — | 每栏字数数组（可选，覆盖自动计算） |
| `TotalHeight` | `double` | 200 | 20+ | 总高度 (mm) |

#### 字体与排版

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `TextSize` | `double` | 3.5 | 正文字号 (mm) |
| `TextXScale` | `double` | 0.7 | 字宽缩放因子 |
| `FontFileName` | `string` | — | SHX 字体文件名 |
| `BigFontFileName` | `string` | — | 大字体文件名 |
| `BoldFontName` | `string` | — | 粗体字体名 |
| `PreviewFontFamily` | `string` | — | 预览字体族 |

#### 标题倍率

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `H1Scale` | `double` | 1.6 | H1 字号倍率 |
| `H2Scale` | `double` | 1.3 | H2 字号倍率 |
| `H3Scale` | `double` | 1.1 | H3 字号倍率 |
| `LineSpacingFactor` | `double` | 1.2 | 行距因子 |

#### 段落间距

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `H1SpaceBefore` | `double` | — | H1 段前间距 (mm) |
| `H1SpaceAfter` | `double` | — | H1 段后间距 (mm) |
| `H2SpaceBefore` | `double` | — | H2 段前间距 (mm) |
| `H2SpaceAfter` | `double` | — | H2 段后间距 (mm) |
| `H3SpaceBefore` | `double` | — | H3 段前间距 (mm) |
| `H3SpaceAfter` | `double` | — | H3 段后间距 (mm) |
| `PSpaceAfter` | `double` | — | 正文段后间距 (mm) |
| `LiSpaceAfter` | `double` | — | 列表项段后间距 (mm) |
| `QuoteSpaceBefore` | `double` | — | 引用段前间距 (mm) |
| `QuoteSpaceAfter` | `double` | — | 引用段后间距 (mm) |

#### 页面设置

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `PagePreset` | `string` | "A4" | 页面预设 (A0/A1/A2/A3/A4) |
| `PageWidthMm` | `double` | 210 | 页面宽度 (mm) |
| `PageHeightMm` | `double` | 297 | 页面高度 (mm) |
| `IsLandscape` | `bool` | false | 是否横向 |

#### 页边距

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `MarginLeftMm` | `double` | — | 左边距 (mm) |
| `MarginRightMm` | `double` | — | 右边距 (mm) |
| `MarginTopMm` | `double` | — | 上边距 (mm) |
| `MarginBottomMm` | `double` | — | 下边距 (mm) |

#### 图框样式

| 属性 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `BorderWidth` | `double` | — | 0.5–5 | 边框线宽 (mm) |
| `HandleWidth` | `double` | — | 1–10 | 手柄宽度 (mm) |
| `HandleActiveWidth` | `double` | — | 6–14 | 活动手柄宽度 (mm) |

### 2.4 PreviewStats

```csharp

    public PreviewColumnStats[] Columns { get; set; }    // 各栏详细统计
    public Dictionary<string, int> BlockTypeCounts { get; set; }  // 区块类型计数
}
```

```csharp
public class PreviewColumnStats
{
    public int CharCount { get; set; }        // 字符数
    public int ParagraphCount { get; set; }   // 段落数
    public int TotalChars { get; set; }       // 总字符数
    public string DisplayUnit { get; set; }   // 显示单位
}
```

## 6. 自定义控件

### 6.1 RulerControl

毫米标尺控件，支持水平和垂直方向。

#### 依赖属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `Orientation` | `Orientation` | Horizontal | 方向 |
| `PixelsPerMm` | `double` | 3.78 | 每毫米像素数（随缩放变化） |
| `SegmentCount` | `int` | 1 | 标尺段数（多栏时 > 1） |
| `RulerBackground` | `Brush` | — | 背景色 |
| `LabelBrush` | `Brush` | — | 标签颜色 |
| `MajorTickBrush` | `Brush` | — | 大刻度颜色 |
| `MinorTickBrush` | `Brush` | — | 小刻度颜色 |
| `RulerBorderBrush` | `Brush` | — | 边框颜色 |

刻度规格：20mm 大刻度（带数字标签）、4mm 小刻度。

### 6.2 TextBoxHelper

TextBox 附加行为，用于数值输入增强。

#### 附加属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `EnableCustomHandlers` | `bool` | false | 启用增强行为 |
| `ScrollStep` | `double` | 0.1 | 滚轮/方向键步进值 |

#### 增强行为

- 获得焦点时自动全选
- 滚轮上下 / ↑↓ 键调整数值（步进 `ScrollStep`）
- 回车键确认并失焦
- 双击全选

## 7. 预览 WebView 消息协议

预览 JS 通过 `window.chrome.webview.postMessage()` 向 C# 发送消息，格式为 JSON：

### 7.1 消息类型

| type | 方向 | 说明 |
|------|------|------|
| `paperScale` | JS → C# | 图纸缩放变化 |
| `wheelZoom` | JS → C# | 鼠标滚轮缩放 |
| `pageState` | JS → C# | 分页状态更新 |
| `contentChanged` | JS → C# | 图纸侧内容变更 |
| `paperGeometry` | JS → C# | 图纸几何信息 |
| `paperMargins` | JS → C# | 图纸边距信息 |

### 7.2 消息示例

```json
// paperScale
{ "type": "paperScale", "scale": 1.5 }

// pageState
{ "type": "pageState", "current": 1, "total": 3 }

// contentChanged
{
  "type": "contentChanged",
  "markdown": "# 标题\n正文...",
  "version": 42,
  "hash": "a1b2c3d4"
}
```
