# MarkdownEditor 当前架构总览（L1）

## 项目定位

`HyCADTool.MarkdownEditor` 是被主插件反射调用的 Markdown 编辑与图纸预览模块：  
输入 `EditorInput(JSON)`，在 WPF + WebView2 中完成编辑、分栏预览与同步，输出 `EditorResult(JSON)` 回 `HyCADTool.Refactored`，用于手动插入和实时同步 AutoCAD。

## 技术栈

- 框架：`.NET 8 WPF`（`net8.0-windows`，x64）
- 编辑容器：`Microsoft.Web.WebView2 1.0.3065.39`
- Markdown 渲染：`Markdig 0.37.0`
- JSON 协议：`Newtonsoft.Json 13.0.3`
- 布局内核依赖：`HyCADTool.TextLayout`（Flow 体验模式下仅部分链路启用）

## 模块关系图（文字版）

`EditorLauncher`（反射入口 / 非模态会话管理）  
-> `EditorWindow`（主编排层，双 WebView 与事件路由）  
-> `EditorViewModel`（状态、参数、命令桥接）  
-> `PreviewManager`（预览刷新、消息处理、回写去重）  
-> `PreviewHtmlRenderer`（图纸 HTML/CSS/JS 生成，当前默认 Flow 体验模式）  
-> `Views/Controls/*`（标题栏、左侧文件/大纲、预览面板、标尺）  
-> `Models/EditorContract`（输入输出契约）

并行编辑通道：

- `EditorWebView`（Vditor 编辑面板）
- `PreviewWebView`（图纸编辑面板，Flow 体验层）

## 数据流（当前实现）

1. 主项目调用 `EditorLauncher.ShowDialog(inputJson, ownerHandle)`。
2. `EditorWindow` 同时初始化 `EditorWebView` 与 `PreviewWebView`。
3. 文本变更触发 `PreviewManager.RefreshPreviewAsync(...)`，生成预览 HTML。
4. 图纸侧通过 `contentChanged/version/hash` 回传，`PreviewManager` 去重后写回 `ViewModel.MarkdownText`。
5. `EditorWindow` 用 `_isUpdatingFromPreview + 文本哈希` 防止双向覆盖回环。
6. `Insert CAD`（手动）与 `Live Sync`（防抖）统一输出 `EditorResult`。

## 当前架构状态（2026-02-19）

- 图纸侧默认启用 Flow 体验模式：`UseFlowExperiencePaperMode = true`。
- 预览消息已包含图纸几何通道：`paperGeometry`、`paperMargins`、`pageState`、`paperScale`。
- 大纲定位已支持双面板联动：点击大纲时同时定位编辑面板与图纸面板。
- 图纸区支持会话态拖拽能力：栏宽/栏高（含上手柄）、页面宽高、页边距导轨。
- `PreviewManager` 在 Flow 模式下跳过旧增量布局脏区主链，按体验层路径渲染。
