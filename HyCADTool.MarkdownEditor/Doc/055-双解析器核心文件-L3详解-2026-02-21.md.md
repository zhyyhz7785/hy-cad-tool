# 双解析器核心文件 L3 详解

\> 范围：VditorHtmlTemplate.cs（编辑窗口）、PreviewHtmlRenderer.cs（视图窗口）

\> 目标：完整理解两套 Markdown 解析/渲染链路的实现细节。

------

## 一、VditorHtmlTemplate.cs 详细说明

### 1.1 类概述

- 类型：静态类

- 职责：生成嵌入 Vditor 编辑器的 HTML 页面（IR 即时渲染模式 / 暗色主题）

- 继承/接口：无

- 依赖：VditorCacheManager.CdnFallback、Newtonsoft.Json

### 1.2 字段/属性

| 名称           | 类型         | 用途                    |
| :------------- | :----------- | :---------------------- |
| VDITOR_VERSION | const string | Vditor 版本号（3.10.8） |

### 1.3 方法清单

| 方法        | 参数                     | 返回   | 职责                     |
| :---------- | :----------------------- | :----- | :----------------------- |
| Generate    | initialMarkdown, cdnBase | string | 主入口：拼接完整 HTML    |
| EscapeForJs | text                     | string | 转义 Markdown 供 JS 使用 |

### 1.4 关键方法详解

#### Generate(initialMarkdown, cdnBase)

- 输入：初始 Markdown、CDN 基础 URL（null 则用默认 CDN）

- 处理：

1. cdn = cdnBase ?? VditorCacheManager.CdnFallback

1. EscapeForJs(initialMarkdown) 转义为 JSON 字符串

1. 拼接 HTML：<link href="{cdn}/dist/index.css">、<script src="{cdn}/dist/index.min.js">

1. 内嵌 CSS：暗色主题、工具条样式、.vditor-ir、.vditor-reset 等

1. 内嵌 <div id="vditor"> + Vditor 初始化脚本

1. 配置：mode: 'ir'、theme: 'dark'、lang: 'zh_CN'

1. preview 配置（影响 IR 渲染样式）：theme: { current: 'dark', path: '{cdn}/dist/css/content-theme' }、hljs: { style: 'native', lineNumber: true }

1. 回调：input → postMessage({ type: 'input', value })；after → postMessage({ type: 'ready' })

1. 暴露全局函数：setContent(md)、getContent()、clickToolbar(name)、wrapSelection、insertHeading、insertParagraph、clearFormatting、triggerFind、scrollToHeading

- 输出：完整 HTML 字符串

- 调用链：EditorContentViewModel → VditorCacheManager 获取 cdnBase → Generate；EditorWindow 加载时 NavigateToString 或 SetVirtualHostNameToFolderMapping 后加载

#### EscapeForJs(text)

- 输入：原始文本

- 处理：空则返回 ''；否则 JsonConvert.SerializeObject(text)

- 输出：JS 可安全嵌入的字符串字面量

- 调用链：仅被 Generate 调用

### 1.5 状态管理

- 无实例状态（静态工具类）

- 无持久化；每次调用纯函数式

### 1.6 编辑窗口 Markdown 渲染来源

- 解析器：Vditor 内置（Lute/JS）

- 样式：Vditor content-theme/dark.css

- 代码块：highlight.js，style: 'native'，带行号

## 二、PreviewHtmlRenderer.cs 详细说明

### 2.1 类概述

- 类型：静态类

- 职责：Markdown → 交互式分栏 HTML 预览（用于 WebView2 预览控件）

- 继承/接口：无

- 依赖：Markdig、EditorConfig、HyCADTool.TextLayout.LayoutResult

### 2.2 字段/属性

| 名称                  | 类型             | 用途                                      |
| :-------------------- | :--------------- | :---------------------------------------- |
| Pipeline              | MarkdownPipeline | Markdig 解析管线（UseAdvancedExtensions） |
| ConsecutiveBlankLines | Regex            | 匹配连续 3+ 空行，用于 PreserveBlankLines |

### 2.3 方法清单

| 方法                        | 参数                                                      | 返回   | 职责                                                 |
| :-------------------------- | :-------------------------------------------------------- | :----- | :--------------------------------------------------- |
| ToInteractiveHtml           | markdown, columnCount, previewScale, config, layoutResult | string | 主入口：完整预览 HTML                                |
| RenderBodyHtml              | markdown                                                  | string | 委托给 RenderFlowBodyHtml                            |
| RenderFlowBodyHtml          | markdown                                                  | string | Flow 模式 body：PreserveBlankLines + Markdown.ToHtml |
| ToFlowExperienceHtml        | markdown, columnCount, previewScale, config               | string | 拼接 flowCssTemplate + flowJsTemplate + body         |
| PreserveBlankLines          | md                                                        | string | 连续空行替换为 \n\n + WORD JOINER + \n\n             |
| BuildDynamicCss             | previewScale, cfg                                         | string | 替换 CSS 模板占位符（用于非 Flow 模式）              |
| BuildDynamicJs              | previewScale, cfg, columnCount, layoutResult              | string | 注入 JS 运行参数（用于非 Flow 模式）                 |
| ResolveFontWidthFactor      | cfg                                                       | double | 按字体名返回宽度系数（1.0/0.98/1.03 等）             |
| BuildCustomColumnWidthsJson | layoutResult, previewScale                                | string | 栏宽数组 JSON                                        |
| ResolvePreviewFontFamily    | cfg                                                       | string | 取 PreviewFontFamily（空则 Microsoft YaHei）         |
| Round                       | value                                                     | double | Math.Round(value, 3)                                 |
| BuildFooterHtml             | count                                                     | string | 生成栏 footer 占位 HTML                              |

### 2.4 关键方法详解

#### ToFlowExperienceHtml(markdown, columnCount, previewScale, config)

- 输入：Markdown、栏数、缩放、配置

- 处理：

1. PreserveBlankLines 预处理

1. Markdown.ToHtml(preprocessed, Pipeline) 生成 body HTML

1. 从 EditorConfig 解析：maxCol、minColWidthPx、minColHeightPx、cols、scale、textSizeMm、textXScale、fontWidthFactor、charWidthPx、paperWidthPx、paperHeightPx、leftPx、rightPx、topPx、bottomPx、gapPx、borderWidth、handleWidth、handleActiveWidth、contentPadPx

1. BuildFooterHtml(cols)、ResolvePreviewFontFamily(cfg)

1. 替换 flowCssTemplate 占位符（/*FLOW_*）

1. 替换 flowJsTemplate 占位符

1. 拼接：<div id="source" style="display:none"> + body + </div> + viewport + paper + footer + script

- 输出：完整 HTML 字符串

- 调用链：PreviewManager.RefreshPreviewAsync → FullNavigatePreview / IncrementalUpdateFlowAsync 间接调用

#### RenderFlowBodyHtml(markdown)

- 输入：Markdown

- 处理：PreserveBlankLines → 空则 "<p class=\"empty\">(无内容)</p>"，否则 Markdown.ToHtml(preprocessed, Pipeline)

- 输出：body HTML 片段

- 调用链：PreviewManager.IncrementalUpdateFlowAsync、FullUpdateInPlaceAsync 调用；updateSource(bodyEscaped, ...) 注入到预览 WebView

#### PreserveBlankLines(md)

- 输入：Markdown 原文

- 处理：ConsecutiveBlankLines.Replace，将 3+ 连续空行替换为 \n\n + WORD JOINER（\u2060）× (n-2) + \n\n

- 输出：预处理后的 Markdown

- 调用链：RenderFlowBodyHtml、ToFlowExperienceHtml 调用

#### ResolveFontWidthFactor(cfg)

- 输入：配置

- 处理：按 PreviewFontFamily/FontFileName 匹配：微软雅黑→1.0、黑体→0.98、宋体→1.03、仿宋→1.02、楷体→1.01、.shx→0.95

- 输出：double 宽度系数

- 调用链：ToFlowExperienceHtml 中计算 charWidthPx

### 2.5 状态管理

- 无实例状态（静态工具类）

- Pipeline、ConsecutiveBlankLines 为静态只读，线程内共享

### 2.6 视图窗口 Markdown 渲染来源

- 解析器：Markdig（UseAdvancedExtensions）

- 样式：内嵌 flowCssTemplate（h1/h2/h3/blockquote/code/pre/table 等）

- 代码块：无 highlight.js，无语法高亮、无行号

## 四、双解析器调用链总览

编辑窗口：

 EditorContentViewModel → VditorHtmlTemplate.Generate() → HTML

 WebView2 加载 → Vditor 初始化 → Lute 解析 → IR 渲染

视图窗口：

 PreviewManager.RefreshPreviewAsync()

  → PreviewHtmlRenderer.ToInteractiveHtml() / RenderFlowBodyHtml()

  → Markdig.ToHtml() → body HTML

  → flowCssTemplate + flowJsTemplate 拼接

  → WebView2.NavigateToString() 或 updateSource(bodyEscaped)
