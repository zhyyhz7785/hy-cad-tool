# Markdown 转 AutoCAD Mtext 参数对比表

## 概述

将 Markdown 文章导入 AutoCAD 并以 Mtext（多行文字）形式显示时，需要将 Markdown 的排版语义映射为 AutoCAD Mtext 的格式控制码（Format Code）或属性参数。以下对比表覆盖核心参数的完整转换关系。

------

## 一、文字样式与字体

| Markdown 语法      | Mtext 格式控制码                    | 属性面板参数                          | 说明                           |
| ------------------ | ----------------------------------- | ------------------------------------- | ------------------------------ |
| 正文（无标记）     | `\f微软雅黑;`                       | 样式：`0-hy-说明-T`，字体：`微软雅黑` | 与截图样式一致                 |
| `**粗体**`         | `\W0.7;\H37.5;\f微软雅黑;{\b 文字}` | 勾选 **B**（Bold）                    | Mtext 中用 `{\b text}` 包裹    |
| `*斜体*`           | `{\i 文字}`                         | 勾选 **I**（Italic）                  | 用 `{\i text}` 包裹            |
| `__下划线__`       | `{\l 文字}`                         | 勾选 **U**（Underline）               | 用 `{\l text}` 包裹            |
| `~~删除线~~`       | `{\K 文字}`                         | 勾选 **O**（Overline/Strikethrough）  | 用 `{\K text}` 包裹            |
| 等宽/代码 ``code`` | `\fCourier New;文字\f微软雅黑;`     | 切换为等宽字体后恢复                  | Mtext 无原生代码块，需切换字体 |

## 二、字号（文字高度）

| Markdown 语义 | Mtext 控制码 | 属性值                 | 说明         |
| ------------- | ------------ | ---------------------- | ------------ |
| H1 一级标题   | `\H56;`      | 文字高度：56           | 约正文 1.5×  |
| H2 二级标题   | `\H48;`      | 文字高度：48           | 约正文 1.27× |
| H3 三级标题   | `\H42;`      | 文字高度：42           | 略大于正文   |
| H4–H6 小标题  | `\H38;`      | 文字高度：38           | 与正文接近   |
| 正文段落      | `\H37.5;`    | 文字高度：38（截图值） | 基准字高     |
| 注释/说明     | `\H30;`      | 文字高度：30           | 小于正文     |

> **注**：截图中实际字高为 `37.5000`（控制码），属性面板显示为 `38`（取整显示）。建议统一使用 `\H37.5;` 作为正文基准。

## 四、行距与段落间距

| Markdown 语义    | Mtext 控制码           | 属性面板参数                                 | 说明                                 |
| ---------------- | ---------------------- | -------------------------------------------- | ------------------------------------ |
| 段落换行（空行） | `\P`                   | —                                            | Mtext 中 `\P` 为硬回车，模拟段落分隔 |

## 十、完整 Mtext 内容格式示例

以下为将一段典型 Markdown 转换为 Mtext 控制码字符串的示例：

**Markdown 输入：**

```markdown
# 标题一
这是**正文**内容，包含 *斜体* 和普通文字。
- 列表项 A
- 列表项 B
```

**对应 Mtext 内容字符串：**

```
{\H56;\b 标题一\P}{\H37.5;\W0.7;\f微软雅黑;这是{\b 正文}内容，包含 {\i 斜体} 和普通文字。\P\pi-2,l2;• 列表项 A\P• 列表项 B\P}
```

------

## 十一、注意事项

1. **样式优先级**：Mtext 中行内控制码优先于 `TEXTSTYLE` 样式设置，转换时需确保控制码与样式参数不冲突。
2. **宽度因子**：截图中使用 `\W0.70`，若 Markdown 正文宽度过宽，可适当降低宽度因子。
3. **精确行距**：使用精确行距（75）时，修改字高后行距不会自适应，需手动同步调整。
4. **定义宽度**：`1467` 为当前 Mtext 框宽度，转换时应根据实际图纸布局重新设定。
5. **编码兼容**：AutoCAD 中文环境建议使用 `\f微软雅黑;` 或 `\f仿宋_GB2312;`，避免乱码。
6. **换行控制**：`\P` 为段落硬回车（等效 Markdown 空行），连续内容用 `\n` 软回车（部分版本支持）。





## MText 参数含义解析

这6个参数分别控制 MText 的不同视觉维度，可以按"行"、"字"、"段"三个层级来理解：

------

### 行级参数（控制行与行之间的关系）

**LineSpacingFactor**（行距因子） 相邻两行文字之间的距离倍数，以字高为基准。值为 1.0 时行与行紧贴，1.2 时行间有 0.2 个字高的空隙，1.5 时是"一倍半行距"。CSS 的 `line-height` 与此语义完全一致，CAD 的 `LineSpacingFactor` 也是同一概念，所以这个参数三端映射最简单。

**MTextLineSpacingStyle**（行距样式） 控制上面那个"因子"的计量方式，有两种模式。"AtLeast"（至少）是弹性模式：如果某行有大字或特殊字符，行距会自动撑大，保证内容不重叠；"Exactly"（精确）是刚性模式：行距固定死，大字可能被裁切。这是两种设计哲学，排版规整的工程图纸常用精确模式，截图中也显示的是"精确"。CSS 的 `line-height` 本质上更接近"AtLeast"语义，所以方案中说 CSS 无直接对应，只能近似。

------

### 字级参数（控制单个字符的形态）

**MTextCharSpacing**（字符间距） 相邻字符之间额外增加的间隙，以字符本身宽度为基准。值为 1.0 是默认密排，无额外间距；1.2 时每个字符右侧多出 0.2 个字宽的空隙，整体文字显得"松散透气"。CAD 用 `\T` 格式码实现（Tracking），CSS 用 `letter-spacing` 实现，语义相同但单位换算方式不同，这也是方案中 `calc(1em * (factor - 1.0))` 的来源。

**MTextObliquingAngle**（倾斜角度） 将字符在不改变字体本身的前提下向右或向左剪切倾斜，制造出"伪斜体"的效果。这和选择斜体字体（Italic）不同——Italic 是字体设计师专门设计的笔画，Obliquing 是纯几何变换，适用于"没有斜体字型的字体"（比如很多中文字体）。值为 0 不倾斜，15 向右倾斜 15°，-15 向左倾斜。CSS 用 `skewX()` 模拟，与 CAD 效果几何等价。

------

### 段级参数（控制整个文字块的行为）

**MTextParagraphAlign**（段落对齐） 每一行文字在 MText 文字框宽度内的横向对齐方式：Left 靠左、Center 居中、Right 靠右、Justify 两端对齐（末行除外）。这是最常见的排版概念，CSS `text-align` 和 CAD MText 的段落对齐格式码（`\pxqc;` 等）语义完全一致。

**MTextAttachment**（附着点） MText 文字框自身相对于插入点的锚定位置，是一个 3×3 的九宫格选项（左上/正上/右上/正左/正中/正右/左下/正下/右下）。它不影响文字内部的排列，只影响"这个文字框整体挂在哪里"。比如插入点在圆心，选"正中"则文字框以圆心为中心展开，选"左上"则文字框从圆心向右下展开。在网页预览中文字天然从左上角流动，所以预览端不需要处理这个参数。

------

### 一张图理解层级关系

```
┌─────────────────────────────────────┐  ← MTextAttachment 决定整框位置
│  ← MTextParagraphAlign 决定行对齐 → │
│  Hello World Abc                    │
│  ↕ LineSpacingFactor                │  ← LineSpacingStyle 决定计量方式
│  H̶e̶l̶l̶o̶  W̶o̶r̶l̶d̶                       │
│  H e l l o                         │  ← CharSpacing 决定字间空隙
│  𝐻𝑒𝑙𝑙𝑜                             │  ← ObliquingAngle 决定字符倾斜
└─────────────────────────────────────┘
```

简单记法：**Attachment** 管框的位置，**ParagraphAlign** 管行的位置，**LineSpacing×2** 管行的高度，**CharSpacing** 管字的间距，**ObliquingAngle** 管字的形状。
