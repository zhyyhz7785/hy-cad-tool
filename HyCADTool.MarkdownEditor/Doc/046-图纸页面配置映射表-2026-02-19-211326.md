| 右边距(px) | `MARGIN_RIGHT` | px | `MarginRightMm × PreviewScale` | 0 | `PAPER_WIDTH - 120` | JS | |
| 上边距(px) | `MARGIN_TOP` | px | `MarginTopMm × PreviewScale` | 0 | `PAPER_HEIGHT - 100` | JS | |
| 下边距(px) | `MARGIN_BOTTOM` | px | `MarginBottomMm × PreviewScale` | 0 | `PAPER_HEIGHT - 100` | JS | |

**边距联合约束**（`ensureMarginBounds()`）：
- `MARGIN_LEFT + MARGIN_RIGHT ≤ PAPER_WIDTH - 120`（保证内区至少 120px 宽）
- `MARGIN_TOP + MARGIN_BOTTOM ≤ PAPER_HEIGHT - 100`（保证内区至少 100px 高）
- 超出时优先压缩右/下边距

### 2.3 分栏参数

| 参数 | 变量 | 单位 | 默认值 | 最小值 | 最大值 | 来源 | 说明 |
|------|------|------|--------|--------|--------|------|------|
| 栏数 | `ColumnCount` | — | 2 | 1 | 10 | ViewModel | |
| 栏间距 | `ColumnGutter` | mm | 10 | 0 | ∞ | ViewModel | |
| 栏间距(px) | `COLUMN_GAP` | px | `ColumnGutter × PreviewScale` | 6 | 260 | JS | `Math.max(6, ...)` 保证可拖拽 |
| 栏宽(px) | `columnWidths[i]` | px | `(innerWidth - totalGap) / N` | 80 | ∞ | JS | 均分后可拖拽微调 |
| 栏高(px) | `columnHeights[i]` | px | `innerHeight - 12` | 80 | `innerHeight` | JS | 每栏独立控制 |

**栏宽默认计算**：
```
innerWidth = PAPER_WIDTH - MARGIN_LEFT - MARGIN_RIGHT     (min 120)
totalGap   = (COLUMN_COUNT - 1) × COLUMN_GAP
defaultColumnWidth = max(80, (innerWidth - totalGap) / COLUMN_COUNT)
```

### 3.2 拖拽行为详解

#### R — 纸张右边拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `paper-right` |
| 改变对象 | `PAPER_WIDTH` |
| 计算公式 | `PAPER_WIDTH = max(180, startW + dx)` |
| 最小值 | 180px |
| 联动 | `updatePaperGeometryStyles()` → `redistributeColumnWidthsEvenly()` → `syncColumnSizesToDom()` → `rebuildPreviewStats()` |
| mouseup 后 | `postPaperGeometry()` + `postPaperScale()` → C# 回写 `PageWidthMm` |
| Ctrl 修饰 | 无特殊行为 |

#### B — 纸张底部拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `paper-bottom` |
| 改变对象 | `PAPER_HEIGHT` |
| 计算公式 | `PAPER_HEIGHT = max(180, startH + dy)` |
| 最小值 | 180px |
| 联动 | 同 R |
| mouseup 后 | 同 R |
| Ctrl 修饰 | 无特殊行为 |

#### C — 纸张右下角拖拽（最复杂）

| 项目 | 值 |
|------|-----|
| dragMode | `paper-corner` |
| 改变对象 | `PAPER_WIDTH` + `PAPER_HEIGHT` |
| **默认行为（无 Ctrl）** | **等比例缩放** |
| 等比例计算 | 按 `startW/startH` 锁定宽高比，dx/dy 谁的比例位移更大即主导轴 |
| 公式（dx 主导） | `PAPER_WIDTH = max(180, startW+dx)`；`PAPER_HEIGHT = max(180, PAPER_WIDTH / ratio)` |
| 公式（dy 主导） | `PAPER_HEIGHT = max(180, startH+dy)`；`PAPER_WIDTH = max(180, PAPER_HEIGHT × ratio)` |
| **Ctrl 按下** | **非等比例自由缩放** |
| 公式 | `PAPER_WIDTH = max(180, startW+dx)`；`PAPER_HEIGHT = max(180, startH+dy)` |
| 最小值 | 两边均 180px |
| 联动 | 同 R |
| mouseup 后 | 同 R |

#### ML — 左边距线拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `margin-left` |
| 改变对象 | `MARGIN_LEFT` |
| 计算公式 | `MARGIN_LEFT = max(0, startMarginLeft + dx)` |
| 约束 | `ensureMarginBounds()`：`MARGIN_LEFT + MARGIN_RIGHT ≤ PAPER_WIDTH - 120` |
| 联动 | `updatePaperGeometryStyles()` → `redistributeColumnWidthsEvenly()` → `syncColumnSizesToDom()` → `rebuildPreviewStats()` |
| mouseup 后 | `postPaperMargins()` → C# 回写 `MarginLeftMm` |

#### MR — 右边距线拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `margin-right` |
| 改变对象 | `MARGIN_RIGHT` |
| 计算公式 | `MARGIN_RIGHT = max(0, startMarginRight - dx)` |
| 约束 | 同 ML |
| mouseup 后 | `postPaperMargins()` |

#### MT — 上边距线拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `margin-top` |
| 改变对象 | `MARGIN_TOP` |
| 计算公式 | `MARGIN_TOP = max(0, startMarginTop + dy)` |
| 约束 | `MARGIN_TOP + MARGIN_BOTTOM ≤ PAPER_HEIGHT - 100` |
| mouseup 后 | `postPaperMargins()` |

#### MB — 下边距线拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `margin-bottom` |
| 改变对象 | `MARGIN_BOTTOM` |
| 计算公式 | `MARGIN_BOTTOM = max(0, startMarginBottom - dy)` |
| 约束 | 同 MT |
| mouseup 后 | `postPaperMargins()` |

#### G — 栏间距拖拽

| 项目 | 值 |
|------|-----|
| dragMode | `col-gap` |
| 改变对象 | `columnWidths[idx]` 和 `columnWidths[idx+1]`（相邻两栏互补） |
| 计算公式 | `left = startWidths[idx] + dx`；`right = startWidths[idx+1] - dx` |
| 最小值 | 两栏各 min 80px |
| 保总宽 | `left + right = startWidths[idx] + startWidths[idx+1]`（总和不变） |
| 联动 | `syncColumnSizesToDom()` → `rebuildPreviewStats()` |
| mouseup 后 | `rebuildColumnsFromCurrent()`（重新分发内容） |

#### CT — 栏顶高度手柄

| 项目 | 值 |
|------|-----|
| dragMode | `col-top` |
| 改变对象 | `columnHeights[colIndex]` |
| 计算公式 | `columnHeights[ci] = clamp(startH - dy, 80, innerHeight)` |
| 方向 | 向上拖增高，向下拖减高 |
| 最小值 | 80px |
| 最大值 | `innerHeight = PAPER_HEIGHT - MARGIN_TOP - MARGIN_BOTTOM` |
| 联动 | `syncColumnSizesToDom()` → `rebuildPreviewStats()` |
| mouseup 后 | `rebuildColumnsFromCurrent()` |

#### CB — 栏底高度手柄

| 项目 | 值 |
|------|-----|
| dragMode | `col-bottom` |
| 改变对象 | `columnHeights[colIndex]` |
| 计算公式 | `columnHeights[ci] = clamp(startH + dy, 80, innerHeight)` |
| 方向 | 向下拖增高，向上拖减高 |
| 最小值 | 80px |
| 最大值 | 同 CT |
| 联动 | 同 CT |
| mouseup 后 | 同 CT |

## 六、px ↔ mm 换算规则

所有 mm 参数在进入 JS 前统一乘以 `PreviewScale` 得到 px。

```
px = mm × PreviewScale
mm = px / PreviewScale
```

JS 侧回传 mm 时：
```
pageWidthMm  = PAPER_WIDTH  / max(0.01, PREVIEW_SCALE)
marginLeftMm = MARGIN_LEFT  / max(0.01, PREVIEW_SCALE)
（其余同理）
```

| C11 | 栏间距最小 | `COLUMN_GAP ≥ 6px` | JS + C# |

| C13 | 栏数范围 | `1 ≤ ColumnCount ≤ 10` | C# + JS `clampNumber` |
| C14 | 角拖拽等比 | 默认锁定 `W/H` 比 | JS `paper-corner` 无 Ctrl |
| C15 | 角拖拽自由 | Ctrl 按下解除等比锁定 | JS `paper-corner` + Ctrl |
| C16 | 栏间拖拽守恒 | `W[i] + W[i+1] = 常量` | JS `col-gap` 拖拽 |

## 十、字宽与栏字数估算

| 参数 | 计算 |
|------|------|
| `basePx` | `TextSize × PreviewScale` |
| `charWidthPx` | `basePx × TextXScale × fontWidthFactor` |
| `charsPerLine` | `max(1, floor((colWidth - 20) / charWidthPx))` |
| 字宽系数 | YaHei=1.0，SimSun=1.03，SHX=0.95 |

栏内 `col-content` 的实际渲染宽度：

```
visualWidth = colWidth / TextXScale     （CSS calc(100% / scaleX) + transform:scaleX）
paddingTotal = 20px                      （8px + 10px 左右 padding 不对称，实际 8+10=约20）
effectiveCharArea = colWidth - paddingTotal
charsPerLine = floor(effectiveCharArea / charWidthPx)
```

## 十一、多页机制

| 行为 | 条件 | 函数 |
