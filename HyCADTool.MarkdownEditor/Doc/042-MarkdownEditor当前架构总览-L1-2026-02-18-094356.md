# MarkdownEditor 当前架构总览（L1）

## 项目定位

`HyCADTool.MarkdownEditor` 是一个被主插件反射调用的 Markdown 设计说明编辑器：  
输入 `EditorInput(JSON)`，在 WebView2 中完成编辑与图纸预览排版，输出 `EditorResult(JSON)` 给 `HyCADTool.Refactored`，用于手动插入和实时同步到 AutoCAD。

## 技术栈

- 框架：`.NET 8 WPF`（`net8.0-windows`，x64）
- Web 容器：`Microsoft.Web.WebView2 1.0.3065.39`
- Markdown 渲染：`Markdig 0.37.0`
- JSON 协议：`Newtonsoft.Json 13.0.3`
- 布局引擎：项目引用 `HyCADTool.TextLayout`

## 模块关系图（文字版）

`EditorLauncher`（外部入口/回调桥）
-> `EditorWindow`（主窗口编排）
-> `EditorViewModel`（状态与命令）
-> `Services/PreviewManager`（预览总调度：解析/布局/同步）
-> `Html/PreviewHtmlRenderer`（HTML/CSS/JS 渲染与交互）
-> `Views/Controls/*`（预览面板/左侧树/标题栏/标尺）
-> `Models/EditorContract`（输入输出契约）

并行链路：

- `EditorViewModel` -> `Html/VditorJsHelper`（编辑面板命令）
- `EditorViewModel` -> `PreviewEditorActionRequested` -> 预览 WebView `applyEditorAction`（图纸面板命令兜底）

## 数据流（当前实现）

1. 主项目传入 `inputJson` 到 `EditorLauncher`，反序列化为 `EditorInput`。
2. `EditorWindow` 初始化两个 WebView 通道（编辑面板 + 图纸预览面板），并挂载消息回调。
3. 内容更新时，`PreviewManager` 走统一链路：  
   `Markdown` -> `MarkdownBlockParser` -> `LayoutEngine` -> `PreviewHtmlRenderer` -> 预览 DOM。
4. 预览侧 `contentChanged` 回传 `markdown + version + hash`，`PreviewManager` 去重后更新 `ViewModel.MarkdownText`。
5. `EditorWindow` 通过 `_isUpdatingFromPreview + 文本哈希` 避免编辑器与预览互相覆盖形成回写环。
6. 手动同步（Insert CAD）和实时同步（debounce live sync）都输出 `EditorResult` 回主项目。

## 当前交互模式（2026-02 代码现状）

- 双通道仍保留：`EditorWebView` 可见时继续走 Vditor 命令链。
- 已支持图纸主编辑模式：可隐藏编辑面板，仅在预览分栏区编辑。
- 命令路由可切换：当编辑面板不可用时，工具栏动作自动转发到预览 `applyEditorAction`。
- 预览编辑链路已加固：版本号、哈希去重、选区书签恢复、增量重排、内容提取兜底。
- 目标形态是单面板，但当前仍保留编辑面板作为回退通道。
