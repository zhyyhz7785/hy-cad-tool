# Views 模块说明（L2）

> 生成时间：2026-02-15

---

## 职责

Views 模块是整个编辑器的 **UI 层**，包含主窗口（EditorWindow）和 5 个子控件，以及全局主题资源。负责：

- 窗口布局与面板可见性切换（大纲 / 预览 / 底部面板 / 标尺）
- WebView2 编辑器初始化 + JS 消息收发
- 预览刷新调度（防抖 180ms）
- 文件树操作（新建 / 重命名 / 删除 / 排序 / 最近目录）
- 三种工作区模式切换（写作 / 排版 / 校对）
- 毫米标尺自绘

## 关键接口/事件

### EditorWindow（主窗口）

- `EditorResult Result` — 窗口关闭后的编辑结果
- 内部通过 `WireChildControlEvents()` 订阅所有子控件事件

### TitleBarControl

- `ThemeDarkRequested` / `ThemeLightRequested` — 主题切换
- `ToggleRulerRequested` / `ToggleOutlineRequested` / `ToggleBottomPanelRequested` / `TogglePreviewRequested`
- `ConfirmRequested` / `MinimizeRequested` / `MaxRestoreRequested` / `CloseRequested`
- `WorkspaceModeRequested` — Writing / Layout / Proofread
- `DragMoveRequested` / `SystemMenuRequested`
- `UpdateToggleState(...)` — 刷新按钮高亮
- `UpdateWindowState(bool)` — 最大化/还原图标

### LeftPanelControl

- `FileOpenRequested` — 请求打开 .md 文件
- `OutlineHeadingSelected` — 大纲标题点击 → 编辑器滚动
- `StatusChanged` — 状态栏消息
- `CurrentFilePathChanged` / `CurrentFileClearedRequested`
- `RefreshOutline(string)` / `RefreshFileList(string)` — 外部调用刷新

### PreviewPanelControl

- `TogglePageOrientationRequested` — 横竖切换
- `PreviousPageRequested` / `NextPageRequested` / `JumpPageRequested` — 翻页
- `UpdatePageState(int, int)` — 更新页码显示
- 属性暴露：`PreviewGrid`、`PreviewWebViewControl`、`HorizontalRuler`、`VerticalRuler`

### RulerControl

- DP：`Orientation`、`PixelsPerMm`、`SegmentCount` + 5 个颜色 Brush
- 自绘 `OnRender`（20mm 大刻度，4mm 小刻度，文字缓存）

## 模块内协作

```
EditorWindow（中枢，拥有所有子控件引用）
  ├─ 监听 TitleBarControl 11 个事件 → 布局/主题/确认
  ├─ 监听 LeftPanelControl 5 个事件 → 打开文件/跳转标题/状态
  ├─ 监听 PreviewPanelControl 4 个事件 → 翻页/横竖切换
  ├─ 通过 PreviewManager 驱动 PreviewWebView 渲染
  ├─ 通过 ThemeManager 操作 EditorTheme.xaml 资源
  ├─ BottomPanelControl 完全由 XAML DataBinding → EditorViewModel
  └─ RulerControl 由 PreviewManager.UpdateRulerScale() 设置参数
```
