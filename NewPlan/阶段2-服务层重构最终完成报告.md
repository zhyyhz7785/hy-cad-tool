### B. 服务使用快速参考

```csharp
// 获取服务
var drawingService = ServiceLocator.Resolve<IDrawingService>();
var editorService = ServiceLocator.Resolve<IEditorService>();
var databaseService = ServiceLocator.Resolve<IDatabaseService>();

// 绘制图形
drawingService.DrawLine(pt1, pt2, "LayerName");
drawingService.DrawCircle(center, radius);

// 用户交互
var point = editorService.GetPoint("请选择点");
var distance = editorService.GetDistance("请输入距离");

// 数据库查询
var entities = databaseService.GetAllEntitiesInModelSpace();
var layers = databaseService.GetAllLayerNames();

// 使用扩展方法
using HyCADTool.Refactored.Infrastructure.AutoCAD.Utilities;

var line = new Line(pt1, pt2)
    .SetLayer("Layer1")
    .SetColor(1)
    .Move(origin, newPosition);
```
