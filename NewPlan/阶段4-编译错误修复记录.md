### 错误 2: HashCode 类型不存在（1 处）

**错误信息**:
```
CS0103: 当前上下文中不存在名称"HashCode"
```

**原因**:
- `HashCode.Combine()` 是 .NET Core/.NET 5+ 的 API
- 项目使用 .NET Framework 4.8，不支持该 API

**修复方案**:
使用传统的哈希码计算方式

**修改文件**:
- `Domain/ValueObjects/Grid/RowColValue.cs`

**修复代码**:
```csharp
public override int GetHashCode()
{
    // .NET Framework 4.8 不支持 HashCode.Combine，使用传统方式
    unchecked
    {
        int hash = 17;
        hash = hash * 23 + Row.GetHashCode();
        hash = hash * 23 + Col.GetHashCode();
        hash = hash * 23 + (Value != null ? Value.GetHashCode() : 0);
        return hash;
    }
}
```

## 💡 经验教训

### 1. AutoCAD API 类型冲突

**常见问题**:
- `Polyline`, `Line`, `Circle` 等类型在多个命名空间中存在

**标准做法**:
```csharp
using AcDb = Autodesk.AutoCAD.DatabaseServices;
using AcGi = Autodesk.AutoCAD.GraphicsInterface;
using AcGe = Autodesk.AutoCAD.Geometry;
using AcEd = Autodesk.AutoCAD.EditorInput;
using AcApp = Autodesk.AutoCAD.ApplicationServices.Application;
```

### 2. .NET Framework vs .NET Core API 差异

**注意事项**:
- `HashCode.Combine()` - .NET Core/.NET 5+ only
- `Span<T>` - .NET Core/.NET 5+ only
- `ValueTuple` - .NET Framework 4.7+ 需要 NuGet 包

**项目目标框架**: .NET Framework 4.8
- 使用传统 API
- 避免使用新的 .NET Core API

### 3. 值类型 vs 引用类型

**值类型（struct）**:
- 永远不会为 `null`
- 不能使用 `?.` 运算符
- 示例: `Point2D`, `Vector2D`, `int`, `double`

**引用类型（class）**:
- 可以为 `null`
- 可以使用 `?.` 运算符
- 示例: `Pile`, `RowColValue<T>`, `string`
