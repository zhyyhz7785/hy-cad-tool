   ```csharp

    .As<IEditorService>()
    .SingleInstance();
```

**注册策略**:
- 所有服务注册为**单例（SingleInstance）**
- 服务无状态设计，线程安全
- 通过 ServiceLocator 解析服务

### 数据流向

```
1. 命令执行:
   用户输入命令 → CommandMethod 方法 → ServiceLocator.Resolve<IXxxService>()

2. 绘制操作:
   DrawingService.DrawLine() 
   → 开启事务 → 获取 BlockTableRecord
   → 创建实体 → AppendEntity 
   → AddNewlyCreatedDBObject → Commit

3. 用户交互:
   EditorService.GetPoint() 
   → PromptPointOptions → Editor.GetPoint()
   → 返回 Point3d? (取消返回null)

4. 数据库查询:
   DatabaseService.GetAllEntitiesInModelSpace()
   → 开启事务 → 获取 ModelSpace BlockTableRecord
   → 遍历实体 → 返回 ObjectId[]
```

## 🎓 技术要点

### 设计模式应用

| 模式 | 应用场景 | 收益 |
|------|----------|------|
| **Service Layer** | 封装 AutoCAD 操作 | 分离关注点、可测试 |
| **Dependency Injection** | 服务依赖管理 | 松耦合、可替换 |
| **Extension Methods** | 辅助工具类 | 简化代码、增强可读性 |
| **Fluent Interface** | EntityHelper 链式调用 | 提升开发体验 |
| **Template Method** | 测试运行器 | 统一测试框架 |

### 关键技术决策

| 决策 | 理由 | 影响 |
|------|------|------|
| **服务注册为单例** | 服务无状态、线程安全 | ✅ 提升性能 |
| **接口与实现分离** | 符合依赖倒置原则 | ✅ 可测试、可替换 |
| **扩展方法模式** | 简化 API 使用 | ✅ 提升开发效率 |
| **链式调用支持** | Fluent Interface 设计 | ✅ 增强可读性 |
| **泛型约束** | 类型安全的实体操作 | ✅ 编译时检查 |
| **可空返回类型** | 明确表示取消操作 | ✅ 避免异常处理 |

### 最佳实践

1. **服务方法应简洁、单一职责**
   - ✅ 每个方法只做一件事
   - ✅ 方法名清晰表达意图

2. **参数验证放在方法开头**
   - ✅ 早期验证、早期失败
   - ✅ 提供有意义的异常消息

3. **事务管理使用 using 语句**
   - ✅ 确保资源正确释放
   - ✅ 异常时自动回滚

4. **扩展方法应有清晰的命名空间**
   - ✅ `Infrastructure.AutoCAD.Utilities`
   - ✅ 便于管理和使用

5. **测试应覆盖核心功能**
   - ✅ 服务注册验证
   - ✅ 基本功能验证
   - ✅ 错误处理验证
