## 一、现状分析

### 1.1 当前架构问题

通过分析典型命令（`hyab.cs`、`OverKill.cs`、`hybg.cs`），发现以下问题：

| 问题 | 表现 | 影响 |
|------|------|------|
| **单体命令方法** | 130+ 行代码在一个方法中 | 难以维护、测试、复用 |
| **职责混淆** | 用户交互 + 业务逻辑 + 数据操作 | 违反单一职责原则 |
| **直接耦合** | 直接操作 Database/Transaction/Editor | 无法单元测试 |
| **重复代码** | 选择实体、事务管理、错误处理 | 维护成本高 |
| **异常处理** | 每个命令独立处理异常 | 不一致，易遗漏 |

### 1.2 命令分类

| 分类 | 示例 | 复杂度 |
|------|------|--------|
| **简单调用** | BR01Command | 低（直接调用静态方法）|
| **数据操作** | hyab（锚栓）| 中（创建实体+扩展字典）|
| **几何处理** | OverKill | 高（复杂算法+事务管理）|
| **交互绘图** | hybg（标高）| 高（Jig 交互+参数配置）|
| **面板命令** | PanelCommand | 中（依赖注入+UI 管理）|

### 2.2 核心接口设计

#### ICommand（命令模式）

```csharp
public interface ICommand
{
    string Name { get; }
    string Description { get; }
    Task<CommandResult> ExecuteAsync(CommandContext context);
    bool CanExecute(CommandContext context);
}

public class CommandResult
{
    public bool IsSuccess { get; set; }
    public string Message { get; set; }
    public Exception Exception { get; set; }
    public object Data { get; set; }
}

public class CommandContext
{
    public Document Document { get; set; }
    public Editor Editor { get; set; }
    public Dictionary<string, object> Parameters { get; set; }
}
```

#### IUseCase（业务逻辑）

```csharp
public interface IUseCase<TRequest, TResponse>

    Task<TResponse> ExecuteAsync(TRequest request);
```

#### ICommandExecutor（执行框架）

```csharp
public interface ICommandExecutor
{
    Task<CommandResult> ExecuteAsync(ICommand command, CommandContext context);
    Task<CommandResult> ExecuteAsync(string commandName, CommandContext context);
}

public class CommandExecutor : ICommandExecutor
{
    private readonly ICommandRegistry _registry;
    private readonly ILogger _logger;
    private readonly ICommandValidator _validator;
    
    public async Task<CommandResult> ExecuteAsync(ICommand command, CommandContext context)
    {
        try
        {
            // 1. 参数验证
            if (!_validator.Validate(command, context))
                return CommandResult.Failure("参数验证失败");
            
            // 2. 权限检查
            if (!command.CanExecute(context))
                return CommandResult.Failure("无法执行命令");
            
            // 3. 执行命令
            _logger.LogInfo($"开始执行命令: {command.Name}");
            var result = await command.ExecuteAsync(context);
            
            // 4. 结果记录
            _logger.LogInfo($"命令执行完成: {command.Name}, 成功: {result.IsSuccess}");
            return result;
        }
        catch (Exception ex)
        {
            _logger.LogError($"命令执行异常: {command.Name}", ex);
            return CommandResult.Failure($"执行失败: {ex.Message}", ex);
        }
    }
}
```

### 3.2 示例实现：锚栓命令重构

#### 1. Use Case（业务逻辑）

```csharp
// Application/UseCases/AnchorBolt/CreateAnchorBoltUseCase.cs
public class CreateAnchorBoltUseCase : ICreateAnchorBoltUseCase
{
    private readonly IAnchorBoltService _anchorBoltService;
    private readonly ILayerService _layerService;
    private readonly IEntityRepository _entityRepository;
    
    public CreateAnchorBoltUseCase(
        IAnchorBoltService anchorBoltService,
        ILayerService layerService,
        IEntityRepository entityRepository)
    {
        _anchorBoltService = anchorBoltService;
        _layerService = layerService;
        _entityRepository = entityRepository;
    }
    
    public async Task<CreateAnchorBoltResponse> ExecuteAsync(CreateAnchorBoltRequest request)
    {
        // 1. 创建锚栓对象
        var bolt = _anchorBoltService.CreateBolt(request.BoltModel);
        
        // 2. 确保图层存在
        await _layerService.EnsureLayerExistsAsync(request.LayerName, ColorIndex.Yellow);
        
        // 3. 处理每个圆
        var newCircleIds = new List<ObjectId>();
        foreach (var circleId in request.CircleIds)
        {
            var oldCircle = await _entityRepository.GetEntityAsync<Circle>(circleId);
            if (oldCircle == null) continue;
            
            // 创建新圆
            var newCircle = new Circle
            {
                Center = oldCircle.Center,
                Radius = bolt.D / 2.0,
                Layer = request.LayerName
            };
            
            // 添加扩展数据
            _anchorBoltService.AttachBoltData(newCircle, bolt);
            
            // 保存并删除旧圆
            var newId = await _entityRepository.AddEntityAsync(newCircle);
            await _entityRepository.DeleteEntityAsync(circleId);
            
            newCircleIds.Add(newId);
        }
        
        return new CreateAnchorBoltResponse
        {
            IsSuccess = true,
            ProcessedCount = newCircleIds.Count,
            NewCircleIds = newCircleIds,
            Message = $"成功处理 {newCircleIds.Count} 个锚栓"
        };
    }
}
```

#### 2. Command（命令封装）

```csharp
// Application/Commands/AnchorBolt/CreateAnchorBoltCommand.cs
public class CreateAnchorBoltCommand : CommandBase
{
    private readonly ICreateAnchorBoltUseCase _useCase;
    private readonly IUserInteraction _userInteraction;
    
    public CreateAnchorBoltCommand(
        ICreateAnchorBoltUseCase useCase,
        IUserInteraction userInteraction)
    {
        _useCase = useCase;
        _userInteraction = userInteraction;
    }
    
    public override string Name => "CreateAnchorBolt";
    public override string Description => "创建锚栓";
    
    public override async Task<CommandResult> ExecuteAsync(CommandContext context)
    {
        // 1. 获取用户输入
        var boltModel = await _userInteraction.GetStringAsync(
            "请输入地脚螺栓型号 (1-9) [默认1]: ", "1");
        if (string.IsNullOrEmpty(boltModel))
            return CommandResult.Cancelled();
        
        // 2. 选择圆
        var circleIds = await _userInteraction.SelectEntitiesAsync<Circle>(
            "请选择多个圆 (将被转换为带螺栓数据的圆): ");
        if (!circleIds.Any())
            return CommandResult.Cancelled();
        
        // 3. 执行业务逻辑
        var request = new CreateAnchorBoltRequest
        {
            BoltModel = boltModel,
            CircleIds = circleIds.ToList(),
            LayerName = $"00_Hy_螺栓_{boltModel}"
        };
        
        var response = await _useCase.ExecuteAsync(request);
        
        return response.IsSuccess 
            ? CommandResult.Success(response.Message, response)
            : CommandResult.Failure(response.Message);
    }
    
    public override bool CanExecute(CommandContext context)
    {
        return context?.Document != null;
    }
}
```

#### 3. AutoCAD Command（表现层）

```csharp
// Presentation/Commands/AnchorBoltCommands.cs
public static class AnchorBoltCommands
{
    private static ICommandExecutor _commandExecutor;
    
    static AnchorBoltCommands()
    {

        _commandExecutor = ServiceLocator.GetService<ICommandExecutor>();

    [CommandMethod("hyab")]

    {
        var context = new CommandContext
        {
            Document = Application.DocumentManager.MdiActiveDocument,
            Editor = Application.DocumentManager.MdiActiveDocument.Editor

        var result = await _commandExecutor.ExecuteAsync("CreateAnchorBolt", context);
        
        context.Editor.WriteMessage(result.IsSuccess 
            ? $"\n✓ {result.Message}" 
            : $"\n✗ {result.Message}");
    }
}
```

## 七、预期成果

### 代码质量提升
- ✅ 单一职责：命令只处理用户交互，Use Case 处理业务逻辑
- ✅ 可测试性：业务逻辑与 AutoCAD API 解耦
- ✅ 可维护性：统一的命令执行框架和错误处理
- ✅ 可扩展性：新命令只需实现 ICommand 接口

### 架构收益
- ✅ 符合 Clean Architecture 原则
- ✅ 依赖倒置：上层不依赖下层具体实现
- ✅ 开闭原则：新增命令无需修改现有代码
- ✅ 接口隔离：小而专注的接口设计
