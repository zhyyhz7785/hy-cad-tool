## 🐛 发现的编译错误

### 错误 1: Vector2D.Dot 方法没有静态重载

**错误信息**:
```
"Dot"方法没有采用 2 个参数的重载
```

**原因**:
- `Vector2D` 类只有实例方法 `Dot(Vector2D other)`
- 但代码中使用了 `Vector2D.Dot(v1, v2)` 静态调用

**修复方案**:
在 `Vector2D.cs` 中添加静态方法：

```csharp
/// <summary>
/// 点积（静态方法）
/// </summary>
public static double Dot(Vector2D a, Vector2D b)
{
    return a.X * b.X + a.Y * b.Y;
}
```

**文件**: `HyCADTool.Refactored/Domain/ValueObjects/Geometry/Vector2D.cs`

### 错误 2: Exception 类型不明确

**错误信息**:
```
"Exception"是"Autodesk.AutoCAD.Runtime.Exception"和"System.Exception"之间的不明确的引用
```

**原因**:
- `TestRunner.cs` 同时引用了两个命名空间
- `Autodesk.AutoCAD.Runtime` 和 `System` 都有 `Exception` 类

**修复方案**:
1. 添加 using 别名：
```csharp
using SysException = System.Exception;
```

2. 替换所有 `throw new Exception` 为 `throw new SysException`

3. 替换所有 `Math.Abs` 为 `System.Math.Abs`（避免冲突）

**文件**: `HyCADTool.Refactored/Test/TestRunner.cs`

**修改数量**: 23 处

### 错误 3: Polyline.GetDistAtParameter 不存在

**错误信息**:
```
"Polyline"未包含"GetDistAtParameter"的定义
```

**原因**:
- AutoCAD API 中 Polyline 的方法名是 `GetDistAtParam`（不是 `GetDistAtParameter`）

**修复方案**:
将 `GetDistAtParameter` 替换为 `GetDistAtParam`：

```csharp
// 修复前
lengths[i] = poly.GetDistAtParameter(i + 1) - poly.GetDistAtParameter(i);

// 修复后
lengths[i] = poly.GetDistAtParam(i + 1) - poly.GetDistAtParam(i);
```

**文件**: `HyCADTool.Refactored/Infrastructure/AutoCAD/Extensions/PolylineExtensions.cs`

## 💡 经验总结

### 1. AutoCAD API 命名规范
- AutoCAD 方法名通常使用缩写（如 `GetDistAtParam` 而非 `GetDistAtParameter`）
- 使用时需参考官方文档或智能提示

### 2. 命名空间冲突处理
- 使用 using 别名避免类型冲突
- 明确使用完整命名空间（如 `System.Math.Abs`）

### 3. 静态方法 vs 实例方法
- 提供常用操作的静态重载可提高 API 便利性
- 如 `Vector2D.Dot(v1, v2)` 比 `v1.Dot(v2)` 更直观
