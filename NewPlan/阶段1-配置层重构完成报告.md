## 💡 核心特性

### 1. **配置分离**
- 全局配置与模块配置完全分离
- 模块配置可独立管理、独立导入/导出
- 清晰的职责划分

### 2. **类型安全**
- 强类型配置对象
- 编译时检查
- 减少运行时错误

### 3. **验证机制**
- 所有配置值对象都有 `IsValid()` 方法
- 在加载和更新时进行验证
- 提供友好的错误信息

### 4. **默认值支持**
- 所有配置都有 `CreateDefault()` 方法
- 配置加载失败时自动回退到默认值
- 确保系统始终可用

### 5. **兼容性**
- JSON 加载器支持旧格式（`BaseConfigData`）
- 自动迁移到新格式
- 无缝升级

### 6. **依赖注入**
- 所有配置服务注册为单例
- 通过接口访问，易于测试
- 解耦高内聚

## 📝 使用示例

### 示例 1: 获取全局配置

```csharp
public class SomeService
{
    private readonly IConfigurationService _configService;
    
    public SomeService(IConfigurationService configService)
    {
        _configService = configService;
    }
    
    public void DoSomething()
    {
        // 获取全局比例
        double scale = _configService.Global.Scale.Default;
        
        // 获取容差
        double tolerance = _configService.Global.Tolerance.Double;
        
        // 获取文本样式
        var textStyle = _configService.Global.Styles.TextStyle;
        string styleName = textStyle.Name;
    }
}
```

### 示例 2: 获取模块配置

```csharp
public class PileService
{
    private readonly IConfigurationService _configService;
    
    public PileService(IConfigurationService configService)
    {
        _configService = configService;
    }
    
    public void DrawPile()
    {
        // 获取桩基模块配置
        var pileConfig = _configService.GetModuleConfig<PileConfiguration>("Pile");
        
        // 使用配置
        double diameter = pileConfig.DiameterOrEdge;
        var section = pileConfig.Section;
        var margin = pileConfig.Margin;
        
        // 绘制桩...
    }
}
```

### 示例 3: 更新配置

```csharp
public void UpdateScale()
{
    var configService = ServiceLocator.Current.Resolve<IConfigurationService>();
    
    // 获取当前比例
    double currentScale = configService.GetScale();
    
    // 更新比例
    configService.SetScale(50.0);
    
    // 保存配置
    configService.SaveAll();
}
```
