## 三、设计要点

- 领域层（Domain）只放接口契约，不暴露 AutoCAD 具体类型以外的实现细节
- 基础设施层（Infrastructure）负责：
  - 将 AutoCAD `DxfCode`/`TypedValue` 细节封装到 Builder/Service
  - 提供实体属性过滤器（替代旧版 `FilterManager` 的内聚实现）
- 测试策略：
  - 全部采用只读路径（不写库），可在任何 DWG 执行
  - 统一纳入 `C1` 命令（`TestRunner.RunAllTests`）

---

## 四、接口与实现摘要

- ISelectionFilterService
  - `Build(type?, layer?, color?, linetype?, lineweight?) -> SelectionFilter`
  - `BuildFromEntity(entity, byLayer?, byColor?, byLinetype?, byLineWeight?, byType?) -> SelectionFilter`

- SelectionService 扩展
  - `SelectAllWithFilter(...)`（静默全选）
  - `SelectEntitiesWithFilter(prompt, ...)`（交互选择）

- SelectionFilterBuilder
  - 规则：多条件使用 `<AND ... AND>` 包裹；类型值使用 `DxfCode.Start`

```23:56:HyCADTool.Refactored/Infrastructure/AutoCAD/Selection/SelectionFilterBuilder.cs
public TypedValue[] BuildValues() {
    if (_conditions.Count == 0) return new TypedValue[0];
    if (_conditions.Count == 1) return _conditions.ToArray();
    var result = new List<TypedValue>();
    result.Add(new TypedValue((int)DxfCode.Operator, "<AND"));
    result.AddRange(_conditions);
    result.Add(new TypedValue((int)DxfCode.Operator, "AND>"));
    return result.ToArray();
}
```

```12:21:HyCADTool.Refactored/Infrastructure/AutoCAD/Selection/SelectionFilterService.cs
public SelectionFilter Build(string dxfType=null, string layerName=null, short? colorIndex=null,
    string linetypeName=null, LineWeight? lineWeight=null)
{
    var b = new SelectionFilterBuilder();
    if (!string.IsNullOrEmpty(dxfType)) b.ByType(dxfType);
    if (!string.IsNullOrEmpty(layerName)) b.ByLayer(layerName);
    if (colorIndex.HasValue) b.ByColorIndex(colorIndex.Value);
    if (!string.IsNullOrEmpty(linetypeName)) b.ByLinetype(linetypeName);
    if (lineWeight.HasValue) b.ByLineWeight(lineWeight.Value);
    return b.BuildFilter();
}
```

## 六、兼容性与注意事项

- .NET Framework 4.8：避免使用 `HashCode.Combine` 等较新 API
- AutoCAD 类型命名冲突：必要时使用别名（`using AcDbPolyline = ...Polyline;`）
- 颜色索引：`ColorIndex` 转换为 `short`（已修复 `CS1503`）
- 只读测试：避免事务写入，保证任何图纸可运行
