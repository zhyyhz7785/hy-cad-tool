## 💡 关键设计

### 1. 平台无关算法

```csharp
// Domain 层 - 纯 C#，无 AutoCAD 依赖
public static class PointAlgorithms
{
    public static double Distance(Point2D p1, Point2D p2)
    {
        double dx = p2.X - p1.X;
        double dy = p2.Y - p1.Y;
        return Math.Sqrt(dx * dx + dy * dy);
    }
}
```

### 2. 扩展方法桥接

```csharp
// Infrastructure 层 - 桥接 Domain 和 AutoCAD
public static class PolylineExtensions
{
    public static bool ContainsPoint(this Polyline poly, Point3d point)
    {
        // 转换 AutoCAD → Domain
        var vertices = poly.GetAllVertices2d()
            .Select(p => new Point2D(p.X, p.Y));
        
        // 调用 Domain 算法
        return PolygonAlgorithms.ContainsPoint(vertices, new Point2D(point.X, point.Y));
    }
}
```

### 3. Blender 迁移

```python
# Python (Blender) - 直接翻译 Domain 算法
class PointAlgorithms:
    @staticmethod
    def distance(p1: Point2D, p2: Point2D) -> float:
        dx = p2.x - p1.x
        dy = p2.y - p1.y
        return math.sqrt(dx * dx + dy * dy)
```
