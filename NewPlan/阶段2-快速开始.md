## 🎓 服务使用示例

### 示例 1: 使用 DrawingService 绘制图形

```csharp
using HyCADTool.Refactored.Infrastructure.Configuration;
using HyCADTool.Refactored.Domain.Interfaces;
using Autodesk.AutoCAD.Geometry;

// 获取绘制服务
var drawingService = ServiceLocator.Resolve<IDrawingService>();

// 绘制线段
var lineId = drawingService.DrawLine(
    new Point3d(0, 0, 0),
    new Point3d(100, 100, 0),
    layerName: "MyLayer"  // 可选，指定图层
);

// 绘制多段线
var points = new[] {
    new Point2d(0, 0),
    new Point2d(100, 0),
    new Point2d(100, 100),
    new Point2d(0, 100)
};
var polyId = drawingService.DrawPolyline(points, isClosed: true);

// 绘制圆
var circleId = drawingService.DrawCircle(
    new Point3d(50, 50, 0),
    30  // 半径
);
```

```csharp

// 获取所有实体
```

### 示例 4: 使用 TransactionHelper 扩展方法

```csharp

var db = databaseService.GetCurrentDatabase();

using (var tr = db.TransactionManager.StartTransaction())
{
    // 获取实体
```

## 🐛 常见问题

### Q1: 编译时找不到接口定义？

**A**: 检查命名空间引用：
```csharp
using HyCADTool.Refactored.Domain.Interfaces;
using HyCADTool.Refactored.Infrastructure.Configuration;
```

### Q2: ServiceLocator 无法解析服务？

**A**: 确保：
1. `AutofacModule.cs` 中已注册服务
2. `PluginInitializer` 已初始化 ServiceLocator
3. 使用 `C2` 命令重新加载 DLL

### Q3: 测试命令无响应？

**A**: 检查：
1. 是否使用 `C2` 加载了最新的 DLL
2. AutoCAD 命令行是否有错误提示
3. 检查文档是否处于锁定状态

### Q4: 绘制的实体看不见？

**A**: 可能原因：
1. 实体在当前视图范围外（使用 ZOOM EXTENTS）
2. 图层被冻结或关闭
3. 颜色与背景色相同
