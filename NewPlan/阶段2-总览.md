## 💡 关键特性

### 1. 统一的服务接口

```csharp
var drawingService = ServiceLocator.Resolve<IDrawingService>();
var lineId = drawingService.DrawLine(pt1, pt2);
```

### 2. 链式调用

```csharp
var line = new Line(pt1, pt2)
    .SetLayer("Layer1")
    .SetColor(1)
    .Move(origin, newPosition);
```

### 3. 简化事务操作

```csharp
using (var tr = db.TransactionManager.StartTransaction())
{
    var entity = tr.GetEntity<Line>(lineId);
    tr.ModifyEntity<Line>(lineId, line => line.Color = Color.FromColorIndex(ColorMethod.ByAci, 1));
    tr.Commit();
}
```
