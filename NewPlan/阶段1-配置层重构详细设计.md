# 阶段 1: 配置层重构详细设计

## 设计理念

配置系统分为两大类：

### 1. 全局配置（Global Configuration）
**特点**：
- 影响整个应用程序
- 所有功能模块共享
- 通常在应用启动时初始化
- 较少变更

**包含内容**：
- **绘图比例（Scale）**：全局统一的绘图比例
- **样式配置**：
  - 文本样式（TextStyle）
  - 标注样式（DimensionStyle）
  - 多重引线样式（MLeaderStyle）
  - 表格样式（TableStyle）
- **图层配置（LayerConfiguration）**：标准图层定义
- **线型配置（LinetypeConfiguration）**：标准线型（虚线、点划线等）
- **容差配置（Tolerance）**：几何计算容差
- **路径配置（Paths）**：
  - 默认导出路径
  - 默认导入路径
  - 临时文件路径
- **CAD 环境配置**：
  - 捕捉设置
  - 栅格设置
  - 等其他 CAD 环境参数

### 2. 模块独立配置（Module Configuration）
**特点**：
- 仅影响特定功能模块
- 独立存储和管理
- 可以有自己的默认值
- 可以独立导入/导出

**包含内容**：
- **桩基配置（PileConfiguration）**：
  - 桩截面类型
  - 桩直径/边长
  - 布置类型
  - 边距
  - 最小桩间距
  - 等桩基特定参数
  
- **基础配置（FoundationConfiguration）**：
  - 基础类型
  - 基础尺寸
  - 配筋参数
  - 等基础特定参数
  
- **钢筋配置（ReinforcementConfiguration）**：
  - 钢筋直径
  - 钢筋间距
  - 锚固长度
  - 保护层厚度
  - 等钢筋特定参数
  
- **标高配置（ElevationConfiguration）**：
  - 标高符号样式
  - 标高文字格式
  - 等标高特定参数

### 3. 核心类设计

#### 3.1 全局配置主类
```csharp
public class GlobalConfiguration
{
    public ScaleConfig Scale { get; set; }
    public ToleranceConfig Tolerance { get; set; }
    public PathConfig Paths { get; set; }
    public StylesConfig Styles { get; set; }
    public LayerConfig Layers { get; set; }
    public LinetypeConfig Linetypes { get; set; }
    
    public static GlobalConfiguration CreateDefault();
    public bool IsValid(out string error);
    public GlobalConfiguration Clone();
}
```

#### 3.2 模块配置服务
```csharp
public class ModuleConfigurationService : IModuleConfigService
{
    // 存储各模块配置
    private readonly Dictionary<string, object> _moduleConfigs;
    
    // 获取指定模块的配置
    public T GetModuleConfig<T>(string moduleName) where T : class;
    
    // 更新指定模块的配置
    public void UpdateModuleConfig<T>(string moduleName, T config) where T : class;
    
    // 重置模块配置为默认值
    public void ResetModuleConfig(string moduleName);
}
```

#### 3.3 配置服务总协调
```csharp
public class ConfigurationService : IConfigurationService
{
    private readonly GlobalConfigurationService _globalConfig;
    private readonly ModuleConfigurationService _moduleConfig;
    
    // 提供统一的配置访问入口
    public GlobalConfiguration Global => _globalConfig.GetConfiguration();
    
    public T GetModuleConfig<T>(string moduleName) where T : class 
        => _moduleConfig.GetModuleConfig<T>(moduleName);
    
    // 加载所有配置
    public void LoadAll();
    
    // 保存所有配置
    public void SaveAll();
}
```

```csharp
    public void DrawSomething()

        // 获取全局比例

        // 获取文本样式
        var textStyle = _configService.Global.Styles.TextStyle;
        
        // 使用配置...
    }
}
```

### 模块配置使用
```csharp
public class PileService

```

## 优势

1. **清晰分离**：全局配置与模块配置分离，职责明确
2. **独立管理**：模块配置可以独立导入/导出，不影响全局配置
3. **易于扩展**：添加新模块时，只需添加新的模块配置类
4. **类型安全**：强类型配置对象，编译时检查
5. **可测试性**：配置服务可以轻松 Mock，便于单元测试
6. **灵活性**：模块配置可以有自己的验证逻辑和默认值

## 与原项目的对应关系

| 原项目 | 重构后 |
|--------|--------|
| `BaseConfig` 静态类 | `GlobalConfiguration` + `GlobalConfigurationService` |
| `ConfigManager.ImportConfigFromCsv()` | `JsonConfigurationLoader.LoadGlobalConfig()` |
| `PileConfig.Instance` | `ModuleConfigurationService.GetModuleConfig<PileConfiguration>("Pile")` |
| 硬编码的样式参数 | `StylesConfig` 中的配置化参数 |
