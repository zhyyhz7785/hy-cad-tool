## 📝 技术说明

### 为什么需要添加到 .csproj？

在 .NET Framework 项目中（不是 .NET Core/5+），项目文件需要**显式列出**所有要编译的源文件。如果文件不在 `.csproj` 中，编译器将**忽略**该文件。

### .NET Core/.NET 5+ 的区别

在较新的 .NET 项目中，项目文件使用 **SDK 样式**，会**自动包含**所有 `.cs` 文件，无需显式列出。但我们使用的是 .NET Framework 4.8，所以需要手动添加。

### 如何避免此类问题？

1. **使用 Visual Studio 添加文件**
   - 在解决方案资源管理器中右键 → 添加 → 新建项
   - Visual Studio 会自动更新 `.csproj`

2. **手动创建后立即更新 .csproj**
   - 创建 `.cs` 文件后
   - 在 `.csproj` 中添加 `<Compile Include="..." />`

3. **检查项目文件**
   - 编译失败时，检查 `.csproj` 是否包含新文件
