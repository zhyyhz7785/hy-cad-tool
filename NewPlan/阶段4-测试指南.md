## 📝 测试详情

### 测试 1: EntityTypeMapping

**测试内容**:
- DXF 类型名称 → 中文（如 "Line" → "直线"）
- 中文 → DXF 标签（如 "多段线" → "LWPOLYLINE"）
- 未知类型处理（返回原值）

**测试用例**:
```csharp
EntityTypeMapping.ToChinese("Line")       // "直线"
EntityTypeMapping.ToChinese("Polyline")   // "多段线"
EntityTypeMapping.ToDxfType("直线")       // "LINE"
EntityTypeMapping.ToDxfType("多段线")     // "LWPOLYLINE"
```

---

### 测试 2: RowColValue

**测试内容**:
- 行、列、值属性正确性
- 相等性比较（Equals）
- 哈希码一致性（GetHashCode）
- ToString 格式

**测试用例**:
```csharp
var cell1 = new RowColValue<double>(row: 2, col: 3, value: 100.5);
cell1.Row == 2
cell1.Col == 3
cell1.Value == 100.5
cell1.Equals(cell2)  // cell2 相同
cell1.GetHashCode() == cell2.GetHashCode()
```

### 测试 3: DCEL - 基础

**测试内容**:
- 顶点创建
- 半边对创建
- 孪生边关系（Twin）
- 起始顶点正确性
- 出射半边列表
- 向量计算

**测试用例**:
```csharp
var dcel = new DCELGraph();
var v1 = dcel.AddVertex(new Point2D(0, 0));
var (he1, he2) = dcel.AddEdgePair(v1, v2);
he1.Twin == he2  // 孪生边
he1.GetVector()  // 向量计算
```

## 🔧 如果测试失败

### 常见问题

**问题 1: 找不到 EntityTypeMapping**
```
错误: 未能找到类型或命名空间名"EntityTypeMapping"
```
**解决**: 检查 `using HyCADTool.Refactored.Domain.Utilities;`

**问题 2: Point2D 构造函数错误**
```
错误: 没有与参数匹配的构造函数
```
**解决**: Point2D 是 readonly struct，确保使用 `new Point2D(x, y)`

**问题 3: DCEL 面创建失败**
```
错误: 面顶点数错误
```
**解决**: 检查半边的 Next/Prev 关系是否正确设置
