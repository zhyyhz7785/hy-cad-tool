# 面板集成使用说明

## 📋 概述

Phase 5.0 已完成所有面板的迁移，并实现了**集成主面板**功能，类似原项目的 `hy` 命令。

---

## 🎯 可用命令

### 1. **集成主面板** (推荐) ⭐

```bash
HYREFACTOR  # 显示集成主面板（包含5个子面板）
HYTOGGLE    # 切换主面板显示/隐藏
HYHIDE      # 隐藏主面板
```

**集成主面板包含的5个子面板（Tab 形式）**:
1. 🔧 **钢筋** - ReinPanel（简化版）
2. 🔍 **过滤器** - FilterPanel（MVVM + 选择服务）
3. 🏗️ **基础钢筋** - BaseReinPanel（完全重构，91.5% Code-Behind 减少）
4. 🏗️ **桩** - PilePanel（桩基布置）
5. 📊 **螺栓聚类与标注** - ClusterPanel（聚类分析）

---

### 2. **单独面板命令** (独立显示)

如果需要单独显示某个面板：

```bash
HYREIN      # 钢筋配置面板
HYFILTER    # 图形过滤器
HYBASEREIN  # 底板钢筋配置
HYPILE      # 桩基布置面板
HYCLUSTER   # 聚类分析面板
```

### 3. **测试命令**

```bash

```

## 🔧 面板功能说明

### 1. 钢筋面板 (ReinPanel)
- **状态**: 简化版（仅用于验证基础设施）
- **功能**: 基本钢筋配置
- **命令**: `HYREIN`

### 2. 过滤器面板 (FilterPanel)
- **状态**: ✅ MVVM 完整实现
- **功能**: 
  - 按类型过滤（Line, Circle, Polyline, Text...）
  - 按图层过滤
  - 按颜色过滤
  - 选择所有图形
- **依赖**: `ISelectionService`（选择服务）
- **命令**: `HYFILTER`

### 3. 基础钢筋面板 (BaseReinPanel) ⭐
- **状态**: ✅ 完全重构
- **重构成果**:
  - Code-Behind: 318 行 → 27 行 (**-91.5%**)
  - XAML: 487 行 → 150 行 (**-69.2%**)
  - 数据绑定率: 30% → 100%
- **功能**: 
  - 26 个配置参数（比例、直径、间距、边距等）
  - 7 个操作命令
  - 5 个折叠面板（基本设置、操作、钢筋绘制、标注、高级设置）
- **依赖**: `IBaseReinforcementService`（桥接模式适配原有逻辑）
- **命令**: `HYBASEREIN`

### 4. 桩基布置面板 (PilePanel)
- **状态**: ✅ 已迁移（保留原有MVVM）
- **功能**:
  - 桩类型选择（圆形桩 / 矩形桩）
  - 布置类型（矩形布置 / 梅花形布置）
  - 桩参数设置（直径、中心距、置换率等）
  - 手控行列输入
  - 绘制桩
- **依赖**: `ICadService`, `IAreaFactory`, `IConfigService`（原项目接口）
- **命令**: `HYPILE`

### 5. 聚类分析面板 (ClusterPanel)
- **状态**: ✅ 已迁移（保留原有MVVM）
- **功能**:
  - 3 个预设聚类方案
  - X/Y 方向聚类参数（EpsilonX, EpsilonY）
  - 26 个绘图开关
  - 参与聚类点开关（基础轮廓点、轴线交点、螺栓点等）
- **依赖**: `DimPointsAndAxis`, `AxisDatas`, `DrawInCad`（原项目工具类）
- **命令**: `HYCLUSTER`

## ⚠️ 已知问题

### 问题 1: PilePanel 没有显示

**原因**: `PilePanelViewModel` 依赖 `ICadService`, `IAreaFactory`, `IConfigService` 三个接口，需要确保容器中已注册这些服务。

**解决方案**: 
1. 已在 `PilePanel.xaml.cs` 中添加无参构造函数，自动解析 ViewModel
2. 如果仍未显示，检查 `AutofacModule.cs` 中是否注册了相关服务

**临时修复** (已实现):
```csharp
public PilePanel()
{
    InitializeComponent();
    
    // 自动解析 ViewModel
    if (DataContext == null && ServiceLocator.Container != null)
    {
        try
        {
            DataContext = ServiceLocator.Container.Resolve<PilePanelViewModel>();
        }
        catch { /* 忽略 */ }
    }
}
```

### 问题 2: 编译时 DLL 被 AutoCAD 锁定

**原因**: AutoCAD 正在使用插件 DLL

**解决方案**:
1. 在 AutoCAD 中卸载插件 (`NETUNLOAD`)
2. 或关闭 AutoCAD
3. 或使用 `ReCall` 热重载工具（推荐）
