## 项目背景

### 现状

- **项目名称**: HyCADTool 重构项目
- **当前阶段**: C15 命令已完成第一轮优化（687行 → 157行）
- **核心问题**: C15 依赖手动选择多边形和标高，缺乏自动化数据流
- **现实挑战**: 2D 图纸数据混乱，需要**用户介入式半自动化工作流**

### 用户需求

1. **从混乱的 2D 图纸到规范的 3D 模型**
2. **支持 1000-10000 多边形规模**（高性能要求）
3. **用户可介入、可验证、可修正的工作流**
4. **为后续力学计算、剖面图生成等扩展奠定基础**

---

## 核心目标

### 主要目标

构建 **HYBC → HYOV → HYDCEL → C15** 完整命令链，实现：

1. ✅ **渐进式数据清理**: 打断 → 去重 → 拓扑构建
2. ✅ **用户介入验证**: 每步可检查、修正、重试
3. ✅ **可视化反馈**: 紫色标记图层（不可打印）标记问题
4. ✅ **高性能处理**: 支持 10000+ 多边形
5. ✅ **数据持久化**: 中间结果保存到图层
6. ✅ **可扩展架构**: 预留力学计算、剖面图生成接口

### 非目标（暂不做）

- ❌ 全自动化流水线（现实中不可行）
- ❌ 完美的错误处理（允许用户修正）
- ❌ 复杂的 UI 界面（命令行为主）

## 关键设计原则

### 1. 用户介入式（非全自动）

**原因**: 2D 图纸数据质量差异极大，完全自动化不现实

**策略**:
- 每个命令后用户可检查结果
- 提供"预览模式"（标记，不执行）
- 提供"应用/取消"选择
- 错误标记到可视化图层

### 2. 紫色标记图层规范

**为什么不用临时图层**: AutoCAD 图层管理命令多，临时图层容易被误删

**统一规范**:
```
图层名称: 00_HY_标记_{功能}
颜色: 200（紫色）
打印: 否
用途: 标记问题区域、待处理项
```

**具体图层**:
- `00_HY_标记_打断点`: HYBC 打断点标记
- `00_HY_标记_重复线`: HYOV 重复线标记
- `00_HY_标记_外轮廓`: HYDCEL 外多边形标记
- `00_HY_标记_内孔洞`: HYDCEL 内多边形标记
- `00_HY_标记_标高检查`: C15V 验证问题标记

### 3. 错误容忍策略

**原则**: 命令遇错不崩溃，输出警告，继续处理

**实现**:
```csharp
// ❌ 旧方式：遇错即停
if (error) throw new Exception("xxx");

// ✅ 新方式：记录警告，继续
if (error) 
{
    warnings.Add(new ValidationWarning(...));
    continue; // 继续处理其他数据
}
```

### 4. 渐进式验证

**验证层次**:
1. **Info**: 提示信息（不影响）
2. **Warning**: 警告（建议检查，可继续）
3. **Error**: 错误（必须修正，不可继续）

**用户决策**:
- Info: 自动继续
- Warning: 询问用户是否继续
- Error: 必须修正

### 5. 高性能设计

**性能目标**:
- 1000 多边形: < 2 秒
- 5000 多边形: < 8 秒
- 10000 多边形: < 20 秒

**优化策略**:
- 空间索引（简化 R-Tree）
- 并行处理（Parallel.ForEach）
- 对象池（减少 GC）
- 延迟计算（Lazy Evaluation）

## 技术架构

### Clean Architecture 分层

```
┌─────────────────────────────────────────────┐
│         Presentation Layer (命令)            │
│  HYBC, HYOV, HYDCEL, C15V, C15              │
│  - 用户交互                                  │
│  - 流程协调                                  │
│  - 输出反馈                                  │
└────────────────┬────────────────────────────┘
                 │ 依赖
                 ▼
┌─────────────────────────────────────────────┐
│       Application Layer (应用服务)           │
│  FoundationDataCollector                    │
│  ElevationDataExtractor                     │
│  SlabGenerationService                      │
│  WallGenerationService                      │
│  - 业务流程编排                              │
│  - 数据验证                                  │
│  - 转换协调                                  │
└────────────────┬────────────────────────────┘
                 │ 使用
                 ▼
┌─────────────────────────────────────────────┐
│          Domain Layer (领域核心)             │
│  ✅ 100% 平台无关（可迁移 Blender）           │
│                                              │
│  实体:                                       │
│  - SurfaceBasedModel                        │
│  - FoundationGeometry (新增)                │
│                                              │
│  值对象:                                     │
│  - Surface3D, WallSolid3D, SlabSolid3D      │
│  - Polygon2D, Point2D, Line2D, Elevation    │
│  - DCELDiagnostics (新增)                   │
│  - ValidationWarning (新增)                 │
│                                              │
│  服务:                                       │
│  - GeometryUtils (已优化)                   │
│  - AdjacencyDetector (已优化)               │
│  - SurfaceBasedElevation3DBuilder           │
│  - SpatialIndexService (新增，高性能)       │
│  - ThicknessCalculator (预留)               │
└────────────────▲────────────────────────────┘
                 │ 实现
                 │
┌────────────────┴────────────────────────────┐
│     Infrastructure Layer (基础设施)          │
│  ⚠️ 依赖 AutoCAD API                         │
│                                              │
│  - MarkerLayerService (新增，紫色图层)       │
│  - DCELDataExtractor (新增)                 │
│  - LayerManager                             │
│  - Solid3DBuilder                           │
│  - PolygonAdapter                           │
│  - DCELRenderer                             │
└─────────────────────────────────────────────┘
```

### 核心数据流

```
AutoCAD 原始数据 (Polyline, DBText)
  ↓ [DCELDataExtractor]
DCEL 图层数据 (dcelOuter, dcelInner)
  ↓ [FoundationDataCollector]
原始数据聚合 (外多边形 + 内多边形 + 标高)
  ↓ [FoundationGeometryConverter]
领域模型 (FoundationGeometry - 平台无关)
  ↓ [SurfaceBasedElevation3DBuilder]
表面模型 (SurfaceBasedModel - 平台无关)
  ↓ [SlabGenerationService + WallGenerationService]
AutoCAD 3D 实体 (Solid3d)
```

## 重要约束条件

### 技术约束

1. **.NET Framework 4.8**: 不能使用 C# 8.0+ 特性
2. **AutoCAD 2024 API**: 基础设施层限制
3. **现有架构**: 必须符合 Clean Architecture
4. **性能要求**: 支持 10000+ 多边形

### 用户约束

1. **介入必要性**: 不能假设数据完美，用户必须参与验证
2. **图层习惯**: 用户习惯 AutoCAD 图层管理，不要临时图层
3. **输出极简**: 遵循项目规范（≤ 3 行输出）
4. **向后兼容**: 不破坏现有命令功能

### 开发约束

1. **分阶段实施**: 每阶段独立可测试
2. **代码质量**: 遵循 SOLID 原则
3. **文档更新**: 每阶段完成后更新文档
4. **测试验证**: 用户测试通过后再进入下一阶段
