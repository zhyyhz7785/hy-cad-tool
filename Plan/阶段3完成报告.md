}

## 双格式加载策略

### 加载优先级

```
1. JSON 优先（现代化、结构化）
   ├─ 文件存在 → 尝试加载
   │  ├─ 成功 → ✅ 使用 JSON 配置
   │  └─ 失败 → 继续
   └─ 文件不存在 → 继续

2. CSV 兜底（向后兼容）
   ├─ 文件存在 → 尝试加载
   │  ├─ 成功 → ✅ 使用 CSV 配置
   │  └─ 失败 → 继续
   └─ 文件不存在 → 继续

3. 默认值（确保系统可用）
   └─ ✅ 使用硬编码默认值
```

### 错误处理

- **JSON 解析失败**：自动降级到 CSV
- **CSV 解析失败**：自动降级到默认值
- **默认值**：始终有效，确保插件可加载

### 路径配置

**JSON 路径**:
```csharp
var jsonPath = Path.Combine(
    AppDomain.CurrentDomain.BaseDirectory,
    "config.json"
);
```

**CSV 路径**:
```csharp
var csvPath = @"E:\BaiduSyncdisk\Code\testResult\0HyConfig.csv";
```

> **注意**: CSV 路径当前为硬编码，未来可改为环境变量或相对路径

## 注意事项

### 1. 路径配置

**当前实现**:
- JSON: 相对于插件 DLL 路径
- CSV: 硬编码绝对路径

**未来改进**:
- 支持环境变量 `%HYCAD_CONFIG_PATH%`
- 支持相对路径解析
- 支持多个配置文件搜索路径

### 2. 错误处理

**当前策略**:
- 配置加载失败不阻止插件初始化
- 自动降级到下一级配置源
- 最终使用默认值确保可用性

**日志输出**:
- 成功加载显示配置信息
- 失败时显示警告但继续运行

### 3. 性能考虑

**优化点**:
- 配置仅在初始化时加载一次
- 后续通过服务访问缓存值（不重复读文件）
- CSV 文件采用共享读取模式（FileShare.ReadWrite）

### 4. 向后兼容

**迁移策略**:
- 保留旧代码 `HyCADtool/Config/` 不变
- 新功能使用新配置服务
- 逐步迁移现有功能到新架构

**兼容性**:
- CSV 格式完全兼容旧代码
- 可与旧代码并存
