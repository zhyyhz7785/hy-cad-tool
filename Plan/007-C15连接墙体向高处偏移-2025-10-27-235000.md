# C15 连接墙体向高处偏移优化

> **时间戳**: 2025-10-27-235000  
> **命令**: C15 (SurfaceBasedElevation3DCommand)  
> **目标**: 修复连接墙体向外凸出的问题，改为向标高较高的多边形内部偏移

---

## 🎯 问题描述

### 用户反馈
"交接处的墙体应该向内，不应当凸出，应当内凹"  
"应该向较高标高处多边形偏移"

### 实际问题
```
当前情况（错误）：
┌─────────────┐
│   -3.000    │
│             │──┐  ← 连接墙体向外凸出
└─────────────┘  │
                 │
        ┌────────┼──┐
        │   -2.000  │
        └───────────┘

期望情况（正确）：
┌─────────────┐
│   -3.000    │
│            ┌┘  ← 连接墙体向标高较高（-2.000）的多边形内部偏移
└────────────┘
        ┌────────┐
        │   -2.000  │
        └───────────┘
```

**原因**：
- 所有墙体（包括相邻边的连接墙体）都使用 `outwardNormal`（向外偏移）
- 导致连接墙体向外凸出，而不是向内收缩

---

## 🔧 解决方案

### 核心逻辑

**连接墙体应该向标高较高的多边形内部偏移**

#### 原理
```
两个基础：
- 基础 A：标高 -3.000m（较低）
- 基础 B：标高 -2.000m（较高）

连接墙体应该：
- 从基础 A 的顶面（-3.000）延伸到基础 B 的顶面（-2.000）
- 墙体位置：向基础 B（较高者）内部偏移
```

#### 判断逻辑
```csharp
// 对于当前多边形的某条相邻边：
// - 如果当前多边形标高 > 相邻多边形标高
//   → 向当前多边形内部偏移（offsetDirection = -1）
// - 如果当前多边形标高 < 相邻多边形标高
//   → 向外偏移（实际上是向相邻多边形内部，offsetDirection = +1）

int offsetDirection = (currentElevation.Value > adjacentElevation.Value) ? -1 : 1;
```

**旧版本**：

```csharp
private void CreateSingleEdgeWall(

```

**新版本**：
```csharp
private void CreateSingleEdgeWall(
    Transaction tr,
    BlockTableRecord modelSpace,
    Point2D v1,
    Point2D v2,
    double bottomElevation,
    double wallHeight,
    Polygon2D polygon,
    double wallThickness,
    int offsetDirection = 1)  // ✅ 可配置偏移方向
```

**参数说明**：
- `offsetDirection = 1`：向外偏移（挡土墙，默认）
- `offsetDirection = -1`：向内偏移（连接墙体）

---

### 2. 修改偏移向量计算逻辑

**旧版本**：
```csharp
// 外侧法向量
var outwardNormal = isCounterClockwise ? leftNormal : new Vector2D(-leftNormal.X, -leftNormal.Y);

// ❌ 固定使用外侧法向量
var outerV1 = new Point2D(v1.X + outwardNormal.X * wallThickness, v1.Y + outwardNormal.Y * wallThickness);
var outerV2 = new Point2D(v2.X + outwardNormal.X * wallThickness, v2.Y + outwardNormal.Y * wallThickness);
```

**新版本**：
```csharp
// 外侧法向量
var outwardNormal = isCounterClockwise ? leftNormal : new Vector2D(-leftNormal.X, -leftNormal.Y);

// ✅ 根据 offsetDirection 调整偏移方向
// offsetDirection = 1: 向外偏移（挡土墙）
// offsetDirection = -1: 向内偏移（连接墙体）
var offsetNormal = new Vector2D(
    outwardNormal.X * offsetDirection, 
    outwardNormal.Y * offsetDirection);

// 计算偏移后的顶点
var outerV1 = new Point2D(v1.X + offsetNormal.X * wallThickness, v1.Y + offsetNormal.Y * wallThickness);
var outerV2 = new Point2D(v2.X + offsetNormal.X * wallThickness, v2.Y + offsetNormal.Y * wallThickness);
```

---

### 3. 调用处：动态计算偏移方向

**相邻边（连接墙体）**：
```csharp
if (adjacentModel != null)
{
    var adjacentElevation = adjacentModel.TopSurface.Elevation;
    
    // 墙体底标高：两侧标高中较低的那个 - 筏板厚度
    double lowerElevation = Math.Min(currentElevation.Value, adjacentElevation.Value);
    double adjacentWallBottom = lowerElevation - slabThickness;
    
    // 墙体顶标高：两侧标高中较高的那个
    double adjacentWallTop = Math.Max(currentElevation.Value, adjacentElevation.Value);
    double adjacentWallHeight = adjacentWallTop - adjacentWallBottom;
    
    // ✅ 判断偏移方向：向标高较高的多边形内部偏移
    // - 当前标高更高（-2） > 相邻标高（-3） → 向当前多边形内部（-1）
    // - 当前标高更低（-3） < 相邻标高（-2） → 向相邻多边形内部（+1）
    int offsetDirection = (currentElevation.Value > adjacentElevation.Value) ? -1 : 1;
    
    CreateSingleEdgeWall(tr, modelSpace, v1, v2, adjacentWallBottom, adjacentWallHeight, 
                        innerPolygon, wallThickness, offsetDirection);
    count++;
    continue;
}
```

**非相邻边（挡土墙）**：
```csharp
// ✅ 挡土墙：默认 offsetDirection = 1（向外偏移）
CreateSingleEdgeWall(tr, modelSpace, v1, v2, retainingWallBottom, retainingWallHeight, 
                    innerPolygon, wallThickness);  // 默认 offsetDirection = 1
```

## 🔍 技术细节

### 偏移方向判断表

| 情况 | 当前标高 | 相邻标高 | offsetDirection | 效果 |
|------|----------|----------|-----------------|------|
| 案例1 | -3.000 | -2.000 | +1 | 向外（实际向 -2.000 内） |
| 案例2 | -2.000 | -3.000 | -1 | 向内（-2.000 内） |
| 案例3 | -2.000 | -2.000 | +1 | 向外（同标高，默认向外） |

### 几何原理

#### 1. **外侧法向量计算**
```csharp
// 判断多边形绕向（逆时针/顺时针）
double signedArea = ∑((p2.X - p1.X) * (p2.Y + p1.Y))
bool isCounterClockwise = signedArea > 0

// 边的单位方向向量
var unitDir = (v2 - v1) / ||v2 - v1||

// 左侧法向量（逆时针90度）
var leftNormal = (-unitDir.Y, unitDir.X)

// 外侧法向量
var outwardNormal = isCounterClockwise ? leftNormal : -leftNormal
```

#### 2. **偏移向量调整**
```csharp
// offsetDirection = 1: 向外
// offsetDirection = -1: 向内（反转法向量）
var offsetNormal = outwardNormal * offsetDirection
```

#### 3. **墙体顶点计算**
```csharp
// 内侧边：原始边（v1, v2）
// 外侧边：偏移后的边（outerV1, outerV2）
var outerV1 = v1 + offsetNormal * wallThickness
var outerV2 = v2 + offsetNormal * wallThickness

// 墙体多段线顶点顺序：
// [0] v1 (内侧起点)
// [1] v2 (内侧终点)
// [2] outerV2 (外侧终点)
// [3] outerV1 (外侧起点)
```

## 💡 设计亮点

### 1. **智能偏移方向**
- 不再硬编码 "向内" 或 "向外"
- 根据相对标高自动判断

### 2. **符合工程逻辑**
- 连接墙体总是向标高较高的基础内部偏移
- 避免墙体凸出导致的视觉混乱

### 3. **简洁的 API**
- `offsetDirection = 1`：向外（挡土墙）
- `offsetDirection = -1`：向内（连接墙体）
- 一个参数解决所有偏移需求

### 4. **可扩展性**
- 未来如果需要其他偏移逻辑，只需传递不同的 `offsetDirection` 值
- 例如：`offsetDirection = 0.5` 可实现中心线偏移
