## 🔧 详细算法解析

### 算法1：MergeOverlappingLines（合并重叠线段）

**输入**：线段列表 `[Line1, Line2, ..., LineN]`  
**输出**：合并后的线段列表

**逻辑**：
```csharp
processed = {} // 已处理集合
result = []

for i in 0..N:
    if i in processed: continue
    
    current = lines[i]
    processed.add(i)
    
    // 查找与 current 重叠的其他线段
    for j in (i+1)..N:
        if j in processed: continue
        
        if CheckAndMergeOverlap(current, lines[j]):
            current = merged  // 更新为合并后的线段
            processed.add(j)
    
    result.add(current)

return result
```

**CheckAndMergeOverlap 判断条件**：
1. ✅ 两线段共线：`line1.IsCollinear(line2, tolerance)`
2. ✅ 有重叠部分：`LineAlgorithms.CheckOverlap(line1, line2) != null`
3. ✅ 合并：取4个端点中投影距离最远的两个点

**示例**：
```
输入：
  Line1: (0,0) → (5,0)
  Line2: (3,0) → (8,0)  // 与 Line1 重叠 2 单位

输出：
  Merged: (0,0) → (8,0)  // 合并为一条
```

### 算法2：SplitAtIntersections（在交点处分割）✨ 核心算法

**目的**：解决问题2（相交线段未分割）

**输入**：线段列表  
**输出**：分割后的线段列表

**逻辑**：
```csharp
result = []

for each line in lines:
    splitPoints = [line.StartPoint, line.EndPoint]
    
    // 查找与其他线段的交点
    for each otherLine in lines:
        if line == otherLine: continue
        
        intersection = line.GetIntersection(otherLine)
        
        if intersection != null AND 
           intersection NOT in endpoints:
            splitPoints.add(intersection)
    
    // 按投影距离排序分割点
    sortedPoints = sort(splitPoints by projection)
    
    // 创建分割后的线段
    for k in 0..(sortedPoints.length - 1):
        p1 = sortedPoints[k]
        p2 = sortedPoints[k+1]
        
        if distance(p1, p2) > tolerance:
            result.add(Line(p1, p2))

return result
```

**示例**：
```
输入：
  Line1: (0,0) → (10,0)  // 水平线
  Line2: (5,-5) → (5,5)   // 垂直线，与 Line1 交于 (5,0)

输出：
  从 Line1 分割：
    Line1a: (0,0) → (5,0)
    Line1b: (5,0) → (10,0)
  从 Line2 分割：
    Line2a: (5,-5) → (5,0)
    Line2b: (5,0) → (5,5)
```

**关键点**：
- ✅ 只在**线段内部**的交点处分割
- ✅ 端点不算交点（避免重复分割）
- ✅ 按投影距离排序，确保顺序正确

### 算法3：TrimOvershootingLines（裁剪过长线段）✨ 核心算法

**目的**：解决问题1（线段超出交点继续延伸）

**输入**：线段列表  
**输出**：裁剪后的线段列表

**逻辑**：
```csharp
result = []

for each line in lines:
    // 检查起点是否需要裁剪
    startTrimPoint = FindClosestIntersectionOnExtension(
        line, checkStart=true)
    
    // 检查终点是否需要裁剪
    endTrimPoint = FindClosestIntersectionOnExtension(
        line, checkStart=false)
    
    // 应用裁剪
    if startTrimPoint != null OR endTrimPoint != null:
        newStart = startTrimPoint ?? line.StartPoint
        newEnd = endTrimPoint ?? line.EndPoint
        
        if distance(newStart, newEnd) > tolerance:
            line = Line(newStart, newEnd)
    
    result.add(line)

return result
```

**FindClosestIntersectionOnExtension 逻辑**：
```csharp
FindClosestIntersectionOnExtension(line, checkStart):
    checkPoint = checkStart ? line.StartPoint : line.EndPoint
    direction = line.Direction.Normalize()
    
    if checkStart:
        direction = -direction  // 反向
    
    // 检查端点是否已连接到其他线段
    if HasConnectionToOtherLines(checkPoint):
        return null  // 已连接，不需要裁剪
    
    // 创建反向延长线（向外延伸 1000 单位）
    extendedStart = checkPoint + direction * (-1000)
    extensionLine = Line(extendedStart, checkPoint)
    
    closestIntersection = null
    closestDistance = infinity
    
    // 查找延长线上的交点
    for each otherLine in lines:
        intersection = extensionLine.GetIntersection(otherLine)
        
        if intersection != null:
            dist = distance(checkPoint, intersection)
            
            // 检查交点是否在端点"外侧"
            toIntersection = Vector(intersection - checkPoint)
            dotProduct = direction.Dot(toIntersection)
            
            // dotProduct < 0 表示在外侧（需要裁剪）
            if dotProduct < 0 AND dist < closestDistance:
                closestIntersection = intersection
                closestDistance = dist
    
    return closestIntersection
```

**示例**：
```
输入：
  Line1: (0,0) → (15,0)  // 过长，应该在 (10,0) 截断
  Line2: (10,-5) → (10,5) // 垂直线，与 Line1 延长线交于 (10,0)

处理：
  检查 Line1 终点 (15,0)：
    - 反向延长线：(1015,0) → (15,0)
    - 找到交点：(10,0) 与 Line2 相交
    - 计算方向：direction = (1,0)
    - toIntersection = (10,0) - (15,0) = (-5,0)
    - dotProduct = (1,0) · (-5,0) = -5 < 0 ✅ 在外侧
    - 裁剪：newEnd = (10,0)

输出：
  Line1 裁剪后: (0,0) → (10,0)
```

**关键点**：
- ✅ 使用**反向延长线**检测外侧交点
- ✅ 通过**点积判断**确认方向
- ✅ 只裁剪未连接的端点

### 算法4：RemoveDuplicateLines（去除重复线段）

**输入**：线段列表  
**输出**：去重后的线段列表

**逻辑**：
```csharp
result = []

for each line in lines:
    isDuplicate = false
    
    for each existingLine in result:
        if AreLinesEqual(line, existingLine):
            isDuplicate = true
            break
    
    if not isDuplicate:
        result.add(line)

return result
```

**AreLinesEqual 判断**：
```csharp
AreLinesEqual(line1, line2):
    // 正向比较
    forwardMatch = 
        distance(line1.Start, line2.Start) < tolerance AND
        distance(line1.End, line2.End) < tolerance
    
    // 反向比较
    reverseMatch =
        distance(line1.Start, line2.End) < tolerance AND
        distance(line1.End, line2.Start) < tolerance
    
    return forwardMatch OR reverseMatch
```

```csharp
/// <summary>
/// 计算智能延伸距离
/// 基于线段的平均长度和分布情况自动调整
/// </summary>
private double CalculateSmartExtensionDistance(List<Line2D> lines)
{
    const double MIN_EXTENSION_DISTANCE = 10.0;
    const double MAX_EXTENSION_DISTANCE = 500.0;
    
    if (lines == null || lines.Count == 0)
        return MIN_EXTENSION_DISTANCE;

    // 计算所有线段的平均长度
    double avgLength = lines.Average(l => l.Length);

    // 计算最小间距（统计相邻端点的距离）
    var minGaps = new List<double>();
    for (int i = 0; i < lines.Count && minGaps.Count < 50; i++)
    {
        var line = lines[i];
        for (int j = i + 1; j < lines.Count; j++)
        {
            var other = lines[j];
            
            // 计算端点之间的最小距离
            double minDist = Math.Min(
                Math.Min(line.StartPoint.DistanceTo(other.StartPoint), 
                         line.StartPoint.DistanceTo(other.EndPoint)),
                Math.Min(line.EndPoint.DistanceTo(other.StartPoint), 
                         line.EndPoint.DistanceTo(other.EndPoint))
            );

            if (minDist > DEFAULT_TOLERANCE && minDist < avgLength * 0.5)
            {
                minGaps.Add(minDist);
            }
        }
    }

    // 使用平均间距的1.5倍作为延伸距离
    double smartDistance = MIN_EXTENSION_DISTANCE;
    if (minGaps.Count > 0)
    {
        double avgGap = minGaps.Average();
        smartDistance = Math.Max(avgGap * 1.5, MIN_EXTENSION_DISTANCE);
    }
    else
    {
        // 如果没有找到合适的间距，使用平均线长的10%
        smartDistance = Math.Max(avgLength * 0.1, MIN_EXTENSION_DISTANCE);
    }

    // 限制在合理范围内
    return Math.Min(smartDistance, MAX_EXTENSION_DISTANCE);
}
```
