# C15 文本中心点定位与红色警告

> **时间戳**: 2025-10-27-224500  
> **命令**: C15 (SurfaceBasedElevation3DCommand)  
> **目标**: 1. 使用文本中心点定位 2. 未匹配标高的多边形标记为红色

---

## 🎯 需求描述

### 用户反馈
> "如果多边形没有匹配标高需要变红提醒，还有文字的定位选用中心点定位"

### 问题分析
1. **文本定位问题**：
   - 原逻辑使用 `DBText.Position`（插入点）和 `MText.Location`
   - 插入点可能在文本左下角、左侧等，不在文本中心
   - **导致**：文本在多边形边缘时，判断不准确

2. **缺少错误提示**：
   - 如果多边形没有匹配到标高文本，会**静默跳过**
   - 用户无法直观发现哪些多边形缺少标高
   - **需要**：视觉提醒（红色）+ 命令行警告

---

## 🔧 解决方案

### 1. 文本中心点定位

#### 原逻辑（插入点）
```csharp
// ❌ 使用插入点（可能在左下角、左侧等）
if (entity is DBText dbText)
{
    textEntities.Add((dbText.Position, dbText.TextString));
}
else if (entity is MText mText)
{
    textEntities.Add((mText.Location, mText.Contents));
}
```

#### 新逻辑（几何中心点）
```csharp
// ✅ 使用几何边界框的中心点
if (entity is DBText dbText)
{
    var bounds = dbText.GeometricExtents;
    var centerPoint = new Point3d(
        (bounds.MinPoint.X + bounds.MaxPoint.X) / 2,
        (bounds.MinPoint.Y + bounds.MaxPoint.Y) / 2,
        (bounds.MinPoint.Z + bounds.MaxPoint.Z) / 2);
    textEntities.Add((centerPoint, dbText.TextString));
}
else if (entity is MText mText)
{
    var bounds = mText.GeometricExtents;
    var centerPoint = new Point3d(
        (bounds.MinPoint.X + bounds.MaxPoint.X) / 2,
        (bounds.MinPoint.Y + bounds.MaxPoint.Y) / 2,
        (bounds.MinPoint.Z + bounds.MaxPoint.Z) / 2);
    textEntities.Add((centerPoint, mText.Contents));
}
```

### 2. 未匹配多边形标记为红色

```csharp
// ✅ 在匹配完成后，检查未匹配的多边形
foreach (var polyline in polygons)
{
    if (!result.ContainsKey(polyline))
    {
        // 将未匹配的多边形变为红色（颜色索引 1）
        var plCopy = tr.GetObject(polyline.ObjectId, OpenMode.ForWrite) as Polyline;
        if (plCopy != null)
        {
            plCopy.ColorIndex = 1; // 红色
            ed.WriteMessage($"\n⚠️ 警告：多边形 (顶点数={plCopy.NumberOfVertices}) 未匹配到标高，已标记为红色");
        }
    }
}
```

## 🔍 技术细节

### GeometricExtents 获取方式

```csharp
// DBText/MText 的 GeometricExtents 属性
var bounds = dbText.GeometricExtents;

// 返回值：Extents3d 结构
// - MinPoint: 边界框最小点 (左下后角)
// - MaxPoint: 边界框最大点 (右上前角)

// 中心点计算
var centerPoint = new Point3d(
    (bounds.MinPoint.X + bounds.MaxPoint.X) / 2,  // X 方向中点
    (bounds.MinPoint.Y + bounds.MaxPoint.Y) / 2,  // Y 方向中点
    (bounds.MinPoint.Z + bounds.MaxPoint.Z) / 2); // Z 方向中点
```

### AutoCAD 颜色索引

| ColorIndex | 颜色   | 用途           |
| --- | --- | --- |
| 0          | ByBlock | 跟随块         |
| 1          | **红色**  | **警告/错误**  |
| 2          | 黄色   | 墙体           |
| 3          | 绿色   | 上表面         |
| 5          | 蓝色   | 下表面         |
| 7          | 白色   | 默认           |
