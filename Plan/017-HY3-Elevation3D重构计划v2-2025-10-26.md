## 二、关键几何算法详解（需要优化）

### 2.1 墙体缓冲区生成（CreateWallBuffer）⚠️ 需要优化

#### 当前逻辑（简单版本）

**输入**：墙体边线 `Line(p1, p2)`，墙体厚度 `thickness`  
**输出**：4顶点封闭多边形 `Polyline`

**几何逻辑**：
```
1. 计算墙体方向向量：direction = p2 - p1
2. 计算法向量（逆时针旋转90度）：normal = direction.RotateBy(π/2, Z轴)
3. 归一化法向量：normal = normal.GetNormal()
4. 计算4个顶点：
   - p1' = p1 + normal * thickness  // 外侧起点
   - p2' = p1                        // 内侧起点
   - p3' = p2                        // 内侧终点
   - p4' = p2 + normal * thickness  // 外侧终点
5. 创建闭合多边形：[p1', p2', p3', p4']
```

**示例**：
```
墙体：Line(0, 0) → (10, 0)，厚度 = 300mm

direction = (10, 0)
normal = (0, 10).Normalize() = (0, 1)

p1' = (0, 300)   -------- p4' = (10, 300)
                 |        |
p2' = (0, 0)     -------- p3' = (10, 0)
```

#### ⚠️ 需要优化的方向

**1. 支持不同的缓冲区类型**


```
输出：梯形缓冲区（4顶点，但厚度渐变）
```

**3. 自动处理边界情况**

- 墙体长度 < thickness 时的处理
- 墙体角度接近 0° 或 180° 时的处理

**4. 性能优化**

### 2.2 墙体连接处理（HandleWallConnection）⚠️ 需要完整实现

#### 当前实现状态

✅ **已实现**：
- Miter 连接（斜接）
- Square 连接（直角）
- Bevel 连接（倒角，部分实现）

❌ **未实现**：
- **Round 连接（圆角）** ← 需要实现

#### Round 连接详细设计

**几何逻辑**：

```
输入：
  - wall1 的外侧边终点 p13
  - wall2 的外侧边起点 p22
  - 圆心 = wall1 和 wall2 的连接点 p14 (= p21)
  - 半径 = thickness

输出：
  - 圆弧顶点序列（16-32 个点，取决于精度）

算法：
  1. 计算起始角度 θ1 = atan2(p13 - p14)
  2. 计算终止角度 θ2 = atan2(p22 - p21)
  3. 计算角度差 Δθ = θ2 - θ1（顺时针为负，逆时针为正）
  4. 根据精度参数计算圆弧段数：segments = ceil(|Δθ| / (π/16))
  5. 生成圆弧顶点：
     for i in 0 to segments:
         θ = θ1 + Δθ * (i / segments)
         x = center.X + radius * cos(θ)
         y = center.Y + radius * sin(θ)
         vertices.Add((x, y))
```

**示例**：

```
墙体1：水平向右
墙体2：垂直向上
夹角 = 90°（逆时针）

                p22
                 |
                 | 墙体2
                 |
                 ◯ ← 圆弧连接（16个点）
                /
墙体1 --------p13

圆心 = p14
半径 = thickness
圆弧角度 = 90°
```

**代码框架**：

```csharp
private Polygon2D CreateRoundConnection(
    Point2D center,
    Point2D outerPoint1,
    Point2D outerPoint2,
    double thickness,
    int segments = 16)
{
    var vertices = new List<Point2D> { center };
    
    // 计算起始和终止角度
    double angle1 = Math.Atan2(
        outerPoint1.Y - center.Y, 
        outerPoint1.X - center.X);
    double angle2 = Math.Atan2(
        outerPoint2.Y - center.Y, 
        outerPoint2.X - center.X);
    
    // 确保角度差在 [-π, π] 范围内
    double angleDiff = angle2 - angle1;
    if (angleDiff > Math.PI) angleDiff -= 2 * Math.PI;
    if (angleDiff < -Math.PI) angleDiff += 2 * Math.PI;
    
    // 生成圆弧顶点
    vertices.Add(outerPoint1);
    for (int i = 1; i < segments; i++)
    {
        double t = (double)i / segments;
        double angle = angle1 + angleDiff * t;
        double x = center.X + thickness * Math.Cos(angle);
        double y = center.Y + thickness * Math.Sin(angle);
        vertices.Add(new Point2D(x, y));
    }
    vertices.Add(outerPoint2);
    
    return new Polygon2D(vertices);
}
```

### 2.3 多边形布尔运算（MergeBuffers）⚠️ 优先自实现

#### 策略：自实现算法 + Clipper2 备用

**自实现算法选项**：

##### 选项1：Weiler-Atherton 多边形裁剪算法

**适用场景**：简单凸多边形或接近凸多边形的合并

**优点**：
- 精度高（不需要整数转换）
- 算法成熟，有大量参考实现
- 适合处理墙体缓冲区（通常是矩形或梯形）

**缺点**：
- 实现复杂度中等
- 处理非凸多边形时需要特殊处理

**算法步骤**：
```
1. 计算两多边形的所有交点
2. 按顺序插入交点到两多边形的顶点序列中
3. 从起点开始遍历，根据进/出标记选择路径
4. 构建合并后的多边形
```

##### 选项2：扫描线算法 + 区域填充

**适用场景**：大量墙体缓冲区的批量合并

**优点**：
- 性能高（O(n log n)）
- 适合批量处理
- 可以处理复杂的重叠情况

**缺点**：
- 实现复杂度高
- 需要构建复杂的数据结构

##### 选项3：简化版本 - 轴对齐矩形合并

**适用场景**：墙体方向与坐标轴对齐（如正交网格）

**优点**：
- 实现简单
- 性能极高
- 无精度损失

**缺点**：
- 仅适用于轴对齐情况
- 通用性差

**推荐方案**：

```csharp
public interface IPolygonMerger
{
```

### 3.3 容差在值对象中的应用

```csharp
public class Point2D : IEquatable<Point2D>
{
    public double X { get; }
    public double Y { get; }
    
    // 使用容差判断相等
    public bool Equals(Point2D other)
    {
        if (other == null) return false;
        
        var tolerance = ToleranceSettings.Instance.DistanceTolerance;
        return Math.Abs(X - other.X) < tolerance &&
               Math.Abs(Y - other.Y) < tolerance;
    }
    
    // 计算距离
    public double DistanceTo(Point2D other)
    {
        double dx = X - other.X;
        double dy = Y - other.Y;
        return Math.Sqrt(dx * dx + dy * dy);
    }
    
    // 判断是否在容差范围内
    public bool IsNearTo(Point2D other)
    {
        var tolerance = ToleranceSettings.Instance.DistanceTolerance;
        return DistanceTo(other) < tolerance;
    }
}
```
