# C15 相邻墙体标高修复

> **时间戳**: 2025-10-27-230500  
> **命令**: C15 (SurfaceBasedElevation3DCommand)  
> **目标**: 修复相邻基础之间的墙体缺失问题

---

## 🎯 问题描述

### 用户反馈
> "墙体的生成，丢失一部分，丢失从一个标高较低的到标高较高的墙体，查看老版本逻辑添加"

### 问题分析（从图片）
```
场景：两个相邻基础，标高不同
- 基础1（黄色）：标高 -0.290m
- 基础2（红色）：标高 -2.550m
- 预期：两基础相邻边应有连接墙体（从 -2.550m 延伸到 -0.290m）
- 实际：❌ 相邻边的墙体缺失（红色箭头指向的位置）
```

### 根本原因
**C15 原逻辑**：
```csharp
// ❌ 所有墙体顶标高都固定为 0.000（挡土墙）
var wallTopElevation = Elevation.FromMillimeters(0.0);
double wallHeight = wallTopElevation.Value - bottomElevation.Value;
```

这导致：
- **非相邻边**：✅ 正确（延伸到 0.000，作为挡土墙）
- **相邻边**：❌ 错误（应延伸到相邻基础的标高，而非 0.000）

---

## 🔧 解决方案

### 核心思路
根据用户之前的需求：
> "墙体的顶标高逻辑是 从墙体和墙体 临边中选择低的那个-筏板厚度，为低，延伸到墙体临边较高的那个标高"

**翻译为代码**：
```csharp
// 相邻边墙体
墙体底标高 = min(标高1, 标高2) - 筏板厚度（400mm）
墙体顶标高 = max(标高1, 标高2)
墙体高度 = 顶标高 - 底标高

// 非相邻边墙体（挡土墙）
墙体底标高 = 当前标高 - 筏板厚度（400mm）
墙体顶标高 = 0.000（地面）
墙体高度 = 顶标高 - 底标高
```

## 📝 修改清单

### 1. 墙体生成逻辑重构

#### 原逻辑（固定顶标高 0.000）
```csharp
// ❌ 所有墙体都延伸到 0.000
var wallTopElevation = Elevation.FromMillimeters(0.0);
double wallHeight = wallTopElevation.Value - bottomElevation.Value;

// 逐边生成墙体
for (int edgeIndex = 0; edgeIndex < innerPolygon.VertexCount; edgeIndex++)
{
    if (isAdjacentEdge) continue; // 跳过相邻边
    
    // 创建墙体（顶标高都是 0.000）
    CreateWall(..., wallHeight);
}
```

#### 新逻辑（根据边类型计算不同顶标高）
```csharp
// 逐边生成墙体，根据边的类型计算不同的顶标高
for (int edgeIndex = 0; edgeIndex < innerPolygon.VertexCount; edgeIndex++)
{
    var currentEdge = new Line2D(v1, v2);
    
    // 查找相邻模型
    var adjacentModel = FindAdjacentModel(currentEdge, models, modelIndex);
    
    if (adjacentModel != null)
    {
        // ✅ 相邻边：生成连接墙体（从低到高）
        var adjacentElevation = adjacentModel.TopSurface.Elevation;
        
        // 墙体底标高：两侧标高中较低的那个 - 筏板厚度
        double lowerElevation = Math.Min(currentElevation.Value, adjacentElevation.Value);
        double adjacentWallBottom = lowerElevation - slabThickness;
        
        // 墙体顶标高：两侧标高中较高的那个
        double adjacentWallTop = Math.Max(currentElevation.Value, adjacentElevation.Value);
        
        double adjacentWallHeight = adjacentWallTop - adjacentWallBottom;
        
        CreateSingleEdgeWall(..., adjacentWallBottom, adjacentWallHeight, ...);
        continue;
    }
    
    // ✅ 非相邻边：生成挡土墙（延伸到 0.000）
    double retainingWallBottom = bottomElevation.Value;
    double retainingWallTop = 0.0;
    double retainingWallHeight = retainingWallTop - retainingWallBottom;
    
    CreateSingleEdgeWall(..., retainingWallBottom, retainingWallHeight, ...);
}
```

### 2. 新增辅助方法

#### `FindAdjacentModel` - 查找相邻模型
```csharp
/// <summary>
/// 查找与当前边相邻的模型
/// </summary>
private SurfaceBasedModel FindAdjacentModel(
    Line2D currentEdge,
    List<SurfaceBasedModel> models,
    int currentModelIndex)
{
    const double tolerance = 1.0; // 1mm 容差
    
    for (int i = 0; i < models.Count; i++)
    {
        if (i == currentModelIndex) continue;
        
        var otherPolygon = models[i].TopSurface.Polygon;
        
        // 检查 otherPolygon 的每条边是否与 currentEdge 重合
        for (int edgeIndex = 0; edgeIndex < otherPolygon.VertexCount; edgeIndex++)
        {
            var otherEdge = GetEdge(otherPolygon, edgeIndex);
            
            if (AreEdgesEqual(currentEdge, otherEdge, tolerance))
            {
                return models[i]; // 返回相邻模型
            }
        }
    }
    
    return null; // 无相邻模型
}
```

    // 计算边的外侧偏移向量（垂直于边，指向外侧）
    // ... 外侧法向量计算逻辑 ...
    
    // 创建墙体多段线（四边形）
    using (var wallPolyline = new Polyline())
    {
        wallPolyline.AddVertexAt(0, new Point2d(v1.X, v1.Y), 0, 0, 0);
        wallPolyline.AddVertexAt(1, new Point2d(v2.X, v2.Y), 0, 0, 0);
        wallPolyline.AddVertexAt(2, new Point2d(outerV2.X, outerV2.Y), 0, 0, 0);

            new SweepOptions());

        modelSpace.AppendEntity(wallSolid);
        tr.AddNewlyCreatedDBObject(wallSolid, true);
        wallSolid.Layer = "00_hy_墙体3D_挡土墙";
    }

## 📊 墙体标高计算示例

### 示例 1：相邻边墙体
```
输入：
- 基础1 标高：-0.290m (-290mm)
- 基础2 标高：-2.550m (-2550mm)
- 筏板厚度：400mm

计算：
墙体底标高 = min(-290, -2550) - 400 = -2550 - 400 = -2950mm
墙体顶标高 = max(-290, -2550) = -290mm
墙体高度 = -290 - (-2950) = 2660mm

结果：
✅ 连接墙体：从 -2950mm 延伸到 -290mm，高度 2660mm
```

### 示例 2：非相邻边墙体（挡土墙）
```
输入：
- 基础标高：-2.550m (-2550mm)
- 筏板厚度：400mm
- 底板标高：-2550 - 400 = -2950mm

计算：
墙体底标高 = -2950mm（底板标高）
墙体顶标高 = 0.000mm（地面）
墙体高度 = 0 - (-2950) = 2950mm

结果：
✅ 挡土墙：从 -2950mm 延伸到 0.000mm，高度 2950mm
```

## 🔍 技术细节

### 墙体类型判定流程
```
1. 获取当前边 currentEdge
2. 调用 FindAdjacentModel(currentEdge, models, modelIndex)
3. 判断：
   ├─ adjacentModel != null
   │    └─ 相邻边 → 生成连接墙体
   │         - 底标高 = min(标高1, 标高2) - 筏板厚度
   │         - 顶标高 = max(标高1, 标高2)
   └─ adjacentModel == null
        └─ 非相邻边 → 生成挡土墙
             - 底标高 = 底板标高
             - 顶标高 = 0.000
```

### 关键参数

| 参数           | 值       | 说明                     |
| --- | --- | --- |
| **slabThickness** | 400.0mm  | 筏板厚度（固定值）       |
| **tolerance**     | 1.0mm    | 相邻边判定容差           |
| **wallThickness** | 100.0mm  | 墙体厚度                 |
