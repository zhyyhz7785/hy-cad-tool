## 新增 API 使用示例

### 示例 1: 多边形偏移

```csharp
var geometryService = ServiceLocator.Resolve<IGeometryService>();

// 创建正方形
var square = new Polygon2D(new[]
{
    new Point2D(0, 0),
    new Point2D(10, 0),
    new Point2D(10, 10),
    new Point2D(0, 10)
});

// 向外偏移 5 单位（配筋保护层）
var offsetPolygons = geometryService.Offset(square, 5.0);

// 向内偏移 2 单位
var insetPolygons = geometryService.Offset(square, -2.0);
```

### 示例 2: 线段重叠合并

```csharp
var line1 = new Line2D(new Point2D(0, 5), new Point2D(10, 5));
var line2 = new Line2D(new Point2D(5, 5), new Point2D(15, 5));

// 检测重叠
var overlap = LineAlgorithms.CheckOverlap(line1, line2);

// 合并共线线段
var lines = new[] { line1, line2 };
var merged = LineAlgorithms.MergeCollinearLines(lines);
```

### 示例 3: 凸包计算

```csharp
var geometryService = ServiceLocator.Resolve<IGeometryService>();

var points = new[]
{
    new Point2D(0, 0),
    new Point2D(10, 0),
    new Point2D(10, 10),
    new Point2D(0, 10),
    new Point2D(5, 5)  // 内部点
};

// 计算凸包
var convexHull = geometryService.ComputeConvexHull(points);

// 验证是否为凸多边形
bool isConvex = ConvexHullAlgorithm.IsConvex(convexHull);
```

### 示例 4: 多边形交集

```csharp
var geometryService = ServiceLocator.Resolve<IGeometryService>();

var rect1 = new Polygon2D(new[] { ... });
var rect2 = new Polygon2D(new[] { ... });

// 计算交集
var intersection = geometryService.Intersection(rect1, rect2);

// 计算异或（对称差）
var xor = geometryService.Xor(rect1, rect2);
```

## 已解决的技术问题

### 问题 1: Clipper2 精度选择

**解决方案**: 统一使用 `PathD` (double 精度) 而非 `Path64` (整数)，避免缩放误差。

### 问题 2: 线段重叠检测方向性

**解决方案**: 判断主方向（水平/垂直），分别处理 X/Y 坐标投影。

### 问题 3: 凸包算法稳定性

**解决方案**: Graham 扫描法处理共线点，确保算法鲁棒性。
