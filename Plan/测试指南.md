# HyCADTool.Refactored 测试指南

## 📋 测试流程概述

每个阶段完成后，都需要按照以下流程进行测试验证：

```
1. 编译项目
   ↓
2. 加载 DLL 到 AutoCAD
   ↓
3. 运行测试命令
   ↓
4. 检查测试结果
   ↓
5. 确认通过后进入下一阶段
```

---

## 🔧 阶段 1 测试步骤

### 步骤 1: 编译项目

#### 1.1 编译重构项目

1. 打开 `HyCADtoolGpt.sln`
2. 在解决方案资源管理器中右键 `HyCADTool.Refactored` 项目
3. 选择 **生成（Build）**
4. 确认编译成功，无错误

**输出路径**: `HyCADTool.Refactored\bin\Debug\HyCADTool.Refactored.dll`

#### 1.2 编译测试项目（ReCall）

1. 在解决方案资源管理器中右键 `ReCall` 项目
2. 选择 **生成（Build）**
3. 确认编译成功

**输出路径**: `ReCall\bin\Debug\ReCall.dll`

---

### 步骤 2: 加载插件到 AutoCAD

#### 方法 1: 使用 NETLOAD（推荐用于测试）

1. 启动 **AutoCAD 2024**
2. 在命令行输入：`NETLOAD`
3. 浏览并选择两个 DLL（按顺序）：
   ```
   第一个：HyCADTool.Refactored\bin\Debug\HyCADTool.Refactored.dll
   第二个：ReCall\bin\Debug\ReCall.dll
   ```

#### 预期加载信息

加载 `HyCADTool.Refactored.dll` 后应显示：

```

========================================
```

#### 失败处理

如果任何测试显示 `❌ 测试失败`：

1. **记录错误信息**：复制完整的错误消息和堆栈跟踪
2. **检查编译错误**：确认无编译警告或错误
3. **检查依赖项**：确认 NuGet 包已正确安装
4. **重新加载**：卸载并重新加载 DLL
5. **反馈问题**：将错误信息提供给开发团队

## 🔍 常见问题排查

### Q1: 插件加载后没有显示初始化信息？

**原因**: `PluginInitializer.cs` 的 `Initialize()` 方法未被调用

**解决**:
1. 检查 `[assembly: CommandClass(...)]` 是否正确
2. 确认 `.csproj` 中包含 `PluginInitializer.cs`
3. 重新编译项目

---

### Q2: 测试命令输入后提示"未知命令"？

**原因**: `ReCall.dll` 未正确加载

**解决**:
1. 确认 `ReCall.dll` 已通过 `NETLOAD` 加载
2. 检查 `[CommandMethod(...)]` 属性是否正确
3. 重新编译 `ReCall` 项目

---

### Q3: 服务解析失败？

**错误示例**:
```
❌ 插件加载失败: Exception has been thrown by the target of an invocation.
```

**解决**:
1. 检查 `AutofacModule.cs` 中的服务注册是否完整
2. 确认所有接口实现类都已正确创建
3. 检查构造函数依赖是否循环

---

### Q4: 几何计算结果不正确？

**错误示例**:
```
❌ 测试失败（误差: 0.52）
```

**解决**:
1. 检查 `Polygon2D` 的面积计算算法
2. 确认顶点顺序（顺时针或逆时针）
3. 验证 `GetSignedArea()` 方法的实现

---

### Q5: Clipper2 布尔运算失败？

**错误示例**:
```
❌ 测试失败: The type initializer for 'Clipper2Lib.Clipper' threw an exception.
```

**解决**:
1. 检查 `Clipper2` NuGet 包是否正确安装
2. 确认 `.NET Framework 4.8` 目标框架
3. 检查 DLL 依赖项是否完整
