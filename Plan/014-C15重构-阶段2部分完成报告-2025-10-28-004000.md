#### 2. **WallGeometryCalculator.cs** (95行)
**路径**: `Application/Services/WallGeometryCalculator.cs`

**功能**:
- ✅ 计算连接墙体的几何参数（底标高、顶标高、偏移方向）
- ✅ 计算挡土墙的几何参数
- ✅ 判断是否需要挡土墙
- ✅ 计算墙体高度

**核心方法**:
```csharp
// 连接墙体（两个不同标高基础之间）
public (double bottom, double top, int offsetDirection) CalculateConnectingWall(
    Elevation currentElevation,
    Elevation adjacentElevation)

// 挡土墙（基础边缘与土壤接触）
public (double bottom, double top, int offsetDirection) CalculateRetainingWall(
    Elevation baseElevation,
    double bottomElevation)
```

**墙体逻辑**:
- **连接墙体**:
  - 底标高 = `Min(当前, 相邻) - 筏板厚度`
  - 顶标高 = `Max(当前, 相邻) - 筏板厚度`（避免与筏板重叠）
  - 偏移方向 = 向标高更高的多边形偏移
- **挡土墙**:
  - 底标高 = 基础底面
  - 顶标高 = 0.000（地面）
  - 偏移方向 = 总是向外

**复用价值**: ⭐⭐⭐⭐⭐
- 100% 平台无关
- 封装了所有墙体几何计算逻辑
- 可直接迁移到 Blender Python
