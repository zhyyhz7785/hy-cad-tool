### 错误 5：PanelManager 无法激活（Autofac DI 错误）

**错误信息**：
```
An exception was thrown while activating HyCADTool.Refactored.Presentation.PanelManager.
```

**影响文件**：
- `AutofacModule.cs`
- `PanelManager.cs`

**原因**：
1. **第一次尝试**：`PanelManager` 构造函数接受 `IServiceProvider`，但 `IContainer` 不能直接转换为 `IServiceProvider`。
2. **第二次尝试**：使用 lambda 表达式 `c => new PanelManager(c.Resolve<IContainer>())`，但 `IContainer` 无法转换为 `IServiceProvider`。
3. **第三次尝试**：显式转换 `(IServiceProvider)c.Resolve<IContainer>()`，但缺少 `using System;`。

**最终修复方案**：
```csharp
// 1. 修改 PanelManager 构造函数，使用 Autofac 原生接口
public PanelManager(IComponentContext componentContext) // 改为 IComponentContext
{
    _componentContext = componentContext ?? throw new ArgumentNullException(nameof(componentContext));
    // ...
}

// 2. 更新 AutofacModule 注册（简化为直接注册）
builder.RegisterType<PanelManager>()
    .AsSelf()
    .SingleInstance();
```

**修复时间**：2025-10-09  
**状态**：✅ 已修复

**核心改进**：使用 Autofac 原生的 `IComponentContext` 而非通用的 `IServiceProvider`，更符合 Autofac 最佳实践。

## 🎨 核心架构设计

### 1. 面板管理器（PanelManager）

**职责**：
- 管理所有面板的生命周期（创建、显示、隐藏）
- 集成 AutoCAD 的 `PaletteSet` API
- 通过 DI 容器创建面板实例

**关键技术**：
```csharp
public class PanelManager
{
    private readonly IComponentContext _componentContext; // Autofac DI 容器
    private readonly Dictionary<Type, PaletteSet> _paletteSets; // 面板缓存
    
    public void TogglePanel<TPanel>(string title, Guid panelId) where TPanel : UserControl
    {
        // 1. 检查是否已存在
        if (_paletteSets.TryGetValue(typeof(TPanel), out var existingPalette))
        {
            existingPalette.Visible = !existingPalette.Visible;
            return;
        }
        
        // 2. 通过 DI 创建面板
        var panel = _componentContext.Resolve<TPanel>();
        
        // 3. 使用 ElementHost 包装 WPF UserControl
        var host = new ElementHost { Child = panel, Dock = DockStyle.Fill };
        
        // 4. 创建 PaletteSet 并添加面板
        var paletteSet = new PaletteSet(title, panelId) { Size = new Size(250, 600) };
        paletteSet.Add(panelId.ToString(), host);
        paletteSet.Visible = true;
        
        // 5. 缓存
        _paletteSets[typeof(TPanel)] = paletteSet;
    }
}
```

**优势**：
- ✅ 单例模式，避免重复创建 PaletteSet
- ✅ 支持 DI，面板可注入任意服务
- ✅ WPF/WinForms 混合架构（通过 ElementHost）

### 2. XAML 资源字典（LibraryResources.xaml）

**职责**：
- 提供全局样式（Expander, Button, TextBox, ListBox 等）
- 注册 XAML 转换器（BoolToVisibility, InverseBool, EnumDescription）

**关键特性**：
```xml
<ResourceDictionary>
    <!-- 转换器声明 -->
    <converters:BoolToVisibilityConverter x:Key="BoolToVisibilityConverter" />
    <converters:InverseBoolConverter x:Key="InverseBoolConverter" />
    
    <!-- 全局样式 -->
    <Style TargetType="Expander">
        <Setter Property="Foreground" Value="#f5f5f5"/>
        <Setter Property="Background" Value="#3b4453"/>
        <!-- ... -->
    </Style>
</ResourceDictionary>
```

**引用方式**：
```xml
<!-- ReinPanel.xaml -->
<UserControl.Resources>
    <ResourceDictionary>
        <ResourceDictionary.MergedDictionaries>
            <ResourceDictionary Source="pack://application:,,,/HyCADTool.Refactored;component/Presentation/Resources/LibraryResources.xaml" />
        </ResourceDictionary.MergedDictionaries>
    </ResourceDictionary>
</UserControl.Resources>
```

**优势**：
- ✅ 避免样式重复（原 ReinPanel 有 200+ 行样式代码）
- ✅ 统一 UI 风格
- ✅ 易于维护和扩展
