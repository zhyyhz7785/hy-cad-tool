# C15 重构 - 单位错误修复报告

> **时间**: 2025-10-28-003000  
> **问题**: 标高单位错误（米被当作毫米，导致1000倍错误）  
> **状态**: ✅ 已修复

---

## 🔍 问题描述

### 症状

用户测试 C15 命令后发现标高数值异常：

```
[文本匹配] 文本="+1.200", 标高=1200.000m  ❌ 错误！
[文本匹配] 文本="+1.650", 标高=1650.000m  ❌ 错误！
[筏板 1] 顶=+1200.000, 底=-0.400, 厚=1200400mm  ❌ 错误！
[筏板 2] 顶=+1650.000, 底=-0.400, 厚=1650400mm  ❌ 错误！
```

**应该是**：
```
[文本匹配] 文本="+1.200", 标高=+1.200m  ✅ 正确
[文本匹配] 文本="+1.650", 标高=+1.650m  ✅ 正确
[筏板 1] 顶=+1.200, 底=-0.400, 厚=1600mm  ✅ 正确
[筏板 2] 顶=+1.650, 底=-0.400, 厚=2050mm  ✅ 正确
```

## 🐛 根本原因

### 错误流程

```
文本 "+1.200" 
  ↓
ElevationParser.TryParse("+1.200", out Elevation elevationObj)
  ↓ 内部：提取数字 1.2（米）
  ↓ 内部：Elevation.FromMeters(1.2)
  ↓ 内部：1.2 * 1000 = 1200 (转换为毫米)
  ↓ 返回：elevationObj.Value = 1200mm ✅ 正确
  ↓
TryParseElevation() 返回 elevationObj.Value = 1200 (本应是毫米)
  ↓
调用处：Elevation.FromMeters(1200)  ❌ 错误！把1200当作米了
  ↓ 内部：1200 * 1000 = 1200000mm
  ↓
结果：elevation.Value = 1200000mm = 1200m  ❌ 错误，导致1000倍错误！
```

### 问题代码

**旧版 `TryParseElevation` (错误)**：
```csharp
private bool TryParseElevation(string text, out double elevation)
{
    if (ElevationParser.TryParse(text, out Elevation elevationObj))
    {
        elevation = elevationObj.Value; // 返回毫米值
        return true;
    }
    
    elevation = 0;
    return false;
}
```

**调用处 (错误)**：
```csharp
if (TryParseElevation(textEntity.text, out double elevationValueInMeters))
{
    result[bestMatch] = Elevation.FromMeters(elevationValueInMeters); // ❌ 又转换一次！
    // ...
}
```

**问题**：
1. `ElevationParser.TryParse()` 返回的 `Elevation` 对象已经是毫米单位
2. `TryParseElevation()` 提取出 `Value`（毫米）并当作 `double` 返回
3. 调用处误以为这个 `double` 是米，又用 `Elevation.FromMeters()` 转换
4. **结果：1.2m → 1200mm → 当作1200m → 1200000mm（1000倍错误）**

---

## ✅ 修复方案

### 修复原则

**让 `TryParseElevation` 直接返回 `Elevation` 对象，避免重复转换。**

### 修复后的代码

**新版 `TryParseElevation` (正确)**：
```csharp
/// <summary>
/// 解析标高文本（使用 Domain 层工具类）
/// </summary>
private bool TryParseElevation(string text, out Elevation elevation)
{
    return ElevationParser.TryParse(text, out elevation);
}
```

**调用处 (正确)**：
```csharp
if (TryParseElevation(textEntity.text, out Elevation elevation))
{
    result[bestMatch] = elevation; // ✅ 直接使用，无需再转换
    
    // 调试输出（显示为米）
    ed.WriteMessage($"\n  ✓ 匹配到多边形（顶点数={bestVertexCount}, 面积={minArea:F0}），标高={elevation.Value / 1000.0:F3}m");
}
```

### 正确流程

```
文本 "+1.200" 
  ↓
ElevationParser.TryParse("+1.200", out Elevation elevation)
  ↓ 内部：提取数字 1.2（米）
  ↓ 内部：Elevation.FromMeters(1.2)
  ↓ 内部：1.2 * 1000 = 1200mm
  ↓ 返回：elevation.Value = 1200mm ✅
  ↓
TryParseElevation() 直接返回 elevation 对象
  ↓
调用处：直接使用 elevation（1200mm）✅
  ↓
结果：elevation.Value = 1200mm = 1.2m  ✅ 正确！
```

## 📝 经验教训

### 单位转换陷阱

1. **Domain 层已处理单位**：`Elevation.FromMeters()` 已经转换为毫米
2. **避免重复转换**：不要在 Presentation 层再次转换
3. **使用强类型**：直接传递 `Elevation` 对象，而不是 `double`

### 重构注意事项

1. **理解原有逻辑**：确保理解单位转换流程
2. **保持接口一致**：尽量使用原有类型（`Elevation`）
3. **充分测试**：单位问题不容易发现，需要实际测试
