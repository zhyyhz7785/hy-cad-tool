# Python (Blender) - 示例
class PointAlgorithms:
    @staticmethod
    def distance(p1: Point2D, p2: Point2D) -> float:
        dx = p2.x - p1.x
        dy = p2.y - p1.y
        return math.sqrt(dx * dx + dy * dy)
    
    @staticmethod
    def midpoint(p1: Point2D, p2: Point2D) -> Point2D:
        return Point2D(
            (p1.x + p2.x) / 2,
            (p1.y + p2.y) / 2
        )

## 🎓 技术亮点

### 1. Clean Architecture 实践

**依赖规则严格执行**:
- Domain → 不依赖任何层（纯业务逻辑）
- Infrastructure → 依赖 Domain（实现细节）
- Application → 依赖 Domain（用例编排）
- Presentation → 依赖所有层（UI/命令）

**收益**:
- 业务逻辑与框架解耦
- 算法可独立测试
- 可迁移到其他平台

---

### 2. DDD 领域驱动设计

**Value Objects（值对象）**:
- `Point2D`, `Vector2D`, `Line2D`, `Polygon2D`
- 不可变，值相等

**Domain Services（领域服务）**:
- `PointAlgorithms`, `LineAlgorithms`, `PolygonAlgorithms`
- `AngleCalculator`, `DistanceCalculator`
- 纯函数，无副作用

---

### 3. 扩展方法作为桥梁

**桥接 Domain 和 Infrastructure**:
```csharp
// Infrastructure 层扩展方法调用 Domain 算法
public static bool ContainsPoint(this Polyline poly, Point3d point)
{
    // 1. 转换 AutoCAD 对象 → Domain 对象
    var vertices = poly.GetAllVertices2d()
        .Select(p => new Point2D(p.X, p.Y));
    
    // 2. 调用 Domain 算法
    return PolygonAlgorithms.ContainsPoint(vertices, new Point2D(point.X, point.Y));
}
```

**优势**:
- 保持 Domain 层纯净
- 为 AutoCAD 用户提供便利 API
- 算法逻辑可复用
